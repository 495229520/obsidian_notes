# 运行文档

## 1. 前置依赖

| 依赖 | 说明 |
| --- | --- |
| ROS 2 Humble | 基础框架，需完整桌面安装 |
| Qt5 | Widgets、Network、WebEngine、Sql、Concurrent |
| MySQL | 客户端库 `libmysqlclient-dev`，以及一个可用的 MySQL 服务 |
| RViz2 | 内嵌可视化，随 ROS 2 桌面版自带 |
| ccache | 可选，加速增量编译 |
| colcon | ROS 2 构建工具 |

## 2. 数据库初始化

用 `src/mfms_server/MFMS_BASE.sql` 建库建表，数据库连接配置在 `config.json`（默认 `test/123456/test schema`）。

## 3. 构建

```bash
source /opt/ros/humble/setup.bash

# 全量构建
colcon build --parallel-workers $(nproc)

# 或用增量脚本
./bal.bash

# source 工作空间
source install/setup.bash
```

## 4. 运行

```bash
ros2 run qt_file qt_file
```
