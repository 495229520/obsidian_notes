# 开题报告

**课题名称：** Research and Development of a Collaborative System for Composite Robot Data Middle Platform Based on Proxy Adapter
（基于代理适配器的复合机器人数据中台协同系统的研究与开发）

---

## 一、课题主要内容

复合机器人（移动底盘 + 协作机械臂）在柔性产线需同时调度多品牌异构设备：Fairino、Aubo 机械臂与仙工 AGV、PLC、相机各带私有 SDK 与协议，与上位机强耦合。本课题引入代理适配器模式，在异构 SDK 与上层之间建抽象隔离层：设计设备 ID 编码与类型推断，用 PIMPL 封装 RobotProxyAdapter 与 AgvProxyAdapter 提供厂商无关命令接口，以 ROS 2 Topic/Service 加 MySQL 事件表构建状态上报、命令下发、事件协同三通道，再用 Facade 网关聚合数据库、ROS 与命令服务，向 Qt 上位机暴露线程安全接口，并实现设备树等可视化协同与性能优化。

---

## 二、课题实践目标

本课题设五项目标。解耦：用代理适配器把上位机与异构 SDK 分离，新增一类设备只需新增一个适配器、不改上层逻辑。统一协同：建立统一的设备 ID、状态结构、命令语义与 Topic/Service 命名约定，使多品牌机械臂与 AGV 在同一上位机下一致监控调度。实时可靠：状态话题约 20Hz 推送，命令请求-应答往返延迟低于 200ms，多线程执行器保证 UI 不阻塞、协同不丢事件。工程化：交付分层清晰、可编译运行、带集成测试与文档的系统。问题定位：在 Aubo、Fairino、Seer 真机环境完成端到端验证，并优化性能与协议配错。

---

## 三、课题实践任务安排

实践按六阶段、共 14 周推进。第 1–2 周做需求分析与架构设计，定代理适配器分层、设备 ID 编码与 Topic/Service 命名约定。第 3–4 周建 common 通用库与 MFMS_BASE 数据库，含状态/事件表、触发器与事件轮询。第 5–7 周实现代理适配器层，用 PIMPL 封装 RobotProxyAdapter、AgvProxyAdapter 与 ROS 2 多线程执行器。第 8–9 周做 ROS 桥接与 Facade 网关，聚合数据库、ROS 与命令服务。第 10–12 周实现 CommunicationInterface 框架与设备树、机械臂切换、AGV 导航等前端协同。第 13–14 周真机联调、性能优化并补齐测试与文档。

---

## 四、课题实践预期成果

预期交付六项成果。其一，可运行的数据中台系统 mfms_server，含 common、mfms_db、ros_bridge、cmd_service、gateway、client_api 六模块，基于 ROS 2 + Qt5 + MySQL。其二，代理适配器组件 RobotProxyAdapter 与 AgvProxyAdapter，验证「新增设备只需新增适配器」的可扩展架构。其三，统一的设备数据模型与接口规范，含 ID 编码、类型推断与 Topic/Service 约定。其四，线程安全的 CommunicationInterface 协同接口。其五，端到端真机联调与性能优化，含「到点」延迟的 CAST 优化与超时配错修正。其六，架构设计文档、客户端接口手册与集成测试。
