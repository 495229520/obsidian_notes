# 34. 在排序数组中查找元素的第一个和最后一个位置

给定一个非递减排序数组 `nums` 和目标值 `target`，要求找出 `target` 在数组中的起始位置和结束位置。如果数组中不存在 `target`，返回 `[-1, -1]`。

---

## 1. 题目概览

### 1.1 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

题目要求时间复杂度必须为 `O(log n)`，因此不能线性扫描，只能利用数组有序这一条件做二分查找。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 有序数组 `nums` 和目标值 `target` |
| 输出 | `target` 的第一个位置和最后一个位置 |
| 数组长度 | `0 <= nums.length <= 10^5` |
| 元素范围 | `-10^9 <= nums[i] <= 10^9` |
| 特殊说明 | `nums` 是非递减数组 |

> [!warning]
> 本题不能只找到一个 `target` 就结束，因为还要找第一个和最后一个位置。核心是分别找到“第一个大于等于 `target` 的位置”和“第一个大于 `target` 的位置”。

### 1.3 示例

#### 示例一

```text
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

#### 示例二

```text
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

#### 示例三

```text
输入：nums = [], target = 0
输出：[-1,-1]
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 是否适合本题 | 原因 |
|------|----------|--------------|------|
| 线性扫描 | 从左到右遍历 | 不适合 | 时间复杂度是 `O(n)`，不满足题目要求 |
| 一次普通二分 + 左右扩展 | 先找任意一个目标值，再向两侧扫描 | 不适合 | 极端情况下全是 `target`，仍然会退化成 `O(n)` |
| 两次边界二分 | `lowerBound` + `upperBound` | 推荐 | 两次二分都是 `O(log n)`，边界清晰 |

### 2.2 本题采用的算法

本题采用：**两次二分查找边界**。

先用 `lowerBound(nums, target)` 找到第一个 `>= target` 的位置，这个位置就是可能的左边界。

如果左边界越界，或者 `nums[left] != target`，说明数组中不存在 `target`，直接返回 `[-1, -1]`。

否则再用 `upperBound(nums, target)` 找到第一个 `> target` 的位置。这个位置本身不属于目标区间，所以右边界是：

```cpp
int right = upperBound(nums, target) - 1;
```

## 3. 解题步骤

### 3.1 核心思路

目标区间可以看成：

```text
[第一个 >= target 的位置, 第一个 > target 的位置 - 1]
```

以 `nums = [5,7,7,8,8,10]`，`target = 8` 为例：

```text
下标：  0  1  2  3  4   5
数组： [5, 7, 7, 8, 8, 10]
                 ^  ^
               left right
```

- `lowerBound(nums, 8)` 返回 `3`
- `upperBound(nums, 8)` 返回 `5`
- 所以答案是 `[3, 5 - 1]`，也就是 `[3, 4]`

### 3.2 详细步骤

#### 第一步：寻找左边界

```cpp
int left = lowerBound(nums, target);
```

`lowerBound` 返回第一个满足 `nums[i] >= target` 的下标。

#### 第二步：判断目标值是否存在

```cpp
if (left == nums.size() || nums[left] != target) {
    return {-1, -1};
}
```

这里必须先判断 `left == nums.size()`，否则空数组或者目标值比所有元素都大时，访问 `nums[left]` 会越界。

#### 第三步：寻找右边界

```cpp
int right = upperBound(nums, target) - 1;
```

`upperBound` 返回第一个满足 `nums[i] > target` 的下标，所以最后一个等于 `target` 的位置就是它的前一个位置。

### 3.3 示例推演

以 `nums = [5,7,7,8,8,10]`，`target = 8` 为例。

#### `lowerBound(nums, 8)`

| 区间 `[l, r)` | `mid` | `nums[mid]` | 判断 | 更新 |
|--------------|-------|-------------|------|------|
| `[0, 6)` | `3` | `8` | `nums[mid] >= 8` | `r = 3` |
| `[0, 3)` | `1` | `7` | `nums[mid] < 8` | `l = 2` |
| `[2, 3)` | `2` | `7` | `nums[mid] < 8` | `l = 3` |

循环结束时 `l == r == 3`，左边界是 `3`。

#### `upperBound(nums, 8)`

| 区间 `[l, r)` | `mid` | `nums[mid]` | 判断 | 更新 |
|--------------|-------|-------------|------|------|
| `[0, 6)` | `3` | `8` | `nums[mid] <= 8` | `l = 4` |
| `[4, 6)` | `5` | `10` | `nums[mid] > 8` | `r = 5` |
| `[4, 5)` | `4` | `8` | `nums[mid] <= 8` | `l = 5` |

循环结束时 `l == r == 5`，第一个大于 `8` 的位置是 `5`，右边界是 `5 - 1 = 4`。

## 4. 二分法边界模板

二分最容易错的地方不是 `mid` 怎么算，而是区间含义是否统一。常见模板有两种：**左闭右开 `[l, r)`** 和 **左闭右闭 `[l, r]`**。

### 4.1 左闭右开 `[l, r)`

左闭右开的意思是：搜索区间包含 `l`，不包含 `r`。

初始化时：

```cpp
int l = 0;
int r = nums.size();
```

因为 `r` 不参与搜索，所以可以等于 `nums.size()`。

循环条件：

```cpp
while (l < r)
```

当 `l == r` 时，区间为空，搜索结束。

更新方式：

```cpp
if (nums[mid] >= target) {
    r = mid;
} else {
    l = mid + 1;
}
```

这里 `r = mid` 是正确的，因为右边界不包含 `r`，而 `mid` 仍然可能是答案，不能跳过。

### 4.2 左闭右闭 `[l, r]`

左闭右闭的意思是：搜索区间同时包含 `l` 和 `r`。

初始化时：

```cpp
int l = 0;
int r = nums.size() - 1;
```

因为 `r` 参与搜索，所以最后一个合法位置是 `nums.size() - 1`。如果数组为空，需要提前处理，或者让 `r` 用有符号整数保存 `-1`。

循环条件：

```cpp
while (l <= r)
```

当 `l > r` 时，区间为空，搜索结束。

更新方式：

```cpp
if (nums[mid] >= target) {
    r = mid - 1;
} else {
    l = mid + 1;
}
```

这里要写 `r = mid - 1`，因为右边界包含 `r`，并且当前 `mid` 已经被检查过了。

### 4.3 两种模板对比

| 项目 | 左闭右开 `[l, r)` | 左闭右闭 `[l, r]` |
|------|------------------|------------------|
| 初始右边界 | `r = nums.size()` | `r = nums.size() - 1` |
| 循环条件 | `l < r` | `l <= r` |
| 区间为空 | `l == r` | `l > r` |
| 保留 `mid` | `r = mid` | 需要额外变量记录答案，或用 `r = mid - 1` 后返回 `l` |
| 越界风险 | 较低，适合查找插入位置 | 空数组时要小心 `size() - 1` |

> [!tip]
> 如果目标是找边界位置，例如第一个 `>= target`、第一个 `> target`、插入位置，左闭右开 `[l, r)` 通常更顺手。因为答案可能等于 `nums.size()`，正好可以作为“插入到末尾”的位置。

### 4.4 用左闭右闭写 `lowerBound`

左闭右闭也能写边界二分，但要保持“答案可能在右侧之外”的意识。常见写法如下：

```cpp
int lowerBoundClosed(vector<int>& nums, int target) {
    int l = 0;
    int r = nums.size() - 1;
    int ans = nums.size();

    while (l <= r) {
        int mid = l + (r - l) / 2;

        if (nums[mid] >= target) {
            ans = mid;
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }

    return ans;
}
```

这种写法用 `ans` 保存当前找到的候选位置，然后继续向左收缩，直到找到最左边的合法位置。

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    vector<int> searchRange(vector<int>& nums, int target) {
        int left = lowerBound(nums, target);

        if (left == nums.size() || nums[left] != target) {
            return {-1, -1};
        }

        int right = upperBound(nums, target) - 1;
        return {left, right};
    }

    int lowerBound(vector<int>& nums, int target) {
        int l = 0;
        int r = nums.size();

        while (l < r) {
            int mid = l + (r - l) / 2;

            if (nums[mid] >= target) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }

        return l;
    }

    int upperBound(vector<int>& nums, int target) {
        int l = 0;
        int r = nums.size();

        while (l < r) {
            int mid = l + (r - l) / 2;

            if (nums[mid] > target) {
                r = mid;
            } else {
                l = mid + 1;
            }
        }

        return l;
    }
};
```

### 5.2 代码中的关键点

| 代码 | 作用 |
|------|------|
| `int r = nums.size();` | 使用左闭右开区间 `[l, r)` |
| `while (l < r)` | 区间非空时继续搜索 |
| `r = mid` | `mid` 可能是答案，不能丢弃 |
| `l = mid + 1` | `mid` 不可能是答案，跳过它 |
| `upperBound(...) - 1` | 第一个大于 `target` 的位置前一位就是右边界 |

### 5.3 为什么 `mid` 这样计算

```cpp
int mid = l + (r - l) / 2;
```

不直接写：

```cpp
int mid = (l + r) / 2;
```

是为了避免 `l + r` 在极大数据范围下发生整数溢出。虽然本题数组长度不一定会触发，但这是二分查找的标准写法。

## 7. 易错点总结

1. `lowerBound` 找的是第一个 `>= target` 的位置，不一定真的等于 `target`。
2. 判断目标值是否存在时，要先判断 `left == nums.size()`，再访问 `nums[left]`。
3. `upperBound` 返回的是第一个 `> target` 的位置，右边界要减 `1`。
4. 左闭右开模板中，右边界 `r` 不参与搜索，所以更新可以写 `r = mid`。
5. 左闭右闭模板中，右边界 `r` 参与搜索，所以通常更新为 `r = mid - 1`。
6. 二分查找每一步都要围绕“当前搜索区间的含义”来写，不能混用两种模板。
