# 547. 省份数量

`n` 个城市，邻接矩阵 `isConnected[i][j] == 1` 表示城市 `i` 与 `j` 相连。「省份」定义为一组直接或间接相连的城市，求省份总数。

本质就是「无向图的连通分量计数」。

---

## 1. 题目概览

### 1.1 题目描述

有 `n` 个城市，其中一些彼此相连，另一些没有相连。如果城市 `a` 与城市 `b` 直接相连，且城市 `b` 与城市 `c` 直接相连，那么城市 `a` 与城市 `c` 间接相连。

省份是一组直接或间接相连的城市，组内不含其他没有相连的城市。

给你一个 `n × n` 的矩阵 `isConnected`，其中 `isConnected[i][j] = 1` 表示第 `i` 个城市和第 `j` 个城市直接相连，而 `isConnected[i][j] = 0` 表示二者不直接相连。

返回矩阵中省份的数量。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | `isConnected: vector<vector<int>>` 邻接矩阵 |
| 输出 | 省份数量 `int` |
| 城市数 | `1 <= n <= 200` |
| 矩阵性质 | `isConnected[i][i] == 1`，`isConnected[i][j] == isConnected[j][i]` |

### 1.3 示例

#### 示例一

```text
输入：isConnected = [[1,1,0],[1,1,0],[0,0,1]]
输出：2
解释：城市 0、1 互联是一个省份；城市 2 自成一个省份。
```

#### 示例二

```text
输入：isConnected = [[1,0,0],[0,1,0],[0,0,1]]
输出：3
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| DFS / BFS | 每个未访问城市启动一次搜索，染色整块连通分量 | `vector<bool> visited` | 推荐 | 通用，代码短 |
| 并查集 | 把所有 `isConnected[i][j] == 1` 的对合并 | `parent` / `rank_` | 推荐 | 模板题，体现并查集核心思想 |

### 2.2 本题采用的算法

主解：**并查集**。直接调用 `count()` 返回连通分量数。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 |
|----------|----------------|
| `vector<int> parent_` | 每个节点的父节点；根节点的父节点是它自己 |
| `vector<int> rank_` | 每棵树的秩，用于按秩合并 |
| `int count_` | 当前连通分量数；初始为 `n`，每成功合并减 1 |

## 3. 解题步骤

### 3.1 核心思路（并查集）

1. 初始化：每个城市自成一个集合，`count_ = n`。
2. 遍历邻接矩阵的上三角（含对角线无意义，跳过），对所有 `isConnected[i][j] == 1` 调用 `unite(i, j)`。每次成功合并减少一个连通分量。
3. 最终 `count_` 即省份数。

只遍历上三角是因为矩阵对称，下三角是冗余信息。

### 3.2 详细步骤

#### 第一步：构造并查集

```cpp
UnionFind uf(n);
```

每个节点的父亲指向自己，秩为 0。

#### 第二步：对所有有边的对调用 `unite`

```cpp
for (int i = 0; i < n; ++i) {
    for (int j = i + 1; j < n; ++j) {
        if (isConnected[i][j] == 1) {
            uf.unite(i, j);
        }
    }
}
```

#### 第三步：返回 `uf.count()`

### 3.3 解法二：DFS

把矩阵当作邻接矩阵图，对每个未访问城市启动 DFS，启动次数即省份数。

## 5. 源码实现

### 5.1 解法一：并查集（推荐）

```cpp
class UnionFind {
public:
    explicit UnionFind(int n) : parent_(n), rank_(n, 0), count_(n) {
        iota(parent_.begin(), parent_.end(), 0);
    }

    int find(int x) {
        if (parent_[x] != x) parent_[x] = find(parent_[x]);
        return parent_[x];
    }

    void unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return;
        if (rank_[rx] < rank_[ry]) swap(rx, ry);
        parent_[ry] = rx;
        if (rank_[rx] == rank_[ry]) ++rank_[rx];
        --count_;
    }

    int count() const { return count_; }

private:
    vector<int> parent_;
    vector<int> rank_;
    int count_;
};

class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        UnionFind uf(n);

        for (int i = 0; i < n; ++i) {
            for (int j = i + 1; j < n; ++j) {
                if (isConnected[i][j] == 1) {
                    uf.unite(i, j);
                }
            }
        }
        return uf.count();
    }
};
```

### 5.2 解法二：DFS

```cpp
class Solution {
public:
    int findCircleNum(vector<vector<int>>& isConnected) {
        int n = isConnected.size();
        vector<bool> visited(n, false);
        int provinces = 0;

        for (int i = 0; i < n; ++i) {
            if (!visited[i]) {
                ++provinces;
                dfs(i, isConnected, visited);
            }
        }
        return provinces;
    }

private:
    void dfs(int u, const vector<vector<int>>& g, vector<bool>& visited) {
        visited[u] = true;
        int n = g.size();
        for (int v = 0; v < n; ++v) {
            if (g[u][v] == 1 && !visited[v]) {
                dfs(v, g, visited);
            }
        }
    }
};
```

## 6. 源码详解

### 6.1 关键点

| 代码 | 含义 |
|------|------|
| `iota(parent_.begin(), parent_.end(), 0)` | 把 `parent_` 初始化为 `[0, 1, 2, ...]`，每个节点自成集合 |
| `if (parent_[x] != x) parent_[x] = find(parent_[x])` | 路径压缩：递归回退时把节点直接挂到根 |
| `if (rank_[rx] < rank_[ry]) swap(rx, ry)` | 按秩合并：让较高的树作为合并后的根 |
| `if (rank_[rx] == rank_[ry]) ++rank_[rx]` | 同秩合并后整体高度加 1 |
| `--count_` | 每成功合并一对，连通分量数减 1 |

### 6.2 为什么从 `j = i + 1` 开始

邻接矩阵对称（`isConnected[i][j] == isConnected[j][i]`），自环（`i == j`）也无意义，所以只遍历严格上三角。

### 6.3 易错点

1. **`unite` 内忘记判断同根**：当 `rx == ry` 时绝不能合并，否则破坏 `parent_` 结构、计数错误。
2. **`find` 不做路径压缩**：在大规模数据下会退化到 `O(n)`，本题数据小但养成习惯仍要写。
3. **直接读 `parent_[x]` 当代表元**：必须经过 `find(x)` 才能拿到真正的根，路径压缩前后中间节点的 `parent_` 不是根。
4. **DFS 入参漏写引用**：`vector<vector<int>>` 不传引用会按值拷贝，超时。

---

## 7. 复杂度分析

设 `n` 为城市数：

| 指标 | 并查集 | DFS |
|------|--------|-----|
| 时间 | `O(n^2 × α(n))` | `O(n^2)` |
| 空间 | `O(n)` | `O(n)` 递归栈 + `visited` |

读取 `n × n` 邻接矩阵主导时间。`α(n)` 是反阿克曼函数，实践中可视作常数。
