K 个一组翻转链表给定单链表头节点 `head` 和整数 `k`，要求每 `k` 个节点一组进行反转，并返回修改后的链表。---## 1. 题目概览### 1.1 题目描述给你链表的头节点 `head` ，每 `k` 个节点一组进行翻转，请你返回修改后的链表。`k` 是一个正整数，它的值小于或等于链表的长度。如果节点总数不是 `k` 的整数倍，那么请将最后剩余的节点保持原有顺序。你不能只是单纯的改变节点内部的值，而是需要实际进行节点交换。### 1.2 输入输出与约束| 项目 | 内容 ||------|------|| 输入 | 单链表头节点 `head` 和整数 `k` || 输出 | 每 `k` 个节点一组翻转后的链表 || 节点数量 | `1 <= k <= n <= 5000` || 节点值范围 | `0 <= Node.val <= 1000` || 特殊要求 | 只能修改节点连接关系；最后不足 `k` 个节点保持原顺序 |> [!warning]> 本题不能只交换节点内部的 `val`，必须实际改变节点之间的 `next` 指针。### 1.3 示例#### 示例一```text输入：head = [1,2,3,4,5], k = 2输出：[2,1,4,3,5]```#### 示例二```text输入：head = [1,2,3,4,5], k = 3输出：[3,2,1,4,5]```### 1.4 进阶你可以设计一个只用 `O(1)` 额外内存空间的算法解决此问题吗？---## 2. 可用算法与数据结构### 2.1 可选解法总览| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 ||------|----------|--------------|--------------|------|| 辅助数组 | 存节点后分组重连 | `vector<ListNode*>` | 不推荐 | 额外空间 `O(n)`，不满足进阶要求 || 递归分组反转 | 每次递归处理一组 | 递归栈 | 可行 | 思路清晰，但栈空间不是 `O(1)` || 迭代分组反转 | 找够 `k` 个节点后局部反转 | 指针变量 + 虚拟头节点 | 推荐 | 原地操作，空间 `O(1)` |### 2.2 本题采用的算法本题采用：**迭代分组反转链表**。选择它的原因：1. 每个节点只会被访问和修改常数次，时间复杂度是 `O(n)`。2. 只使用少量指针变量，空间复杂度是 `O(1)`。3. 能自然处理“不足 `k` 个节点不翻转”的边界。### 2.3 本题使用的数据结构| 数据结构 | 在本题中的作用 | 为什么需要它 ||----------|----------------|--------------|| `ListNode*` 指针 | 操作链表节点连接关系 | 本题必须实际交换节点 || `dummy` 虚拟头节点 | 统一处理第一组翻转 | 第一组翻转后头节点会变化 || `groupPrev` | 当前组前一个节点 | 负责把上一段接到翻转后的新组头 || `kth` | 当前组第 `k` 个节点 | 判断是否够一组，并作为翻转后新头 || `groupNext` | 当前组后面的第一个节点 | 翻转边界，也是组尾接回的位置 |### 2.4 相关 STL / 算法笔记引用- [[206. 反转链表]] — 本题的局部翻转基础- 6.1指针 — 指针基础- [[14.3 list及其与其他结构的区别]] — 链表结构理解---## 3. 解题步骤### 3.1 核心思路这题可以看成是 [[206. 反转链表]] 的进阶版：普通反转链表是把整条链表翻转，本题是每次只翻转长度为 `k` 的一小段。关键不是“怎么翻转”，而是每翻转完一组后，要把这一组重新接回原链表。整体结构可以理解为：```text已处理部分 -> 当前待翻转组 -> 后续未处理部分```为了统一处理第一组，使用虚拟头节点 `dummy`。### 3.2 详细步骤#### 第一步：创建虚拟头节点```cppListNode dummy(0);dummy.next = head;ListNode* groupPrev = &dummy;````groupPrev` 永远站在当前待翻转组的前一个节点。#### 第二步：找到当前组的第 k 个节点```cppListNode* kth = groupPrev;for (int i = 0; i < k; i++) {    kth = kth->next;    if (kth == nullptr) {        return dummy.next;    }}```如果中途遇到 `nullptr`，说明剩余节点不足 `k` 个，不能翻转，直接返回。#### 第三步：保存当前组后面的节点```cppListNode* groupNext = kth->next;````groupNext` 是当前组后面的第一个节点，也是本组翻转循环的停止边界。#### 第四步：翻转当前 k 个节点```cppListNode* prev = groupNext;ListNode* curr = groupPrev->next;while (curr != groupNext) {    ListNode* temp = curr->next;    curr->next = prev;    prev = curr;    curr = temp;}```这里 `prev` 初始化为 `groupNext`，这样原组头翻转成组尾后，会自然接回后续链表。#### 第五步：接回原链表并进入下一组```cppListNode* oldGroupHead = groupPrev->next;groupPrev->next = kth;groupPrev = oldGroupHead;```翻转后，`kth` 成为当前组新头，`oldGroupHead` 成为当前组新尾。### 3.3 示例推演以链表 `1 -> 2 -> 3 -> 4 -> 5`，`k = 2` 为例：| 步骤 | 当前组 | 翻转结果 | `groupPrev` 移动到 ||------|--------|----------|-------------------|| 初始 | `[1,2]` | `2 -> 1 -> 3 -> 4 -> 5` | `1` || 第二组 | `[3,4]` | `2 -> 1 -> 4 -> 3 -> 5` | `3` || 剩余 | `[5]` | 不足 `k` 个，不翻转 | 返回答案 |最终结果：```text[2,1,4,3,5]```---## 4. *     ListNode *next; *     ListNode() : val(0), next(nullptr) {} *     ListNode(int x) : val(x), next(nullptr) {} *     ListNode(int x, ListNode *next) : val(x), next(next) {} * }; */class Solution {public:    ListNode* reverseKGroup(ListNode* head, int k) {        if (head == nullptr || head->next == nullptr) {            return head;        }        ListNode dummy(0);        dummy.next = head;        ListNode* groupPrev = &dummy;        while (true) {            ListNode* kth = groupPrev;            for (int i = 0; i < k; i++) {                kth = kth->next;                if (kth == nullptr) {                    return dummy.next;                }            }            ListNode* groupNext = kth->next;            ListNode* prev = groupNext;            ListNode* curr = groupPrev->next;            while (curr != groupNext) {                ListNode* temp = curr->next;                curr->next = prev;                prev = curr;                curr = temp;            }            ListNode* oldGroupHead = groupPrev->next;            groupPrev->next = kth;            groupPrev = oldGroupHead;        }    }};```### 5.2 代码中的关键注释| 代码位置 | 解释重点 ||----------|----------|| `dummy.next = head` | 统一处理第一组翻转后头节点变化 || `for (int i = 0; i < k; i++)` | 检查当前组是否够 `k` 个节点 || `groupNext = kth->next` | 保存后续链表入口 || `prev = groupNext` | 让翻转后的组尾自然接回后续链表 || `groupPrev->next = kth` | 把上一段接到翻转后的新组头 || `groupPrev = oldGroupHead` | 移动到当前组尾，准备处理下一组 |---## 6. 源码详解### 6.1 核心变量说明| 变量 | 含义 | 生命周期 | 为什么需要它 ||------|------|----------|--------------|| `dummy` | 虚拟头节点 | 整个函数过程 | 方便返回最终头节点 || `groupPrev` | 当前组前一个节点 | 每轮处理后更新 | 连接已处理部分和当前组 || `kth` | 当前组第 `k` 个节点 | 每轮重新查找 | 判断是否够一组，并作为新组头 || `groupNext` | 当前组后的第一个节点 | 每轮保存 | 翻转边界和后续链表入口 || `prev` | 翻转过程中当前节点应指向的前驱 | 当前组翻转过程 | 完成局部反转 || `curr` | 当前正在翻转的节点 | 当前组翻转过程 | 遍历组内节点 || `oldGroupHead` | 翻转前的组头 | 每轮接回时使用 | 翻转后成为组尾 |### 6.2 为什么 `prev` 初始化为 `groupNext`普通反转链表常让 `prev = nullptr`，因为整条链表反转后尾节点应该指向空。但本题只翻转一组，翻转后的组尾应该接回后续链表，所以需要：```cppListNode* prev = groupNext;```这样原组头最终会指向 `groupNext`。### 6.3 为什么 `groupPrev->next = kth` 是安全的翻转前：```textgroupPrev -> oldGroupHead -> ... -> kth -> groupNext```翻转后，`kth` 会变成这一组的新头：```textgroupPrev -> kth -> ... -> oldGroupHead -> groupNext```因此：```cppgroupPrev->next = kth;```就能把已处理部分接到翻转后的新组头。### 6.4 易错点1. 找 `kth` 时要从 `groupPrev` 开始走 `k` 步，而不是从 `groupPrev->next` 开始走 `k` 步。2. 如果不足 `k` 个节点，必须直接返回，不能翻转剩余节点。3. `groupNext` 必须在翻转前保存，否则翻转后会丢失后续链表入口。4. 翻转本组时，`prev` 应该初始化为 `groupNext`，不是 `nullptr`。5. 翻转完成后，要先保存 `oldGroupHead`，再修改 `groupPrev->next`。6. 下一轮的 `groupPrev` 应该移动到当前组翻转后的尾节点，也就是 `oldGroupHead`。---## 7. 复杂度分析### 7.1 时间复杂度- 时间复杂度：`O(n)`原因：每个节点只会被访问和修改常数次。### 7.2 空间复杂度- 空间复杂度：`O(1)`原因：只使用少量指针变量，没有使用额外数组或递归栈。---## 8. 相关链接- [[206. 反转链表]] — 本题的局部翻转基础- 6.1指针 — 指针基础- [[14.3 list及其与其他结构的区别]] — 链表结构理解
