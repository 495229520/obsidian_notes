# 5. 最长回文子串

给定一个字符串 `s`，要求找到 `s` 中最长的回文子串。回文子串必须是**连续子串**，并且正着读和反着读完全一样。

---

## 1. 题目概览

### 1.1 题目描述

输入一个只包含数字和英文字母的字符串 `s`，返回其中最长的回文子串。

回文串的特点是：

```text
s[left] == s[right]
```

并且继续向内看时仍然满足相同条件。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 字符串 `s` |
| 输出 | `s` 中最长的回文子串 |
| 字符串长度 | `1 <= s.length <= 1000` |
| 字符范围 | 仅由数字和英文字母组成 |
| 特殊说明 | 如果存在多个答案，返回任意一个即可 |

### 1.3 示例

#### 示例一

```text
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

#### 示例二

```text
输入：s = "cbbd"
输出："bb"
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 暴力枚举 | 枚举所有子串再判断回文 | 字符串下标 | 不推荐 | 时间复杂度可到 `O(n^3)` |
| 动态规划 | `dp[i][j]` 表示区间是否回文 | 二维 `bool` 表 | 适合 | 思路系统，但需要 `O(n^2)` 空间 |
| 中心扩展 | 从每个中心向两边扩展 | 左右指针 | 推荐 | 代码短，空间 `O(1)` |
| Manacher | 回文半径数组 | 预处理字符串 + 数组 | 进阶 | 时间 `O(n)`，但实现复杂 |

### 2.2 本题采用的算法

本题采用：**中心扩展法**。

选择它的原因：

1. 回文串天然围绕“中心”对称。
2. 只需要枚举每个可能中心，再向左右扩展。
3. 不需要额外 DP 表，空间复杂度是 `O(1)`。
4. 对 `n <= 1000` 的数据范围，`O(n^2)` 时间完全可以接受。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 | 为什么需要它 |
|----------|----------------|--------------|
| `std::string` | 存储原字符串和返回子串 | 支持下标访问与 `substr` 截取 |
| 左右指针 | 从中心向两侧扩展 | 判断当前区间是否仍然是回文 |
| `start`、`maxLen` | 记录最长回文子串的位置和长度 | 最后通过 `substr(start, maxLen)` 返回答案 |

## 3. 解题步骤

### 3.1 核心思路

回文串一定有一个中心。

中心有两种情况：

1. **奇数长度回文**：中心是一个字符，例如 `bab` 的中心是 `a`
2. **偶数长度回文**：中心是两个字符之间，例如 `bb` 的中心在两个 `b` 中间

所以对每个下标 `i`，都尝试两种扩展：

```cpp
expand(s, i, i);      // 奇数长度
expand(s, i, i + 1);  // 偶数长度
```

每次扩展得到一个回文长度，如果比当前最长答案更长，就更新 `start` 和 `maxLen`。

### 3.2 详细步骤

#### 第一步：初始化答案区间

```cpp
int start = 0;
int maxLen = 1;
```

含义：

- `start`：当前最长回文子串的起点
- `maxLen`：当前最长回文子串的长度

因为题目保证 `s.length >= 1`，所以最短答案至少是任意一个单字符。

#### 第二步：枚举每个中心

对每个位置 `i`：

1. 以 `i` 为中心扩展奇数长度回文
2. 以 `i` 和 `i + 1` 中间为中心扩展偶数长度回文
3. 取两者中更长的长度

```cpp
int len1 = expand(s, i, i);
int len2 = expand(s, i, i + 1);
int len = max(len1, len2);
```

#### 第三步：更新最长答案

如果当前中心扩出来的回文更长：

```cpp
start = i - (len - 1) / 2;
maxLen = len;
```

这里的起点公式同时适用于奇数长度和偶数长度：

| 回文长度 | 中心 | 起点公式 |
|----------|------|----------|
| 奇数 `3` | `i` | `i - 1` |
| 偶数 `2` | `i` 和 `i + 1` 中间 | `i` |
| 偶数 `4` | `i` 和 `i + 1` 中间 | `i - 1` |

#### 第四步：返回子串

```cpp
return s.substr(start, maxLen);
```

### 3.3 示例推演

以 `s = "babad"` 为例：

| 中心 | 奇数扩展 | 偶数扩展 | 当前最长 | 说明 |
|------|----------|----------|----------|------|
| `i = 0` | `"b"` | 空 | `"b"` | 单字符是回文 |
| `i = 1` | `"bab"` | 空 | `"bab"` | 向两边扩展，`b == b` |
| `i = 2` | `"aba"` | 空 | `"bab"` 或 `"aba"` | 长度相同，保留原答案即可 |
| `i = 3` | `"a"` | 空 | `"bab"` | 没有更长 |
| `i = 4` | `"d"` | 空 | `"bab"` | 没有更长 |

图中展示了中心扩展法的核心过程：

3. 只要左右字符相等，就继续向外扩展
4. 扩展结束后得到当前中心能形成的最长回文长度
5. 如果当前长度超过 `maxLen`，就更新答案区间

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    std::string longestPalindrome(std::string s) {
        int n = s.size();

        int start = 0;
        int maxLen = 1;

        for (int i = 0; i < n; i++) {
            int len1 = expand(s, i, i);
            int len2 = expand(s, i, i + 1);

            int len = len1;
            if (len2 > len) {
                len = len2;
            }

            if (len > maxLen) {
                maxLen = len;
                start = i - (len - 1) / 2;
            }
        }

        return s.substr(start, maxLen);
    }

private:
    int expand(const std::string& s, int left, int right) {
        int n = s.size();

        while (left >= 0 && right < n && s[left] == s[right]) {
            left--;
            right++;
        }

        return right - left - 1;
    }
};
```

### 5.2 代码中的关键注释

| 代码位置 | 解释重点 |
|----------|----------|
| `start = 0, maxLen = 1` | 字符串非空，单字符必然是回文 |
| `expand(s, i, i)` | 处理奇数长度回文 |
| `expand(s, i, i + 1)` | 处理偶数长度回文 |
| `start = i - (len - 1) / 2` | 根据中心和长度反推出回文起点 |
| `right - left - 1` | 扩展结束时左右指针已经多走一步，需要减掉越界部分 |

## 6. 源码详解

### 6.1 核心变量说明

| 变量 / 函数 | 含义 | 为什么需要它 |
|-------------|------|--------------|
| `n` | 字符串长度 | 用于判断右边界 |
| `start` | 当前最长回文子串起点 | 最后截取答案 |
| `maxLen` | 当前最长回文子串长度 | 判断是否需要更新答案 |
| `expand` | 从 `[left, right]` 向两边扩展 | 统一处理奇数和偶数中心 |
| `left`、`right` | 当前扩展的左右边界 | 判断区间是否仍然回文 |

### 6.2 `expand` 为什么返回 `right - left - 1`

扩展循环结束时，有三种可能：

1. `left < 0`
2. `right >= n`
3. `s[left] != s[right]`

此时 `left` 和 `right` 都已经停在**不属于回文串的位置**。

真正的回文区间是：

```text
[left + 1, right - 1]
```

所以长度是：

```text
(right - 1) - (left + 1) + 1 = right - left - 1
```

### 6.3 起点公式怎么来的

当前中心是 `i`，回文长度是 `len`。

起点写成：

```cpp
start = i - (len - 1) / 2;
```

这里用 `(len - 1) / 2`，是为了**同时兼容奇数长度回文和偶数长度回文**。

中心扩展中，`i` 的含义有两种：

| 情况 | 扩展方式 | `i` 的含义 |
|------|----------|------------|
| 奇数长度回文 | `expand(s, i, i)` | `i` 就是中心字符 |
| 偶数长度回文 | `expand(s, i, i + 1)` | `i` 是偶数中心左边那个字符 |

所以从中心位置反推起点时，不能简单写成：

```cpp
start = i - len / 2;
```

因为偶数长度时会多往左退一格。

#### 奇数长度示例

例如回文串 `"bab"`：

```text
下标：0 1 2
字符：b a b
      ↑
      i = 1
```

此时：

```text
len = 3
```

正确起点是 `0`。

代入公式：

```cpp
start = 1 - (3 - 1) / 2
      = 1 - 1
      = 0
```

#### 偶数长度示例

例如回文串 `"bb"`，在字符串 `"cbbd"` 中：

```text
下标：0 1 2 3
字符：c b b d
        ↑ ↑
        i i+1
```

此时：

```text
i = 1
len = 2
```

正确起点是 `1`。

代入公式：

```cpp
start = 1 - (2 - 1) / 2
      = 1 - 0
      = 1
```

如果错误地写成：

```cpp
start = i - len / 2;
```

则会得到：

```cpp
start = 1 - 2 / 2
      = 0
```

这样会从字符 `c` 开始截取，起点就错了。

#### 统一理解

`(len - 1) / 2` 表示：

> 从 `i` 往左退多少步，才能到达当前回文子串的起点。

| 回文长度 | 示例 | 中心 | 正确起点 | `(len - 1) / 2` |
|----------|------|------|----------|-----------------|
| `1` | `"a"` | `i` | `i` | `0` |
| `2` | `"aa"` | `i` 和 `i + 1` 中间 | `i` | `0` |
| `3` | `"aba"` | `i` | `i - 1` | `1` |
| `4` | `"abba"` | `i` 和 `i + 1` 中间 | `i - 1` | `1` |
| `5` | `"abcba"` | `i` | `i - 2` | `2` |

因此：

```cpp
start = i - (len - 1) / 2;
```

本质上是把奇数中心和偶数中心的起点计算统一成一个公式。

### 6.4 易错点

1. 只检查奇数中心，会漏掉 `"cbbd" -> "bb"` 这种偶数长度答案。
2. `expand` 返回长度时不能写成 `right - left + 1`，因为循环结束时左右指针已经越过合法回文区间。
3. 更新 `start` 时不要直接写 `i - len / 2`，偶数长度时容易偏一位。
4. 题目要求的是子串 substring，必须连续；不是子序列 subsequence。
5. 如果存在多个同样长度的答案，返回任意一个即可，不需要额外处理字典序。

## 7. 复杂度分析

### 7.1 时间复杂度

- 时间复杂度：`O(n^2)`

原因：一共有 `n` 个中心，每个中心最坏可能向两边扩展 `O(n)`。

### 7.2 空间复杂度

- 空间复杂度：`O(1)`

原因：除了少量整数变量之外，没有使用额外数组或哈希表。`substr` 返回答案字符串不计入算法辅助空间时，额外空间为 `O(1)`。
