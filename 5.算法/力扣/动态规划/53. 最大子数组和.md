# 53. 最大子数组和

给定整数数组 `nums`，要求找出和最大的连续子数组，并返回这个最大和。

---

## 1. 题目概览

### 1.1 题目描述

给你一个整数数组 `nums` ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 整数数组 `nums` |
| 输出 | 连续子数组的最大和 |
| 数组长度 | `1 <= nums.length <= 10^5` |
| 元素范围 | `-10^4 <= nums[i] <= 10^4` |
| 特殊说明 | 子数组必须连续，至少包含一个元素 |

> [!warning]
> 初始化不能写成 `0`。如果数组全是负数，答案也应该是其中最大的负数，而不是空子数组的和。

### 1.3 示例

#### 示例一

```text
输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。
```

#### 示例二

```text
输入：nums = [1]
输出：1
```

#### 示例三

```text
输入：nums = [5,4,-1,7,8]
输出：23
```

### 1.4 进阶

如果你已经实现复杂度为 `O(n)` 的解法，尝试使用更为精妙的**分治法**求解。

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 暴力枚举 | 枚举所有子数组求和 | 数组下标 | 不推荐 | 时间复杂度高，容易超时 |
| 前缀和 | 子数组和转化为前缀差 | 前缀和数组 | 可行 | 需要维护最小前缀和 |
| 动态规划 / Kadane | 维护以当前位置结尾的最大和 | 两个整数变量 | 推荐 | 时间 `O(n)`，空间 `O(1)` |
| 分治法 | 分别求左、右、跨中点最大和 | 递归 | 进阶 | 思路精妙，但实现更复杂 |

### 2.2 本题采用的算法

本题采用：**Kadane 算法 / 线性动态规划**。

选择它的原因：

1. 子数组必须连续，适合定义“以当前位置结尾”的状态。
2. 每个位置只需要由前一个位置推出，空间可以压缩到 `O(1)`。
3. 时间复杂度是 `O(n)`，满足题目进阶前的最优线性解法。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 | 为什么需要它 |
|----------|----------------|--------------|
| `vector<int>` | 存储输入数组 | 支持顺序遍历 |
| `cur` | 以当前位置结尾的最大连续子数组和 | 判断当前连续段是否应该延续 |
| `ans` | 全局最大连续子数组和 | 最终返回答案 |

## 3. 解题步骤

### 3.1 核心思路

本题是线性动态规划的经典入门题。它的难点不在代码，而在状态定义：

```text
以当前位置 i 结尾的最大连续子数组和是多少？
```

这个状态天然带着“连续”限制。到达 `nums[i]` 时只有两种选择：

1. 从 `nums[i]` 重新开始一段连续子数组
2. 把 `nums[i]` 接到前一个位置结尾的最优连续段后面

如果前面的连续和会拖累当前元素，就丢掉前面，从当前元素重新开始；否则继续接上当前元素。

### 3.2 详细步骤

#### 第一步：初始化状态

```cpp
int cur = nums[0];
int ans = nums[0];
```

`cur` 表示必须以当前位置结尾的最大连续子数组和，`ans` 表示遍历过程中见过的全局最大值。

两者都必须用 `nums[0]` 初始化，保证全负数数组也能得到正确答案。

#### 第二步：状态转移

从第二个元素开始遍历数组：

```cpp
cur = max(nums[i], cur + nums[i]);
```

含义：

- `nums[i]`：前面那段不要了，从当前元素重新开始
- `cur + nums[i]`：保留前面那段，把当前元素接上去

#### 第三步：更新全局答案

```cpp
ans = max(ans, cur);
```

`cur` 只代表“以当前位置结尾”的最优值，不一定是全局最优，所以每一步都要更新 `ans`。

### 3.3 示例推演

以 `nums = [-2,1,-3,4,-1,2,1,-5,4]` 为例：

| i | nums[i] | cur 的选择 | cur | ans |
|---|---------|------------|-----|-----|
| 0 | -2 | 初始化 | -2 | -2 |
| 1 | 1 | `max(1, -2 + 1)` | 1 | 1 |
| 2 | -3 | `max(-3, 1 - 3)` | -2 | 1 |
| 3 | 4 | `max(4, -2 + 4)` | 4 | 4 |
| 4 | -1 | `max(-1, 4 - 1)` | 3 | 4 |
| 5 | 2 | `max(2, 3 + 2)` | 5 | 5 |
| 6 | 1 | `max(1, 5 + 1)` | 6 | 6 |
| 7 | -5 | `max(-5, 6 - 5)` | 1 | 6 |
| 8 | 4 | `max(4, 1 + 4)` | 5 | 6 |

最终答案是 `6`。

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        int cur = nums[0];
        int ans = nums[0];

        for (int i = 1; i < nums.size(); i++) {
            cur = max(nums[i], cur + nums[i]);
            ans = max(ans, cur);
        }

        return ans;
    }
};
```

### 5.2 代码中的关键注释

| 代码位置 | 解释重点 |
|----------|----------|
| `cur = nums[0]` | 以当前位置结尾的最大和，必须从第一个元素初始化 |
| `ans = nums[0]` | 全局最大值，保证全负数数组正确 |
| `cur = max(...)` | 判断重新开始还是延续前一段 |
| `ans = max(ans, cur)` | 用当前位置结尾的最优值更新全局答案 |

## 6. 源码详解

### 6.1 核心变量说明

| 变量 | 含义 | 生命周期 | 为什么需要它 |
|------|------|----------|--------------|
| `cur` | 必须以当前位置 `i` 结尾的最大连续子数组和 | 整个遍历过程 | 用来进行状态转移 |
| `ans` | 遍历到当前位置为止的全局最大连续子数组和 | 整个遍历过程 | 最终返回答案 |
| `nums[i]` | 当前处理的元素 | 每轮循环 | 决定重新开始还是延续前一段 |

### 6.2 状态转移为什么正确

对每个位置 `i`，如果要求子数组必须以 `i` 结尾，那么只有两种可能：

1. 当前元素单独成段：`nums[i]`
2. 接在前一个位置结尾的最优连续段后面：`cur + nums[i]`

所以状态转移是：

```cpp
cur = max(nums[i], cur + nums[i]);
```

### 6.3 为什么不是滑动窗口

这题虽然也是连续子数组问题，但不能直接用常见的双指针滑动窗口。

因为数组里有负数，窗口扩大后和可能变小，窗口缩小后和也可能变大，没有一个稳定的“窗口不合法就收缩”的判断条件。

动态规划的优势在于：它只关心“前面的连续和对当前元素有没有帮助”。如果没有帮助，就从当前元素重新开始。

### 6.4 易错点

1. `cur` 不是全局最大值，而是“必须以当前位置结尾”的最大和。
2. `ans` 才是最终答案，需要每一轮更新。
3. 初始化不能写成 `0`，否则全负数数组会出错。
4. 子数组要求连续，不能跳过中间的负数；例如 `[4,-1,2,1]` 中的 `-1` 必须保留。
5. `cur + nums[i]` 使用的是更新前的 `cur`，表示前一个位置结尾的最优连续段。

## 7. 复杂度分析

### 7.1 时间复杂度

- 时间复杂度：`O(n)`

原因：只遍历数组一次，每个元素只处理一次。

### 7.2 空间复杂度

- 空间复杂度：`O(1)`

原因：只使用 `cur` 和 `ans` 两个整数变量。
