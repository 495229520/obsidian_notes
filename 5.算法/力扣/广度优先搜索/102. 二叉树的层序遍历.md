# 102. 二叉树的层序遍历

## 广度优先搜索简介

广度优先搜索（BFS，Breadth-First Search）是一种按照“由近到远、按层扩展”的遍历方法。对于二叉树来说，BFS 最典型的应用就是层序遍历：先访问根节点，再访问第二层所有节点，再访问第三层所有节点。

BFS 通常使用队列实现。队列的特点是先进先出，因此先进入队列的上层节点会先被处理，它的孩子再被放到队列尾部，最终自然形成逐层访问的顺序。

### 核心思想

> 使用 `queue` 保存当前还没访问的节点，每次取出队首节点，再把它的左右孩子放入队尾。

> [!tip]
> 看到“逐层”“最短层数”“从上到下”“扩散”这类关键词时，通常优先考虑 BFS。

### 基本模板

```cpp
queue<TreeNode*> que;
que.push(root);

while (!que.empty()) {
    TreeNode* node = que.front();
    que.pop();

    // 处理当前节点

    if (node->left != nullptr) que.push(node->left);
    if (node->right != nullptr) que.push(node->right);
}
```

---

## 题目描述

给定一棵二叉树的根节点 `root`，要求返回它的层序遍历结果。所谓层序遍历，就是按照从上到下、每一层从左到右的顺序访问所有节点。

本题要求返回二维数组：每一层的节点值单独放入一个 `vector<int>` 中。

### 示例

```text
输入：root = [3,9,20,null,null,15,7]
输出：[[3],[9,20],[15,7]]
解释：
第 1 层：3
第 2 层：9, 20
第 3 层：15, 7
```

> [!important]
> 空树要返回空数组 `[]`，不要把空节点加入队列。

---

## 解题思路

本题最适合使用队列进行 BFS。队列中保存“下一批需要访问的节点”。为了让结果按层分组，每一轮循环开始时要先记录当前队列大小 `size`，这个大小就代表当前层的节点个数。

### 步骤分解

1. 如果 `root == nullptr`，直接返回空结果。
2. 创建队列 `queue<TreeNode*> que`，先把根节点放入队列。
3. 当队列不为空时，说明还有节点没处理。
4. 每一层开始时，记录 `int size = que.size()`，固定当前层节点数量。
5. 循环 `size` 次：取出队首节点，加入当前层数组 `level`。
6. 如果该节点有左孩子或右孩子，就分别加入队列，等待下一层处理。
7. 当前层处理完后，把 `level` 加入最终答案 `result`。

### 图解

![[5_1_102_1.svg|760]]

图中队列每次从队首取出节点，再把当前节点的左右孩子加入队尾。因为队列是先进先出，所以第 1 层节点会先被处理，第 2 层节点随后被处理，第 3 层节点最后被处理。

### 示例推演

以输入 `root = [3,9,20,null,null,15,7]` 为例：

| 轮次 | 队列开始状态 | 当前层 size | 本轮取出的节点 | 新入队节点 | 当前层结果 |
|------|--------------|-------------|----------------|------------|------------|
| 1 | `[3]` | 1 | `3` | `9, 20` | `[3]` |
| 2 | `[9, 20]` | 2 | `9, 20` | `15, 7` | `[9, 20]` |
| 3 | `[15, 7]` | 2 | `15, 7` | 无 | `[15, 7]` |

最终答案：

```text
[[3], [9,20], [15,7]]
```

## 代码实现

```cpp
class Solution {
public:
    vector<vector<int>> levelOrder(TreeNode* root) {
        vector<vector<int>> result;
        if (root == nullptr) return result;

        queue<TreeNode*> que;
        que.push(root);

        while (!que.empty()) {
            int size = que.size();
            vector<int> level;

            for (int i = 0; i < size; i++) {
                TreeNode* node = que.front();
                que.pop();

                level.push_back(node->val);

                if (node->left != nullptr) que.push(node->left);
                if (node->right != nullptr) que.push(node->right);
            }

            result.push_back(level);
        }

        return result;
    }
};
```

### 代码分析

```cpp
vector<vector<int>> result;
```

最终答案是二维数组，因为题目要求按层返回，每一层都是一个 `vector<int>`。

```cpp
if (root == nullptr) return result;
```

空树没有任何节点，直接返回空数组。

```cpp
queue<TreeNode*> que;
que.push(root);
```

队列保存接下来要访问的节点。先把根节点入队。

```cpp
int size = que.size();
vector<int> level;
```

每一轮循环开始时，队列里的节点正好是当前层的所有节点。先固定 `size`，再创建当前层数组 `level`。

```cpp
for (int i = 0; i < size; i++) {
```

只处理当前层的 `size` 个节点。循环过程中加入队列的孩子节点属于下一层，不应该在本轮处理。

```cpp
TreeNode* node = que.front();
que.pop();
```

取出队首节点并弹出，这是队列 BFS 的核心操作。

```cpp
level.push_back(node->val);
```

把当前节点值加入当前层结果。

```cpp
if (node->left != nullptr) que.push(node->left);
if (node->right != nullptr) que.push(node->right);
```

先加入左孩子，再加入右孩子，保证同一层从左到右访问。

```cpp
result.push_back(level);
```

当前层处理完后，加入最终结果。

## 易错点

1. **忘记空树判断**：如果 `root == nullptr` 还直接入队，后面访问 `node->val` 会出错。
2. **没有固定当前层大小**：如果直接 `while (!que.empty())` 一直处理，会把所有节点放进同一个数组，无法按层分组。
3. **左右孩子入队顺序写反**：如果先入队右孩子，再入队左孩子，同一层输出顺序会变成从右到左。
4. **把 `size = que.size()` 写进 for 条件里动态判断**：队列大小会在循环中变化，应该在每层开始时先固定。

> [!warning]
> 本题和普通层序遍历最大区别是：普通遍历返回一维数组，本题要求返回二维数组，所以必须使用 `size` 来分层。

---

## 复杂度

- **时间复杂度**：`O(n)` — 每个节点只会入队一次、出队一次，`n` 是节点数量。
- **空间复杂度**：`O(n)` — 最坏情况下，队列中可能保存接近一层的所有节点，结果数组也需要保存所有节点值。
