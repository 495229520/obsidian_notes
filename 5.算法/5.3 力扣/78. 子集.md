# 78. 子集

给定一个元素互不相同的整数数组 `nums`，返回该数组所有可能的子集，也就是幂集。

---

## 1. 题目概览

### 1.1 题目描述

输入一个整数数组 `nums`，数组中的元素互不相同。要求返回所有可能的子集，结果中不能包含重复子集。

子集可以按任意顺序返回。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 整数数组 `nums` |
| 输出 | 所有可能的子集 |
| 数组长度 | `1 <= nums.length <= 10` |
| 元素范围 | `-10 <= nums[i] <= 10` |
| 特殊说明 | `nums` 中所有元素互不相同 |

### 1.3 示例

#### 示例一

```text
输入：nums = [1,2,3]
输出：[[],[1],[2],[1,2],[3],[1,3],[2,3],[1,2,3]]
```

#### 示例二

```text
输入：nums = [0]
输出：[[],[0]]
```

> [!warning]
> 子集不要求保持题目示例中的输出顺序，只要结果完整且不重复即可。

## 2. 什么是回溯法

### 2.1 回溯法的直观理解

回溯法可以理解为：**在一棵选择树上深度优先搜索，做出一个选择后继续向下尝试，尝试完后撤销选择，再换另一个选择。**

它的关键动作有三个：

1. **做选择**：把当前元素加入路径 `path`
2. **递归搜索**：进入下一层继续选择
3. **撤销选择**：把刚才加入的元素移除，回到上一步

这个“撤销选择”的动作，就是“回溯”。

```
```
### 2.2 回溯法适合解决什么问题

回溯法常用于“枚举所有可能结果”的问题，例如：

1. 子集
2. 组合
3. 排列
4. 棋盘搜索
5. 分割字符串

这些问题都有一个共同点：结果不是一个值，而是一批可能方案。我们需要把所有合法路径都找出来。

### 2.3 回溯模板

```cpp
void backtrack(参数) {
    if (终止条件) {
        收集结果;
        return;
    }

    for (选择 : 当前可选列表) {
        做选择;
        backtrack(下一层参数);
        撤销选择;
    }
}
```

不过本题“子集”稍微特殊：每一个中间状态本身就是一个子集，所以进入函数后就可以先记录当前 `path`，不需要等到叶子节点才记录。

---

## 3. 为什么本题用回溯法

对于数组 `nums = [1,2,3]`，每个元素都有两种状态：

```text
选它 / 不选它
```

所以全部子集数量是：

```text
2^n
```

当 `n = 3` 时，一共有 `2^3 = 8` 个子集：

```text
[]
[1]
[2]
[3]
[1,2]
[1,3]
[2,3]
[1,2,3]
```

回溯法做的事情就是：用递归把这些选择全部走一遍。

### 4.2 ASCII 推演

以 `nums = [1,2,3]` 为例，回溯树可以写成：

```text
path = []
├── 选 1 -> [1]
│   ├── 选 2 -> [1,2]
│   │   └── 选 3 -> [1,2,3]
│   └── 选 3 -> [1,3]
├── 选 2 -> [2]
│   └── 选 3 -> [2,3]
└── 选 3 -> [3]
```

注意，`[]` 也是一个子集，所以一开始就要记录空路径。

### 4.3 `path` 的变化过程

```text
进入 backtrack(start = 0)，记录 []

选择 1：path = [1]
进入 backtrack(start = 1)，记录 [1]

选择 2：path = [1,2]
进入 backtrack(start = 2)，记录 [1,2]

选择 3：path = [1,2,3]
进入 backtrack(start = 3)，记录 [1,2,3]

撤销 3：path = [1,2]
撤销 2：path = [1]

选择 3：path = [1,3]
进入 backtrack(start = 3)，记录 [1,3]

撤销 3：path = [1]
撤销 1：path = []

选择 2：path = [2]
...
```

这就是回溯的核心：**向下走时 push，回来时 pop**。

## 5. 解题步骤

### 5.1 定义两个全局变量

```cpp
vector<vector<int>> res;
vector<int> path;
```

含义：

| 变量 | 作用 |
|------|------|
| `res` | 保存所有子集 |
| `path` | 保存当前正在构造的子集 |

### 5.2 进入递归时记录当前路径

```cpp
res.push_back(path);
```

这一步非常关键。因为子集问题中，任意长度的 `path` 都是一个合法子集：

```text
[]
[1]
[1,2]
[1,2,3]
```

所以不需要等到递归结束才记录。

### 5.3 从 `start` 开始枚举选择

```cpp
for (int i = start; i < nums.size(); i++) {
    path.push_back(nums[i]);
    backtrack(nums, i + 1);
    path.pop_back();
}
```

`start` 的作用是：保证下一层只能选择当前位置右边的元素，避免重复。

例如已经选了 `1` 后，下一层只能从 `2` 和 `3` 中继续选，不能再回头选 `1`。

### 5.4 为什么不会出现重复子集

因为每次递归都把下一层起点设置成 `i + 1`：

```cpp
backtrack(nums, i + 1);
```

这表示元素只能按原数组顺序向后选择。

所以会出现：

```text
[1,2]
```

不会出现：

```text
[2,1]
```

对于子集来说，`[1,2]` 和 `[2,1]` 表示同一个集合，后者应该避免。

## 6. 完整 C++ 代码

```cpp
class Solution {
public:
    vector<vector<int>> res;
    vector<int> path;

    vector<vector<int>> subsets(vector<int>& nums) {
        backtrack(nums, 0);
        return res;
    }

    void backtrack(vector<int>& nums, int start) {
        res.push_back(path);

        for (int i = start; i < nums.size(); i++) {
            path.push_back(nums[i]);
            backtrack(nums, i + 1);
            path.pop_back();
        }
    }
};
```

## 7. 代码逐行理解

### 7.1 `backtrack(nums, 0)`

```cpp
backtrack(nums, 0);
```

从下标 `0` 开始选择元素。

一开始 `path` 是空的，所以第一次进入递归时会先记录空集 `[]`。

### 7.2 `res.push_back(path)`

```cpp
res.push_back(path);
```

把当前路径保存到答案中。

对于 `nums = [1,2,3]`，递归过程中会依次记录：

```text
[]
[1]
[1,2]
[1,2,3]
[1,3]
[2]
[2,3]
[3]
```

### 7.3 `path.push_back(nums[i])`

```cpp
path.push_back(nums[i]);
```

表示做选择，把当前元素加入子集。

例如：

```text
path = [1]
选择 2
path = [1,2]
```

### 7.4 `backtrack(nums, i + 1)`

```cpp
backtrack(nums, i + 1);
```

进入下一层递归，并且下一层只能从 `i + 1` 开始选择。

这能保证每个元素最多使用一次，也能避免重复子集。

### 7.5 `path.pop_back()`

```cpp
path.pop_back();
```

撤销刚才的选择。

例如：

```text
path = [1,2,3]
撤销 3
path = [1,2]
```

撤销后，程序才能回到上一层，继续尝试其他分支。

## 8. 复杂度分析

| 项目 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | `O(n * 2^n)` | 一共有 `2^n` 个子集，每个子集复制到 `res` 时最多需要 `O(n)` |
| 空间复杂度 | `O(n)` | 不计算返回结果时，递归深度和 `path` 最多为 `n` |
| 返回结果空间 | `O(n * 2^n)` | 所有子集本身需要保存下来 |

---

## 9. 易错点总结

1. 空集 `[]` 也是子集，所以一进入递归就要记录 `path`。
2. `start` 不是当前递归层数，而是下一次可以选择的起始下标。
3. `path.push_back` 后一定要 `path.pop_back`，否则不同分支会互相污染。
4. 子集问题不需要显式终止条件，因为 `for` 循环走不动时递归自然结束。
5. `nums` 元素互不相同，所以本题不需要排序去重。
