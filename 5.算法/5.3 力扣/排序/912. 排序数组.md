# 912. 排序数组

给你一个整数数组 `nums`，请你将该数组升序排列。

你必须在**不使用任何内置函数**的情况下解决问题，时间复杂度为 `O(nlog(n))`，并且空间复杂度尽可能小。

---

## 1. 题目概览

### 1.1 题目描述

输入一个整数数组 `nums`，需要返回一个新的排列结果，使得数组中的元素按照从小到大的顺序排列。

这道题本质上不是考察 `std::sort` 的调用，而是考察常见排序算法的手写能力：

1. 快速排序
2. 归并排序
3. 计数排序
4. 堆排序

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 整数数组 `nums` |
| 输出 | 升序排列后的 `nums` |
| 数组长度 | `1 <= nums.length <= 5 * 10^4` |
| 元素范围 | `-5 * 10^4 <= nums[i] <= 5 * 10^4` |
| 特殊要求 | 不使用内置排序函数；时间复杂度尽量为 `O(nlogn)`；空间复杂度尽量小 |

> [!warning]
> 示例解释中说“某些数字的位置没有改变，某些数字的位置发生改变”，只是说明排序结果，不要求保持相同元素的原始相对顺序。也就是说，本题不强制稳定排序。

### 1.3 示例

#### 示例一

```text
输入：nums = [5,2,3,1]
输出：[1,2,3,5]
解释：数组排序后，一些数字的位置没有改变（例如，2 和 3），而其他数字的位置发生了改变（例如，1 和 5）。
```

#### 示例二

```text
输入：nums = [5,1,1,2,0,0]
输出：[0,0,1,1,2,5]
解释：请注意，nums 的值不一定唯一。
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 快速排序 | Hoare 分区 + 递归 | 原数组、递归栈 | 适合 | 平均 `O(nlogn)`，常数小，但最坏可能退化 |
| 归并排序 | 分治 + 合并有序区间 | 辅助数组 `temp` | 适合 | 最坏 `O(nlogn)`，稳定，但需要 `O(n)` 空间 |
| 计数排序 | 统计值域出现次数 | 计数数组 `count` | 很适合 | 本题值域固定为 `[-50000, 50000]` |
| 堆排序 | 大根堆 | 原数组表示堆 | 适合 | 原地排序，最坏 `O(nlogn)` |

### 2.2 本题最推荐的思路

如果只看本题给出的数据范围，**计数排序非常有竞争力**：

- `nums[i]` 的范围固定为 `[-50000, 50000]`
- 值域大小只有 `100001`
- 可以用 `value + 50000` 把负数映射到计数数组下标

如果题目没有给出小值域限制，则更通用的是：

1. 归并排序：复杂度稳定，边界清晰
2. 堆排序：原地，最坏复杂度稳定
3. 快速排序：平均表现好，但要注意退化和重复值

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 | 为什么需要它 |
|----------|----------------|--------------|
| `vector<int>` | 存储原数组和辅助数组 | LeetCode 默认输入容器，支持随机访问 |
| 递归栈 | 快排、归并递归划分区间 | 保存未处理完的子问题 |
| `count` 数组 | 计数排序记录每个值出现次数 | 将排序转化为统计和回填 |
| 数组堆 | 堆排序中用原数组模拟完全二叉树 | 原地维护大根堆 |

## 4. 写法一：快速排序（Hoare 分区）

### 4.1 核心思路

快速排序每次选择一个基准值 `pivot`，通过左右指针扫描，把数组分成两部分：

```text
[left, j]       整体 <= pivot
[j + 1, right]  整体 >= pivot
```

然后递归处理左右两段。

### 4.2 完整代码

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        if (!nums.empty()) {
            quickSort(nums, 0, static_cast<int>(nums.size()) - 1);
        }
        return nums;
    }

private:
    void quickSort(vector<int>& nums, int left, int right) {
        if (left >= right) return;

        int i = left - 1;
        int j = right + 1;
        int pivot = nums[left + (right - left) / 2];

        while (i < j) {
            do ++i; while (nums[i] < pivot);
            do --j; while (nums[j] > pivot);

            if (i < j) {
                swap(nums[i], nums[j]);
            }
        }

        quickSort(nums, left, j);
        quickSort(nums, j + 1, right);
    }
};
```

### 4.3 源码详解

| 代码 | 解释 |
|------|------|
| `left >= right` | 当前区间为空或只有一个元素，天然有序 |
| `i = left - 1` | 配合 `do ++i`，第一次移动后正好来到 `left` |
| `j = right + 1` | 配合 `do --j`，第一次移动后正好来到 `right` |
| `pivot` | 只是基准值，不一定是最终位置 |
| `quickSort(nums, left, j)` | Hoare 分区返回的左边界结尾是 `j` |
| `quickSort(nums, j + 1, right)` | 右区间从 `j + 1` 开始 |

> [!warning]
> 用户代码中的变量名 `pvoid` 应该改为 `pivot`。同时，Hoare 分区中比较条件要写成 `< pivot` 和 `> pivot`，不要写成 `<=` 和 `>=`，否则遇到大量重复值时容易越界。

### 4.4 复杂度

- 平均时间复杂度：`O(nlogn)`
- 最坏时间复杂度：`O(n²)`
- 空间复杂度：平均 `O(logn)`，来自递归栈

## 5. 写法二：归并排序

### 5.1 核心思路

归并排序使用分治：

1. 把当前区间拆成左右两半
2. 递归排好左右两半
3. 合并两个有序区间

### 5.2 完整代码

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        if (!nums.empty()) {
            mergeSort(nums, 0, static_cast<int>(nums.size()) - 1);
        }
        return nums;
    }

private:
    void mergeSort(vector<int>& nums, int left, int right) {
        if (left >= right) return;

        int mid = left + (right - left) / 2;
        mergeSort(nums, left, mid);
        mergeSort(nums, mid + 1, right);

        vector<int> temp;
        int i = left;
        int j = mid + 1;

        while (i <= mid && j <= right) {
            if (nums[i] <= nums[j]) temp.push_back(nums[i++]);
            else temp.push_back(nums[j++]);
        }

        while (i <= mid) temp.push_back(nums[i++]);
        while (j <= right) temp.push_back(nums[j++]);

        for (int k = 0; k < static_cast<int>(temp.size()); ++k) {
            nums[left + k] = temp[k];
        }
    }
};
```

### 5.3 源码详解

| 变量 | 含义 |
|------|------|
| `left`、`right` | 当前处理的闭区间 `[left, right]` |
| `mid` | 中点，把区间拆成 `[left, mid]` 和 `[mid + 1, right]` |
| `temp` | 当前这一层递归的临时数组，只保存 `[left, right]` 合并后的结果 |
| `i` | 左半区间当前指针 |
| `j` | 右半区间当前指针 |
| `left + k` | `temp[k]` 在原数组中对应的真实位置 |

这份写法把 `temp` 放在每次合并时局部创建，代码更紧凑，逻辑也更直接。

`nums[i] <= nums[j]` 可以保证稳定性：当两个元素相等时，优先放左半边的元素。最后拷回时要写 `nums[left + k] = temp[k]`，因为当前排序的区间不一定从 `0` 开始。

### 5.4 复杂度

- 时间复杂度：`O(nlogn)`
- 空间复杂度：`O(n)`
- 稳定性：稳定

## 6. 写法三：计数排序

### 6.1 核心思路

本题的值域固定：

```text
-50000 <= nums[i] <= 50000
```

因此可以开一个长度为 `100001` 的计数数组：

```text
count[value + 50000] 表示 value 出现的次数
```

最后从小到大遍历值域，把每个值按出现次数写回 `nums`。

### 6.2 完整代码

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        const int minValue = -50000;
        const int maxValue = 50000;
        const int offset = -minValue;
        const int range = maxValue - minValue + 1;

        vector<int> count(range, 0);

        for (int value : nums) {
            ++count[value + offset];
        }

        int index = 0;
        for (int value = minValue; value <= maxValue; ++value) {
            int times = count[value + offset];
            while (times--) {
                nums[index++] = value;
            }
        }

        return nums;
    }
};
```

### 6.3 为什么本题适合计数排序

| 条件 | 本题是否满足 | 说明 |
|------|--------------|------|
| 元素是整数 | 是 | `nums[i]` 是整数 |
| 值域较小 | 是 | 只有 `100001` 个可能值 |
| 允许额外空间 | 是 | `count` 数组大小固定 |
| 不使用内置排序 | 是 | 全程只统计和回填 |

> [!tip]
> 对于 LeetCode 912，计数排序的复杂度是 `O(n + 100001)`，在本题范围内完全可以接受。

### 6.4 复杂度

- 时间复杂度：`O(n + k)`，本题 `k = 100001`
- 空间复杂度：`O(k)`
- 稳定性：当前写法只排序整数，不讨论对象的相对顺序；如果排序对象，可以用“前缀和 + 逆序回填”写成稳定版

## 7. 写法四：堆排序

### 7.1 核心思路

堆排序使用大根堆：

1. 先把整个数组建成大根堆
2. 堆顶是当前最大值
3. 把堆顶和当前堆尾交换
4. 缩小堆范围，对堆顶执行下沉调整
5. 重复直到数组升序

### 7.2 完整代码

```cpp
class Solution {
public:
    vector<int> sortArray(vector<int>& nums) {
        int n = static_cast<int>(nums.size());

        for (int i = n / 2 - 1; i >= 0; --i) {
            heapify(nums, n, i);
        }

        for (int end = n - 1; end > 0; --end) {
            swap(nums[0], nums[end]);
            heapify(nums, end, 0);
        }

        return nums;
    }

private:
    void heapify(vector<int>& nums, int heapSize, int root) {
        int largest = root;
        int left = root * 2 + 1;
        int right = root * 2 + 2;

        if (left < heapSize && nums[left] > nums[largest]) {
            largest = left;
        }

        if (right < heapSize && nums[right] > nums[largest]) {
            largest = right;
        }

        if (largest != root) {
            swap(nums[root], nums[largest]);
            heapify(nums, heapSize, largest);
        }
    }
};
```

### 7.3 源码详解

| 步骤 | 代码 | 说明 |
|------|------|------|
| 建堆 | `for (int i = n / 2 - 1; i >= 0; --i)` | 从最后一个非叶子节点开始下沉 |
| 取最大值 | `swap(nums[0], nums[end])` | 堆顶最大值放到当前末尾 |
| 缩小堆 | `heapify(nums, end, 0)` | `[0, end)` 继续保持大根堆 |
| 下沉调整 | `heapify` | 让根节点和更大的孩子交换，直到堆性质恢复 |

### 7.4 复杂度

- 时间复杂度：`O(nlogn)`
- 空间复杂度：递归版 `heapify` 有 `O(logn)` 调用栈；如果改成迭代下沉可做到严格 `O(1)`
- 稳定性：不稳定

## 8. 四种写法怎么选

| 场景 | 推荐写法 | 原因 |
|------|----------|------|
| 想练习最经典的面试排序 | 快速排序 | 思想重要，但要注意最坏退化 |
| 想要稳定的 `O(nlogn)` | 归并排序 | 边界清晰，复杂度稳定 |
| 针对 LeetCode 912 的固定值域 | 计数排序 | 充分利用 `[-50000, 50000]`，接近线性 |
| 想要原地且最坏 `O(nlogn)` | 堆排序 | 不需要 `O(n)` 辅助数组 |

如果只考虑本题约束，**计数排序是非常直接的解法**；如果题目没有小值域限制，则更通用的是归并排序、堆排序或快排。

## 10. 易错点

1. 快排 Hoare 分区的递归区间是 `[left, j]` 和 `[j + 1, right]`，不要随意改成 `[left, j - 1]`。
2. 快排比较条件使用 `< pivot` 和 `> pivot`，不要用 `<=` 和 `>=` 跳过重复值。
3. 归并排序拷回原数组时，要从 `left` 到 `right`，不要从 `0` 开始覆盖。
4. 计数排序要处理负数偏移，`value + offset` 才是计数数组下标。
5. 堆排序建堆要从 `n / 2 - 1` 开始，因为这才是最后一个非叶子节点。
6. 本题明确要求不使用内置排序函数，所以提交时不要直接写 `sort(nums.begin(), nums.end())`。
