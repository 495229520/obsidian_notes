# 65. 有效数字

给定一个字符串 `s`，判断该字符串是否表示一个有效的数值（整数、小数以及可选的科学计数法指数）。

---

## 1. 题目概览

### 1.1 语法规则解析

根据题目定义，有效数字由以下部分按顺序组成：

1. **底数部分（必选）**：可以是一个整数或一个小数。
   - **整数**：可选符号（`'+'` 或 `'-'`）接至少一位数字（如 `"2"`、`"-0089"`）。
   - **小数**：可选符号接以下三种形态之一：
     - 数字 + 小数点（如 `"4."`）
     - 数字 + 小数点 + 数字（如 `"+3.14"`、`"-123.456"`）
     - 小数点 + 数字（如 `"-.9"`、`".1"`）
     - *注：仅有一个单独的小数点 `"."` 或符号接小数点 `"+."` 为非法。*
2. **指数部分（可选）**：
   - 以 `'e'` 或 `'E'` 开头。
   - 紧跟一个**整数**（可带可选符号，但绝对不能包含小数点或再次出现指数）。

### 1.2 示例对照

| 字符串 | 是否有效 | 归类说明 |
|---|---|---|
| `"2"`、`"-0089"` | 有效 | 纯整数 |
| `"+3.14"`、`"-123.456e789"` | 有效 | 标准浮点数 / 科学计数法浮点数 |
| `"4."` | 有效 | 整数后带点，省略小数部分 |
| `"-.9"` | 有效 | 省略整数部分的小数 |
| `"2e10"`、`"-90E3"`、`"3e+7"` | 有效 | 包含指数与可选阶符 |
| `"abc"`、`"1a"` | 无效 | 包含非法字母 |
| `"."`、`"+."` | 无效 | 缺失任何数字位 |
| `"1e"`、`"e3"` | 无效 | 指数缺少底数或缺少阶数 |
| `"99e2.5"` | 无效 | 指数部分必须是整数，不能含小数点 |
| `"--6"`、`"-+3"` | 无效 | 符号位连续重复 |

| 解法 | 核心逻辑 | 优势 | 劣势 |
|---|---|---|---|
| **标志位单遍扫描** | 用 `seenDigit`、`seenDot`、`seenExponent` 追踪状态 | 代码量少，手写快，直观 | 需要仔细梳理符号与重置条件 |

### 状态定义

- **状态 0**：初始状态
- **状态 1**：底数符号位（`'+'` / `'-'`）
- **状态 2**：底数整数部分（合法终止态）
- **状态 3**：小数点（前面未出现数字，如 `"."`、`"+."`）
- **状态 4**：小数部分数字（合法终止态）
- **状态 5**：小数点（前面已有数字，如 `"4."`，合法终止态）
- **状态 6**：指数符号（`'e'` / `'E'`）
- **状态 7**：指数符号位（`'+'` / `'-'`）
- **状态 8**：指数数值部分（合法终止态）

## 4. 解法一：标志位扫描法（推荐工程实现）

### 4.1 算法逻辑

维护三个布尔标志：
1. `seenDigit`：是否遇到过有效数字。
2. `seenDot`：是否遇到过小数点。
3. `seenExponent`：是否遇到过指数符号 `'e'` / `'E'`。

遍历每个字符 `s[i]`：
- **遇到数字 `'0'-'9'`**：置 `seenDigit = true`。
- **遇到符号 `'+' / '-'`**：符号只能出现在第 0 位，或者紧跟在 `'e'` / `'E'` 后面；若不是则直接返回 `false`。
- **遇到小数点 `'.'`**：小数点前不能出现过小数点（`seenDot`），也不能出现在指数后面（`seenExponent`）；否则非法，合法时置 `seenDot = true`。
- **遇到指数 `'e' / 'E'`**：指数前必须出现过数字（`seenDigit`），且不能出现过指数（`seenExponent`）；合法时置 `seenExponent = true`，**并将 `seenDigit` 重置为 `false`**（因为指数后必须紧跟新的数字）。
- **遇到其他字符**：直接返回 `false`。

循环结束后，只需验证 `seenDigit` 是否为 `true`。若末尾悬挂了未完成的指数（如 `"1e"`）或符号（如 `"1e+"`），`seenDigit` 均为 `false`。

### 4.2 C++ 实现

```cpp
#include <string>
#include <cctype>

class Solution {
public:
    bool isNumber(std::string s) {
        bool seenDigit = false;
        bool seenDot = false;
        bool seenExponent = false;

        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
            char ch = s[i];

            if (std::isdigit(ch)) {
                seenDigit = true;
            } else if (ch == '+' || ch == '-') {
                // 符号只能在开头或紧随 e/E
                if (i > 0 && s[i - 1] != 'e' && s[i - 1] != 'E') {
                    return false;
                }
            } else if (ch == '.') {
                // 小数点不能重复，且不能出现在指数后
                if (seenDot || seenExponent) {
                    return false;
                }
                seenDot = true;
            } else if (ch == 'e' || ch == 'E') {
                // 指数不能重复，且必须在底数数字之后
                if (seenExponent || !seenDigit) {
                    return false;
                }
                seenExponent = true;
                seenDigit = false; // 重置：要求指数后必须跟着至少一位数字
            } else {
                return false;
            }
        }

        return seenDigit;
    }
};
```

## 5. 解法二：确定有限状态自动机 (DFA)

### 5.1 转移矩阵设计

输入字符划分为 4 类：
1. `CHAR_NUMBER`：`'0'`–`'9'`
2. `CHAR_EXP`：`'e'` / `'E'`
3. `CHAR_POINT`：`'.'`
4. `CHAR_SIGN`：`'+'` / `'-'`

转移表 `transfer[当前状态][字符类别]` 定义如下（`-1` 代表转移到非法态）：

```text
       NUMBER   EXP   POINT   SIGN
0:        2      -1     3       1     (初始)
1:        2      -1     3      -1     (底数符号)
2:        2       6     5      -1     (底数整数 *)
3:        4      -1    -1      -1     (前无整数的点)
4:        4       6    -1      -1     (小数部分 *)
5:        4       6    -1      -1     (前有整数的点 *)
6:        8      -1    -1       7     (指数 e/E)
7:        8      -1    -1      -1     (指数符号)
8:        8      -1    -1      -1     (指数数字 *)
```
带 `*` 的为终止接受状态：`{2, 4, 5, 8}`。

### 5.2 C++ 实现

```cpp
#include <string>

class Solution {
private:
    enum CharType {
        CHAR_NUMBER = 0,
        CHAR_EXP = 1,
        CHAR_POINT = 2,
        CHAR_SIGN = 3,
        CHAR_ILLEGAL = 4
    };

    CharType toCharType(char ch) {
        if (ch >= '0' && ch <= '9') return CHAR_NUMBER;
        if (ch == 'e' || ch == 'E') return CHAR_EXP;
        if (ch == '.') return CHAR_POINT;
        if (ch == '+' || ch == '-') return CHAR_SIGN;
        return CHAR_ILLEGAL;
    }

public:
    bool isNumber(std::string s) {
        // 9 个状态，4 种有效字符类型
        static const int transfer[9][4] = {
            { 2, -1, 3, 1 },  // 0: 初始
            { 2, -1, 3, -1 }, // 1: 底数符号
            { 2, 6, 5, -1 },  // 2: 底数整数
            { 4, -1, -1, -1 },// 3: 无前置整数的小数点
            { 4, 6, -1, -1 }, // 4: 小数部分数字
            { 4, 6, -1, -1 }, // 5: 有前置整数的小数点
            { 8, -1, -1, 7 }, // 6: 指数字符
            { 8, -1, -1, -1 },// 7: 指数符号
            { 8, -1, -1, -1 } // 8: 指数数字
        };

        int state = 0;
        for (char ch : s) {
            CharType type = toCharType(ch);
            if (type == CHAR_ILLEGAL) {
                return false;
            }
            state = transfer[state][type];
            if (state == -1) {
                return false;
            }
        }

        return state == 2 || state == 4 || state == 5 || state == 8;
    }
};
```

## 6. 核心边界用例走查

| 边界输入 | 难点所在 | 判定逻辑 | 预期结果 |
|---|---|---|---|
| `"."` | 只有小数点，没有数字 | `seenDigit` 始终为 `false` | `false` |
| `"+."` | 符号接小数点无数字 | `seenDigit` 始终为 `false` | `false` |
| `"4."` | 小数点后无数字 | `'4'` 使 `seenDigit = true`，停在状态 5（接受态） | `true` |
| `"-.9"` | 符号接小数点后有数字 | `'9'` 使 `seenDigit = true`，停在状态 4（接受态） | `true` |
| `"1e"` | 指数后无阶数 | 遇 `'e'` 后重置 `seenDigit = false`，末尾未补数字 | `false` |
| `"1e+"` | 符号悬挂在末尾 | 符号合法但未遇到数字，`seenDigit` 为 `false` | `false` |
| `"99e2.5"` | 指数出现浮点数 | 遇 `'.'` 时 `seenExponent` 已为 `true`，触发拒绝 | `false` |
| `"123.456e789"` | 完整标准科学记数法 | 底数合规，指数合规，停在状态 8（接受态） | `true` |

## 7. 复杂度分析

- **时间复杂度**：$\mathcal{O}(N)$，其中 $N$ 为字符串长度。只需单次遍历字符串，字符判断与转移均为 $\mathcal{O}(1)$ 操作。
- **空间复杂度**：$\mathcal{O}(1)$，仅需几个标量状态标志或固定常数大小的状态转移矩阵。
