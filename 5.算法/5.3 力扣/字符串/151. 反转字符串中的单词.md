# 151. 反转字符串中的单词

给定一个字符串 `s`，要求反转字符串中单词的顺序。返回结果中，单词之间只能保留一个空格，并且不能有前导空格和尾随空格。

---

## 1. 题目概览

### 1.1 题目描述

输入字符串 `s` 可能包含：

1. 前导空格
2. 尾随空格
3. 单词之间的多个连续空格

需要返回单词顺序反转后的字符串，并把单词之间的空格压缩为一个。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 字符串 `s` |
| 输出 | 单词顺序反转后的字符串 |
| 字符串长度 | `1 <= s.length <= 10^4` |
| 字符范围 | 英文字母、数字和空格 |
| 特殊说明 | `s` 中至少存在一个单词 |

> [!warning]
> 本题不是把整个字符串简单反转，而是反转单词顺序。例如 `"the sky is blue"` 要变成 `"blue is sky the"`。

### 1.3 示例

#### 示例一

```text
输入：s = "the sky is blue"
输出："blue is sky the"
```

#### 示例二

```text
输入：s = "  hello world  "
输出："world hello"
```

#### 示例三

```text
输入：s = "a good   example"
输出："example good a"
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| `stringstream` 分词 | 先按空格提取单词，再倒序拼接 | `vector<string>` | 适合 | 写法简单，逻辑清晰 |
| 原地风格翻转 | 压缩空格 + 整体反转 + 逐词反转 | `string` + 双指针 | 推荐掌握 | 更贴近进阶要求，可做到额外空间更少 |

### 2.2 本题采用的算法

本题记录两种写法：

1. **双指针压缩空格 + 两次反转**
2. **`stringstream` 分词 + 倒序拼接**

第一种写法更适合理解字符串翻转类题目，第二种写法更适合快速写出正确答案。

## 3. 写法一：压缩空格 + 整体反转 + 逐词反转

### 3.1 核心思路

先把原字符串中的多余空格删除，只保留单词之间的一个空格。

然后整体反转字符串：

```text
hello world
dlrow olleh
```

整体反转后，单词顺序已经反过来了，但是每个单词内部字符也被反了。所以还需要再逐个反转每个单词：

```text
dlrow olleh
world hello
```

### 3.2 ASCII 可视化渲染过程

以输入 `s = "  hello   world  "` 为例。

#### 第一步：压缩空格

```text
原始字符串：
[_][_][h][e][l][l][o][_][_][_][w][o][r][l][d][_][_]

fast 扫描每个字符，slow 写入有效字符：
          fast
           |
[_][_][h][e][l][l][o][_][_][_][w][o][r][l][d][_][_]
       |
      slow

压缩结果：
[h][e][l][l][o][_][w][o][r][l][d]
```

这里 `_` 表示空格。压缩规则是：

1. 开头空格不要
2. 连续空格只保留第一个
3. 最后的尾随空格再删掉

#### 第二步：整体反转

```text
压缩后：
[h][e][l][l][o][_][w][o][r][l][d]

整体反转：
[d][l][r][o][w][_][o][l][l][e][h]

此时：
单词顺序已经变成 world -> hello
但是每个单词内部还是反的：dlrow、olleh
```

#### 第三步：逐词反转

```text
整体反转后：
[d][l][r][o][w][_][o][l][l][e][h]
 start          i
 |              |
 0              5   遇到空格，反转 [start, i)

反转第一个单词：
[w][o][r][l][d][_][o][l][l][e][h]
                 start       i
                  |          |
                  6          11  到达末尾，反转 [start, i)

最终结果：
[w][o][r][l][d][_][h][e][l][l][o]
```

### 3.4 完整 C++ 代码

```cpp
class Solution {
public:
    void reduceEmpty(string& s) {
        int slow = 0;

        for (int fast = 0; fast < s.size(); fast++) {
            if (s[fast] == ' ' && (fast == 0 || s[fast - 1] == ' ')) {
                continue;
            }

            s[slow++] = s[fast];
        }

        if (slow > 0 && s[slow - 1] == ' ') {
            slow--;
        }

        s.resize(slow);
    }

    string reverseWords(string s) {
        reduceEmpty(s);

        reverse(s.begin(), s.end());

        int start = 0;

        for (int i = 0; i <= s.size(); i++) {
            if (i == s.size() || s[i] == ' ') {
                reverse(s.begin() + start, s.begin() + i);
                start = i + 1;
            }
        }

        return s;
    }
};
```

### 3.5 代码关键点

| 代码 | 作用 |
|------|------|
| `fast` | 扫描原字符串 |
| `slow` | 写入压缩后的有效字符 |
| `s.resize(slow)` | 删除多余尾部内容 |
| `reverse(s.begin(), s.end())` | 先整体反转，让单词顺序倒过来 |
| `reverse(s.begin() + start, s.begin() + i)` | 再把当前单词内部顺序修正 |

> [!tip]
> `for (int i = 0; i <= res.size(); i++)` 中的 `i == res.size()` 是为了处理最后一个单词。因为最后一个单词后面没有空格，需要在到达字符串末尾时主动触发一次反转。

## 4. 写法二：`stringstream` 分词 + 倒序拼接

### 4.1 核心思路

`stringstream` 默认会按照空白字符提取单词，并自动跳过连续空格。

所以可以先把所有单词依次读入 `vector<string>`：

```text
"  hello   world  " -> ["hello", "world"]
```

然后从后往前拼接：

```text
["hello", "world"] -> "world hello"
```

### 4.2 完整 C++ 代码

```cpp
class Solution {
public:
    string reverseWords(string s) {
        vector<string> ans;
        stringstream ss(s);
        string tmp;

        while (ss >> tmp) {
            ans.push_back(tmp);
        }

        string res;

        for (int i = ans.size() - 1; i >= 0; i--) {
            res += ans[i];

            if (i != 0) {
                res += " ";
            }
        }

        return res;
    }
};
```

### 4.3 代码关键点

| 代码 | 作用 |
|------|------|
| `stringstream ss(s)` | 把字符串放入输入流 |
| `ss >> tmp` | 每次读取一个单词，自动跳过多余空白 |
| `ans.push_back(tmp)` | 保存读取到的单词 |
| `for (int i = ans.size() - 1; i >= 0; i--)` | 从后往前拼接单词 |

> [!note]
> 题目保证 `s` 中至少存在一个单词，所以 `ans` 不会为空。如果在普通工程代码中使用，建议把下标写成 `int i = static_cast<int>(ans.size()) - 1`，并额外处理空数组情况。

## 5. 两种写法对比

| 对比项 | 压缩空格 + 两次反转 | `stringstream` 分词 |
|--------|--------------------|--------------------|
| 思路难度 | 中等 | 简单 |
| 代码长度 | 较长 | 较短 |
| 额外空间 | 主要是结果字符串 | 需要 `vector<string>` 保存所有单词 |
| 是否贴近进阶要求 | 更贴近 | 不贴近 |
| 推荐用途 | 训练字符串原地处理和区间反转 | 快速 AC |

## 6. 复杂度分析

### 6.1 写法一

| 项目 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | `O(n)` | 压缩空格、整体反转、逐词反转都只线性处理字符串 |
| 空间复杂度 | `O(1)` | 直接在参数 `s` 上压缩空格和反转，不再额外拷贝字符串 |

这里的 `reverseWords(string s)` 仍然会接收 LeetCode 传入字符串的一份参数副本，但算法处理过程中没有再额外创建同规模字符串，因此符合题目进阶要求的原地处理思路。

### 6.2 写法二

| 项目 | 复杂度 | 说明 |
|------|--------|------|
| 时间复杂度 | `O(n)` | 每个字符被读取和拼接 |
| 空间复杂度 | `O(n)` | `vector<string>` 保存所有单词 |

---

## 7. 易错点总结

1. 不能只整体反转字符串，否则单词内部字符也会反。
2. 压缩空格时，要同时处理前导空格、连续空格和尾随空格。
3. 逐词反转时，循环要能处理最后一个单词。
4. `reverse` 的区间是左闭右开 `[begin, end)`。
5. `stringstream` 写法简单，但会额外保存所有单词。
