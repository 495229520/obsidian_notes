# 415. 字符串相加

给定两个用字符串表示的非负整数 `num1` 和 `num2`，要求在**不使用任何内置大整数库、也不能直接把字符串转成整数**的前提下，计算它们的和并以字符串返回。这正是「高精度加法」的标准应用场景。

---

## 1. 题目概览

### 1.1 题目描述

`num1` 和 `num2` 都是只包含数字 `0-9` 的字符串，长度可能很大（远超 `long long` 能表示的范围），因此必须像竖式计算一样**逐位相加并处理进位**。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 字符串 `num1`、`num2` |
| 输出 | 表示二者之和的字符串 |
| 长度 | `1 <= num1.length, num2.length <= 10^4` |
| 字符范围 | 仅含 `0-9` |
| 前导零 | 除数字 `0` 本身外，**不含前导零** |
| 限制 | 不能把输入直接转为整数，也不能使用内置大整数库 |

> [!important]
> 因为长度可达 `10^4`，远超 64 位整数范围，所以**只能用字符串/数组模拟**，这就是高精度算法的用武之地。

### 1.3 示例

```text
输入：num1 = "11", num2 = "123"
输出："134"
```

```text
输入：num1 = "456", num2 = "77"
输出："533"
```

```text
输入：num1 = "0", num2 = "0"
输出："0"
```

---

## 2. 高精度加法简介

> [!note]
> 本题对应的通用高精度加 / 减 / 乘 / 除模板出处见 [[5.2.3 高精度]]。

### 2.1 核心思想

把大整数**逆序存入数组**（低位存低索引），再从低位到高位**逐位相加 + 进位**，模拟手算竖式。

逆序存储是关键技巧：进位总是从低位向高位传递，把低位放在数组前面，最高位进位时只需在数组**末尾追加**一个元素即可，无需整体搬移。

> [!tip]
> 凡是「数字大到普通整型装不下」「按位做加减乘除」的题目，都可以套用高精度模板。判断信号：输入是数字字符串、长度上限很大（如 `10^4`、`10^5`）。

### 2.2 三步框架

1. **逆序存储**：`A[i] = num1[len-1-i] - '0'`，把字符转成数字并反向放入 `vector<int>`。
2. **逐位相加**：用进位变量 `t`，每一位 `t = 进位 + A[i] + B[i]`，当前位写 `t % 10`，新进位为 `t / 10`。
3. **逆序输出**：结果数组同样是低位在前，输出时要从高位（数组末尾）到低位（数组开头）。

---

## 3. 解题思路

### 3.1 步骤分解

1. 把 `num1`、`num2` 逆序转存到 `A`、`B` 两个数字数组。
2. 调用 `add(A, B)`：循环条件用 `i < A.size() || i < B.size()`，保证较长的数也能处理完；用 `if (i < A.size())` / `if (i < B.size())` 防止越界。
3. 累加进位 `t`，每轮 `C.push_back(t % 10)` 后 `t /= 10`。
4. 循环结束后若仍有进位 `t`，再 `C.push_back(t)`（处理像 `99 + 1` 这种最高位进位）。
5. 把结果数组 `C` 逆序拼接成字符串返回。

### 3.2 图解

以 `num1 = "99"`、`num2 = "999"` 为例（不等长 + 最高位进位，覆盖所有易错点）：

![[图片/5.算法/5.3 力扣/5.3.3 高精度/5_1_415_1.svg|820]]

逐位过程：个位 `9+9=18` 写 `8` 进 `1`；十位 `1+9+9=19` 写 `9` 进 `1`；百位 `1+0+9=10`（此时 `A` 已越界，只加 `B[2]`）写 `0` 进 `1`；循环结束仍有进位 `1`，追加到末尾。结果数组 `C = [8,9,0,1]`，逆序输出得到 `"1098"`。

## 4. 代码实现

```cpp
class Solution {
public:
    vector<int> add(vector<int>& A, vector<int>& B) {
        vector<int> C;
        int t = 0;  // 进位

        for (int i = 0; i < A.size() || i < B.size(); i++) {
            if (i < A.size()) t += A[i];
            if (i < B.size()) t += B[i];

            C.push_back(t % 10);
            t /= 10;
        }

        if (t) C.push_back(t);  // 处理最高位进位

        return C;
    }

    string addStrings(string num1, string num2) {
        vector<int> A, B;

        // 逆序存储：低位放数组前面
        for (int i = num1.size() - 1; i >= 0; i--) {
            A.push_back(num1[i] - '0');
        }

        for (int i = num2.size() - 1; i >= 0; i--) {
            B.push_back(num2[i] - '0');
        }

        auto C = add(A, B);

        // 逆序输出：从高位（数组末尾）到低位
        string res;
        for (int i = C.size() - 1; i >= 0; i--) {
            res += C[i] + '0';
        }

        return res;
    }
};
```

### 4.1 代码关键点

| 代码 | 作用 |
|------|------|
| `num1[i] - '0'` | 字符转数字（`'9' - '0' == 9`） |
| `for (...; i--) A.push_back(...)` | 逆序存储，低位存低索引 |
| `i < A.size() \|\| i < B.size()` | 用 `\|\|` 保证较长的数也走完，处理不等长 |
| `if (i < A.size())` / `if (i < B.size())` | 防越界，短数用完后这一位只取长数 |
| `t % 10` / `t /= 10` | 取当前位 / 更新进位 |
| `if (t) C.push_back(t)` | 循环后处理最高位进位 |
| `res += C[i] + '0'` | 数字转字符并逆序拼接 |

> [!tip]
> 加法的进位 `t` 在任意一步都只可能是 `0` 或 `1`，所以这里 `push_back(t)` 与某些模板里写死的 `push_back(1)` 等价；但写 `push_back(t)` 更通用、不易记错。

---

## 5. 易错点

1. **漏掉最高位进位**：如 `99 + 1`，若循环后忘记 `if (t) C.push_back(t)`，结果会少一位。
2. **不等长处理**：循环条件必须用 `||` 而非 `&&`，并对每个数组单独做 `i < size()` 越界判断，否则短数用完后会读到非法内存。
3. **逆序方向搞反**：存储和输出都要逆序，二者方向必须一致，否则得到错误答案。
4. **字符/数字转换**：读入用 `- '0'`、输出用 `+ '0'`，两处都不能漏。
5. **是否去前导零**：加法结果**不会**出现多余前导零（输入无前导零，且 `"0"+"0"="0"`），所以不需要像高精度减法/乘法/除法那样 `while (C.size()>1 && C.back()==0) C.pop_back()`。

> [!warning]
> 最常见的失分点是「最高位进位」和「不等长越界」。记住模板里那句 `if (t) C.push_back(t)` 和循环条件里的 `||`。

---

## 6. 复杂度

- **时间复杂度**：`O(max(m, n))` —— `m`、`n` 分别为两字符串长度，逆序存储、逐位相加、逆序输出都只线性扫描一遍。
- **空间复杂度**：`O(max(m, n))` —— 额外使用 `A`、`B`、`C` 三个数组及结果字符串，规模与较长的数相当。
