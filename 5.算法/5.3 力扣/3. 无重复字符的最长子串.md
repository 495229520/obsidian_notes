# 3. 无重复字符的最长子串

给定字符串 `s`，要求找到其中不含重复字符的最长连续子串，并返回这个子串的长度。

---

## 1. 题目概览

### 1.1 题目描述

给定一个字符串 `s` ，请你找出其中不含有重复字符的**最长子串**的长度。

这里要求的是**子串**，所以字符必须连续；不是子序列，不能跳过中间字符。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 字符串 `s` |
| 输出 | 不含重复字符的最长子串长度 |
| 字符串长度 | `0 <= s.length <= 5 * 10^4` |
| 字符范围 | 英文字母、数字、符号和空格 |
| 特殊说明 | 子串必须连续，答案只需要返回长度 |

> [!warning]
> `"pwke"` 是 `"pwwkew"` 的子序列，不是子串；本题答案必须来自连续区间。

### 1.3 示例

#### 示例一

```text
输入：s = "abcabcbb"
输出：3
解释：因为无重复字符的最长子串是 "abc"，所以其长度为 3。
```

#### 示例二

```text
输入：s = "bbbbb"
输出：1
解释：因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

#### 示例三

```text
输入：s = "pwwkew"
输出：3
解释：因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 暴力枚举 | 枚举所有子串并检查重复 | 字符串下标 / 集合 | 不推荐 | 时间复杂度高，容易超时 |
| 滑动窗口 | 动态维护无重复连续区间 | `unordered_set<char>` | 推荐 | 每个字符最多进出窗口一次，时间 `O(n)` |
| 滑动窗口优化 | 记录字符最近出现位置 | `unordered_map<char, int>` | 适合 | 可一次性跳过重复字符前的位置 |

### 2.2 本题采用的算法

本题采用：**滑动窗口 + 哈希集合**。

选择它的原因：

1. 题目要求的是连续子串，天然适合用左右指针表示窗口。
2. 窗口中不能有重复字符，可以用哈希集合快速判断当前字符是否已经出现。
3. `left` 和 `right` 都只会向右移动，总时间复杂度是 `O(n)`。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 | 为什么需要它 |
|----------|----------------|--------------|
| `std::string` | 保存输入字符串 | 支持下标访问字符 |
| `unordered_set<char>` | 维护当前窗口中已有字符 | 快速判断字符是否重复 |
| `left`、`right` 指针 | 表示当前窗口左右边界 | 动态维护连续子串 |
| `ans` | 记录当前见过的最长合法窗口长度 | 最终返回答案 |

## 3. 解题步骤

### 3.1 核心思路

用两个指针 `left` 和 `right` 维护一个窗口 `[left, right]`，保证窗口中的字符始终不重复。

`right` 负责向右扩张窗口。每次准备加入 `s[right]` 时，如果它已经存在于窗口中，说明窗口不合法，需要不断右移 `left` 并删除旧字符，直到 `s[right]` 不再重复。

当窗口重新合法后，把 `s[right]` 加入窗口，并用窗口长度更新答案。

### 3.2 详细步骤

#### 第一步：初始化窗口

```cpp
unordered_set<char> window;
int left = 0;
int ans = 0;
```

`window` 保存当前窗口内出现过的字符，`left` 是窗口左边界，`ans` 是最长长度。

#### 第二步：移动右边界

从左到右枚举 `right`：

```cpp
for (int right = 0; right < s.size(); ++right) {
    // 处理 s[right]
}
```

每轮尝试把 `s[right]` 加入窗口。

#### 第三步：如果重复就收缩窗口

```cpp
while (window.count(s[right])) {
    window.erase(s[left]);
    ++left;
}
```

只要当前字符已经在窗口中，就说明窗口不合法。持续移除左侧字符，直到当前字符可以安全加入。

#### 第四步：加入当前字符并更新答案

```cpp
window.insert(s[right]);
ans = max(ans, right - left + 1);
```

此时窗口合法，因此可以用当前窗口长度更新最长答案。

### 3.3 示例推演

以 `s = "abcabcbb"` 为例：

| 步骤 | 当前字符 | 窗口变化 | 当前答案 | 说明 |
|------|----------|----------|----------|------|
| 1 | `a` | `"a"` | 1 | 加入 `a` |
| 2 | `b` | `"ab"` | 2 | 无重复 |
| 3 | `c` | `"abc"` | 3 | 更新最长长度 |
| 4 | `a` | `"bca"` | 3 | 移除旧 `a` 后加入新 `a` |
| 5 | `b` | `"cab"` | 3 | 移除旧 `b` 后加入新 `b` |

### 4.2 关键状态变化

1. `right` 每次向右扩张一个字符。
2. 如果 `s[right]` 已经在窗口中，说明当前窗口出现重复字符。
3. `left` 右移并删除旧字符，直到窗口重新合法。
4. 每次窗口合法后，使用 `right - left + 1` 更新答案。

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        if (s.size() <= 1) {
            return s.size();
        }

        unordered_set<char> window;
        int left = 0, ans = 0;

        for (int right = 0; right < s.size(); ++right) {
            while (window.count(s[right])) {
                window.erase(s[left]);
                ++left;
            }

            window.insert(s[right]);
            ans = max(ans, right - left + 1);
        }

        return ans;
    }
};
```

### 5.2 代码中的关键注释

| 代码位置 | 解释重点 |
|----------|----------|
| `unordered_set<char> window` | 记录窗口中已有字符，判断是否重复 |
| `while (window.count(s[right]))` | 当前字符重复时持续收缩左边界 |
| `window.erase(s[left])` | 左边界右移前先移除旧字符 |
| `window.insert(s[right])` | 当前字符加入合法窗口 |
| `ans = max(...)` | 用当前合法窗口长度更新答案 |

## 6. 源码详解

### 6.1 核心变量说明

| 变量 / 数据结构 | 含义 | 生命周期 | 为什么需要它 |
|-----------------|------|----------|--------------|
| `window` | 当前窗口中的字符集合 | 整个遍历过程 | 快速判断重复字符 |
| `left` | 窗口左边界 | 整个遍历过程 | 控制窗口收缩 |
| `right` | 窗口右边界 | `for` 循环中变化 | 控制窗口扩张 |
| `ans` | 当前最长合法窗口长度 | 整个遍历过程 | 最终返回答案 |

### 6.2 为什么时间复杂度是 `O(n)`

虽然代码中有 `for` 和 `while` 两层循环，但它们不是独立的嵌套枚举：

- `right` 只会从左到右移动一遍
- `left` 也只会从左到右移动一遍

所以每个字符最多进入窗口一次、移出窗口一次，总时间复杂度仍然是 `O(n)`。

### 6.3 为什么先收缩再插入

当 `window.count(s[right])` 为真时，如果直接插入当前字符，窗口中就会出现重复字符。

因此必须先移除左侧字符，直到当前字符不再重复，再把它插入窗口。

### 6.4 易错点

1. 题目求的是**最长长度**，不是具体子串内容。
2. 题目要求的是**子串**，必须连续。
3. 先缩小窗口，再插入当前字符。
4. `left` 右移时，要同步把旧字符从 `window` 中删除。
5. 空字符串长度为 `0`，应返回 `0`。

## 7. 复杂度分析

### 7.1 时间复杂度

- 时间复杂度：`O(n)`

原因：每个字符最多进入窗口一次、移出窗口一次。

### 7.2 空间复杂度

- 空间复杂度：`O(k)`

其中 `k` 是窗口内不同字符的数量，最坏情况下可看作 `O(n)`。
