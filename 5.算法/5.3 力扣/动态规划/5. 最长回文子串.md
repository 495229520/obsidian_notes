# 5. 最长回文子串

本篇记录 LeetCode 5「最长回文子串」的**动态规划写法**。核心是用 `dp[i][j]` 记录区间 `s[i...j]` 是否为回文，再按子串长度从短到长填表。

---

## 1. 题目概览

### 1.1 题目描述

给定一个字符串 `s`，要求返回 `s` 中最长的回文子串。

回文子串必须满足：

1. 子串是连续的。
2. 正着读和反着读完全一样。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 字符串 `s` |
| 输出 | `s` 中最长的回文子串 |
| 字符串长度 | `1 <= s.length <= 1000` |
| 字符范围 | 仅由数字和英文字母组成 |
| 特殊说明 | 如果存在多个答案，返回任意一个即可 |

> [!warning]
> 本题要求的是子串 substring，必须连续；不是子序列 subsequence。

### 1.3 示例

#### 示例一

```text
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

#### 示例二

```text
输入：s = "cbbd"
输出："bb"
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 暴力枚举 | 枚举所有子串再判断回文 | 字符串下标 | 不推荐 | 时间复杂度可到 `O(n^3)` |
| 中心扩展 | 从每个中心向两边扩展 | 左右指针 | 推荐 | 代码短，空间 `O(1)` |
| 动态规划 | `dp[i][j]` 表示区间是否回文 | 二维 `bool` 表 | 适合 | 状态转移清晰，便于系统理解区间问题 |
| Manacher | 回文半径数组 | 预处理字符串 + 数组 | 进阶 | 时间 `O(n)`，但实现复杂 |

### 2.2 本题采用的算法

本篇采用：**动态规划**。

选择它的原因：

1. 回文串具有明显的区间依赖关系：外层字符相等，并且内部区间也是回文。
2. `dp[i][j]` 可以直接表示 `s[i...j]` 是否是回文。
3. 对 `n <= 1000`，`O(n^2)` 时间和 `O(n^2)` 空间可以接受。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 | 为什么需要它 |
|----------|----------------|--------------|
| `std::string` | 存储输入字符串和返回子串 | 支持下标访问与 `substr` 截取 |
| `vector<vector<bool>> dp` | 记录每个区间是否回文 | 避免重复判断内部子串 |
| `start`、`maxLen` | 记录最长回文子串的位置和长度 | 最后通过 `substr(start, maxLen)` 返回答案 |

## 3. 解题步骤

### 3.1 核心思路

定义状态：

```cpp
dp[i][j] 表示子串 s[i...j] 是否是回文串
```

如果 `s[i] != s[j]`，那么两端字符不同，`s[i...j]` 一定不是回文。

如果 `s[i] == s[j]`，还要看内部子串 `s[i+1...j-1]` 是否回文：

```text
s[i...j] 是回文
= 两端字符相等 + 内部子串是回文
```

但长度较短时可以直接判断：

- 长度为 1：单个字符一定是回文
- 长度为 2：两个字符相等就是回文
- 长度为 3：两端字符相等，中间只有一个字符，也一定是回文

### 3.2 详细步骤

#### 第一步：初始化答案

```cpp
int start = 0;
int maxLen = 1;
```

因为题目保证字符串非空，所以至少存在一个长度为 `1` 的回文子串。

#### 第二步：创建 DP 表

```cpp
vector<vector<bool>> dp(n, vector<bool>(n, false));
```

`dp[i][j]` 默认是 `false`，之后按照子串长度从小到大填表。

#### 第三步：按长度枚举子串

```cpp
for (int len = 1; len <= n; ++len) {
    for (int i = 0; i + len - 1 < n; ++i) {
        int j = i + len - 1;
    }
}
```

这样可以保证计算 `dp[i][j]` 时，它依赖的 `dp[i + 1][j - 1]` 已经提前算过。

#### 第四步：状态转移

当 `s[i] == s[j]` 时：

```cpp
if (j - i < 3) {
    dp[i][j] = true;
} else {
    dp[i][j] = dp[i + 1][j - 1];
}
```

完整含义：

1. 若两端字符不同，`dp[i][j] = false`。
2. 若两端字符相同，并且区间长度不超过 3，则一定回文。
3. 若两端字符相同，并且区间长度大于 3，则取决于内部区间是否回文。

#### 第五步：更新最长答案

```cpp
if (dp[i][j] && len > maxLen) {
    start = i;
    maxLen = len;
}
```

### 3.3 示例推演

以 `s = "babad"` 为例：

| 子串长度 | 典型区间 | 判断 | 结果 |
|----------|----------|------|------|
| 1 | `"b"`, `"a"` | 单字符必回文 | 更新长度至少为 1 |
| 2 | `"ba"`, `"ab"` | 两端不等 | 不是回文 |
| 3 | `"bab"` | `s[0] == s[2]`，长度为 3 | 是回文，更新答案 |
| 3 | `"aba"` | `s[1] == s[3]`，长度为 3 | 也是回文 |
| 4/5 | 继续判断 | 没有更长回文 | 保留长度 3 的答案 |

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    std::string longestPalindrome(std::string s) {
        int n = s.size();

        int start = 0;
        int maxLen = 1;

        std::vector<std::vector<bool>> dp(n, std::vector<bool>(n, false));

        for (int len = 1; len <= n; ++len) {
            for (int i = 0; i + len - 1 < n; ++i) {
                int j = i + len - 1;

                if (s[i] != s[j]) {
                    dp[i][j] = false;
                } else {
                    if (j - i < 3) {
                        dp[i][j] = true;
                    } else {
                        dp[i][j] = dp[i + 1][j - 1];
                    }
                }

                if (dp[i][j] && len > maxLen) {
                    start = i;
                    maxLen = len;
                }
            }
        }

        return s.substr(start, maxLen);
    }
};
```

### 5.2 代码中的关键注释

| 代码位置 | 解释重点 |
|----------|----------|
| `dp[i][j]` | 表示区间 `s[i...j]` 是否回文 |
| `len` 从小到大枚举 | 保证内部区间 `dp[i+1][j-1]` 已经算过 |
| `j - i < 3` | 长度为 1、2、3 时，只要两端相等即可 |
| `dp[i + 1][j - 1]` | 长区间依赖内部短区间 |
| `substr(start, maxLen)` | 根据记录的起点和长度截取答案 |

## 6. 源码详解

### 6.1 核心变量说明

| 变量 / 数据结构 | 含义 | 为什么需要它 |
|-----------------|------|--------------|
| `n` | 字符串长度 | 控制循环边界 |
| `dp` | 二维状态表 | 记录每个区间是否回文 |
| `len` | 当前枚举的子串长度 | 保证短区间先于长区间计算 |
| `i`、`j` | 当前子串左右边界 | 表示区间 `s[i...j]` |
| `start` | 最长回文子串起点 | 最后截取答案 |
| `maxLen` | 最长回文子串长度 | 判断是否需要更新答案 |

### 6.2 为什么要按长度从小到大枚举

状态转移中：

```cpp
dp[i][j] = dp[i + 1][j - 1]
```

右侧区间 `s[i+1...j-1]` 比当前区间 `s[i...j]` 短 `2`。

因此必须先计算短区间，再计算长区间。

按 `len = 1, 2, 3, ...` 枚举，就能保证依赖关系正确。

### 6.3 为什么 `j - i < 3` 可以直接判断

当 `s[i] == s[j]` 时：

| 区间长度 | 情况 | 是否回文 |
|----------|------|----------|
| 1 | `i == j` | 单字符必回文 |
| 2 | 两端字符相等 | 例如 `"bb"`，是回文 |
| 3 | 中间只有一个字符 | 例如 `"bab"`，是回文 |

这三种情况都不需要再查内部状态。

### 6.4 易错点

1. `dp[i][j]` 的含义必须是闭区间 `s[i...j]` 是否回文。
2. 长区间依赖短区间，遍历顺序不能乱。
3. `j - i < 3` 是为了处理长度为 1、2、3 的边界。
4. 更新答案时要判断 `len > maxLen`。
5. 最后返回的是 `s.substr(start, maxLen)`，第二个参数是长度，不是结束下标。

## 7. 复杂度分析

### 7.1 时间复杂度

- 时间复杂度：`O(n^2)`

原因：一共有 `O(n^2)` 个区间状态，每个状态 `O(1)` 转移。

### 7.2 空间复杂度

- 空间复杂度：`O(n^2)`

原因：需要二维 `dp` 表记录所有区间是否为回文。
