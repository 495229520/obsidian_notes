# 207. 课程表

总共有 `numCourses` 门课，部分课程之间存在先修关系 `prerequisites[i] = [a, b]`（学 `a` 之前必须先学 `b`）。判断是否能学完所有课程。

等价于判定：把先修关系视为有向图，是否存在拓扑排序（即图是否是 DAG）。

---

## 1. 题目概览

### 1.1 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。

在选修某些课程之前需要一些先修课程，先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [ai, bi]` 表示如果要学习课程 `ai` 则必须先学习课程 `bi` 。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true`；否则，返回 `false`。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | `numCourses: int`，`prerequisites: vector<vector<int>>` |
| 输出 | 能否完成所有课程 `bool` |
| 课程数 | `1 <= numCourses <= 2000` |
| 先修对数 | `0 <= prerequisites.length <= 5000` |
| 元素 | `prerequisites[i].length == 2`；不重复 |

### 1.3 示例

#### 示例一

```text
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：先学课程 0 再学课程 1，可以完成。
```

#### 示例二

```text
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：1 依赖 0，0 又依赖 1，存在环。
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| Kahn 算法 | BFS + 入度数组 | `queue<int>` + `vector<int>` 入度 | 推荐 | 直观、好实现、可顺手输出拓扑序 |
| DFS 三色标记 | 后序时机判断回边 | 颜色数组（白/灰/黑） | 推荐 | 不需要入度，递归写法更直接 |

### 2.2 本题采用的算法

主解：**Kahn 算法**。它把「能否完成」直接转换为「拓扑结果是否包含全部 `n` 个节点」，逻辑非常清晰。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 |
|----------|----------------|
| `vector<vector<int>>` | 邻接表：`g[b]` 存放「学完 `b` 后可以解锁的后继课程」 |
| `vector<int> indeg` | 每门课的入度（先修课程数量） |
| `queue<int>` | Kahn 算法的待处理队列 |

## 3. 解题步骤

### 3.1 核心思路（Kahn）

1. 构图：题目里 `prerequisites[i] = [a, b]` 表示「先 `b` 后 `a`」，所以图边方向是 `b -> a`，`a` 入度加一。
2. 初始把所有入度为 `0` 的节点（没有先修课）入队。
3. 反复取队首 `u`，相当于「学完 `u`」，把 `u` 的所有后继 `v` 的入度减一；如果某个 `v` 的入度变为 `0`，意味着它的所有先修都已完成，入队。
4. 统计被处理过的节点总数；如果等于 `numCourses`，说明全部能学完；否则存在环。

### 3.2 详细步骤

#### 第一步：建图与初始化入度

```cpp
vector<vector<int>> g(numCourses);
vector<int> indeg(numCourses, 0);
for (auto& p : prerequisites) {
    int a = p[0], b = p[1];     // 先修 b 才能学 a
    g[b].push_back(a);
    ++indeg[a];
}
```

#### 第二步：所有入度 0 的节点入队

```cpp
queue<int> q;
for (int i = 0; i < numCourses; ++i) {
    if (indeg[i] == 0) q.push(i);
}
```

#### 第三步：BFS 处理

```cpp
int finished = 0;
while (!q.empty()) {
    int u = q.front();
    q.pop();
    ++finished;

    for (int v : g[u]) {
        if (--indeg[v] == 0) q.push(v);
    }
}
return finished == numCourses;
```

## 5. 源码实现

### 5.1 解法一：Kahn 算法（推荐）

```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> g(numCourses);
        vector<int> indeg(numCourses, 0);

        for (auto& p : prerequisites) {
            int a = p[0], b = p[1];
            g[b].push_back(a);
            ++indeg[a];
        }

        queue<int> q;
        for (int i = 0; i < numCourses; ++i) {
            if (indeg[i] == 0) q.push(i);
        }

        int finished = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            ++finished;

            for (int v : g[u]) {
                if (--indeg[v] == 0) q.push(v);
            }
        }

        return finished == numCourses;
    }
};
```

### 5.2 解法二：DFS 三色标记

```cpp
class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        vector<vector<int>> g(numCourses);
        for (auto& p : prerequisites) {
            g[p[1]].push_back(p[0]);
        }

        // 0 = 未访问；1 = 正在递归栈上；2 = 已完成
        vector<int> color(numCourses, 0);

        for (int i = 0; i < numCourses; ++i) {
            if (color[i] == 0 && hasCycle(i, g, color)) return false;
        }
        return true;
    }

private:
    bool hasCycle(int u, const vector<vector<int>>& g, vector<int>& color) {
        color[u] = 1;
        for (int v : g[u]) {
            if (color[v] == 1) return true;             // 回边：环
            if (color[v] == 0 && hasCycle(v, g, color)) return true;
        }
        color[u] = 2;
        return false;
    }
};
```

## 6. 源码详解

### 6.1 Kahn 解法关键点

| 代码 | 含义 |
|------|------|
| `g[b].push_back(a)` | 边的方向：从先修课指向后续课 |
| `++indeg[a]` | `a` 的入度加一，表示它有一门先修课 |
| `if (--indeg[v] == 0) q.push(v)` | 后继节点入度归零即可入队 |
| `return finished == numCourses` | 没全部处理完 ⇒ 存在节点处在环里入度始终降不到 0 |

### 6.2 DFS 解法的「三色」含义

- **白（0）**：尚未访问
- **灰（1）**：正在 DFS 递归栈中
- **黑（2）**：递归已结束，子树都没问题

DFS 沿邻居走时若再次遇到「灰色」节点，说明存在指回祖先的「回边」，即环。

### 6.3 易错点

1. **建图方向**：`[a, b]` 是「学 `a` 之前要学 `b`」，所以图边方向是 `b -> a`，新手很容易反向。
2. **使用 `--indeg[v]` 与 `if (indeg[v] == 0)`** 必须组合在一起，缺一不可。
3. **DFS 解法忘记三色**：只有「访问过 / 没访问」两种状态时无法区分「在递归栈上」与「递归完成的安全节点」，会误报环。
4. **图不连通**：必须对每个未访问节点都启动一次 DFS / 都把入度为 0 的节点入队。

## 7. 复杂度分析

设 `n = numCourses`，`m = prerequisites.size()`：

| 指标 | Kahn | DFS |
|------|------|-----|
| 时间 | `O(n + m)` | `O(n + m)` |
| 空间 | `O(n + m)` 邻接表 + 入度 | `O(n + m)` 邻接表 + 颜色数组 + 递归栈 |

每个节点和每条边各处理一次。
