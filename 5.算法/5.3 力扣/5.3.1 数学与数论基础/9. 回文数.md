# 9. 回文数

> 判断一个整数是否是回文数。回文数指正序读和倒序读都一样的整数。

这题可以用栈保存数字，也可以直接用数学方式反转一半数字。你的写法属于**栈模拟数字反转顺序**。

## 一、题目关键点

整数回文的判断，本质是比较：

```text
从左往右看的数字序列 == 从右往左看的数字序列
```

例如：

```text
121 是回文，因为 1 2 1 反过来仍然是 1 2 1
123 不是回文，因为 1 2 3 反过来是 3 2 1
```

负数一定不是回文，因为负号只出现在最左侧：

```text
-121 反过来看不是 -121
```

## 二、你的栈写法

先把 `x` 的每一位压入栈中。由于栈是后进先出，弹出时得到的就是从高位到低位的顺序。

然后再次从 `x` 的低位开始取数字，和栈顶比较。

```cpp
class Solution {
public:
    bool isPalindrome(int x) {
        if (x < 0) {
            return false;
        }

        if (x == 0) {
            return true;
        }
        std::stack<int> st;
        int tmp = x;
        while(tmp > 0)
        {
            st.push(tmp % 10);
            tmp /= 10;
        }
        tmp = x;
        while(tmp > 0)
        {
            if(st.top() != tmp % 10)
            {
                return false;
            }
            tmp /= 10;
            st.pop();
        }
        return true;
    }
};
```

## 三、过程示例

以 `x = 121` 为例。

第一次循环压栈：

| tmp | 压入数字 | 栈内容 |
|-----:|---------:|--------|
| 121 | 1 | `1` |
| 12 | 2 | `1, 2` |
| 1 | 1 | `1, 2, 1` |

第二次循环比较：

| tmp 当前低位 | 栈顶 | 是否相等 |
|-------------:|-----:|----------|
| 1 | 1 | 是 |
| 2 | 2 | 是 |
| 1 | 1 | 是 |

全部相等，所以返回 `true`。

## 四、优化写法：反转一半数字

练习分配表里建议的重点是**反转一半数字判断回文**。这样不需要额外栈空间。

核心思路：

```text
原数字左半边 == 反转后的右半边
```

```cpp
class Solution {
public:
    bool isPalindrome(int x) {
        if (x < 0 || (x % 10 == 0 && x != 0)) {
            return false;
        }

        int reversedHalf = 0;

        while (x > reversedHalf) {
            reversedHalf = reversedHalf * 10 + x % 10;
            x /= 10;
        }

        return x == reversedHalf || x == reversedHalf / 10;
    }
};
```

为什么最后有两个判断：

| 情况 | 示例 | 判断 |
|------|------|------|
| 偶数位 | `1221` | `x == reversedHalf` |
| 奇数位 | `121` | `x == reversedHalf / 10`，去掉中间位 |

## 五、易错点

| 易错点 | 说明 |
|--------|------|
| 负数 | 一定不是回文 |
| 末尾为 0 | 除了 `0` 本身，其他末尾为 0 的数都不是回文 |
| 奇数位数字 | 中间位不影响回文判断 |
| 栈写法空间 | 需要 `O(k)` 额外空间 |

## 六、复杂度

设整数有 `k` 位。

| 写法 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 栈写法 | `O(k)` | `O(k)` |
| 反转一半数字 | `O(k)` | `O(1)` |
