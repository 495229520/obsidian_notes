# 50. Pow(x, n)

> 实现 `pow(x, n)`，计算 `x` 的整数次幂。

这题的核心是**快速幂**。不能直接循环乘 `n` 次，因为 `n` 的范围很大，需要把复杂度从 `O(n)` 降到 `O(log n)`。

## 一、为什么要快速幂

直接计算：

```text
x^10 = x * x * x * x * x * x * x * x * x * x
```

需要乘 10 次。

快速幂利用指数的二进制拆分：

```text
10 = 1010₂ = 8 + 2
x^10 = x^8 * x^2
```

每一轮都让底数平方，指数右移一位：

```text
x, x^2, x^4, x^8, ...
```

如果当前二进制位是 `1`，就把当前底数乘进答案。

## 二、代码

```cpp
class Solution {
public:
    double myPow(double x, int n) {
        if(x==0)
            return 0;
        long long N = n;
        if(N < 0)
        {
            x = 1 / x;
            N = -1 * N;
        }
        double res = 1.0;
        while(N > 0)
        {
            if(N & 1ll)
            {
                res *= x;
            }
            x *= x;
            N >>= 1;
        }
        return res;
    }
};
```

## 三、关键边界：为什么先转 long long

`n` 是 `int`，最小值是：

```text
INT_MIN = -2147483648
```

如果直接写：

```cpp
n = -n;
```

当 `n == INT_MIN` 时会溢出，因为 `2147483648` 超出了 `int` 的正数范围。

所以要先转成 `long long`：

```cpp
long long N = n;
```

再处理负指数：

```cpp
if (N < 0) {
    x = 1 / x;
    N = -N;
}
```

这样 `INT_MIN` 也能安全转成正数指数。

## 四、循环过程示例

以 `x = 2.0, n = 10` 为例：

```text
10 = 1010₂
```

| N | 当前位 | res | x | 操作 |
|---:|-------:|----:|---:|------|
| 10 | 0 | 1 | 2 | 不乘，x 平方 |
| 5 | 1 | 4 | 4 | 乘入 res，x 平方 |
| 2 | 0 | 4 | 16 | 不乘，x 平方 |
| 1 | 1 | 1024 | 256 | 乘入 res |

最终：

```text
2^10 = 1024
```

## 五、负指数怎么处理

负指数可以转成倒数：

```text
x^-n = 1 / x^n
```

例如：

```text
2^-3 = 1 / 2^3 = 0.125
```

代码中先把底数变成倒数：

```cpp
x = 1 / x;
```

再把指数转成正数：

```cpp
N = -N;
```

后面的快速幂逻辑就和正指数完全一样。

## 六、易错点

| 易错点 | 说明 |
|--------|------|
| `INT_MIN` | 必须先用 `long long` 保存指数，再取相反数 |
| 负指数 | 先把 `x` 变成 `1 / x`，再把指数转正 |
| 当前位判断 | `N & 1LL` 表示当前最低位是否为 1 |
| 指数右移 | `N >>= 1` 等价于处理下一位二进制 |
| `x == 0` | 本题通常不会要求计算 `0` 的负指数；这份代码直接返回 `0` |

## 七、复杂度

每轮指数减半。

- 时间复杂度：`O(log |n|)`
- 空间复杂度：`O(1)`
