# 168. Excel 表列名称

> 给定一个正整数 `columnNumber`，返回它在 Excel 表中相对应的列名称。
>
> ```text
> 1 -> A
> 2 -> B
> ...
> 26 -> Z
> 27 -> AA
> 28 -> AB
> ...
> ```

这题本质是**进制转换**：把数字转成 26 进制字符串。但它有一个反直觉的地方——**从 1 开始计数，没有「0」这个字符**。这种编号方式叫**双射进制（bijective base-26）**，处理它的关键就是每取一位前先做一次 `columnNumber--`。

## 一、为什么不是普通的 26 进制

普通 26 进制用 `0~25` 这 26 个数字，对应 `A~Z` 的话就是 `A=0, B=1, ..., Z=25`。但 Excel 列名里：

```text
A = 1，不是 0
Z = 26
AA = 27
```

也就是说**没有一个字符代表 0**。`Z` 之后不是 `BA`（27=1×26+0），而是 `AA`（27）。

这就导致直接套用「`% 26` 取余、`/ 26` 取商」会出错：

```text
columnNumber = 26
26 % 26 = 0   -> 没有第 0 个字母，错！应该是 Z
```

问题出在 `26` 应该映射到 `Z`（第 26 个字母），但取余得到 `0`。

## 二、核心技巧：先减一，再取余

解决办法是在每一轮取数字**之前**先 `columnNumber--`，把「1-indexed」临时转成「0-indexed」：

```cpp
columnNumber--;          // 1~26 变成 0~25
int x = columnNumber % 26;   // 现在 0->A, 25->Z 就对上了
res += char('A' + x);
columnNumber /= 26;
```

以 `columnNumber = 26` 验证：

```text
columnNumber-- -> 25
25 % 26 = 25   -> 'A' + 25 = 'Z'  ✓
25 / 26 = 0    -> 循环结束
```

结果是 `Z`，正确。

> [!important] 关键理解
> `--` 的作用是把「第 1 个字母」对齐到「下标 0」。因为这套编号里 `A` 是 1 而不是 0，每往低位走一步，都要先「借一位」把它拉回从 0 开始的常规进制，取完字母再 `/ 26` 进入下一位。

## 三、代码

```cpp
class Solution {
public:
    string convertToTitle(int columnNumber) {
        string res;

        while (columnNumber > 0) {
            columnNumber--;

            int x = columnNumber % 26;
            res += char('A' + x);

            columnNumber /= 26;
        }

        reverse(res.begin(), res.end());
        return res;
    }
};
```

注意最后要 `reverse`：和所有「短除取余」的进制转换一样，余数是**从低位到高位**得到的，结果字符串顺序是反的，最后翻转过来。

## 四、过程示例

以 `columnNumber = 701` 为例（答案应为 `ZY`）：

| 轮次 | 进入时的值 | `--` 后 | `% 26` | 字母 | `/ 26` 后 | res（逆序） |
|------|----------:|--------:|-------:|------|----------:|-------------|
| 1 | 701 | 700 | 24 | `Y` | 26 | `"Y"` |
| 2 | 26 | 25 | 25 | `Z` | 0 | `"YZ"` |

循环结束，`res = "YZ"`，翻转得到 `"ZY"`，正确。

再看一个进位的例子 `columnNumber = 28`（答案 `AB`）：

| 轮次 | 进入时的值 | `--` 后 | `% 26` | 字母 | `/ 26` 后 |
|------|----------:|--------:|-------:|------|----------:|
| 1 | 28 | 27 | 1 | `B` | 1 |
| 2 | 1 | 0 | 0 | `A` | 0 |

翻转 `"BA"` 得到 `"AB"`，正确。

## 五、与「168 的逆问题」对照

这题的逆操作是 **171. Excel 表列序号**（字母转数字），那一题是按权展开：

```cpp
// 171：把 "AB" 转成 28
int result = 0;
for (char c : columnTitle) {
    result = result * 26 + (c - 'A' + 1);   // 注意这里是 +1，对应 A=1
}
```

两题对照记忆：

| 方向 | 操作 | 关键点 |
|------|------|--------|
| 168 数字 → 字母 | 短除取余 + 反转 | 取余前先 `--`（借位） |
| 171 字母 → 数字 | 按权展开累乘 | 每位 `c - 'A' + 1`（A 记作 1） |

「先减一」和「加一」恰好是一对互逆的偏移，都是为了处理 `A=1` 这个 1-indexed 的约定。

## 六、易错点

| 易错点 | 说明 |
|--------|------|
| 忘记 `--` | 直接 `% 26` 会让 26 的倍数（如 Z、AZ）算错 |
| `--` 的位置 | 必须在 `% 26` 和 `/ 26` **之前**，且每轮都要做 |
| 忘记 reverse | 余数是低位到高位得到的，最后必须翻转 |
| 字符转换 | `'A' + x` 得到的是 `int`，需显式转 `char` |

## 七、复杂度

设结果字符串长度为 `k`（约 `log₂₆(columnNumber)`）。

- 时间复杂度：`O(k)` —— 每位处理一次，`reverse` 也是 `O(k)`
- 空间复杂度：`O(1)`（不计返回字符串）

## 说说

168. Excel 表列名称 ✅

卡点只有一个：26 进制里没有「0」，`A` 从 1 开始。想通「取余前先 `--` 把它拉回从 0 开始的常规进制」之后，整道题就是标准的短除取余加反转。和 171 字母转数字（`+1`）正好是互逆的一对偏移，连着记最牢。
