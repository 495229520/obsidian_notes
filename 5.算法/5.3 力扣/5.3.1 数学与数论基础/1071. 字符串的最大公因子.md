# 1071. 字符串的最大公因子

> 对于字符串 `s` 和 `t`，如果 `s = t + t + ... + t`（`t` 重复若干次），则称 `t` 能整除 `s`。求两个字符串的最长公共"因子"字符串。

**关键洞察**：

1. **拼接到别**：如果两个字符串存在共同重复单元，`str1 + str2` 和 `str2 + str1` 必须相等。
2. **答案是长度 gcd**：满足条件后，重复单元的最大长度就是两个字符串长度的 `gcd`，答案取 `str1` 的前 `gcd(len1, len2)` 个字符即可。

```cpp
class Solution {
public:
    string gcdOfStrings(string str1, string str2) {
        if (str1 + str2 != str2 + str1) {
            return "";
        }

        int len = gcd(static_cast<int>(str1.size()), static_cast<int>(str2.size()));
        return str1.substr(0, len);
    }

    int gcd(int a, int b) {
        if (b == 0) {
            return a;
        }

        return gcd(b, a % b);
    }
};
```

**复杂度**：`O(len1 + len2)` 字符串拼接比较 + `O(log min(len1, len2))` gcd。
