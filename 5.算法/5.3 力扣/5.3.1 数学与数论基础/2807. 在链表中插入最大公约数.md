# 2807. 在链表中插入最大公约数

> 给定一个链表，在每对相邻节点之间插入一个新节点，新节点的值为相邻两节点值的**最大公约数**。

**关键技巧**：遍历时先保存 `current->next`，再在中间插入 gcd 节点，最后将 current 移动到保存的原 next 节点继续遍历。

```cpp
class Solution {
public:
    ListNode* insertGreatestCommonDivisors(ListNode* head) {
        ListNode* current = head;

        while (current->next != nullptr) {
            ListNode* nextNode = current->next;
            ListNode* newNode = new ListNode(gcd(current->val, nextNode->val), nextNode);
            current->next = newNode;
            current = nextNode;
        }

        return head;
    }

    int gcd(int a, int b) {
        if (b == 0) {
            return a;
        }

        return gcd(b, a % b);
    }
};
```

**易错点**：插入新节点前必须先保存 `nextNode`，否则插入后链表断开，无法继续遍历。
