# 13. 罗马数字转整数

> 给定一个罗马数字字符串，把它转换成整数。

这题不是复杂数学，而是**规则模拟**：大多数情况下从左到右累加；如果小值出现在大值前面，就表示减法。

## 一、罗马数字规则

基本字符对应关系：

| 字符 | 数值 |
|------|-----:|
| `I` | 1 |
| `V` | 5 |
| `X` | 10 |
| `L` | 50 |
| `C` | 100 |
| `D` | 500 |
| `M` | 1000 |

通常罗马数字从大到小排列，直接相加即可：

```text
VIII = 5 + 1 + 1 + 1 = 8
```

但如果当前字符比右边字符小，说明这一位要做减法：

```text
IV = -1 + 5 = 4
IX = -1 + 10 = 9
XL = -10 + 50 = 40
```

## 二、核心思路

从左到右扫描字符串 `s`：

```text
cur = 当前罗马字符的值
next = 下一个罗马字符的值
```

如果：

```text
cur < next
```

说明当前字符属于减法组合，答案减去 `cur`。

否则答案加上 `cur`。

## 三、代码

```cpp
class Solution {
public:
    int romanToInt(string s) {
        std::unordered_map<char,int> mp{
            {'I',1},
            {'V',5},
            {'X',10},
            {'L',50},
            {'C',100},
            {'D',500},
            {'M',1000}
        };

        int res = 0;
        for(int i = 0;i < s.size();i++)
        {
            int cur = mp[s[i]];
            if(i < s.size()-1 && cur < mp[s[i+1]])
            {
                res -= cur;
            }
            else
            {
                res += cur;
            }
        }
            return res;
    }
};
```

## 四、过程示例

以 `s = "MCMXCIV"` 为例：

| 字符 | 当前值 | 右侧值 | 操作 | res |
|------|-------:|-------:|------|----:|
| `M` | 1000 | 100 | 加 | 1000 |
| `C` | 100 | 1000 | 减 | 900 |
| `M` | 1000 | 10 | 加 | 1900 |
| `X` | 10 | 100 | 减 | 1890 |
| `C` | 100 | 1 | 加 | 1990 |
| `I` | 1 | 5 | 减 | 1989 |
| `V` | 5 | 无 | 加 | 1994 |

最终答案是 `1994`。

## 五、为什么只看右边一位

罗马数字的减法规则只和相邻字符有关。只要当前值比下一个值小，当前值就应该被减掉。

所以不需要枚举 `IV`、`IX`、`XL`、`XC`、`CD`、`CM` 这几种组合，统一用：

```cpp
cur < mp[s[i + 1]]
```

就能覆盖。

## 六、易错点

| 易错点 | 说明 |
|--------|------|
| 最后一位 | 没有右侧字符，必须直接加 |
| 减法规则 | 小值在大值前才减，否则加 |
| 映射表 | 字符到数值可以用 `unordered_map`，也可以用 `switch` |
| 字符串下标 | 判断 `i < s.size() - 1` 后才能访问 `s[i + 1]` |

## 七、复杂度

设字符串长度为 `n`。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，映射表大小固定
