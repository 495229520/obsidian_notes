# 343. 整数拆分

> 给定一个正整数 `n`，将其拆分为 `k` 个正整数的和（`k >= 2`），并使这些整数的乘积最大化。返回最大乘积。

这题有两种经典解法：**数学优化**和 [[5.算法/5.2 算法/5.2.19 动态规划|动态规划]]。这里记录数学优化解法。

## 一、数学结论

核心结论：**尽量拆成 3，乘积最大**。

为什么是 3？对于任意因子 `f >= 5`，都可以拆成更小的数使乘积更大：

```text
f >= 5 时：
  2 * (f - 2) = 2f - 4 > f（因为 f >= 5）
  3 * (f - 3) = 3f - 9 > f（因为 f >= 5）
```

所以最优拆分只会包含 2 和 3。又因为 `3 * 3 > 2 * 2 * 2`（三个 2 不如两个 3），所以 2 最多用两个。

归纳出三种情况：

| `n % 3` | 策略 | 原因 |
|---------|------|------|
| 0 | 全部拆成 3 | `3^a` |
| 1 | 拿出一个 3，和余 1 凑成 `2 × 2` | `3 × 1 < 2 × 2` |
| 2 | 最后多乘一个 2 | `3^a × 2` |

## 二、特殊情况

`n <= 3` 时，至少要拆成两个数，不能保留自身：

```text
n = 2: 1 + 1 → 1 × 1 = 1
n = 3: 1 + 2 → 1 × 2 = 2
```

所以 `n <= 3` 直接返回 `n - 1`。

## 三、代码

```cpp
class Solution {
public:
    int integerBreak(int n) {
        if (n <= 3) return n - 1;

        int a = n / 3;
        int b = n % 3;

        if (b == 0) {
            return pow(3, a);
        } else if (b == 1) {
            return pow(3, a - 1) * 4;
        } else {
            return pow(3, a) * 2;
        }
    }
};
```

## 四、过程示例

以 `n = 10` 为例：

```text
10 / 3 = 3，余 1
余数为 1 → 拿出一个 3 凑成 4
结果 = 3^2 × 4 = 9 × 4 = 36

拆分方式：3 + 3 + 4 = 10
乘积：3 × 3 × 4 = 36
```

更多例子：

| n | a = n/3 | b = n%3 | 拆分 | 乘积 |
|---|---------|---------|------|------|
| 6 | 2 | 0 | 3+3 | 9 |
| 7 | 2 | 1 | 3+4 | 12 |
| 8 | 2 | 2 | 3+3+2 | 18 |
| 10 | 3 | 1 | 3+3+4 | 36 |

## 五、复杂度

- 时间复杂度：`O(1)`（`pow` 在此范围内视为常数）
- 空间复杂度：`O(1)`

## 六、DP 解法对比

本题也可以用动态规划解决，状态转移为：

```text
dp[i] = max(j * (i - j), j * dp[i - j])，对所有 1 <= j < i
```

DP 解法时间 `O(n²)`，数学解法 `O(1)`，但 DP 更通用，适合理解拆分优化的递推本质。
