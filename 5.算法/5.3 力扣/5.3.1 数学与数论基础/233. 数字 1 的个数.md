# 233. 数字 1 的个数

> 给定一个整数 `n`，计算所有小于等于 `n` 的非负整数中数字 `1` 出现的总次数。

这题的关键是**逐位统计**：不去遍历每个数，而是对每个十进制位单独计算该位上 `1` 出现了多少次。

## 一、核心思路

对于数字 `n`，把每一位拆成三部分：

```text
n = higher × factor × 10 + cur × factor + lower

例如 n = 2314, factor = 10（十位）：
  higher = 23, cur = 1, lower = 4
```

- `higher`：当前位左边的高位数字
- `cur`：当前位上的数字
- `lower`：当前位右边的低位数字
- `factor`：当前位的权重（1, 10, 100, ...）

当前位出现 `1` 的次数取决于 `cur` 的值：

| cur 的值 | 当前位出现 1 的次数 | 直觉理解 |
|---------|-------------------|---------|
| `cur == 0` | `higher × factor` | 高位只能取 `0` 到 `higher - 1`，低位全范围 |
| `cur == 1` | `higher × factor + lower + 1` | 高位取满时低位受限（只能 `0` 到 `lower`） |
| `cur >= 2` | `(higher + 1) × factor` | 高位可取 `0` 到 `higher`，低位全范围 |

### 以 `n = 2314` 的十位为例

十位 `cur = 1`，`higher = 23`，`lower = 4`，`factor = 10`：

- 高位取 `00` ~ `22`（共 23 种）：十位为 1 时，低位可取 `0~9`，贡献 `23 × 10 = 230`
- 高位取 `23`：十位为 1 时，低位只能取 `0~4`，贡献 `4 + 1 = 5`
- 总计：`230 + 5 = 235`

## 二、代码

```cpp
class Solution {
public:
    int countDigitOne(int n) {
        long long ans = 0;

        for (long long factor = 1; factor <= n; factor *= 10)
        {
            long long lower = n % factor;
            long long cur = (n / factor) % 10;
            long long higher = n / (factor * 10);

            if (cur == 0)
            {
                ans += higher * factor;
            }
            else if (cur == 1)
            {
                ans += higher * factor + lower + 1;
            }
            else
            {
                ans += (higher + 1) * factor;
            }
        }

        return ans;
    }
};
```

## 三、完整示例

以 `n = 1234` 为例，逐位统计：

| 位 | factor | higher | cur | lower | 贡献 |
|----|--------|--------|-----|-------|------|
| 个位 | 1 | 123 | 4 | 0 | (123+1)×1 = 124 |
| 十位 | 10 | 12 | 3 | 4 | (12+1)×10 = 130 |
| 百位 | 100 | 1 | 2 | 34 | (1+1)×100 = 200 |
| 千位 | 1000 | 0 | 1 | 234 | 0×1000+234+1 = 235 |

总计：`124 + 130 + 200 + 235 = 689`

## 四、为什么用 long long

`factor` 每轮乘 10，当 `n` 接近 `INT_MAX` 时，`factor * 10` 和 `higher * factor` 都可能溢出 `int`。用 `long long` 保证中间计算不溢出。

## 五、易错点

| 易错点 | 说明 |
|--------|------|
| `cur == 1` 的特殊处理 | 高位取满时低位受限，必须加 `lower + 1` 而不是整个 `factor` |
| `factor` 溢出 | 循环条件 `factor <= n`，`factor` 用 `long long` |
| `higher` 的计算 | 是 `n / (factor * 10)` 而不是 `n / factor / 10`（后者等价但要注意括号） |
| `n = 0` | 循环不进入，直接返回 0，正确 |

## 六、复杂度

设 `n` 有 `k` 位十进制数字。

- 时间复杂度：`O(k)` —— 即 `O(log n)`，每位处理一次
- 空间复杂度：`O(1)`
