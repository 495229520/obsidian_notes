# 914. 卡牌分组

> 给定一副牌，每张牌上写着一个整数。判断能不能选出一个数字 `X`，使整副牌被分成若干组，并且满足：
>
> - 每组都有 `X` 张牌；
> - 每组内部的数字完全相同；
> - `X >= 2`。

这题虽然是简单题，但核心不在排序，而是把题意转成一句数论判断：

```text
每种牌的出现次数，是否存在一个公共因数 X，并且 X >= 2。
```

## 一、题目到底要求什么

假设：

```text
deck = [1,1,2,2,3,3,4,4]
```

每种牌的出现次数：

```text
1 出现 2 次
2 出现 2 次
3 出现 2 次
4 出现 2 次
```

可以选：

```text
X = 2
```

分成：

```text
[1,1] [2,2] [3,3] [4,4]
```

返回 `true`。

再看一个不能分的例子：

```text
deck = [1,1,1,2,2,2,3,3]
```

每种牌的出现次数：

```text
1 出现 3 次
2 出现 3 次
3 出现 2 次
```

如果选 `X = 3`，前两种牌可以分，但 `3` 只有 2 张，不行。
如果选 `X = 2`，`3` 可以分，但 `1` 和 `2` 各有 3 张，也不行。

唯一能同时整除 `3, 3, 2` 的数是 `1`，但题目要求 `X >= 2`，所以返回 `false`。

## 二、为什么用 gcd

设每种牌的出现次数为：

```text
c1, c2, c3, ..., ck
```

要选一个合法的组大小 `X`，必须满足：

```text
c1 % X == 0
c2 % X == 0
c3 % X == 0
...
ck % X == 0
```

也就是说：

```text
X 必须同时整除所有出现次数。
```

这正是在找所有出现次数的**公因数**。

而这些公因数里最大的那个，就是：

```text
gcd(c1, c2, c3, ..., ck)
```

所以判断逻辑变成：

```text
如果 gcd(所有出现次数) >= 2，说明存在合法的 X，返回 true。
如果 gcd(所有出现次数) == 1，说明只能按 1 张一组，返回 false。
```

## 三、算法思路

本篇笔记使用**排序 + 连续计数 + gcd**。

1. 先把 `deck` 排序，让相同数字挨在一起。
2. 扫描排序后的数组，统计每一段相同数字的长度。
3. 每统计完一种牌的出现次数，就把这个次数合并到 `g` 里：

```cpp
g = gcd(g, count);
```

4. 最后判断：

```cpp
return g >= 2;
```

这里的 `g` 表示：

```text
目前已统计过的所有出现次数的最大公因数。
```

## 四、代码

```cpp
class Solution {
public:
    bool hasGroupsSizeX(vector<int>& deck) {
        if (deck.size() < 2) {
            return false;
        }

        sort(deck.begin(), deck.end());

        int g = 0;
        int count = 1;

        for (int i = 1; i < deck.size(); i++) {
            if (deck[i] == deck[i - 1]) {
                count++;
            } else {
                g = gcd(g, count);
                count = 1;
            }
        }

        g = gcd(g, count);

        return g >= 2;
    }

    int gcd(int a, int b) {
        if (b == 0) {
            return a;
        }

        return gcd(b, a % b);
    }
};
```

## 五、循环过程详解

以这个输入为例：

```text
deck = [1,1,1,2,2,2,3,3]
```

排序后：

```text
1 1 1 2 2 2 3 3
```

初始化：

```cpp
int g = 0;
int count = 1;
```

含义：

```text
g：已统计过的出现次数的最大公因数
count：当前这个数字连续出现了几次
```

扫描过程：

| 扫描位置 | 当前段 | count | 触发操作 | g |
|---|---:|---:|---|---:|
| `1 1 1` 结束，遇到 `2` | `1` | 3 | `gcd(0, 3)` | 3 |
| `2 2 2` 结束，遇到 `3` | `2` | 3 | `gcd(3, 3)` | 3 |
| 循环结束后补算最后一段 | `3` | 2 | `gcd(3, 2)` | 1 |

最终：

```text
g = 1
```

说明这些出现次数没有 >= 2 的公共因数，所以返回：

```cpp
false
```

注意最后一定要写：

```cpp
g = gcd(g, count);
```

因为最后一种牌不会再遇到"下一个不同的数字"，如果不补算，就会漏掉最后一段的频次。

## 六、容易写错的地方

### 1. `size` 要加括号

```cpp
deck.size()
```

不能写成：

```cpp
deck.size
```

`size()` 是 `vector` 的成员函数。

### 2. `vector` 没有 `sort` 成员

不能写：

```cpp
vector<int> newDeck = deck.sort();
```

正确写法：

```cpp
sort(deck.begin(), deck.end());
```

如果想保留原数组，先复制再排：

```cpp
vector<int> newDeck = deck;
sort(newDeck.begin(), newDeck.end());
```

### 3. 不是求 `deck.size()` 和 `count` 的 gcd

这题要看的是：

```text
所有牌面出现次数之间有没有公共因数。
```

所以应该求：

```text
gcd(次数1, 次数2, 次数3, ...)
```

而不是：

```text
gcd(总牌数, 当前次数)
```

例如：

```text
出现次数 = 3, 3, 2
总牌数 = 8
```

`gcd(8, 2) = 2`，但 `3` 不能被 `2` 整除，所以不能只拿总牌数和某一个次数判断。

### 4. 不要把变量命名为 `gcd`

如果写：

```cpp
int gcd = gcd(deckNum, num);
```

变量名和函数名重名，代码会非常混乱，也容易编译失败。建议用：

```cpp
int g = 0;
```

## 七、复杂度

```text
时间复杂度：O(n log n)
```

排序是主要开销。扫描数组是 `O(n)`，求 gcd 的开销很小。

```text
空间复杂度：O(log n)
```

主要来自排序过程的递归栈或内部辅助空间。

## 八、总结

这题的关键不是真的把牌分出来，而是看每种牌的数量能不能被同一个 `X` 整除。

```text
出现次数：2, 2, 2, 2
gcd = 2
可以分组
```

```text
出现次数：3, 3, 2
gcd = 1
不能分组
```

最终判断：

```cpp
return gcd(所有出现次数) >= 2;
```
