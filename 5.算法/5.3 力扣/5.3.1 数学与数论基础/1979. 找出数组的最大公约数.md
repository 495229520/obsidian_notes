# 1979. 找出数组的最大公约数

> 返回数组中**最大值**和**最小值**的最大公约数。

**关键技巧**：只需数组的最小值和最大值，不需要完整排序——用 `std::minmax_element` 一次遍历拿到两个值。

```cpp
class Solution {
public:
    int findGCD(vector<int>& nums) {
        auto [minIt, maxIt] = std::minmax_element(nums.begin(), nums.end());
        return gcd(*minIt, *maxIt);
    }

    int gcd(int a, int b) {
        if (b == 0) {
            return a;
        }

        return gcd(b, a % b);
    }
};
```

**复杂度**：`O(n)` 遍历数组 + `O(log min(a,b))` gcd。
