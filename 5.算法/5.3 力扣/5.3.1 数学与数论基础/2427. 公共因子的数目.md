# 2427. 公共因子的数目

> 给定两个正整数 `a` 和 `b`，返回 `a` 和 `b` 的**公因子**的数目。公因子是能同时整除 `a` 和 `b` 的数。

**关键洞察**：`a` 和 `b` 的公共因子一定是 `gcd(a, b)` 的因子，所以可以先求最大公约数，再统计它的因子个数。

```cpp
class Solution {
public:
    int commonFactors(int a, int b) {
        int common = gcd(a, b);
        int count = 0;

        for (int i = 1; i <= common; ++i) {
            if (common % i == 0) {
                ++count;
            }
        }

        return count;
    }

    int gcd(int a, int b) {
        if (b == 0) {
            return a;
        }

        return gcd(b, a % b);
    }
};
```

**复杂度**：`O(min(a, b))`，统计因子个数需要遍历到 `gcd(a, b)`。
