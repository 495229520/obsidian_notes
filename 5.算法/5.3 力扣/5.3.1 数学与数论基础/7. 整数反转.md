# 7. 整数反转

> 给定一个 32 位有符号整数 `x`，把它的十进制数字反转。如果反转后超出 32 位有符号整数范围，返回 `0`。

这题是典型的**逐位取数 + 溢出判断**。核心操作是：

```text
digit = x % 10      // 取末位
x     = x / 10      // 砍掉末位
res   = res * 10 + digit   // 把末位拼到 res 的尾部
```

## 一、核心思路

每次从 `x` 的末尾取出一位数字，拼接到答案 `res` 的末尾。**`x` 被取走的末位（红色），恰好成为 `res` 的新末位（绿色）**，这条线索贯穿整个过程：

对应的状态表：

| 步骤 | digit | x 变成 | res 变成 |
|------|------:|-------:|---------:|
| 1 | 3 | 12 | 3 |
| 2 | 2 | 1 | 32 |
| 3 | 1 | 0 | 321 |

如果 `x` 是负数，C++ 中 `%` 和 `/` 会**向零取整并保留符号**：

```text
-123 % 10 = -3
-123 / 10 = -12
```

所以同一套循环也能自然处理负数，`res` 会一路保持负号，无需单独取绝对值。

## 二、代码（long long 解法）

```cpp
class Solution {
public:
    int reverse(int x) {
        long long res = 0;

        while (x != 0) {
            int digit = x % 10;
            x /= 10;

            res = res * 10 + digit;
        }

        if (res > INT_MAX || res < INT_MIN) {
            return 0;
        }

        return (int)res;
    }
};
```

## 三、为什么用 long long

题目要求返回 `int`，但反转过程中 `res` 可能**临时超出 `int` 范围**。例如 `x = 1534236469` 反转后是 `9646324351`，远大于 `INT_MAX`（约 21.5 亿），按题意应返回 `0`。

`long long`（约 ±9.2×10¹⁸）足以容纳任何 32 位整数的反转结果，于是可以**先安全算出，再统一判断越界**：

> [!tip] 一句话
> `long long` 是「安全缓冲区」：让你把可能溢出的中间结果先算完，最后只做一次边界判断，逻辑最简单。

> [!warning]
> 如果题目额外要求**不能使用 64 位整数**，就必须在 `res = res * 10 + digit` *之前* 提前判断会不会溢出，见下一节。

## 四、进阶：不用 64 位整数的提前溢出判断

如果只能用 `int`，思路是：在乘 10 拼接之前，先检查这一步会不会越界。关键边界来自 `INT_MAX = 2147483647` 和 `INT_MIN = -2147483648` 的**末位 7 和 -8**：

```cpp
class Solution {
public:
    int reverse(int x) {
        int res = 0;

        while (x != 0) {
            int digit = x % 10;        // 范围 [-9, 9]
            x /= 10;

            // 正向溢出：res*10 + digit > INT_MAX
            if (res > INT_MAX / 10 || (res == INT_MAX / 10 && digit > 7)) {
                return 0;
            }
            // 负向溢出：res*10 + digit < INT_MIN
            if (res < INT_MIN / 10 || (res == INT_MIN / 10 && digit < -8)) {
                return 0;
            }

            res = res * 10 + digit;
        }

        return res;
    }
};
```

判断逻辑拆解（以正向为例）：

- `res > INT_MAX / 10`：再乘 10 必然超界，直接返回 `0`；
- `res == INT_MAX / 10 && digit > 7`：乘 10 后正好顶到 `214748364?`，而 `INT_MAX` 的末位是 `7`，所以 `digit` 一旦大于 `7` 就溢出。

负向同理，`INT_MIN` 末位是 `-8`，故用 `digit < -8` 判断。

> [!note] 两种写法对比
> - `long long` 版：好写、好懂，面试默认首选。
> - `int` 提前判断版：不依赖更宽的整型，是面试常见的追问，体现你理解溢出边界。

## 五、易错点

| 易错点 | 说明 |
|--------|------|
| 负数处理 | 不需要单独取绝对值，直接用 `% 10` 和 `/ 10` 即可 |
| 溢出判断 | 反转结果超过 `INT_MAX` 或小于 `INT_MIN` 时返回 `0` |
| 末尾零 | `120` 会自然反转成 `21`（前导零不存在） |
| 输入为 `0` | 循环不进入，直接返回 `0` |
| 边界末位 7/8 | `int` 提前判断时，正向比 `7`、负向比 `-8`，别写反 |

## 六、复杂度

设整数有 `k` 位（十进制位数）。

- 时间复杂度：`O(k)` —— 每位处理一次，`k ≤ 10`
- 空间复杂度：`O(1)`
