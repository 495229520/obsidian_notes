### 49. 字母异位词分组

将每个字符串排序后作为哈希表的 key，排序结果相同的字符串归入同一组。

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> hash;

        for (string str : strs) {
            string key = str;
            sort(key.begin(), key.end());
            hash[key].push_back(str);
        }

        vector<vector<string>> result;
        for (auto& pair : hash) {
            result.push_back(pair.second);
        }

        return result;
    }
};
```

### 128. 最长连续序列

先用 `unordered_set` 去重；只从序列起点（不存在 `num - 1`）开始向后扫描，避免重复遍历。

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        int len = static_cast<int>(nums.size());
        if (len <= 1) {
            return len;
        }

        unordered_set<int> hash(nums.begin(), nums.end());
        int maxLen = 1;

        for (int num : hash) {
            if (hash.find(num - 1) != hash.end()) {
                continue;
            }

            int currentNum = num;
            int currentLen = 1;
            while (hash.find(currentNum + 1) != hash.end()) {
                currentNum++;
                currentLen++;
            }

            maxLen = max(currentLen, maxLen);
        }

        return maxLen;
    }
};
```

### 88. 合并两个有序数组

快速做法：从两个数组的末尾开始比较，把较大值放入 `nums1` 的末尾，避免覆盖尚未处理的元素。整体时间复杂度 `O(m + n)`，额外空间复杂度 `O(1)`。

```cpp
class Solution {
public:
    void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int k = m + n - 1;

        while (i >= 0 && j >= 0) {
            nums1[k--] = nums1[i] > nums2[j] ? nums1[i--] : nums2[j--];
        }

        while (j >= 0) {
            nums1[k--] = nums2[j--];
        }
    }
};
```

### 148. 排序链表

题解已单独整理：[[5.算法/5.3 力扣/5.3.9 链表/148. 排序链表|148. 排序链表]]。

复习重点：

- `fast` 从 `head->next` 开始，保证两节点链表能够切成两个单节点链表。
- 找到右半段入口后必须执行 `slow->next = nullptr`，否则递归规模不会缩小。
- 当前实现是递归归并排序，时间复杂度 `O(nlogn)`，额外空间复杂度为递归栈 `O(logn)`。
