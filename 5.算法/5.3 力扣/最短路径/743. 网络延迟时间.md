# 743. 网络延迟时间

`n` 个网络节点，给定有向带权边 `times[i] = [u, v, w]`（从 `u` 到 `v` 传一条信号需要 `w` 时间）。从节点 `k` 同时向所有可达节点广播信号，求所有节点都收到信号所需的最少时间；若有节点不可达，返回 `-1`。

本质：单源最短路径中，对所有节点取 `max(dist[i])`。

---

## 1. 题目概览

### 1.1 题目描述

有 `n` 个网络节点，标记为 `1` 到 `n`。

给你一个列表 `times`，表示信号经过有向边的传递时间。`times[i] = (u_i, v_i, w_i)`，其中 `u_i` 是源节点，`v_i` 是目标节点，`w_i` 是一个信号从源节点传递到目标节点的时间。

现在，从某个节点 `k` 发出一个信号。需要多久才能使所有节点都收到信号？如果不能使所有节点收到信号，返回 `-1`。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | `times: vector<vector<int>>`、`n: int`、`k: int` |
| 输出 | 所有节点收到信号所需的最少时间 `int`；不可达返回 `-1` |
| 节点数 | `1 <= n <= 100` |
| 边数 | `1 <= times.length <= 6000` |
| 边权 | `0 <= w_i <= 100` |
| 起点 | `1 <= k <= n` |

### 1.3 示例

#### 示例一

```text
输入：times = [[2,1,1],[2,3,1],[3,4,1]], n = 4, k = 2
输出：2
解释：从节点 2 出发，1 在时刻 1 收到，3 在时刻 1 收到，4 在时刻 2 收到。
```

#### 示例二

```text
输入：times = [[1,2,1]], n = 2, k = 1
输出：1
```

#### 示例三

```text
输入：times = [[1,2,1]], n = 2, k = 2
输出：-1
解释：从 2 出发无法到达 1。
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 朴素 Dijkstra | 每轮在未确定集合中找最小 dist | `dist` + 数组扫描 | 可行 | `O(n^2)`，`n = 100` 没问题 |
| 堆优化 Dijkstra | 用小顶堆维护「下一个最近」节点 | `priority_queue` + 邻接表 | 推荐 | `O((n + m) log n)`，是图论必备模板 |
| Bellman-Ford | 反复对所有边松弛 `n - 1` 次 | 边集数组 | 可行但慢 | 边权非负时不必使用 |
| Floyd-Warshall | 求所有点对最短路径 | `n × n` 矩阵 | 用力过猛 | `O(n^3)`，本题只需单源 |

### 2.2 本题采用的算法

**堆优化 Dijkstra**。题目带权且非负，是 Dijkstra 的标准应用场景。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 |
|----------|----------------|
| `vector<vector<pair<int,int>>>` | 邻接表 + 边权：`g[u]` 存放 `(v, w)` |
| `vector<int> dist` | 起点到每个节点的当前最短距离 |
| `priority_queue<pair<int,int>, vector<...>, greater<>>` | 小顶堆，按当前 `dist` 选取下一个待扩展节点 |

## 3. 解题步骤

### 3.1 核心思路

1. 把 `times` 转成邻接表 `g`。
2. 初始化 `dist[k] = 0`，其余为无穷大。
3. 用小顶堆按当前 `dist` 取出最近节点 `u`，对 `u` 的所有出边 `(v, w)` 做松弛：若 `dist[u] + w < dist[v]`，更新并把 `(dist[v], v)` 入堆。
4. 堆空后，`max(dist)` 即所有节点都收到信号的时间；若仍存在 `dist[i] == INF`，返回 `-1`。

### 3.2 详细步骤

#### 第一步：建图

```cpp
vector<vector<pair<int, int>>> g(n + 1);
for (auto& e : times) {
    g[e[0]].emplace_back(e[1], e[2]);
}
```

注意题目里节点编号是 1-based，邻接表大小开 `n + 1`，下标 `0` 弃用即可。

#### 第二步：初始化与堆

```cpp
constexpr int INF = numeric_limits<int>::max();
vector<int> dist(n + 1, INF);
dist[k] = 0;

using PII = pair<int, int>;
priority_queue<PII, vector<PII>, greater<PII>> pq;
pq.emplace(0, k);
```

#### 第三步：循环松弛

```cpp
while (!pq.empty()) {
    auto [d, u] = pq.top();
    pq.pop();

    if (d > dist[u]) continue;          // 过期记录

    for (auto [v, w] : g[u]) {
        if (dist[u] + w < dist[v]) {
            dist[v] = dist[u] + w;
            pq.emplace(dist[v], v);
        }
    }
}
```

#### 第四步：取所有节点 dist 的最大值

```cpp
int ans = 0;
for (int i = 1; i <= n; ++i) {
    if (dist[i] == INF) return -1;
    ans = max(ans, dist[i]);
}
return ans;
```

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    int networkDelayTime(vector<vector<int>>& times, int n, int k) {
        vector<vector<pair<int, int>>> g(n + 1);
        for (auto& e : times) {
            g[e[0]].emplace_back(e[1], e[2]);
        }

        constexpr int INF = numeric_limits<int>::max();
        vector<int> dist(n + 1, INF);
        dist[k] = 0;

        using PII = pair<int, int>;
        priority_queue<PII, vector<PII>, greater<PII>> pq;
        pq.emplace(0, k);

        while (!pq.empty()) {
            auto [d, u] = pq.top();
            pq.pop();

            if (d > dist[u]) continue;

            for (auto [v, w] : g[u]) {
                if (dist[u] + w < dist[v]) {
                    dist[v] = dist[u] + w;
                    pq.emplace(dist[v], v);
                }
            }
        }

        int ans = 0;
        for (int i = 1; i <= n; ++i) {
            if (dist[i] == INF) return -1;
            ans = max(ans, dist[i]);
        }
        return ans;
    }
};
```

## 6. 源码详解

### 6.1 关键点

| 代码 | 含义 |
|------|------|
| `priority_queue<PII, vector<PII>, greater<PII>>` | 显式指定容器与比较器，得到小顶堆。`pair` 默认按 `first` 升序，所以堆顶是当前最短的距离 |
| `pq.emplace(0, k)` | 起点入堆，距离 0 |
| `if (d > dist[u]) continue;` | 过期记录处理：堆里可能存在同一节点的旧（更大）距离，这条记录已经被新的覆盖，直接丢弃 |
| `pq.emplace(dist[v], v)` | 不删除旧记录，直接插入新记录；通过上面那行过期检查兜底 |

### 6.2 为什么需要「过期记录」处理

C++ 的 `priority_queue` 不支持 decrease-key 操作。当我们松弛 `v` 时只能往堆里追加新的 `(dist[v], v)`，旧的较大记录还留在堆里。出堆时若 `d > dist[u]` 就说明这是一个被更短路径取代的过期项。

### 6.3 为什么 BFS 解不了

BFS 假设所有边权相等（视为 1），第一次到达即最短。本题边权 `0 <= w <= 100`，BFS 给出的是「最少经过几条边」而不是「累积权重最小」，会得错误结果。

### 6.4 易错点

1. **节点编号 1-based**：邻接表与 `dist` 都要开到 `n + 1`，最终循环也从 `1` 到 `n`。
2. **`priority_queue` 默认是大顶堆**：必须显式写 `greater<PII>` 才能得到小顶堆。
3. **`INF` 加法溢出**：本题边权小，不易触发；但通用 Dijkstra 模板要警惕 `dist[u] + w` 在 `dist[u] == INT_MAX` 时溢出。可以先 `if (dist[u] == INF) continue;` 防御，或选用 `LLONG_MAX / 2` 做 INF。
4. **不可达节点判断**：若有节点 `dist[i] == INF`，说明从 `k` 到不了它，必须返回 `-1` 而不是 `0`。

> [!warning]
> 本题如果数据范围扩大到包含负权边（题目并不允许，仅作警示），Dijkstra 会得到错误结果，此时必须改用 Bellman-Ford。

## 7. 复杂度分析

设 `n` 为节点数，`m = times.size()` 为边数：

| 指标 | 复杂度 |
|------|--------|
| 时间 | `O((n + m) log n)` |
| 空间 | `O(n + m)` 邻接表 + `dist` + 堆 |

每条边最多导致一次入堆与一次松弛操作，每次堆操作是 `O(log n)`。
