# 15. 三数之和

给定整数数组 `nums`，要求找出所有不重复的三元组，使得三元组中三个数的和等于 `0`。

---

## 1. 题目概览

### 1.1 题目描述

给你一个整数数组 `nums` ，判断是否存在三元组 `[nums[i], nums[j], nums[k]]` 满足 `i != j`、`i != k` 且 `j != k` ，同时还满足 `nums[i] + nums[j] + nums[k] == 0` 。请你返回所有和为 `0` 且不重复的三元组。

注意：答案中不可以包含重复的三元组。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | 整数数组 `nums` |
| 输出 | 所有和为 `0` 且不重复的三元组 |
| 数组长度 | `3 <= nums.length <= 3000` |
| 元素范围 | `-10^5 <= nums[i] <= 10^5` |
| 特殊说明 | 输出顺序和三元组内部顺序不重要，但不能包含重复三元组 |

> [!warning]
> 本题最容易错在“去重”。排序后既要跳过重复的固定数 `nums[i]`，也要在命中答案后跳过重复的 `left` / `right`。

### 1.3 示例

#### 示例一

```text
输入：nums = [-1,0,1,2,-1,-4]
输出：[[-1,-1,2],[-1,0,1]]
解释：
nums[0] + nums[1] + nums[2] = (-1) + 0 + 1 = 0 。
nums[1] + nums[2] + nums[4] = 0 + 1 + (-1) = 0 。
nums[0] + nums[3] + nums[4] = (-1) + 2 + (-1) = 0 。
不同的三元组是 [-1,0,1] 和 [-1,-1,2] 。
注意，输出的顺序和三元组的顺序并不重要。
```

#### 示例二

```text
输入：nums = [0,1,1]
输出：[]
解释：唯一可能的三元组和不为 0 。
```

#### 示例三

```text
输入：nums = [0,0,0]
输出：[[0,0,0]]
解释：唯一可能的三元组和为 0 。
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 三层枚举 | 暴力枚举三元组 | 数组下标 | 不推荐 | 时间复杂度 `O(n^3)`，容易超时 |
| 哈希辅助 | 固定一个数，再做两数之和 | 哈希集合 | 可行 | 去重处理比较麻烦 |
| 排序 + 双指针 | 固定一个数，左右夹逼找另外两个数 | 排序数组 + 双指针 | 推荐 | 时间 `O(n^2)`，去重逻辑清晰 |

### 2.2 本题采用的算法

本题采用：**排序 + 双指针**。

选择它的原因：

1. 排序后数组具有单调性，可以根据三数之和大小移动左右指针。
2. 固定一个数后，问题可以降维成有序数组中的两数之和。
3. 排序后重复值相邻，方便统一去重。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 | 为什么需要它 |
|----------|----------------|--------------|
| `vector<int>` | 存储输入数组 | 支持排序和下标访问 |
| `vector<vector<int>>` | 保存所有三元组答案 | 返回多个结果 |
| `left`、`right` | 在有序区间中查找两数之和 | 通过左右夹逼降低复杂度 |

## 3. 解题步骤

### 3.1 核心思路

三数之和可以转化成“固定一个数，再在剩余区间里找两数之和”。

先将数组升序排序。固定 `nums[i]` 后，在它右侧区间 `[i + 1, n - 1]` 中使用双指针：

```text
nums[i] + nums[left] + nums[right]
```

如果三数之和太小，就移动 `left` 让和变大；如果三数之和太大，就移动 `right` 让和变小；如果等于 `0`，就记录答案并跳过重复值。

### 3.2 详细步骤

#### 第一步：排序数组

```cpp
sort(nums.begin(), nums.end());
```

排序后，相同数字相邻，方便去重；同时数组具备单调性，可以使用双指针。

#### 第二步：枚举第一个数

从左到右枚举 `i`：

1. 如果 `nums[i] > 0`，可以直接结束。
2. 如果 `i > 0 && nums[i] == nums[i - 1]`，跳过当前重复固定数。

#### 第三步：双指针查找另外两个数

初始化：

```cpp
int left = i + 1;
int right = n - 1;
```

当 `left < right` 时：

- `sum < 0`：说明当前和太小，`left++`
- `sum > 0`：说明当前和太大，`right--`
- `sum == 0`：加入答案，然后跳过重复的 `left` 和 `right`

### 3.3 示例推演

以 `nums = [-1,0,1,2,-1,-4]` 为例。

排序后：

```text
[-4, -1, -1, 0, 1, 2]
```

| 固定数 | 双指针过程 | 结果 |
|--------|------------|------|
| `-4` | 右侧找两数之和为 `4`，找不到 | 无 |
| `-1` | `-1 + (-1) + 2 = 0` | `[-1,-1,2]` |
| `-1` | 与上一个固定数重复，跳过 | 避免重复 |
| `0` | `0 + ...` 无新答案 | 无 |

最终答案为：

```text
[[-1,-1,2],[-1,0,1]]
```

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());

        int n = nums.size();

        for (int i = 0; i < n; i++) {
            if (nums[i] > 0) {
                break;
            }

            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            int left = i + 1;
            int right = n - 1;

            while (left < right) {
                int sum = nums[i] + nums[left] + nums[right];

                if (sum > 0) {
                    right--;
                } else if (sum < 0) {
                    left++;
                } else {
                    res.push_back({nums[i], nums[left], nums[right]});

                    while (left < right && nums[left] == nums[left + 1]) {
                        left++;
                    }

                    while (left < right && nums[right] == nums[right - 1]) {
                        right--;
                    }

                    left++;
                    right--;
                }
            }
        }

        return res;
    }
};
```

### 5.2 代码中的关键注释

| 代码位置 | 解释重点 |
|----------|----------|
| `sort(nums.begin(), nums.end())` | 排序建立单调性，并让重复值相邻 |
| `nums[i] > 0` | 当前数已大于 0，后面三数和不可能为 0 |
| `nums[i] == nums[i - 1]` | 固定数去重 |
| `left++` / `right--` | 根据当前和大小调整 |
| 命中答案后的两个 `while` | 跳过重复的第二、第三个数 |

## 6. 源码详解

### 6.1 核心变量说明

| 变量 / 数据结构 | 含义 | 生命周期 | 为什么需要它 |
|-----------------|------|----------|--------------|
| `res` | 最终答案列表 | 整个函数过程 | 保存所有不重复三元组 |
| `i` | 固定的第一个数下标 | 外层循环 | 把三数之和降维成两数之和 |
| `left` | 右侧区间左指针 | 内层循环 | 指向候选第二个数 |
| `right` | 右侧区间右指针 | 内层循环 | 指向候选第三个数 |
| `sum` | 当前三数之和 | 每轮内层循环 | 决定指针移动方向 |

### 6.2 为什么排序后可以用双指针

排序后，数组从小到大排列。

固定 `nums[i]` 后：

- 如果 `sum < 0`，说明当前和太小，需要让和变大，所以 `left++`
- 如果 `sum > 0`，说明当前和太大，需要让和变小，所以 `right--`
- 如果 `sum == 0`，说明找到一个答案

这就是双指针能够把内层查找从 `O(n^2)` 降到 `O(n)` 的原因。

### 6.3 去重逻辑

#### 固定数 `i` 的去重

```cpp
if (i > 0 && nums[i] == nums[i - 1]) {
    continue;
}
```

如果当前固定的数和上一次相同，就会产生重复三元组。

#### 命中答案后的双指针去重

```cpp
while (left < right && nums[left] == nums[left + 1]) {
    left++;
}
while (left < right && nums[right] == nums[right - 1]) {
    right--;
}
```

找到一个答案后，`left` 和 `right` 指向的值也可能重复，需要先跳过重复值，再同时移动两个指针。

### 6.4 易错点

1. 不能用三层循环暴力做，否则容易超时。
2. 必须先排序，否则双指针移动没有单调性依据。
3. `i` 的去重条件必须是 `i > 0 && nums[i] == nums[i - 1]`。
4. 找到答案后，要先跳过重复的 `left/right`，再同时移动两个指针。
5. `nums[i] > 0` 后可以直接 `break`，不是 `continue`。
6. 返回结果不能包含重复三元组。

## 7. 复杂度分析

### 7.1 时间复杂度

- 时间复杂度：`O(n^2)`

原因：排序需要 `O(nlogn)`，外层枚举 `i`，内层双指针总体为 `O(n)`，主导复杂度是 `O(n^2)`。

### 7.2 空间复杂度

- 空间复杂度：`O(logn)` 到 `O(n)`

原因：额外空间主要来自排序实现的递归栈或临时空间，不计答案数组。
