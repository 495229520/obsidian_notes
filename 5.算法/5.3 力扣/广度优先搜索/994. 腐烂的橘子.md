# 994. 腐烂的橘子

给定一个 `m × n` 的网格，每个格子是空、好橘子、烂橘子三种状态之一。每分钟，烂橘子会让四方向相邻的好橘子也变烂。求让所有好橘子都腐烂所需的最少分钟数；若不可能则返回 `-1`。

---

## 1. 题目概览

### 1.1 题目描述

在给定的 `m × n` 网格 `grid` 中，每个单元格可以有以下三个值之一：

- `0` 表示空单元格
- `1` 表示新鲜橘子
- `2` 表示腐烂的橘子

每分钟，腐烂的橘子周围 4 个方向上相邻的新鲜橘子都会腐烂。返回直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1`。

### 1.2 输入输出与约束

| 项目 | 内容 |
|------|------|
| 输入 | `grid: vector<vector<int>>` |
| 输出 | 最少分钟数 `int`；不可能返回 `-1` |
| 行数 | `1 <= m <= 10` |
| 列数 | `1 <= n <= 10` |
| 元素 | `0` / `1` / `2` |

### 1.3 示例

#### 示例一

```text
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
```

#### 示例二

```text
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角的橘子永远不会腐烂，因为它的四周没有腐烂橘子可以传染过来。
```

#### 示例三

```text
输入：grid = [[0,2]]
输出：0
解释：一开始没有新鲜橘子，所以答案是 0。
```

## 2. 可用算法与数据结构

### 2.1 可选解法总览

| 方案 | 核心算法 | 核心数据结构 | 是否适合本题 | 原因 |
|------|----------|--------------|--------------|------|
| 暴力模拟 | 每分钟扫一遍网格找新腐烂橘子 | `vector` | 可行但慢 | `O((m × n)^2)`，浪费 |
| 多源 BFS | 所有腐烂橘子同时入队，分层扩展 | `queue<pair<int,int>>` | 推荐 | `O(m × n)`，与 BFS 求最短步数模型完全一致 |

### 2.2 本题采用的算法

**多源 BFS**。把所有初始腐烂橘子作为同一层，配合分层扩展，BFS 的层数即所需的总分钟数。

### 2.3 本题使用的数据结构

| 数据结构 | 在本题中的作用 |
|----------|----------------|
| `queue<pair<int,int>>` | 存放当前层待扩散的烂橘子坐标 |
| `int fresh` | 剩余新鲜橘子计数，用来判断最终能否全部腐烂 |
| `int minutes` | 当前已经经过的分钟数 |
| 方向数组 `dirs[4][2]` | 四方向偏移 |

## 3. 解题步骤

### 3.1 核心思路

「多分钟同时扩散」等价于「所有起点同时入队的 BFS」。每一层出队意味着流逝一分钟。

### 3.2 详细步骤

1. 初始化：扫一遍网格，统计 `fresh` 数量，把所有 `2` 入队。
2. 若 `fresh == 0`，直接返回 `0`。
3. BFS 分层扩展：每层取出当前队列里的所有烂橘子，对四方向相邻的新鲜橘子标记为 `2` 并入队，`fresh--`。
4. 每完成一层 `minutes++`。
5. 队列空后：若 `fresh == 0` 返回 `minutes`，否则返回 `-1`。

### 3.3 示例推演

以 `grid = [[2,1,1],[1,1,0],[0,1,1]]` 为例：

| 分钟 | 此时已腐烂的位置 | fresh |
|------|-----------------|-------|
| 0 | `(0,0)` | 6 |
| 1 | `(0,0), (0,1), (1,0)` | 4 |
| 2 | 上 + `(0,2), (1,1)` | 2 |
| 3 | 上 + `(2,1)` | 1 |
| 4 | 上 + `(2,2)` | 0 |

最终 `fresh == 0`，返回 `4`。

## 5. 源码实现

### 5.1 完整 C++ 代码

```cpp
class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = grid.size();
        int n = grid[0].size();
        queue<pair<int, int>> q;
        int fresh = 0;

        for (int i = 0; i < m; ++i) {
            for (int j = 0; j < n; ++j) {
                if (grid[i][j] == 2) {
                    q.emplace(i, j);
                } else if (grid[i][j] == 1) {
                    ++fresh;
                }
            }
        }

        if (fresh == 0) return 0;

        const int dirs[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        int minutes = 0;

        while (!q.empty() && fresh > 0) {
            int sz = q.size();                // 当前层大小
            for (int k = 0; k < sz; ++k) {
                auto [x, y] = q.front();
                q.pop();

                for (auto& d : dirs) {
                    int nx = x + d[0];
                    int ny = y + d[1];
                    if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
                    if (grid[nx][ny] != 1) continue;

                    grid[nx][ny] = 2;
                    --fresh;
                    q.emplace(nx, ny);
                }
            }
            ++minutes;
        }

        return fresh == 0 ? minutes : -1;
    }
};
```

## 6. 源码详解

### 6.1 关键变量

| 变量 | 含义 |
|------|------|
| `fresh` | 当前剩余新鲜橘子数；用来判断结束条件与不可达情况 |
| `minutes` | 已经过的分钟数；每完成一层 BFS 加一 |
| `sz = q.size()` | 当前层节点数；必须先快照，否则边遍历边入队会把下一层混入本层 |

### 6.2 关键技巧：分层 BFS

普通 BFS 用 `dist[v] = dist[u] + 1` 直接保存距离即可。但如果只关心「最远那个节点的距离」，可以用「每出队一层 `minutes++`」的写法，节省 `dist` 数组。

注意：取队列大小要在 `for` 之前完成，循环内部不能写 `q.size()`，否则会扩散到下一层。

### 6.3 易错点

1. **初始没有新鲜橘子**：直接返回 `0`，否则 BFS 会跑 0 层但仍然返回 `0` ——其实代码中 `if (fresh == 0) return 0;` 这一句必须有。
2. **修改格子状态时机**：取出邻居后立即把 `grid[nx][ny] = 2` 并入队；如果延后到出队时再改，邻居会被多次重复入队。
3. **出队循环条件**：`while (!q.empty() && fresh > 0)` 可以提前结束；但如果忘记 `fresh > 0`，最后一层的 `minutes++` 仍会触发，导致答案多 1。
4. **判断不可达**：BFS 结束后必须再查一次 `fresh`，因为可能存在被空格隔开的孤立新鲜橘子。

> [!warning]
> 易错：把 `q.size()` 写在 `for (int k = 0; k < q.size(); ++k)` 里。每次出队 `q.size()` 都会变小，循环变量上限一边减一边比较，会导致只处理半层。务必先用 `int sz = q.size();` 快照。
