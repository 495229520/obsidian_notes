# 191. 位 1 的个数

## 位运算技巧简介

> [!note]
> Brian Kernighan 算法和 `n & (n-1)` 技巧已在 [[5.算法/5.2 算法/5.2.2 位运算|5.2.2 位运算]] 中详细介绍，此处不再重复。

---

## 题目描述

给定一个无符号整数 `n`，返回其二进制表示中 `1` 的个数（也称为**汉明权重 Hamming Weight**）。

### 示例

```text
输入：n = 11 (二进制 1011)
输出：3
解释：1011 中有三个 1。
```

> [!important]
> 输入是**无符号整数**，不需要考虑负数和符号位。

---

## 解题思路

核心操作只有一个：`n &= (n - 1)` —— 每次消去 `n` 二进制中**最低位的 1**。

### 原理

```text
n     = ...1000   （最低位的 1 和它右边的 0）
n - 1 = ...0111   （该位变 0，右边全变 1）
n & (n-1) = ...0000   （最低位的 1 被消去）
```

反复执行直到 `n` 变成 `0`，执行了几次就说明原来有几个 `1`。

### 步骤分解

1. 初始化计数器 `sum = 0`
2. 当 `n != 0` 时循环：执行 `n &= (n - 1)` 消去一个 `1`，`sum++`
3. 返回 `sum`

### 图解

![[图片/5.算法/5.3 力扣/5.3.2 位运算/5_1_191_1.svg|760]]

以 `n = 11 (1011)` 为例，三轮操作分别消去从低到高的三个 `1`，循环恰好执行 3 次。

---

## 代码实现

```cpp
class Solution {
public:
    int hammingWeight(int n) {
        int sum = 0;
        while (n != 0) {
            n &= (n - 1);
            sum++;
        }
        return sum;
    }
};
```

### 代码分析

- `n &= (n - 1)`：每次去掉最低位的 `1`，这是 Brian Kernighan 算法的核心。
- 循环条件 `n != 0`：当所有 `1` 都被消完时退出。
- 循环次数**等于 `1` 的个数**，而非整数的总位数（32 位），这就是该算法比逐位检查更优的地方。

---

## 易错点

1. **把循环条件写成固定 32 次**：虽然结果正确，但 Brian Kernighan 的优势就在于按 `1` 的个数循环，写成 32 次就退化成逐位检查了。
2. **对有符号整数右移**：如果用 `n >>= 1` 的逐位检查法，负数右移会在高位填 `1` 导致死循环。本题用 `n & (n-1)` 不受影响。

> [!warning]
> C++20 可以用 `std::popcount(static_cast<unsigned>(n))` 一行搞定，但面试时通常要求手写 Brian Kernighan 算法，需要理解 `n & (n-1)` 的原理。

---

## 复杂度

- **时间复杂度**：`O(k)` — `k` 是二进制中 `1` 的个数（最多 32 次）
- **空间复杂度**：`O(1)` — 只用了一个计数变量
