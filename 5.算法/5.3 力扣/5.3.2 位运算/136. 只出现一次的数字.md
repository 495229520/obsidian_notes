# 136. 只出现一次的数字

> 给定一个非空整数数组 `nums`，除了某个元素只出现一次以外，其余每个元素均出现两次。找出那个只出现了一次的元素。

这题是**异或运算**最经典的应用：成对的数异或后抵消为 `0`，剩下的就是只出现一次的数。

## 一、核心原理

异或有三个关键性质：

```text
a ^ a = 0     相同数字抵消
a ^ 0 = a     和 0 异或不变
a ^ b = b ^ a 交换律
```

把数组中所有元素异或起来：

```text
nums = [4, 1, 2, 1, 2]

4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4 ^ 0 ^ 0
= 4
```

成对出现的元素全部抵消，最后只剩下那个唯一的数。

## 二、代码

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        if (nums.size() == 1) {
            return nums[0];
        }
        int res = nums[0];
        for (int i = 1; i < nums.size(); i++) {
            res ^= nums[i];
        }
        return res;
    }
};
```

## 三、可以更简洁

`size() == 1` 的特判其实不需要，因为当数组只有一个元素时，循环不会执行，`res` 就是 `nums[0]`。

初始值设为 `0` 可以统一处理：

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int res = 0;
        for (int x : nums) {
            res ^= x;
        }
        return res;
    }
};
```

`res` 从 `0` 开始，因为 `0 ^ x = x`，不影响结果。这样也避免了下标从 `1` 开始的写法。

## 四、过程示例

以 `nums = [2, 1, 4, 1, 2]` 为例：

| 步骤 | 当前元素 | res（十进制） | res（二进制） | 操作 |
|-----:|---------:|-------------:|-------------:|------|
| 0 | - | 0 | `000` | 初始值 |
| 1 | 2 | 2 | `010` | `0 ^ 2 = 2` |
| 2 | 1 | 3 | `011` | `2 ^ 1 = 3` |
| 3 | 4 | 7 | `111` | `3 ^ 4 = 7` |
| 4 | 1 | 6 | `110` | `7 ^ 1 = 6` |
| 5 | 2 | 4 | `100` | `6 ^ 2 = 4` |

最终结果为 `4`，正是唯一出现一次的数。

## 五、为什么不用哈希表

| 方法 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 异或 | `O(n)` | `O(1)` | 最优解 |
| 哈希表计数 | `O(n)` | `O(n)` | 需要额外空间 |
| 排序后比较 | `O(n log n)` | `O(1)` | 改变了原数组 |

题目要求线性时间、常数空间，异或是唯一满足的方法。

## 六、易错点

| 易错点 | 说明 |
|--------|------|
| 初始值选择 | 从 `0` 开始比从 `nums[0]` 开始更简洁 |
| 异或顺序 | 异或满足交换律和结合律，顺序无关 |
| 负数 | 异或对负数同样有效，因为是按位操作 |

## 七、复杂度

- 时间复杂度：`O(n)`，遍历一次数组
- 空间复杂度：`O(1)`，只用一个变量
