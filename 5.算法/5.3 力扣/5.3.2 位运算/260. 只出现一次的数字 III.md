# 260. 只出现一次的数字 III

> 给定一个整数数组 `nums`，其中恰好有**两个**元素只出现一次，其余所有元素均出现两次。找出只出现一次的那两个元素。要求线性时间、常数空间。

这题是 [[5.算法/5.3 力扣/5.3.2 位运算/136. 只出现一次的数字|136. 只出现一次的数字]] 的进阶版。136 题只有一个唯一数，全部异或即可得到。现在有两个唯一数，直接异或只能得到它们的异或值，需要一个额外的手段把它们分离出来。

---

## 一、思路：异或 + 分组

整体分三步：

**Step 1**：把所有数异或起来，得到 `x = a ^ b`（成对的数自动抵消）。

**Step 2**：`x` 中为 `1` 的位，说明 `a` 和 `b` 在这一位上不同。取 `x` 最低位的 `1`（`bit = x & -x`），用这一位作为分组标准。

**Step 3**：遍历数组，按这一位是 `1` 还是 `0` 分成两组。成对出现的数一定被分到同一组（因为它们二进制完全相同），而 `a` 和 `b` 一定被分到不同组。对每组分别异或，就得到了 `a` 和 `b`。

> [!tip]
> 关键洞察：`x & -x` 取出的那一位，是 `a` 和 `b` 的"分歧位"。相同的数在这一位上一样，所以分组后一定还在一起；而 `a` 和 `b` 在这一位不同，自然被分开。

## 二、图解过程

以 `nums = [1, 2, 1, 3, 2, 5]` 为例：

![[图片/5.算法/5.3 力扣/5.3.2 位运算/lc_260_xor_split.svg]]

| 步骤 | 操作 | 结果 |
|------|------|------|
| 全部异或 | `1^2^1^3^2^5` | `x = 6 (0b110)` |
| 取最低位 1 | `6 & -6` | `bit = 2 (0b010)` |
| 绿组 (bit1=1) | `2^3^2` | `a = 3` |
| 蓝组 (bit1=0) | `1^1^5` | `b = 5` |

## 三、代码

```cpp
class Solution {
public:
    vector<int> singleNumber(vector<int>& nums) {
        long long x = 0;

        // 1. 全部异或，得到两个答案的异或值 a ^ b
        for (int n : nums) {
            x ^= n;
        }

        // 2. 找到 x 中最低位的 1
        long long bit = x & -x;

        int a = 0, b = 0;

        // 3. 按这一位分组，各自异或
        for (int n : nums) {
            if (n & bit) {
                a ^= n;
            } else {
                b ^= n;
            }
        }

        return {a, b};
    }
};
```

---

## 四、为什么用 `long long`

`x` 声明为 `long long` 是为了处理 `x = INT_MIN` 的边界情况。

当 `x = -2147483648` 时，`-x` 会导致 `int` 溢出（`int` 的范围是 `[-2^31, 2^31-1]`，`-(-2^31)` 超出上界）。使用 `long long` 可以安全地计算 `-x`。

```text
INT_MIN = -2147483648 = 0x80000000
-INT_MIN 在 int 范围内是未定义行为
-INT_MIN 在 long long 范围内 = 2147483648，合法
```

---

## 五、分组的正确性

分组之所以有效，依赖两个性质：

| 性质 | 说明 |
|------|------|
| 成对元素分到同一组 | 两个相同的数，每一位都相同，所以 `n & bit` 结果一样 |
| `a` 和 `b` 分到不同组 | `bit` 选的是 `a ^ b` 中为 1 的位，说明 `a` 和 `b` 在这一位上不同 |

分到同一组后，成对的数异或抵消为 0，只剩下唯一的那个数。

---

## 六、`x & -x` 的原理

这是 lowbit 操作，取出 `x` 二进制中最右边的 `1`：

```text
x       = ...1010 1000
-x      = ...0101 1000   (取反 + 1)
x & -x  = ...0000 1000   (只保留最低位的 1)
```

补码的性质：`-x` 等价于 `~x + 1`。取反会把最低位 `1` 右边的 `0` 全变成 `1`，加 `1` 后进位，恰好只保留那个最低位的 `1`。

> [!note]
> 不一定要取最低位的 1，取 `x` 中任意一个为 1 的位都能实现分组。`x & -x` 只是最简洁的写法。

---

## 七、复杂度

- 时间复杂度：`O(n)`，两次遍历数组
- 空间复杂度：`O(1)`，只用了常数个变量

## 九、易错点

| 易错点 | 说明 |
|--------|------|
| `x` 类型用 `int` | 当 `x = INT_MIN` 时 `-x` 溢出，需要用 `long long` |
| 分组条件写反 | `n & bit` 判断的是这一位是否为 1，不是是否等于 `bit` |
| 忘记初始化 `a, b = 0` | 异或累加必须从 0 开始 |
