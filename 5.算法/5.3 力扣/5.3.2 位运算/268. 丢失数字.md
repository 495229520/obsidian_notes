# 268. 丢失数字

> 给定一个包含 `[0, n]` 中 `n` 个**不同**数字的数组 `nums`，找出 `[0, n]` 这个范围内**没有出现**在数组里的那个数字。

本题和 [[5.算法/5.3 力扣/5.3.2 位运算/136. 只出现一次的数字|136. 只出现一次的数字]] 同源：都利用异或「相同元素成对抵消」的性质。区别在于这里要自己**凑出**配对的另一半。

---

## 题目描述

数组 `nums` 长度为 `n`，元素是 `[0, n]`（含两端，共 `n + 1` 个数）中**缺了一个**后剩下的 `n` 个互不相同的数。返回缺失的那个数。

### 示例

```text
输入：nums = [3, 0, 1]
输出：2
解释：n = 3，范围 [0,3] 应包含 {0,1,2,3}，数组里少了 2。
```

> [!note]
> 进阶要求：时间 `O(n)`，额外空间 `O(1)`。

---

## 解题思路

异或有两条关键性质（详见 [[5.算法/5.2 算法/5.2.2 位运算|5.2.2 位运算]]）：

- `a ^ a = 0`：相同的数抵消。
- `a ^ 0 = a`：和 `0` 异或不变。

如果把**完整集合 `{0, 1, …, n}`** 和**数组里实际出现的值**全部异或在一起：

- 每个真正出现过的数字会贡献**两次**（一次来自完整集合、一次来自数组）→ 成对抵消变 `0`。
- 唯独缺失的数字只来自完整集合这一侧，没有配对 → **幸存下来**。

剩下的那个就是答案。

> [!tip]
> 完整集合怎么来？循环里让 `i` 走遍下标 `0 .. n-1`，最后再补一个 `nums.size()`（就是 `n`），正好凑齐 `{0, 1, …, n}`。

### 图解过程

![[图片/SVG/lc_268_xor_missing.svg]]

以 `nums = [3, 0, 1]`、`n = 3` 为例，逐步追踪 `res`：

| 步骤 | 操作 | `res` |
|------|------|-------|
| 初始 | `res = 0` | `0` |
| `i=0` | `^= 0`，`^= nums[0]=3` | `3` |
| `i=1` | `^= 1`，`^= nums[1]=0` | `2` |
| `i=2` | `^= 2`，`^= nums[2]=1` | `1` |
| 收尾 | `^= nums.size()=3` | `2` |

整体等价于 `(0^1^2^3) ^ (3^0^1) = 2`，异或满足交换律，顺序无关紧要。

---

## 代码

```cpp
class Solution {
public:
    int missingNumber(vector<int>& nums) {
        int res = 0;
        for(int i = 0;i < nums.size();i++)
        {
            res ^= i;          // 异或下标：贡献 0 .. n-1
            res ^= nums[i];    // 异或数组值
        }
        res ^= nums.size();    // 补上 n，凑齐完整集合 0 .. n
        return res;
    }
};
```

### 代码分析

- 循环内 `res ^= i` 把下标 `0 .. n-1` 异或进来，`res ^= nums[i]` 把数组值异或进来。
- 循环结束后 `res ^= nums.size()` 补上 `n`——因为下标只到 `n-1`，差一个 `n` 才能凑齐 `{0..n}`。
- 全程只用一个 `int`，空间 `O(1)`；只遍历一次，时间 `O(n)`，满足进阶要求。

> [!tip]
> 也可以把 `res` 初始化为 `nums.size()`，省掉收尾那行：`int res = nums.size();` 然后循环里 `res ^= i ^ nums[i];`。等价写法。

---

## 为什么不会溢出 / 不依赖顺序

- 异或是**逐位**运算，不像求和那样可能溢出，对大数组更稳健。
- 异或满足交换律、结合律，因此「先异或谁」无所谓，乱序数组也照样正确。

---

## 复杂度

- **时间复杂度**：`O(n)`，一次遍历。
- **空间复杂度**：`O(1)`，只用一个变量。

---

## 其它解法对比

| 解法 | 思路 | 时间 | 空间 | 风险 |
|------|------|------|------|------|
| **异或**（本题） | 完整集合 ^ 数组值，配对抵消 | `O(n)` | `O(1)` | 无溢出风险 |
| 求和 | `n(n+1)/2 - sum(nums)` | `O(n)` | `O(1)` | `n` 很大时求和可能溢出 |
| 排序后扫描 | 找第一个 `nums[i] != i` | `O(n log n)` | `O(1)` | 慢 |
| 哈希集合 | 标记出现过的数 | `O(n)` | `O(n)` | 额外空间 |

> [!tip]
> 异或法和求和法都是 `O(n)`/`O(1)`，但异或天然规避了整型溢出，面试中是更稳的首选。

---

## 易错点

| 易错点 | 说明 |
|--------|------|
| 忘记补 `nums.size()` | 只异或下标 `0..n-1` 会少一个 `n`，完整集合不完整，结果错误 |
| 下标循环写成 `i <= nums.size()` | 会越界访问 `nums[n]` |
| 误用求和又不防溢出 | `n` 较大时 `n(n+1)/2` 可能超出 `int` 范围 |
