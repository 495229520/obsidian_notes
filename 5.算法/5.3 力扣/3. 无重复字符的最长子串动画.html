无重复字符的最长子串 · 算法动画

记录每个字符最近出现的下标，遇到重复字符时 slow = max(slow, last[s[fast]] + 1) 实现跨步跃迁。

C++ 执行行追踪

C++17
1: unordered_map<char, int> last;
2: int slow = 0, max_len = 0;
3: for (int fast = 0; fast < s.size(); fast++) {
4: if (last.count(s[fast])) {
5: slow = max(slow, last[s[fast]] + 1);
6: }
7: last[s[fast]] = fast;
8: max_len = max(max_len, fast - slow + 1);
9: }
10: return max_len;

💡 核心算法洞察

  • • 为什么取 max？ 当重复字符的上一次出现位置在 slow 左侧时（如 "abba" 的第二个 a），不能倒退 slow。
  • • O(N) 无需逐个弹出： 传统双指针需要不断 erase 字符直到去重，哈希表记录下标可实现一次性 O(1) 跃迁。
