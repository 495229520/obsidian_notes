# 5.2.9 链表常见技巧

> 链表题的难点不在语法，而在指针边界：谁是前驱、谁是当前节点、谁是后继节点、修改 `next` 后还能不能找到剩余链表。

---

## 链表题核心

LeetCode 中的单链表一般给出这样的节点定义：

```cpp
struct ListNode {
    int val = 0;
    ListNode* next = nullptr;
};
```

链表不能像 [[5.算法/5.1 STL/5.1.1 vector|vector]] 一样随机访问下标，只能沿着 `next` 指针向后走。因此很多数组题里自然的“访问第 i 个元素”，到了链表里都要换成“维护前驱和后继关系”。

链表题最常见的三个原则：

1. **先保存后继，再修改指针**：写 `curr->next = ...` 前，先保存 `ListNode* next = curr->next`。
2. **明确前驱节点**：删除、插入、合并、分组反转通常都需要知道当前节点前面的节点。
3. **只改连接，不改节点值**：很多题明确要求不能交换 `val`，必须调整节点之间的 `next`。

> [!warning]
> 面试手写链表时，不要急着写循环。先在纸上标出 `prev`、`curr`、`next`、`dummy` 分别站在哪里，再决定移动顺序。

---

## 链表题套路总览

![[图片/5.算法/5.2 算法/5_2_2_9_1.svg]]

| 题目关键词 | 优先技巧 | 关键不变量 |
|------------|----------|------------|
| 头节点可能被删除或替换 | 虚拟头节点 | `dummy.next` 始终指向当前答案头节点 |
| 找中点、找环、倒数第 N 个 | 快慢指针 | 两个指针保持速度差或固定距离差 |
| 反转整链或局部区间 | 三指针反转 | 修改 `curr->next` 前必须保存 `next` |
| 合并有序链表 | 双指针尾插 | `tail` 始终指向已合并链表末尾 |
| 相交链表 | 两指针换头 | 两个指针最终走过相同总长度 |
| 排序链表 | 归并排序 | 快慢切分后要断开前半段尾节点 |

这些技巧和 [[5.算法/5.2 算法/5.2.7 双指针与滑动窗口|双指针与滑动窗口]] 中的快慢指针思想一脉相承，只是链表更强调空指针保护和连接关系。

## 虚拟头节点

虚拟头节点 `dummy` 适合所有“头节点可能变化”的场景，例如删除头节点、在头部插入、合并两条链表、K 个一组反转。

没有 `dummy` 时，删除头节点和删除中间节点往往要分开处理：

```cpp
if (head->val == target) {
    return head->next;
}
```

有了 `dummy`，所有删除都变成“删除 `prev->next`”：

```cpp
ListNode* deleteValue(ListNode* head, int target) {
    ListNode dummy;
    dummy.next = head;

    ListNode* prev = &dummy;
    while (prev->next != nullptr) {
        if (prev->next->val == target) {
            prev->next = prev->next->next;
        } else {
            prev = prev->next;
        }
    }

    return dummy.next;
}
```

**关键点**：

- `prev` 指向“待检查节点的前一个节点”。
- 删除节点时移动连接，不需要立刻移动 `prev`。
- 最终返回 `dummy.next`，不是原来的 `head`。

## 快慢指针

快慢指针适合在一次遍历中得到位置关系。它不是固定写法，而是两类不变量：

| 场景 | 指针关系 | 用途 |
|------|----------|------|
| 找中点 | `fast` 每次两步，`slow` 每次一步 | 排序链表、回文链表前置步骤 |
| 找环 | `fast` 在环内追上 `slow` | 判断链表是否有环 |
| 倒数第 N 个 | `fast` 先走固定步数 | 删除倒数节点、找倒数节点 |

### 找中点

找中点有两个最关键的细节：**链表长度是奇数还是偶数？偶数长度时我们需要的是「上中点（左半段末尾）」还是「下中点（右半段开头）」？**

这取决于快指针 `fast` 的起始位置：

| 起始位置 | 奇数长度（如 3 节点） | 偶数长度（如 4 节点） | 核心用途 |
| :--- | :--- | :--- | :--- |
| **`fast = head`** | 停在正中点 | 停在 **下中点（右半段开头）** | 找中点、[[234. 回文链表]]（找后半段直接反转） |
| **`fast = head->next`** | 停在正中点 | 停在 **上中点（左半段末尾）** | 链表切分、[[5.算法/5.3 力扣/5.3.9 链表/148. 排序链表\|148. 排序链表]]、[[5.算法/5.3 力扣/5.3.9 链表/143. 重排链表\|143. 重排链表]] |

---

#### 模板一：找下中点（`fast = head`）

若只需要定位链表的中间节点（偶数长度时偏向右侧），让 `slow` 和 `fast` 从同一起点出发：

```cpp
ListNode* middleNode(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }

    return slow;
}
```

* **奇数长度**（`1 -> 2 -> 3`）：`slow` 停在 `2`（正中点）。
* **偶数长度**（`1 -> 2 -> 3 -> 4`）：`slow` 停在 `3`（第 2 个中点 / 下中点）。

---

#### 模板二：找上中点与断链（`fast = head->next`）

若需要将链表**平分为两半（断链操作）**，推荐让快指针提前一步 `fast = head->next`，这样 `slow` 恰好停在**左半部分的最后一个节点**：

```cpp
// 1. 快慢指针找到左半部分末尾（上中点）
ListNode* slow = head;
ListNode* fast = head->next;

while (fast != nullptr && fast->next != nullptr) {
    slow = slow->next;
    fast = fast->next->next;
}

// 2. 安全切断链表
ListNode* rightHead = slow->next;
slow->next = nullptr;
```

* **奇数长度**（`1 -> 2 -> 3`）：`slow` 停在 `2`（正中点），断链后左半段 `1 -> 2`，右半段 `3`。
* **偶数长度**（`4 -> 2 -> 1 -> 3`）：`slow` 停在 `2`（上中点），断链后左半段 `4 -> 2`，右半段 `1 -> 3`。

> [!important] 深度剖析：为什么切分链表时 `fast` 必须提前一步？（防死循环/栈溢出）
> 
> 在递归拆分链表（如归并排序）时，最致命的是 **2 个节点（`1 -> 2`）** 的基准情况：
> 
> 1. **如果写成 `fast = head`**：
>    - 初始 `slow` 在 `1`，`fast` 在 `1`；
>    - 走一步后 `slow` 到达 `2`，`fast` 到达 `nullptr`；
>    - 执行断链 `rightHead = slow->next`（为 `nullptr`），`slow->next = nullptr`；
>    - 结果：左半段仍然是完整的 `1 -> 2`，右半段是 `nullptr`！
>    - 下次递归继续调用 `sortList(1 -> 2)`，问题规模**完全没有缩小**，直接导致**无限递归与栈溢出（Stack Overflow）**。
> 
> 2. **如果写成 `fast = head->next`**：
>    - 初始 `slow` 在 `1`，`fast` 在 `2`；
>    - 此时 `fast->next == nullptr`，`while` 循环直接跳过，`slow` 稳稳停在 `1`；
>    - 执行断链：左半段为 `1`，右半段为 `2`；
>    - 两段长度都变为 1（触发 `head->next == nullptr` 递归出口），**递归安全终止**！
> 
> *(注：如果使用 `fast = head`，也可以通过额外维护一个 `prev` 指针来记录 `slow` 的前驱并在 `prev` 处断链，但直接写 `fast = head->next` 代码更优雅精炼，无需多维护一个指针变量)*

### 固定距离

倒数第 `n` 个节点的本质是让 `fast` 和 `slow` 保持固定距离。当 `fast` 到达结尾，`slow` 就在目标位置。

```cpp
ListNode* kthFromEnd(ListNode* head, int n) {
    if (n <= 0) return nullptr;

    ListNode* slow = head;
    ListNode* fast = head;

    for (int i = 0; i < n; ++i) {
        if (fast == nullptr) return nullptr;
        fast = fast->next;
    }

    while (fast != nullptr) {
        slow = slow->next;
        fast = fast->next;
    }

    return slow;
}
```

## 反转链表

反转链表是链表题的基础动作，完整题解可看 [[206. 反转链表|206. 反转链表]]。核心模板是三指针：

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;

    while (curr != nullptr) {
        ListNode* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }

    return prev;
}
```

**四步顺序不能乱**：

1. `next = curr->next`：保存后继。
2. `curr->next = prev`：当前节点指回前面。
3. `prev = curr`：扩大已反转部分。
4. `curr = next`：继续处理原链表剩余部分。

局部反转和 K 个一组反转只是把“整条链表反转”限制在一段区间里。[[25. K 个一组翻转链表|25. K 个一组翻转链表]] 中最重要的边界是：

- `groupPrev`：当前组前一个节点。
- `kth`：当前组第 `k` 个节点。
- `groupNext`：当前组后面的第一个节点。
- `prev = groupNext`：让翻转后的组尾自然接回后续链表。

## 合并链表

合并两个有序链表时，使用 `dummy + tail` 最清楚。`tail` 始终指向已合并链表的最后一个节点。

```cpp
ListNode* mergeTwoLists(ListNode* a, ListNode* b) {
    ListNode dummy;
    ListNode* tail = &dummy;

    while (a != nullptr && b != nullptr) {
        if (a->val <= b->val) {
            tail->next = a;
            a = a->next;
        } else {
            tail->next = b;
            b = b->next;
        }
        tail = tail->next;
    }

    tail->next = (a != nullptr) ? a : b;
    return dummy.next;
}
```

**关键点**：

- 每次只把较小节点接到 `tail->next`。
- 接完后必须移动 `tail`。
- 一条链表耗尽后，剩余部分可以整体接上。

这类题虽然名字叫“链表”，但和 [[5.算法/5.1 STL/5.1.3 list及其与其他结构的区别|list及其与其他结构的区别]] 中的容器用法不同，面试题通常直接操作裸节点指针。

## 找环

Floyd 判环使用快慢指针。如果链表有环，`fast` 会在环内追上 `slow`；如果无环，`fast` 会先到达 `nullptr`。

```cpp
bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            return true;
        }
    }

    return false;
}
```

如果要找入环点，相遇后让一个指针回到 `head`，两个指针每次都走一步，再次相遇的位置就是入环点：

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            ListNode* entry = head;
            while (entry != slow) {
                entry = entry->next;
                slow = slow->next;
            }
            return entry;
        }
    }

    return nullptr;
}
```

**空指针保护**永远写在访问 `fast->next->next` 前面。

## 相交链表

相交链表判断的是两个链表是否共享同一批节点，不是节点值是否相等。

双指针换头写法：

```cpp
ListNode* getIntersectionNode(ListNode* a, ListNode* b) {
    ListNode* p = a;
    ListNode* q = b;

    while (p != q) {
        p = (p == nullptr) ? b : p->next;
        q = (q == nullptr) ? a : q->next;
    }

    return p;
}
```

**为什么可行**：

- 如果相交，两个指针都会走过 `a` 的非公共部分、`b` 的非公共部分和公共尾部，最终在交点相遇。
- 如果不相交，两个指针最终都会走到 `nullptr`，循环结束并返回 `nullptr`。
- 判断相交用的是指针地址相同，即 `p == q`。

## 删除倒数第 N 个节点

删除节点时必须拿到目标节点的前驱，所以推荐写成 `dummy + fast` 先走 `n + 1` 步，让 `slow` 最终停在待删除节点前面。

```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy;
    dummy.next = head;

    ListNode* slow = &dummy;
    ListNode* fast = &dummy;

    for (int i = 0; i <= n; ++i) {
        if (fast == nullptr) return dummy.next;
        fast = fast->next;
    }

    while (fast != nullptr) {
        slow = slow->next;
        fast = fast->next;
    }

    if (slow->next != nullptr) {
        slow->next = slow->next->next;
    }

    return dummy.next;
}
```

**关键点**：

- 从 `dummy` 开始走 `n + 1` 步，保证 `slow` 停在删除目标的前驱。
- 删除头节点时，`slow` 会停在 `dummy`，不用单独分支。
- 如果题目保证 `n` 合法，可以省略部分非法输入保护；手写模板保留保护更稳。

## 排序链表

排序链表常用归并排序，原因是链表不适合随机访问，但很适合通过指针合并两个有序链表。

整体步骤：

1. 快慢指针找到中点。
2. 断开链表，递归排序左右两段。
3. 合并两个有序链表。

```cpp
ListNode* sortList(ListNode* head) {
    if (head == nullptr || head->next == nullptr) {
        return head;
    }

    // 推荐写法：fast = head->next，让 slow 停在上中点
    ListNode* slow = head;
    ListNode* fast = head->next;

    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
    }

    ListNode* rightHead = slow->next;
    slow->next = nullptr; // 必须断链

    ListNode* left = sortList(head);
    ListNode* right = sortList(rightHead);
    return mergeTwoLists(left, right);
}
```

**关键点**：

- `head == nullptr || head->next == nullptr` 是递归出口。
- 快指针必须从 `head->next` 开始（或配合 `prev` 记录慢指针前驱），确保在 2 个节点时 `slow` 停在第 1 个节点，断链后两半规模严格缩小，彻底避免死循环。
- `slow->next = nullptr` 必须写，否则左右两段没有真正断开，递归会无限处理同一条链。
- 合并阶段复用“合并有序链表”的 `dummy + tail` 模板。

## 复杂度总结

| 技巧 | 典型题型 | 时间复杂度 | 空间复杂度 |
|------|----------|------------|------------|
| 虚拟头节点 | 删除、插入、合并、头节点变化 | 取决于主流程 | `O(1)` |
| 快慢指针 | 中点、找环、倒数第 N 个 | `O(n)` | `O(1)` |
| 三指针反转 | 反转链表、局部反转 | `O(n)` | `O(1)` |
| 双指针换头 | 相交链表 | `O(n + m)` | `O(1)` |
| 归并排序 | 排序链表 | `O(nlogn)` | 递归栈 `O(logn)` |

## 常见误区

### 1. 修改 `next` 前没有保存后继

```cpp
curr->next = prev;
curr = curr->next; // 错误：这里已经走回 prev，原链表后续节点丢了
```

正确写法是先保存：

```cpp
ListNode* next = curr->next;
curr->next = prev;
curr = next;
```

### 2. 删除头节点忘记更新返回值

只返回原 `head` 时，删除头节点会失败。使用 `dummy` 后统一返回 `dummy.next`。

### 3. 快指针缺少空指针保护

访问 `fast->next->next` 前，必须确认 `fast != nullptr && fast->next != nullptr`。

### 4. 判断相交时比较节点值

相交链表比较的是节点地址，不是 `val`。两个节点值相等不代表它们是同一个节点。

### 5. 归并排序切分错误导致死递归

- **忘记断链**：找到中点后未执行 `slow->next = nullptr`，左右两段未真正分开。
- **快指针起点错误（`fast = head`）**：在只有 2 个节点（如 `1 -> 2`）时，`slow` 走到第 2 个节点，切分后左半段依然是 `1 -> 2`（右半段为 `nullptr`），导致递归规模未缩减而栈溢出。应使用 `fast = head->next`，或显式维护 `prev` 前驱并在 `prev` 处断链。

## 面试手写检查清单

| 检查项 | 自查问题 |
|--------|----------|
| 返回值 | 头节点是否可能变化？是否应该返回 `dummy.next`？ |
| 空链表 | `head == nullptr` 时是否安全？ |
| 单节点 | `head->next == nullptr` 时是否直接返回？ |
| 保存后继 | 修改 `curr->next` 前是否保存了原 `next`？ |
| 前驱节点 | 删除或插入时是否拿到了目标节点前驱？ |
| 循环条件 | 是否会访问空指针？是否会漏掉最后一个节点？ |
| 指针比较 | 相交、找环是否比较节点地址而不是节点值？ |

---

## 关键要点

1. 链表题的核心是维护连接关系，而不是记住某个模板名字。
2. `dummy` 解决头节点变化，`fast/slow` 解决位置关系，`prev/curr/next` 解决反转。
3. 删除节点要拿前驱，反转节点要存后继，找环要先保护空指针。
4. 相交链表比较地址，排序链表用快慢切分和归并合并。
5. 写代码前先画节点关系，代码后检查空链表、单节点、删除头节点、不足一组等边界。
