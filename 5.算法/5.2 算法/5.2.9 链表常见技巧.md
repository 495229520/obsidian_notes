# 5.2.9 链表常见技巧

链表题主要在维护连接关系。写代码前先确定：哪个指针负责找到剩余节点，哪个指针负责把处理完的部分接回去。改写一条 `next`，就要知道原来那条边是否还需要使用。

本文结合 [[CodeTop 高频题 Top300]] 整理。排名、频率取自当前本地题单，属于该题单的快照；刷题次数以题单为准，不在这里重复维护。文末按题目映射到具体技巧。

> [!tip] 复习入口
> 先看 [[#5. 反转链表|反转链表]]、[[#6. 合并链表|合并链表]] 和 [[#4. 快慢指针|快慢指针]]。基础动作能手写后，再组合成 [[#8. 重排与回文|重排与回文]]、[[#7. 排序链表|排序链表]]。原有 [链表技巧动画](<5.2.9.1 链表技巧动画.html>) 可用于逐步观察指针移动。

## 1. 链表题套路总览

| 要完成的操作 | 维护什么关系 | 典型题 |
| --- | --- | --- |
| 删除或替换头节点 | `dummy` 提供固定前驱，返回 `dummy.next` | 19、82、92、25 |
| 定位中点或倒数位置 | 明确起点、步长和停止条件 | 876、19、Offer 22 |

| 判断环或相交 | 比较节点地址 | 141、142、160 |

## 2. 链表题核心

以下代码共用这个节点定义，支持文中的 `ListNode dummy(0, head)`：

```cpp
struct ListNode {
    int val;
    ListNode* next;
    explicit ListNode(int x = 0, ListNode* p = nullptr)
        : val(x), next(p) {}
};
```

除找环章节外，默认输入是有限、无环的单链表。合并模板还要求输入链表互不共享节点，否则同一个节点可能被接入两次而成环。

- `p = p->next` 移动局部指针，不改变链表结构；`p->next = q` 才是在修改连接。
- 只有旧后继还要使用、且没有其他指针保存它时，才需要先存 `next`。不必在每次赋值前机械增加临时变量。
- 题目要求交换节点时，要改连接，不能仅交换 `val`。相交和找环则始终比较地址。
- 已知前驱时，插入或摘除一个节点是 `O(1)`；寻找这个前驱可能需要 `O(n)`。

> [!note] 摘除节点与释放内存
> 本文删除模板只修改连接，节点由题目测试环境或调用者统一管理。若自己用 `new` 创建并独占整条链表，应保存被摘除节点，在确认没有其他使用者后 `delete`，最后释放剩余节点。`dummy` 是局部对象，返回它指向的真实节点 `dummy.next`，不要返回 `&dummy`。

## 3. 虚拟头节点

`dummy` 让原头节点也有前驱，删除头节点与删除中间节点便能使用同一段代码。它是方便统一边界的写法，不是所有链表题都必须使用。

```cpp
ListNode* deleteValue(ListNode* head, int target) {
    ListNode dummy(0, head);
    ListNode* prev = &dummy;
    while (prev->next) {
        if (prev->next->val == target) {
            prev->next = prev->next->next;
        } else {
            prev = prev->next;
        }
    }
    return dummy.next;
}
```

循环开始时，`prev` 后面是尚未检查的部分。删除后留在原地，继续检查新的 `prev->next`；否则会漏掉连续相同节点，例如 `1 → 1 → 2` 中第二个 `1`。时间 `O(n)`，额外空间 `O(1)`。

## 4. 快慢指针

### 4.1 找中点

快慢指针找中点的基本原理是**两倍速追及**：慢指针 `slow` 每次走 1 步，快指针 `fast` 每次走 2 步。当快指针走完全程时，慢指针刚好走了一半。

奇数长度（如 5 个节点）的中心唯一，毫无歧义。难点在于**偶数长度（如 `1 -> 2 -> 3 -> 4`）存在两个中点**，需要根据题目目的选择让慢指针停在哪里：
- **右中点（节点 3）**：后半段的开头。用于**提取或反转后半段**（如回文链表）。
- **左中点（节点 2）**：前半段的末尾。用于**从中间切断链表**（如归并排序），必须停在 2，才能执行 `slow->next = nullptr` 把它分成 `[1, 2]` 与 `[3, 4]`。

#### 4.1.1 两套起步策略对比

统一采用 `while (fast && fast->next)` 作为循环条件时，仅需改变快指针的**起跑位置**即可控制慢指针的落点：

| 目标分类 | 起步条件 | 偶数长度落点（以 `1→2→3→4` 为例） | 切分与使用效果 | 对应题型 |
| --- | --- | --- | --- | --- |
| **找右中点（取后半段开头）** | `slow = head`<br>`fast = head`（同一起点） | 停在 **`3`** | `slow` 直接作为后半段头节点 | 876. 链表的中间结点<br>234. 回文链表 |
| **找左中点（对半断链切分）** | `slow = head`<br>`fast = head->next`（快指针抢跑一步） | 停在 **`2`** | 在此处断链：`slow->next = nullptr`，切为 `1→2` 与 `3→4` | 148. 排序链表（归并切分）<br>143. 重排链表 |

> **直观理解：为什么快指针抢跑一步，慢指针就会停在左中点？**
> 快指针速度是慢指针的 2 倍。让快指针提前出发一步，它就会提前到达末尾，使 `while` 循环**少执行一轮**退出。慢指针少走了一步，落点刚好从右中点退回到了左中点。

#### 4.1.2 模板一：找右中点（取后半段开头）

```cpp
// 奇数长度停在正中点；偶数长度停在后半段开头（右中点）
ListNode* middleNode(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}
```

#### 4.1.3 模板二：找左中点并断链（归并切分标准写法）

```cpp
// 找到左半段末尾（左中点）
ListNode* firstHalfEnd(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head->next; // 关键：fast 抢跑一步
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    return slow;
}

// 找到左半段末尾并在其后切断，返回右半段头节点
ListNode* splitHalf(ListNode* head) {
    if (!head || !head->next) return nullptr;
    ListNode* mid = firstHalfEnd(head);
    ListNode* rightHead = mid->next;
    mid->next = nullptr; // 切断左右两半
    return rightHead;
}
```

#### 4.1.4 避坑要点：归并切分为什么绝不能让 fast 从 head 出发？

归并排序拆分链表时，最致命的是 **2 个节点（`1 -> 2`）** 的递归基准情况：
- **若用 `fast = head`**：循环执行一次，`slow` 走到 `2`。断链后右半段是 `nullptr`，左半段依然是长为 2 的 `1 -> 2`。子问题规模**完全没有缩小**，下一轮递归继续调用原链表，直接导致**无限递归与栈溢出（Stack Overflow）**。
- **若用 `fast = head->next`**：初始 `fast` 在 `2`，因 `fast->next == nullptr`，循环一次都不执行。`slow` 留在 `1`，顺利将链表切分为 `[1]` 和 `[2]` 两半，递归安全终止。

### 4.2 固定距离

定位倒数节点时，两指针速度相同。差别在于一个先走若干步。

| 目标 | 两指针起点 | fast 先走 | 同步循环条件 | slow 最终位置 |
| --- | --- | --- | --- | --- |
| 倒数第 k 个节点 | `head` | `k` 步 | `fast != nullptr` | 目标节点 |
| 删除倒数第 n 个 | `dummy` | `n + 1` 步 | `fast != nullptr` | 目标前驱 |
| 同一删除题的另一写法 | `dummy` | `n` 步 | `fast->next != nullptr` | 目标前驱 |

起点、先走步数和终点要成套记，不能只记“先走 n 步”。

```cpp
ListNode* kthFromEnd(ListNode* head, int k) {
    if (k <= 0) return nullptr;
    ListNode* slow = head;
    ListNode* fast = head;
    for (int i = 0; i < k; ++i) {
        if (!fast) return nullptr;
        fast = fast->next;
    }
    while (fast) {
        slow = slow->next;
        fast = fast->next;
    }
    return slow;
}
```

### 4.3 删除倒数第 N 个节点

此处使用表中第二种写法。`n <= 0` 或超过链长时保持原链不变。

```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    if (n <= 0) return head;
    ListNode dummy(0, head);
    ListNode* slow = &dummy;
    ListNode* fast = &dummy;
    for (int i = 0; i <= n; ++i) {
        if (!fast) return head;
        fast = fast->next;
    }
    while (fast) {
        slow = slow->next;
        fast = fast->next;
    }
    slow->next = slow->next->next;
    return dummy.next;
}
```

例如 `dummy → 1 → 2 → 3 → 4 → 5 → null`，删除倒数第 2 个：`fast` 先走 3 步到 `3`，再同步走到 `null`，`slow` 停在 `3`，摘除其后的 `4`。上述定位与删除均为 `O(n)` 时间、`O(1)` 额外空间。

## 5. 反转链表

### 5.1 整链反转

循环开始时，`prev` 是已经反转部分的头，`curr` 是未处理部分的头。先保存旧后继，再把当前节点接到已反转部分前面。

```cpp
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    while (curr) {
        ListNode* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

`curr = curr->next` 不能替代最后一行：此时 `curr->next` 已经被改成旧的 `prev`。整链反转时间 `O(n)`、额外空间 `O(1)`；递归版本还要计算 `O(n)` 调用栈。完整题解见 [[206. 反转链表]]。

### 5.2 区间反转：92

对位置 `[left, right]` 反转。先停在区间前驱 `before`，再把区间首节点之后的节点逐个搬到区间最前面。`tail` 始终指向原区间首节点，最终成为区间尾。

```cpp
// 前提：1 <= left <= right <= 链表长度。
ListNode* reverseBetween(ListNode* head, int left, int right) {
    ListNode dummy(0, head);
    ListNode* before = &dummy;
    for (int i = 1; i < left; ++i) before = before->next;
    ListNode* tail = before->next;
    for (int i = 0; i < right - left; ++i) {
        ListNode* move = tail->next;
        tail->next = move->next;
        move->next = before->next;
        before->next = move;
    }
    return dummy.next;
}
```

`1 → 2 → 3 → 4 → 5` 反转 `[2,4]`：先把 `3` 搬到 `2` 前面，得到 `1 → 3 → 2 → 4 → 5`；再搬 `4`，得到 `1 → 4 → 3 → 2 → 5`。`before` 一直在 `1`，`tail` 一直在 `2`。时间 `O(n)`，额外空间 `O(1)`。

### 5.3 K 个一组翻转：25 与 24

每组先找第 `k` 个节点 `kth`。只有确认够一组后才开始反转；[25 题](https://leetcode.cn/problems/reverse-nodes-in-k-group/)要求不足一组的尾段保持原序。

![[图片/SVG/5_2_2_9_2.svg|900]]

```cpp
ListNode* reverseKGroup(ListNode* head, int k) {
    if (k <= 1) return head;
    ListNode dummy(0, head);
    ListNode* groupPrev = &dummy;
    while (true) {
        ListNode* kth = groupPrev;
        for (int i = 0; i < k && kth; ++i) kth = kth->next;
        if (!kth) break;

        ListNode* groupNext = kth->next;
        ListNode* oldFirst = groupPrev->next;
        ListNode* prev = groupNext;
        ListNode* curr = oldFirst;
        while (curr != groupNext) {
            ListNode* next = curr->next;
            curr->next = prev;
            prev = curr;
            curr = next;
        }
        groupPrev->next = kth;
        groupPrev = oldFirst;
    }
    return dummy.next;
}
```

反转区间是 `[oldFirst, groupNext)`，右端点不参与反转。`prev = groupNext` 会让原首节点直接接上下一段；翻转后再把组前驱接到 `kth`。下一轮的 `groupPrev` 是原首节点，不能继续停在旧组前驱。

每个节点最多参与一次找组尾和一次反转，时间 `O(n)`、额外空间 `O(1)`。24 题就是 `k = 2` 的情形；详见 [[25. K 个一组翻转链表]]。

## 6. 合并链表

### 6.1 两条有序链表：21

`tail` 指向结果中已经选定的最后一个节点。每轮从两个剩余链表头中选较小者。相等时先选左链，有利于归并排序保持稳定。

```cpp
ListNode* mergeTwoLists(ListNode* a, ListNode* b) {
    ListNode dummy;
    ListNode* tail = &dummy;
    while (a && b) {
        if (a->val <= b->val) {
            tail->next = a;
            a = a->next;
        } else {
            tail->next = b;
            b = b->next;
        }
        tail = tail->next;
    }
    tail->next = a ? a : b;
    return dummy.next;
}
```

结果复用原节点，会改变输入链表的连接。时间 `O(n + m)`、额外空间 `O(1)`。

### 6.2 K 条有序链表：23

只有每条链的当前头可能成为下一最小值，因此用最小堆维护这些候选即可。弹出一个节点后，将它原来的后继入堆。

```cpp
#include <queue>
#include <vector>

ListNode* mergeKLists(const std::vector<ListNode*>& lists) {
    auto cmp = [](ListNode* a, ListNode* b) {
        return a->val > b->val;
    };
    std::priority_queue<ListNode*, std::vector<ListNode*>, decltype(cmp)> pq(cmp);
    for (ListNode* head : lists) {
        if (head) pq.push(head);
    }
    ListNode dummy;
    ListNode* tail = &dummy;
    while (!pq.empty()) {
        ListNode* node = pq.top();
        pq.pop();
        if (node->next) pq.push(node->next);
        tail->next = node;
        tail = node;
    }
    tail->next = nullptr;
    return dummy.next;
}
```

设总节点数为 `N`，链表数为 `k`：扫描输入需要 `O(k)`，堆处理需要 `O(N log(k + 1))`，额外空间 `O(k)`。常见简写是 `O(N log k)`，默认忽略空链扫描并取 `k >= 2`。

另一方案是两两归并，每轮将链表数减半，共约 `log k` 轮。不要每次都把一条新链合入越来越长的结果：长度相近时，顺序合并最坏为 `O(Nk)`。堆的用法见 [[5.2.11 堆与优先队列]]。

## 7. 排序链表

归并排序只需遍历与重连，不依赖随机访问。下面复用 `firstHalfEnd` 与 `mergeTwoLists`：

```cpp
ListNode* sortList(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode* mid = firstHalfEnd(head);
    ListNode* right = mid->next;
    mid->next = nullptr;
    ListNode* a = sortList(head);
    ListNode* b = sortList(right);
    return mergeTwoLists(a, b);
}
```

每层切分和合并合计 `O(n)`，共 `O(log n)` 层，时间为 `O(n log n)`。递归调用占 `O(log n)` 栈空间，不能因为没有申请节点就写成 `O(1)`。

[148 题的常数空间进阶](https://leetcode.cn/problems/sort-list/)可用自底向上归并：先合并长度为 1 的相邻段，再合并长度 2、4、8 的段。每次截出两段时保留下一段入口，合并后更新结果尾指针。这样消除递归栈，额外空间 `O(1)`。题解见 [[5.算法/5.3 力扣/5.3.9 链表/148. 排序链表|148. 排序链表]]。

## 8. 重排与回文

这两题共用“找左半段末尾 + 反转右半段”，区别在最后一步。

![[图片/SVG/5_2_2_9_3.svg|900]]

### 8.1 重排链表：143

目标顺序是 `L0 → Ln → L1 → Ln-1 → …`。后半段反转后，就可以从两段头部交替取节点。

```cpp
void reorderList(ListNode* head) {
    if (!head || !head->next) return;
    ListNode* mid = firstHalfEnd(head);
    ListNode* right = mid->next;
    mid->next = nullptr;
    right = reverseList(right);
    ListNode* left = head;
    while (right) {
        ListNode* nextLeft = left->next;
        ListNode* nextRight = right->next;
        left->next = right;
        right->next = nextLeft;
        left = nextLeft;
        right = nextRight;
    }
}
```

左段长度大于等于右段，因此以 `right` 耗尽为结束条件。必须先断开两段，否则交替重连时可能沿着旧边形成环。时间 `O(n)`、额外空间 `O(1)`；详见 [[5.算法/5.3 力扣/5.3.9 链表/143. 重排链表|143. 重排链表]]。

### 8.2 回文链表：234

只需比较对称位置的值。下面在返回前恢复原链，调用者仍能按原序遍历；这是模板约定，[题目本身](https://leetcode.cn/problems/palindrome-linked-list/)要求判断回文，并给出 `O(n)` 时间、`O(1)` 空间的进阶目标。

```cpp
bool isPalindrome(ListNode* head) {
    if (!head || !head->next) return true;
    ListNode* mid = firstHalfEnd(head);
    ListNode* right = mid->next;
    mid->next = nullptr;
    right = reverseList(right);
    ListNode* p = head;
    ListNode* q = right;
    bool ok = true;
    while (q) {
        if (p->val != q->val) ok = false;
        p = p->next;
        q = q->next;
    }
    mid->next = reverseList(right);
    return ok;
}
```

奇数长度的中间节点留在左段，不参与比较。用 `q` 控制比较次数，发现不匹配后也要走到恢复步骤，不能直接 `return false`。时间 `O(n)`、额外空间 `O(1)`。

## 9. 有序链表去重

83 与 82 的输入都已经排好序。差别在于重复值是否还保留一个。

| 输入 | 83：每个值留一个 | 82：重复值整组删除 |
| --- | --- | --- |
| `1 → 1 → 2 → 3 → 3` | `1 → 2 → 3` | `2` |
| `1 → 1` | `1` | 空链表 |

```cpp
ListNode* deleteDuplicatesKeepOne(ListNode* head) {
    ListNode* curr = head;
    while (curr && curr->next) {
        if (curr->val == curr->next->val) {
            curr->next = curr->next->next;
        } else {
            curr = curr->next;
        }
    }
    return head;
}

ListNode* deleteDuplicatesAll(ListNode* head) {
    ListNode dummy(0, head);
    ListNode* prev = &dummy;
    while (prev->next && prev->next->next) {
        if (prev->next->val == prev->next->next->val) {
            int duplicate = prev->next->val;
            while (prev->next && prev->next->val == duplicate) {
                prev->next = prev->next->next;
            }
        } else {
            prev = prev->next;
        }
    }
    return dummy.next;
}
```

82 中 `prev` 是已确认保留部分的尾节点。发现重复后，它不前进，直到整段相同值都被跳过。两种算法都是 `O(n)` 时间、`O(1)` 额外空间；无序输入不能靠“相邻是否相同”判断全局重复。

## 10. 找环

### 10.1 判环：141

```cpp
bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

要先移动再比较，初始时二者同在 `head` 并不能说明有环。无环时快指针到达末尾；有环时，两指针进入环后相对距离每轮减少 1，必然相遇。

### 10.2 找入口：142

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            ListNode* entry = head;
            while (entry != slow) {
                entry = entry->next;
                slow = slow->next;
            }
            return entry;
        }
    }
    return nullptr;
}
```

设头到入口距离为 `a`，入口沿 `next` 到相遇点距离为 `b`，环长为 `L`。慢指针相遇时走了 `t = a + b + qL` 步；快指针走 `2t`，两者路程差是整圈，即 `t = mL`。于是：

$$
a+b=(m-q)L \quad\Rightarrow\quad a\equiv-b\pmod L
$$

从相遇点再走 `a` 步便回到入口。从头出发的指针也在 `a` 步后首次到达入口，所以同步每次走一步就能相遇于入口。这里依赖的是快慢速度比 `2:1`；改变速度后不能直接照搬重置规则。

判环和找入口都是 `O(n)` 时间、`O(1)` 额外空间，`n` 为可达的不同节点数。

## 11. 相交链表

160 的相交是两条无环链表共享尾部节点。值相同不代表相交；共享节点之后的 `next` 也相同，因此公共部分一定是尾段。

```cpp
ListNode* getIntersectionNode(ListNode* a, ListNode* b) {
    ListNode* p = a;
    ListNode* q = b;
    while (p != q) {
        p = p ? p->next : b;
        q = q ? q->next : a;
    }
    return p;
}
```

设两条独占前缀长度为 `aLen`、`bLen`，公共尾段长 `c`。换头后到入口，两个指针分别走过 `aLen + c + bLen` 和 `bLen + c + aLen` 个节点对应的路段；代码还各有一次从 `nullptr` 换头的迭代，二者开销相同。长度差因此被抵消。不相交时最终同时停在 `nullptr`。

时间 `O(n + m)`，额外空间 `O(1)`，不修改输入。此模板依赖无环前提；带环链表不能直接套用。

## 12. 拆分、分隔与旋转

### 12.1 按条件稳定分隔：86

维护“小于 x”和“大于等于 x”两条链，逐个尾插，最后连接。尾插保留各自的原始顺序。

```cpp
ListNode* partition(ListNode* head, int x) {
    ListNode smallDummy, largeDummy;
    ListNode* small = &smallDummy;
    ListNode* large = &largeDummy;
    while (head) {
        ListNode* next = head->next;
        head->next = nullptr;
        if (head->val < x) {
            small->next = head;
            small = head;
        } else {
            large->next = head;
            large = head;
        }
        head = next;
    }
    small->next = largeDummy.next;
    return smallDummy.next;
}
```

这里每次摘出节点时就清空旧 `next`，两条结果链的尾部始终为空。也可以保留旧边直到最后，但必须将最终第二条链的尾指针置空，否则可能保留指向前面节点的边。

### 12.2 按位置拆分：328 与奇升偶降

328 按第 1、3、5…个节点和第 2、4、6…个节点拆分，判断的是位置，不是 `val` 的奇偶。沿用上面的双尾链思路，每次切换目标链，最后连接“奇位置链尾 → 偶位置链头”，时间 `O(n)`、额外空间 `O(1)`。

“排序奇升偶降链表”的前提是奇数位置值升序、偶数位置值降序：按位置拆成两链后，反转偶位置链，再用 `mergeTwoLists` 合并。总时间 `O(n)`、额外空间 `O(1)`。没有这个有序前提时，应回到普通链表排序。

### 12.3 旋转链表：61

```cpp
ListNode* rotateRight(ListNode* head, int k) {
    if (!head || !head->next || k <= 0) return head;
    int n = 1;
    ListNode* tail = head;
    while (tail->next) {
        tail = tail->next;
        ++n;
    }
    k %= n;
    if (k == 0) return head;
    tail->next = head;
    ListNode* newTail = head;
    for (int i = 1; i < n - k; ++i) newTail = newTail->next;
    ListNode* newHead = newTail->next;
    newTail->next = nullptr;
    return newHead;
}
```

右移 `k` 位相当于把后 `k % n` 个节点搬到前面。新尾是原链第 `n - k` 个节点（从 1 计数）。临时成环后必须断开；`k` 是链长倍数时直接返回。时间 `O(n)`、额外空间 `O(1)`。

## 13. 两数相加

2 题的低位在前，可以边遍历边产生结果。循环条件要包含进位，例如 `9 + 1` 最后还需生成节点 `1`。

```cpp
ListNode* addTwoNumbers(ListNode* a, ListNode* b) {
    ListNode dummy;
    ListNode* tail = &dummy;
    int carry = 0;
    while (a || b || carry) {
        int sum = carry;
        if (a) { sum += a->val; a = a->next; }
        if (b) { sum += b->val; b = b->next; }
        tail->next = new ListNode(sum % 10);
        tail = tail->next;
        carry = sum / 10;
    }
    return dummy.next;
}
```

前提是每个节点存一位 `0..9` 的十进制数字。结果新建节点，交给调用者释放。时间 `O(max(n,m))`；不计返回结果，辅助空间 `O(1)`，结果本身占 `O(max(n,m))`。

445 的高位在前，可用两个栈分别保存输入数字，从栈顶弹出低位相加，将新节点头插到结果中。这样不修改输入；时间、辅助空间都是 `O(n + m)`。面试题 02.05 的低位在前版本可以复用 2 题模板。

## 14. 随机指针链表复制

[138 题](https://leetcode.cn/problems/copy-list-with-random-pointer/)要求深拷贝：所有新节点的 `next`、`random` 都指向新链节点或空指针，不能连回旧链。`random` 可能向前、向后、指向自身或为空。

### 14.1 地址映射

最直接的方法分两轮：先创建全部新节点，建立“旧地址 → 新地址”映射，再填写连接。

```cpp
#include <unordered_map>

struct RandomNode {
    int val;
    RandomNode* next = nullptr;
    RandomNode* random = nullptr;
    explicit RandomNode(int x) : val(x) {}
};

RandomNode* copyRandomList(RandomNode* head) {
    std::unordered_map<RandomNode*, RandomNode*> copy;
    for (RandomNode* p = head; p; p = p->next) {
        copy[p] = new RandomNode(p->val);
    }
    for (RandomNode* p = head; p; p = p->next) {
        copy[p]->next = p->next ? copy.at(p->next) : nullptr;
        copy[p]->random = p->random ? copy.at(p->random) : nullptr;
    }
    return head ? copy.at(head) : nullptr;
}
```

本文用 `RandomNode` 区分普通链表节点，提交题目时改为平台的 `Node`。`next` 链无环，非空 `random` 指向这条链上的某个节点。哈希键必须是地址：节点值可能重复。哈希表平均时间 `O(n)`，最坏碰撞情况下可退化到 `O(n²)`，辅助空间 `O(n)`，结果另占 `O(n)`。

### 14.2 交织复制

![[图片/SVG/5_2_2_9_4.svg|900]]

将 `A → B → C` 暂时改成 `A → A′ → B → B′ → C → C′`，此时 `原节点->next` 就是对应副本：

1. 逐个创建副本，插在原节点后面。
2. 设置 `p->next->random = p->random ? p->random->next : nullptr`。
3. 拆开奇偶位置的节点，恢复原链，同时接好副本链。

第二轮必须在所有副本都插入后进行，否则向后指的 `random` 可能找不到对应副本。拆分时先保存下一原节点 `nextOriginal = clone->next`，再恢复 `p->next`，并设置 `clone->next = nextOriginal ? nextOriginal->next : nullptr`。

这种方法时间 `O(n)`，不计输出节点的辅助空间 `O(1)`；需要临时修改输入。若输入不能改，使用地址映射。两种写法中的节点分配都按题目环境假定成功，工程代码还需考虑分配失败时的资源回收。

## 15. 双向链表与缓存

CodeTop 本地题单中，146 的排名为 2，频率为 929。它需要的是“已知节点后能在 `O(1)` 时间摘除并移到头部”，因此采用哈希表定位、双向链表记录最近使用顺序。

用头尾两个哨兵时，真实节点 `x` 的摘除操作是：

```cpp
struct DNode {
    int key = 0;
    int value = 0;
    DNode* prev = nullptr;
    DNode* next = nullptr;
};

// x 是已连接的真实节点，左右都有真实节点或哨兵。
void unlinkNode(DNode* x) {
    x->prev->next = x->next;
    x->next->prev = x->prev;
}

// x 已摘除或尚未加入；head 是头哨兵且后面至少有尾哨兵。
void insertAfter(DNode* head, DNode* x) {
    x->prev = head;
    x->next = head->next;
    head->next->prev = x;
    head->next = x;
}
```

最近访问的节点放在头哨兵后面，淘汰尾哨兵前面的节点。哈希表与链表必须同步插入、删除；移动已有节点时通常只改链表连接。具体实现见 [[146. LRU 缓存]]。

460 LFU 再增加“访问次数 → 双向链表”的分桶，相同频率内按最近使用顺序淘汰，并维护最小频率 `minFreq`。链表摘除、插入仍复用上述动作。哈希操作按平均 `O(1)` 计算，两题操作平均为 `O(1)`，空间 `O(capacity)`。

## 17. 常见错误与陷阱

### 17.1 重排节点后未切断尾节点导致成环

**典型场景**：
借助辅助容器（如 `std::multimap`、优先队列或哈希表）对链表节点排序或重新组装。例如按值排序后重新串联：

```cpp
// 常见错误写法：只建立新边，未断开末尾旧边
while (it != mp.end()) {
    tmp->next = it->second;
    tmp = tmp->next;
    it++;
}
// 缺少：tmp->next = nullptr;
```

这段循环只改写了从虚拟头节点到新尾节点之间的前向连接。排在最终结果末尾的那个节点，依然保留着它在原链表中的旧 `next` 指针。

**成环推导**：
以原链表 `4 -> 2 -> 1 -> 3 -> nullptr` 为例：
用 `multimap` 排序后的节点序列为 `1, 2, 3, 4`。
重连时依次建立新边：
- `dummy -> 1`
- `1 -> 2`
- `2 -> 3`
- `3 -> 4`

但节点 `4` 在原链表中初始就指向 `2`（原链表开头为 `4 -> 2`）。重连循环中从未修改过 `4->next`，导致最终结构变成：

```text
原链表：
4 ──→ 2 ──→ 1 ──→ 3 ──→ null
│
└── 4->next 原始指向 2

重排后实际结构：
1 ──→ 2 ──→ 3 ──→ 4
      ↑           │
      └───────────┘
```

实际遍历顺序变为 `1 -> 2 -> 3 -> 4 -> 2 -> 3 -> 4 -> ...`，形成闭环。在线判题系统遍历链表验证结果时便陷入死循环，表现为超时（TLE）或内存超限（MLE）。

**修复方案**：
遍历重连结束后，显式切断新尾节点的旧边：

```cpp
tmp->next = nullptr;
```

**关联避坑：哨兵节点的内存分配**：
重连时不需要写 `ListNode* dummy = new ListNode();`。力扣和常规工程中，无配对 `delete` 的堆分配会产生内存泄漏。直接在栈上定义局部变量即可：

```cpp
ListNode dummy;
ListNode* tmp = &dummy;
```

**完整参考代码（multimap 排序版）**：

```cpp
class Solution {
public:
    ListNode* sortList(ListNode* head) {
        if (!head || !head->next) return head;

        // 收集节点指针，multimap 自动按 val 升序排列并允许重复键
        std::multimap<int, ListNode*> mp;
        ListNode* cur = head;
        while (cur) {
            mp.insert({cur->val, cur});
            cur = cur->next;
        }

        // 栈上哨兵节点，避免堆内存泄漏
        ListNode dummy;
        ListNode* tmp = &dummy;

        for (auto it = mp.begin(); it != mp.end(); ++it) {
            tmp->next = it->second;
            tmp = tmp->next;
        }

        // 关键断尾：切断排在最后节点的旧 next，防止环形链表
        tmp->next = nullptr;

        return dummy.next;
    }
};
```

### 17.2 快慢指针移动前缺少 fast && fast->next 双重保护

**典型错误代码（142 题判环典型崩溃）**：

```cpp
// 错误写法：只在开头判空，循环体内部两步推进缺乏防护
ListNode *detectCycle(ListNode *head) {
    if (head == nullptr || head->next == nullptr)
        return nullptr;

    ListNode* fast = head;
    ListNode* slow = head;
    do {
        fast = fast->next->next; // 崩溃点：若 fast->next 为 nullptr，触发 (nullptr)->next
        slow = slow->next;
        if (fast == nullptr)
            return nullptr;      // 事后检查，此时崩溃已经发生
    } while (fast != slow);
    // ...
}
```

**报错原因与本质**：
- 报错信息：`runtime error: member access within null pointer of type 'ListNode'`。
- 表达式 `fast->next->next` 是两级指针解引用，等价于 `(fast->next)->next`。
- 函数开头的 `if (head == nullptr || head->next == nullptr)` **只能保护从 head 开始的第一步推进**，无法为后续所有迭代提供安全保证。
- 如果链表无环，且节点数量大于等于 3（尤其是奇数长度，例如 `1 -> 2 -> 3 -> nullptr`）：
  - **第 1 轮推进**：`fast` 从节点 `1` 走到节点 `3`，`slow` 走到节点 `2`。此时 `fast != nullptr` 且 `fast != slow`，循环继续。
  - **第 2 轮推进**：`fast` 停在节点 `3`（末尾节点）。
    1. 计算 `fast->next`：节点 `3` 的后继是 `nullptr`。
    2. 计算 `(nullptr)->next`：试图通过空指针访问成员 `next`，立即触发未定义行为崩溃。
- **事后判空的误区**：代码里的 `if (fast == nullptr) return nullptr;` 放在了 `fast = fast->next->next` 之后。崩溃在解引用时就已经发生，程序根本执行不到下一行的 `if`；并且它只检查跳完两步后的结果，未拦截 `fast->next` 为空时强行迈第二步的操作。

**防护规则与标准模板**：
- 执行 `fast = fast->next->next` 之前，必须确保**当前节点**和**下一个节点**都非空：
  - `fast != nullptr`：保证能访问 `fast->next`（迈出第 1 步）。
  - `fast->next != nullptr`：保证能访问 `(fast->next)->next`（迈出第 2 步）。
- 利用 C++ `&&` 的**短路求值特性**：先判 `fast`，若非空再判 `fast->next`。
- 避免使用 `do-while` 结构写快慢指针。`do-while` 强行先执行再判断，极易造成前置安全校验缺失；统一使用 `while (fast != nullptr && fast->next != nullptr)`。

**正确写法（142. 环形链表 II 规范实现）**：

```cpp
class Solution {
public:
    ListNode *detectCycle(ListNode *head) {
        ListNode* slow = head;
        ListNode* fast = head;

        // 每次走两步前，必须同时确保 fast 与 fast->next 均有效
        while (fast != nullptr && fast->next != nullptr) {
            slow = slow->next;
            fast = fast->next->next;
            if (slow == fast) {
                // 相遇后，一指针从头出发，步长为 1，与 slow 同步前进直到在入口相遇
                ListNode* entry = head;
                while (entry != slow) {
                    entry = entry->next;
                    slow = slow->next;
                }
                return entry;
            }
        }

        // fast 到达链表末尾，说明无环
        return nullptr;
    }
};
```
