## 什么是高精度

当整数大到连 `long long` 都装不下时（`long long` 上限约 `9.2 × 10¹⁸`，即 19 位），就无法用内置类型直接运算，只能像**手算竖式**那样，用数组逐位模拟加减乘除。

| 语言 | 大整数支持 | 是否需手写高精度 |
|------|-----------|------------------|
| Python | 原生 `int` 任意精度 | 不需要 |
| Java | `BigInteger` / `BigDecimal` | 不需要 |
| C++ | 内置类型最多 64 位 | **需要手写** |

> [!tip] 四种运算的核心套路
> | 运算 | 关键变量 | 方向 | 易错点 |
> |------|----------|------|--------|
> | 加法 | 进位 `t` | 低 → 高 | 末尾进位要补一位 |
> | 减法 | 借位 `t` | 低 → 高 | `(t+10)%10`、去前导零 |
> | 乘法（×小数） | 进位 `t` | 低 → 高 | `t += A[i]*b` 再 `%10` |
> | 除法（÷小数） | 余数 `r` | **高 → 低** | 结果需 `reverse` |

## 大整数的存储方式

### 存储原则

- 以字符串形式读入大整数
- **逆序存储**到 [[5.1.1 vector|vector]] 中：低位存在数组低索引，高位存在数组高索引
- 原因：进位永远朝最高位走；逆序后最高位在数组末尾，`C.push_back()` 直接追加新位即可，无需移动元素

### 图解

![[图片/5.算法/5.2 算法/5_2_2_3_1.svg]]

```cpp
string a = "12345";
// 逆序存储为: A[0]=5, A[1]=4, A[2]=3, A[3]=2, A[4]=1
for (int i = a.size() - 1; i >= 0; i--) A.push_back(a[i] - '0');
```

## 高精度加法

### 思路

1. 逆序存储两个大整数 A 和 B
2. 从低位开始逐位相加：`t = A[i] + B[i] + 进位`
3. 当前结果位 `= t % 10`，新进位 `= t / 10`
4. 循环结束后若进位非 0，再追加一位

### 图解

![[图片/5.算法/5.2 算法/5_2_2_3_2.svg]]

### 代码模板

```cpp
#define _CRT_SECURE_NO_WARNINGS
#include <iostream>
#include <vector>

using namespace std;

// A、B 均为逆序存储的大数，返回逆序的和 C
vector<int> add(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;  // 进位

    for (int i = 0; i < A.size() || i < B.size(); i++) {
        if (i < A.size()) t += A[i];
        if (i < B.size()) t += B[i];
        C.push_back(t % 10);  // 结果位
        t /= 10;              // 新进位
    }

    if (t) C.push_back(t);    // 末尾进位补一位（t 此时为 0 或 1）

    return C;
}

int main() {
    string a, b;
    vector<int> A, B;

    cin >> a >> b;
    // 反转存储：字符串高位在前，逆序后低位在前
    for (int i = a.size() - 1; i >= 0; i--) A.push_back(a[i] - '0');
    for (int i = b.size() - 1; i >= 0; i--) B.push_back(b[i] - '0');

    auto C = add(A, B);

    // 结果也是逆序存储，需逆序输出
    for (int i = C.size() - 1; i >= 0; i--) printf("%d", C[i]);

    return 0;
}
```

> 原模板末尾写的是 `if (t) C.push_back(1);`——这里进位恒为 0 或 1，写 `1` 没问题；但更通用的写法是 `C.push_back(t)`，对乘法等进位可能 >1 的场景同样成立。

## 高精度减法

### 核心思想：竖式借位

减法就是小学列竖式：**两数右对齐，从个位开始逐列相减**。某一列「不够减」时，向高一位借 1，本列加 10 再减；被借的高位下次计算时要先减掉这个 1。代码把整件事压成一个循环：

- 从低位（数组的低索引）扫到高位；
- 每一列计算 `本位结果 = A[i] − B[i] − 借位`；
- 不够减就向高位借位，够减就不借。

由于程序无法表示负数结果，**必须保证被减数 ≥ 减数**；若 A < B，就交换两数相减、并在结果前加负号（见下方主函数）。

### 比较大小：保证大数减小数

`cmp(A, B)` 返回 `A ≥ B`，用于决定谁当被减数。注意数组是**逆序存储**的（高位在高索引），所以比较要从高索引往低走：

```cpp
// 返回 true 表示 A >= B
bool cmp(vector<int>& A, vector<int>& B) {
    if (A.size() != B.size()) return A.size() > B.size();  // 位数多的更大
    for (int i = A.size() - 1; i >= 0; i--) {              // 从最高位往下比
        if (A[i] != B[i])
            return A[i] > B[i];
    }
    return true;  // 完全相等，视为 A >= B
}
```

### 图解

![[图片/5.算法/5.2 算法/5_2_2_3_3.svg]]

### 代码模板

```cpp
// 调用前需保证 A >= B
vector<int> sub(vector<int>& A, vector<int>& B) {
    vector<int> C;
    int t = 0;  // t：上一位传来的借位（0 或 1）

    for (int i = 0; i < A.size(); i++) {
        t = A[i] - t;                  // 先扣掉上一位借走的 1
        if (i < B.size()) t -= B[i];   // 再减 B 的当前位（B 可能更短）
        C.push_back((t + 10) % 10);    // 写入本位结果
        t = t < 0 ? 1 : 0;             // 本位是否需要向高位借位
    }

    while (C.size() > 1 && C.back() == 0) C.pop_back();  // 去前导零

    return C;
}
```

### 关键 1：借位变量 `t` 的双重身份

整段最容易看晕的，是 `t` 在一次循环里换了三次角色：

| 时机 | `t` 代表什么 | 取值 |
|------|-------------|------|
| 进入循环体时 | **上一位传来的借位** | 0 或 1 |
| 执行完 `t = A[i] - t` 和 `t -= B[i]` 后 | **本位的带符号差** `A[i]−借位−B[i]` | −10 ~ 9 |
| 执行完 `t = t < 0 ? 1 : 0` 后 | **要传给下一位的借位** | 0 或 1 |

所以这四行就是「读入借位 → 算本位 → 写结果 → 算出新借位」的流水线，`t` 同时充当**输入借位**与**临时差值**，省掉了额外变量。

### 关键 2：为什么是 `(t + 10) % 10`

算完 `t = A[i] − 借位 − B[i]` 后，`t` 的范围是 `[−10, 9]`，要把它变成 `[0, 9]` 的真实数字位：

- **够减**（`t ≥ 0`）：`(t + 10) % 10 == t`，原样保留；
- **不够减**（`t < 0`）：`(t + 10) % 10 == t + 10`，正好就是「向高位借 10 后」该填的数字。

一个表达式把「借」与「不借」两种情况合并，无需 `if` 分支。

> ⚠️ 不能写成 `t % 10`：C++ 中负数取模结果仍为负（`-2 % 10 == -2`），得不到正确的位。

### 逐位模拟：`205 − 47 = 158`

逆序存储后 `A = [5,0,2]`、`B = [7,4]`（`B` 没有第 2 位，按 0 处理）：

| `i` | 位 | `A[i]` | 借入 `t` | `A[i]−t−B[i]` | `(t+10)%10` → `C[i]` | 借出 `t` |
|:---:|:--:|:------:|:--------:|:-------------:|:--------------------:|:--------:|
| 0 | 个 | 5 | 0 | 5 − 0 − 7 = **−2** | **8** | 1 |
| 1 | 十 | 0 | 1 | 0 − 1 − 4 = **−5** | **5** | 1 |
| 2 | 百 | 2 | 1 | 2 − 1 − 0 = **1** | **1** | 0 |

`C = [8,5,1]`，逆序输出即 `158`。下图把竖式、四步代码与逐列借位串到一起：

![[图片/5.算法/5.2 算法/5_2_3_1.svg]]

*图：`205 − 47` 的逐位借位过程——借位 `t` 从个位一路向高位传递。*

### 去除前导零

高位相减可能产生多余的 0。例如 `1000 − 2 = 998`，`A` 有 4 位但结果只有 3 位，计算得到 `C = [8,9,9,0]`（逆序是 `0998`）。数组**末尾**的 0 正是结果的**高位前导零**，要去掉：

```cpp
while (C.size() > 1 && C.back() == 0) C.pop_back();
```

`C.size() > 1` 不可省略：否则当结果本身就是 0（如 `5 − 5`）时，会把唯一的 0 也删掉，输出空串。

### 主函数：先比较，再相减

`sub` 只处理 `A ≥ B`；负数结果要在外层用 `cmp` 判断并补负号：

```cpp
int main() {
    string a, b;
    cin >> a >> b;
    vector<int> A, B;
    for (int i = a.size() - 1; i >= 0; i--) A.push_back(a[i] - '0');
    for (int i = b.size() - 1; i >= 0; i--) B.push_back(b[i] - '0');

    if (cmp(A, B)) {                 // A >= B，结果非负
        auto C = sub(A, B);
        for (int i = C.size() - 1; i >= 0; i--) printf("%d", C[i]);
    } else {                         // A < B，结果为负
        printf("-");
        auto C = sub(B, A);          // 交换，仍然用大数减小数
        for (int i = C.size() - 1; i >= 0; i--) printf("%d", C[i]);
    }
    return 0;
}
```

### 易错点

1. **不比较大小直接相减**：`sub` 假设 `A ≥ B`，否则结果错乱；`A < B` 时必须交换并输出负号。
2. **用 `t % 10` 代替 `(t + 10) % 10`**：负数取模在 C++ 中为负，得到错误的位。
3. **去前导零漏掉 `C.size() > 1`**：结果为 0 时会被删成空串。
4. **忘记 `if (i < B.size())`**：当 `B` 比 `A` 短时会越界访问 `B[i]`。

## 高精度乘法（大数 × 小数）

乘法与加法是**同一套进位机制**：把「逐位相加」换成「逐位乘 b 再累加进位」即可。

`t = A[i] * b + 进位`，结果位 `= t % 10`，新进位 `= t / 10`。注意此时进位可能远大于 1（如 `9*9=81`），所以循环条件要带上 `t`。

> [!tip] 动画演示
> `456 × 8 = 3648` 的逐位过程——看进位如何一次到 4、以及末尾 `t=3` 靠 `|| t` 补出最高位：[▶ 乘法动画](<file:///Users/melene/Documents/C++/obsidian_notes-main/5.算法/5.2 算法/5.2.3.1 高精度动画.html#scene=mul>)。

### 代码模板

```cpp
// A 为逆序大数，b 为小整数，返回 A * b（逆序）
vector<int> mul(vector<int>& A, int b) {
    vector<int> C;
    int t = 0;

    for (int i = 0; i < A.size() || t; i++) {  // t 非 0 时继续处理高位进位
        if (i < A.size()) t += A[i] * b;
        C.push_back(t % 10);
        t /= 10;
    }

    while (C.size() > 1 && C.back() == 0) C.pop_back();  // 处理 b == 0

    return C;
}
```

> 大数 × 大数则需双重循环：`num1[i] * num2[j]` 累加到结果的第 `i + j` 位（详见练习题 43）。

## 高精度除法（大数 ÷ 小数）

### 思路

除法是唯一**从高位开始**的运算。维护一个余数 `r`，自最高位向低位扫描：

`r = r * 10 + A[i]`，商位 `= r / b`，新余数 `= r % b`。

由于商是高位→低位生成的，与逆序存储相反，所以最后要 `reverse` 再去前导零。

### 图解

![[图片/5.算法/5.2 算法/5_2_2_3_4.svg]]

### 代码模板

```cpp
// A 为逆序大数，b 为小整数，r 引用返回余数，返回商（逆序）
vector<int> div(vector<int>& A, int b, int& r) {
    vector<int> C;
    r = 0;

    for (int i = A.size() - 1; i >= 0; i--) {  // 从最高位开始
        r = r * 10 + A[i];
        C.push_back(r / b);  // 商位（暂为高→低顺序）
        r %= b;
    }

    reverse(C.begin(), C.end());  // 翻成低→高，与其他运算对齐
    while (C.size() > 1 && C.back() == 0) C.pop_back();  // 去前导零

    return C;
}

int main() {
    string a;
    int b;

    cin >> a >> b;
    vector<int> A;
    // 除法本可不逆序，但为与其他运算保持一致仍逆序存储
    for (int i = a.size() - 1; i >= 0; i--) A.push_back(a[i] - '0');

    int r;
    auto C = div(A, b, r);

    for (int i = C.size() - 1; i >= 0; i--) printf("%d", C[i]);
    printf("\n%d", r);  // 输出余数

    return 0;
}
```

---

## 关键要点

1. **逆序存储**：低位存低索引，进位时末尾追加，免去元素搬移。
2. **进位 / 借位**：用变量 `t` 统一处理，加法 `t/10`、乘法 `t/=10`、减法看 `t<0`。
3. **去除前导零**：`while (C.size() > 1 && C.back() == 0) C.pop_back();`，保留至少一位。
4. **比较大小**：先比位数，再从最高位逐位比较。
5. **除法特殊**：从高位开始，结果需 `reverse`。

---

## 易错点

| 易错点 | 说明 |
|--------|------|
| 前导零未去除 | 减法、乘 0、除法都可能产生高位多余的 0，须 `pop_back` 但**至少保留一位**。 |
| 减法未保证 A≥B | 不先 `cmp` 就相减会得到错误的负数结果；需要负号时应交换并补 `-`。 |
| 进位写死为 1 | 加法进位是 0/1，但乘法进位可 >1，循环条件务必带 `|| t`，补位用 `push_back(t)`。 |
| 除法忘记 reverse | 商是高→低生成的，不翻转会整体倒序输出。 |
| 输出顺序 | 内部逆序存储，输出时必须从 `C.size()-1` 倒着打印。 |
| 越界访问 | 加减法两数长度不同，访问 `A[i]`/`B[i]` 前先判 `i < size()`。 |
