# 5.2.24 图论基础

图（Graph）是节点（Vertex）和边（Edge）组成的非线性数据结构，用来描述一组对象之间的关联关系。它是算法竞赛与力扣高频考点之一，地图寻路、依赖关系、网络传播、社交关系等问题都能抽象成图。

本章聚焦力扣中最常见的图算法核心：图的存储、DFS / BFS、拓扑排序、并查集、最短路径（Dijkstra）。每个算法都给出 Modern C++ 模板代码，并链到一道经典力扣案例题。

---

## 1. 图概览

### 1.1 什么是图

形式化定义：图是一个二元组 `G = (V, E)`，其中：

- `V` 是节点（Vertex）集合，也称顶点
- `E` 是边（Edge）集合，每条边连接两个节点

```text
节点：A、B、C、D
边：(A, B)、(A, C)、(B, D)、(C, D)
```

直观示意：

```text
    A ─── B
    │     │
    C ─── D
```

> [!note]
> [[5.2.12 二叉树与遍历算法]] 中的二叉树是图的一种特殊形式：它是一个**无环、连通、有根**的有向图，每个节点最多有 2 个出边。

### 1.2 基本术语

| 术语 | 含义 |
|------|------|
| 度（Degree） | 一个节点连接的边数 |
| 入度（In-degree） | 有向图中指向该节点的边数 |
| 出度（Out-degree） | 有向图中从该节点发出的边数 |
| 路径（Path） | 节点序列，相邻节点之间都有边相连 |
| 环（Cycle） | 起点与终点相同的路径 |
| 连通（Connected） | 两节点之间存在路径 |
| 连通分量 | 极大连通子图 |
| 强连通 | 有向图中两节点能互相到达 |
| 稀疏图 | 边数远小于 `V^2` |
| 稠密图 | 边数接近 `V^2` |

### 1.3 常见图类型

| 类型 | 特点 | 力扣典型题 |
|------|------|-----------|
| 无向图 | 边没有方向，`(u, v)` 与 `(v, u)` 等价 | 547. 省份数量、200. 岛屿数量 |
| 有向图 | 边有方向 | 207. 课程表 |
| 带权图 | 每条边附带权重 | 743. 网络延迟时间 |
| 无权图 | 所有边权重相同（视为 1） | 994. 腐烂的橘子 |
| DAG（有向无环图） | 有向、无环；可拓扑排序 | 207. 课程表、210. 课程表 II |
| 完全图 | 任意两点都有边 | 罕见 |

### 1.4 图与已有数据结构的关系

C++ STL 没有直接提供图容器，但常用容器组合即可表达图：

- 节点列表、邻接表：[[5.1.1 vector]]、[[5.1.5 map]]
- BFS 队列：[[5.1.2 queue]]
- DFS 栈（迭代写法）、Dijkstra 优先队列：[[5.1.8 容器适配器]]
- 顶点去重 / 集合判断：[[5.1.4 set]]

## 2. 图的存储方式

存图本质就是把「节点之间的连接关系」编码进数据结构。三种主流方案各有取舍。

### 2.1 邻接矩阵

用一个 `n × n` 的二维数组 `g[u][v]` 表示是否有边。

```cpp
int n = 4;
vector<vector<int>> g(n, vector<int>(n, 0));

// 添加无向边 (0, 1)
g[0][1] = 1;
g[1][0] = 1;

// 带权图：直接存储权值，不存边时用 INT_MAX 或 -1
```

特点：

1. 查询任意两点之间是否有边 `O(1)`。
2. 空间 `O(V^2)`，节点多时会爆内存。
3. 适合**稠密图**或节点数较小（一般 `n <= 1000`）。

### 2.2 邻接表

每个节点维护一个邻居列表。

```cpp
int n = 4;
vector<vector<int>> g(n);

// 添加无向边 (u, v)
g[u].push_back(v);
g[v].push_back(u);

// 带权图：邻居列表存 pair<邻居, 权重>
vector<vector<pair<int, int>>> wg(n);
wg[u].emplace_back(v, w);
wg[v].emplace_back(u, w);
```

特点：

1. 空间 `O(V + E)`，对**稀疏图**友好。
2. 遍历某点的所有邻居 `O(度数)`。
3. 力扣 99% 的图题都用邻接表。

### 2.3 边集数组

直接保存所有边。

```cpp
struct Edge {
    int u, v, w;
};

vector<Edge> edges;
edges.push_back({0, 1, 5});
```

特点：

1. 实现最简单。
2. 适合 Kruskal 最小生成树、Bellman-Ford 等需要按边迭代的算法。
3. 单次「查某条边是否存在」要 `O(E)`，不适合频繁查询。

### 2.4 三种存储对比

| 存储方式 | 空间 | 查询有边 | 遍历邻居 | 适用场景 |
|----------|------|----------|----------|----------|
| 邻接矩阵 | `O(V^2)` | `O(1)` | `O(V)` | 稠密图、节点少 |
| 邻接表 | `O(V + E)` | `O(度数)` | `O(度数)` | 稀疏图（推荐） |
| 边集数组 | `O(E)` | `O(E)` | 不直接支持 | Kruskal、Bellman-Ford |

> [!tip]
> 力扣输入常见两种格式：①邻接矩阵 `vector<vector<int>>`；②边列表 `vector<vector<int>>` 形如 `[[u, v, w], ...]`。后者通常需要先转成邻接表再做算法。

## 3. 深度优先搜索 DFS

### 3.1 核心思想

沿着一条路径走到尽头再回退，类似于走迷宫时一直贴左墙走。配合 `visited` 数组防止重复访问导致的死循环。

### 3.2 邻接表上的递归模板

```cpp
void dfs(int u, const vector<vector<int>>& g, vector<bool>& visited) {
    visited[u] = true;

    // 此处处理节点 u（前序时机）

    for (int v : g[u]) {
        if (!visited[v]) {
            dfs(v, g, visited);
        }
    }

    // 此处处理节点 u（后序时机）
}

// 调用入口：对每个未访问节点启动一次 DFS
int n = g.size();
vector<bool> visited(n, false);
for (int i = 0; i < n; ++i) {
    if (!visited[i]) {
        dfs(i, g, visited);
    }
}
```

### 3.3 网格图上的 DFS（力扣高频）

岛屿系列题里图的节点用 `(行, 列)` 表示：

```cpp
const int dirs[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};

void dfs(int x, int y, vector<vector<char>>& grid) {
    int m = grid.size(), n = grid[0].size();
    if (x < 0 || x >= m || y < 0 || y >= n) return;
    if (grid[x][y] != '1') return;

    grid[x][y] = '0';                       // 直接修改原图作为 visited
    for (auto& d : dirs) {
        dfs(x + d[0], y + d[1], grid);
    }
}
```

### 3.4 典型应用

1. 连通分量计数（每启动一次 DFS 等于发现一个分量）
2. 路径搜索 / 全路径枚举
3. 环检测（带颜色标记的 DFS）
4. 树形 DP 的后序时机

### 3.5 力扣案例

- [[200. 岛屿数量]] — 网格 DFS 入门题，求连通分量数

> [!warning]
> 递归 DFS 在最坏情况下递归深度等于节点数，节点数大于 10⁵ 时可能栈溢出，此时改用显式栈的迭代写法。

## 4. 广度优先搜索 BFS

### 4.1 核心思想

用队列分层扩展，先访问与起点距离 1 的节点，再访问距离 2 的，依此类推。在**无权图**中，BFS 第一次到达某节点的步数就是最短路径长度。

### 4.2 邻接表上的 BFS 模板

```cpp
vector<int> bfs(int start, const vector<vector<int>>& g) {
    int n = g.size();
    vector<int> dist(n, -1);
    queue<int> q;

    dist[start] = 0;
    q.push(start);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : g[u]) {
            if (dist[v] == -1) {
                dist[v] = dist[u] + 1;
                q.push(v);
            }
        }
    }

    return dist;
}
```

`dist` 兼任两个角色：①标记是否访问过（`-1` 表示没访问）；②记录到起点的最短步数。

### 4.3 多源 BFS

把所有起点同时入队，本质是「在所有起点上方虚拟一个超级源点」。

```cpp
queue<pair<int, int>> q;
for (int i = 0; i < m; ++i) {
    for (int j = 0; j < n; ++j) {
        if (grid[i][j] == 2) {              // 所有腐烂橘子都是起点
            q.emplace(i, j);
        }
    }
}
// 之后做正常的 BFS 扩展
```

### 4.4 与二叉树层序遍历的对比

| 方面 | 二叉树层序 | 图的 BFS |
|------|-----------|---------|
| 是否需要 `visited` | 不需要（树天然无环） | 需要（图可能有环） |
| 邻居数量 | 至多 2 个 | 任意 |
| 终点条件 | 队列空或目标节点 | 队列空或目标节点 |
| 模板差异 | 仅扩展 `left` / `right` | 遍历邻接表 |

详见 [[5.2.12 二叉树与遍历算法]]。

## 5. 拓扑排序

### 5.1 适用场景

仅适用于 **DAG（有向无环图）**。把节点排成一条线，使每条有向边都从前指向后；典型应用：

- 编译依赖（先编译被依赖的模块）
- 课程先修关系
- 任务调度

### 5.2 Kahn 算法（BFS + 入度数组）

```cpp
vector<int> topoSort(int n, const vector<vector<int>>& g) {
    vector<int> indeg(n, 0);
    for (int u = 0; u < n; ++u) {
        for (int v : g[u]) ++indeg[v];
    }

    queue<int> q;
    for (int i = 0; i < n; ++i) {
        if (indeg[i] == 0) q.push(i);
    }

    vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);

        for (int v : g[u]) {
            if (--indeg[v] == 0) q.push(v);
        }
    }

    return order;                           // 长度 < n 表示有环
}
```

### 5.3 DFS 后序逆序法

对图做 DFS，节点在「后序时机」加入结果数组，最终反转即可得到拓扑序。判环需要三色标记：白（未访问）、灰（在递归栈上）、黑（递归完成）；遇到灰色节点表示存在环。

### 5.4 环检测

`Kahn` 算法天然能检测环：如果最终 `order.size() < n`，说明有节点的入度始终降不到 0，意味着这些节点处在环中。

### 5.5 力扣案例

- [[207. 课程表]] — 判断是否能完成所有课程，等价于「DAG 是否存在拓扑排序」

> [!important]
> 拓扑排序的结果**不唯一**。同一张 DAG 可能有多个合法的线性序，只要满足所有「先决关系」即可。

## 6. 并查集 Union-Find

### 6.1 核心思想

维护若干不相交集合，支持两个核心操作：

- `find(x)`：查 `x` 所在集合的代表元
- `union(x, y)`：合并 `x` 和 `y` 所在的集合

集合用「树」表示，树根作为代表元。

### 6.2 实现要点

两项关键优化让单次操作均摊接近 `O(1)`（更精确是反阿克曼函数 `O(α(n))`）：

1. **路径压缩**：`find` 时把链上所有节点直接挂到根
2. **按秩合并**：让矮树挂到高树下面，避免树高失衡

### 6.3 C++ 模板

```cpp
class UnionFind {
public:
    explicit UnionFind(int n) : parent_(n), rank_(n, 0), count_(n) {
        iota(parent_.begin(), parent_.end(), 0);    // 每个节点自成一个集合
    }

    int find(int x) {
        if (parent_[x] != x) {
            parent_[x] = find(parent_[x]);          // 路径压缩
        }
        return parent_[x];
    }

    bool unite(int x, int y) {
        int rx = find(x), ry = find(y);
        if (rx == ry) return false;

        if (rank_[rx] < rank_[ry]) swap(rx, ry);    // 按秩合并：rx 较高
        parent_[ry] = rx;
        if (rank_[rx] == rank_[ry]) ++rank_[rx];
        --count_;
        return true;
    }

    int count() const { return count_; }            // 当前连通分量数

private:
    vector<int> parent_;
    vector<int> rank_;
    int count_;
};
```

### 6.4 应用场景

1. 连通分量计数（动态合并）
2. 判断两个节点是否在同一集合
3. Kruskal 最小生成树（按权重排边后用并查集判环）
4. 在线连通性问题（节点 / 边动态加入）

### 6.5 力扣案例

- [[547. 省份数量]] — 邻接矩阵给定，求连通分量数；并查集解法直接调用 `count()`

> [!tip]
> 「连通性」「合并集合」「分组判断」这三类关键词出现时，优先考虑并查集。

## 7. 最短路径：Dijkstra

### 7.1 适用条件

- **非负权**有向图或无向图
- 单源最短路径：从一个起点到所有其他点

如果存在负权边，必须改用 Bellman-Ford；如果图很小且需要任意两点最短路径，可以用 Floyd-Warshall。本章不展开后两者。

### 7.2 朴素版与堆优化版

| 版本 | 时间复杂度 | 空间 | 实现难度 | 适用场景 |
|------|-----------|------|----------|----------|
| 朴素 Dijkstra | `O(V^2)` | `O(V)` | 简单 | 稠密图 |
| 堆优化 Dijkstra | `O((V + E) log V)` | `O(V + E)` | 中等 | 稀疏图（推荐） |

### 7.3 堆优化 C++ 实现

```cpp
vector<int> dijkstra(int n, int start,
                     const vector<vector<pair<int, int>>>& g) {
    constexpr int INF = numeric_limits<int>::max();
    vector<int> dist(n, INF);
    dist[start] = 0;

    // 小顶堆：(当前已知最短距离, 节点编号)
    using PII = pair<int, int>;
    priority_queue<PII, vector<PII>, greater<PII>> pq;
    pq.emplace(0, start);

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        if (d > dist[u]) continue;          // 过期记录直接丢弃

        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;      // 松弛操作
                pq.emplace(dist[v], v);
            }
        }
    }

    return dist;
}
```

### 7.4 关键点

1. **松弛操作（Relaxation）**：尝试用 `u` 这条路径来更新 `v` 的当前最短距离。
2. **小顶堆而非普通队列**：BFS 适用于无权图，每条边权重相同；Dijkstra 必须每次取出当前距离最小的节点，否则贪心策略不成立。
3. **过期记录处理**：堆里可能存在同一节点的多条距离记录，新的更短距离插入后，旧的较长距离没有删除，所以出堆时要判断 `d > dist[u]`。

### 7.5 为什么不能处理负权

Dijkstra 基于贪心：「当前堆顶的距离已经是最终答案」。负权破坏了这个前提——之后可能出现一条更短的路径回头更新已经定型的节点。

## 8. 算法选型与复杂度对照

### 8.1 一表对照

| 算法 | 时间复杂度 | 空间复杂度 | 典型用途 | 力扣案例 |
|------|-----------|-----------|----------|----------|
| DFS | `O(V + E)` | `O(V)` | 连通性、路径枚举、环检测 | [[200. 岛屿数量]] |
| BFS | `O(V + E)` | `O(V)` | 无权最短步数、分层扩展 | [[994. 腐烂的橘子]] |
| 拓扑排序 Kahn | `O(V + E)` | `O(V)` | DAG 线性化、依赖排序、环检测 | [[207. 课程表]] |
| 并查集 | `O(α(n))` 均摊 | `O(V)` | 动态连通性、分组、Kruskal MST | [[547. 省份数量]] |
| Dijkstra（堆） | `O((V + E) log V)` | `O(V + E)` | 非负权单源最短路径 | [[743. 网络延迟时间]] |

### 8.2 选型决策树

> [!tip]
> 看到题目特征时优先考虑：
> - **「连通分量」「是否能从 A 到 B」** → 并查集 或 DFS
> - **「最短步数」（无权图）** → BFS
> - **「最短距离 / 最少代价」（带权非负）** → Dijkstra
> - **「依赖关系 / 先修课」「能否完成所有」** → 拓扑排序
> - **「岛屿 / 网格连通块」** → DFS / BFS / 并查集 三选一
> - **「有环检测」** → 拓扑排序（有向）或 DFS 颜色标记

## 9. 常见易错点

1. **`visited` 数组遗漏**：图可能有环，DFS / BFS 必须标记，否则死循环或栈溢出。
2. **无向图建图忘记双向加边**：邻接表里要 `g[u].push_back(v)` 与 `g[v].push_back(u)` 两次。
3. **网格 DFS 的越界判断**：先判 `x, y` 是否在 `[0, m) × [0, n)` 范围内，再判内容。
4. **Dijkstra 用普通队列**：会得到错误结果，必须用小顶堆。
5. **并查集忘记路径压缩**：在 10⁵ 量级数据上会 TLE。
6. **拓扑排序未处理多个起点**：图可能不连通，初始时所有入度为 0 的节点都要入队。
7. **递归 DFS 深度过大**：节点数大于 10⁵ 时可能爆栈，改用迭代或显式栈。
8. **带权图与无权图混淆**：边权 = 1 时 BFS 也能求最短，但边权不等时 BFS 会给出错误答案。
