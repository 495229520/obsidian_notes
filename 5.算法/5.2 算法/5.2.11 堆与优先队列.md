# 5.2.11 堆与优先队列

> 堆适合维护一个动态候选集合里的最大值或最小值。`priority_queue` 是 C++ 对堆的封装，核心能力是快速 `push`、`pop` 和查看 `top`。

---

## 堆解决什么问题

很多题目不需要把所有元素完整排序，只需要反复拿到当前最大或最小的候选值。

| 场景 | 需要维护什么 | 常用堆 |
|------|--------------|--------|
| Top K | 当前最大的 k 个或最小的 k 个 | 大根堆 / 小根堆 |
| 合并 K 个有序链表 | K 个链表当前最小头节点 | 小根堆 |
| 数据流中位数 | 左半区最大值和右半区最小值 | 大根堆 + 小根堆 |
| Dijkstra | 当前已知距离最小的节点 | 小根堆 |
| 任务调度 | 当前优先级最高的任务 | 按题意自定义 |

> [!tip]
> 堆不是让所有元素都有序，而是保证堆顶元素优先级最高。只要题目反复出现“动态插入 + 取最大/最小”，就应该想到堆。

## priority_queue 基础

`priority_queue` 默认是大根堆，堆顶是当前最大值。

```cpp
#include <queue>

std::priority_queue<int> maxHeap;
maxHeap.push(3);
maxHeap.push(10);
maxHeap.push(5);

int top = maxHeap.top();  // 10
maxHeap.pop();
```

如果要小根堆，需要使用 `greater<int>`：

```cpp
#include <functional>
#include <queue>
#include <vector>

std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;
```

基本复杂度：

| 操作 | 复杂度 | 说明 |
|------|--------|------|
| `top()` | `O(1)` | 查看堆顶 |
| `push()` | `O(log n)` | 插入后上浮调整 |
| `pop()` | `O(log n)` | 删除堆顶后下沉调整 |
| `size()` | `O(1)` | 元素数量 |

接口细节可回看 [[5.算法/5.1 STL/5.1.8 容器适配器|5.1.8 容器适配器]]。

## C++ 自定义比较器

`priority_queue<T, Container, Compare>` 里的 `Compare` 决定谁优先级低。

如果 `Compare(a, b)` 返回 `true`，表示 `a` 的优先级低于 `b`，`a` 更不应该排在堆顶。

### 小根堆

```cpp
#include <functional>
#include <queue>
#include <vector>

std::priority_queue<int, std::vector<int>, std::greater<int>> minHeap;
```

`greater<int>` 会让较大的元素优先级更低，所以较小的元素在堆顶。

### 结构体比较器

```cpp
#include <queue>
#include <vector>

struct Node {
    int value;
    int freq;
};

struct Compare {
    bool operator()(const Node& a, const Node& b) const {
        if (a.freq != b.freq) {
            return a.freq > b.freq;
        }
        return a.value > b.value;
    }
};

std::priority_queue<Node, std::vector<Node>, Compare> heap;
```

这个比较器让 `freq` 较小的节点排在堆顶；频率相同时，`value` 较小的节点排在堆顶。

> [!warning]
> `priority_queue` 的比较器和 `sort` 很容易写反。`sort` 里的比较器表示“谁排前面”，而 `priority_queue` 里的比较器表示“谁优先级更低”。

## Top K

Top K 是堆最典型的场景。以“第 K 大元素”为例，可以用小根堆维护当前最大的 `k` 个数。

```cpp
#include <functional>
#include <queue>
#include <vector>

int kthLargest(const std::vector<int>& nums, int k) {
    std::priority_queue<int, std::vector<int>, std::greater<int>> heap;

    for (int x : nums) {
        heap.push(x);
        if (static_cast<int>(heap.size()) > k) {
            heap.pop();
        }
    }

    return heap.top();
}
```

为什么小根堆有效：

1. 堆里只保留当前见过的最大的 `k` 个数。
2. 堆顶是这 `k` 个数里最小的。
3. 遍历结束后，堆顶就是整个数组的第 `k` 大。

这个思路对应 [[5.算法/力扣/215. 数组中的第K个最大元素|215. 数组中的第K个最大元素]]。

> [!note]
> 力扣题通常保证 `1 <= k <= nums.size()`。如果写工程代码，需要先处理 `k <= 0` 或 `k > nums.size()` 的非法输入。

## 合并 K 个有序链表

合并 K 个有序链表时，每条链表当前头节点都是候选。每次取最小头节点接到答案后，再把它的下一个节点放入堆。

```cpp
#include <queue>
#include <vector>

struct ListNode {
    int val;
    ListNode* next;
};

struct CompareListNode {
    bool operator()(const ListNode* a, const ListNode* b) const {
        return a->val > b->val;
    }
};

ListNode* mergeKLists(std::vector<ListNode*>& lists) {
    std::priority_queue<ListNode*, std::vector<ListNode*>, CompareListNode> heap;

    for (ListNode* head : lists) {
        if (head != nullptr) {
            heap.push(head);
        }
    }

    ListNode dummy{0, nullptr};
    ListNode* tail = &dummy;

    while (!heap.empty()) {
        ListNode* node = heap.top();
        heap.pop();

        tail->next = node;
        tail = tail->next;

        if (node->next != nullptr) {
            heap.push(node->next);
        }
    }

    return dummy.next;
}
```

设所有链表总节点数为 `N`，链表数量为 `K`：

- 每个节点进堆、出堆一次。
- 堆大小最多为 `K`。
- 时间复杂度是 `O(NlogK)`，空间复杂度是 `O(K)`。

## 数据流中位数

数据流中位数需要动态插入数字，并随时返回中位数。常见做法是维护两个堆：

| 堆 | 保存内容 | 堆顶含义 |
|----|----------|----------|
| 大根堆 `left` | 较小的一半 | 左半区最大值 |
| 小根堆 `right` | 较大的一半 | 右半区最小值 |

要求：

1. `left.size()` 和 `right.size()` 的差不超过 1。
2. `left.top() <= right.top()`。
3. 如果总数为奇数，让 `left` 多一个元素。

```cpp
#include <functional>
#include <queue>
#include <vector>

class MedianFinder {
public:
    void addNum(int num) {
        if (left.empty() || num <= left.top()) {
            left.push(num);
        } else {
            right.push(num);
        }

        if (left.size() > right.size() + 1) {
            right.push(left.top());
            left.pop();
        } else if (right.size() > left.size()) {
            left.push(right.top());
            right.pop();
        }
    }

    double findMedian() const {
        if (left.size() == right.size()) {
            return (left.top() + right.top()) / 2.0;
        }
        return left.top();
    }

private:
    std::priority_queue<int> left;
    std::priority_queue<int, std::vector<int>, std::greater<int>> right;
};
```

插入复杂度是 `O(log n)`，查询中位数是 `O(1)`。

> [!warning]
> `findMedian()` 默认已经至少插入过一个数字；如果允许空数据流查询，需要额外定义返回值或错误处理策略。

## Dijkstra 中的优先队列

Dijkstra 需要每次取出“当前已知距离最小”的节点。这个动作适合用小根堆。

```cpp
#include <functional>
#include <limits>
#include <queue>
#include <utility>
#include <vector>

std::vector<int> dijkstra(
    int n,
    int start,
    const std::vector<std::vector<std::pair<int, int>>>& graph) {
    const int INF = std::numeric_limits<int>::max() / 2;
    std::vector<int> dist(n, INF);

    using State = std::pair<int, int>;  // (distance, node)
    std::priority_queue<State, std::vector<State>, std::greater<State>> heap;

    dist[start] = 0;
    heap.push({0, start});

    while (!heap.empty()) {
        auto [d, u] = heap.top();
        heap.pop();

        if (d != dist[u]) continue;

        for (auto [v, w] : graph[u]) {
            if (dist[v] > d + w) {
                dist[v] = d + w;
                heap.push({dist[v], v});
            }
        }
    }

    return dist;
}
```

关键点：

- 堆里可能有同一个节点的多条距离记录。
- C++ `priority_queue` 不支持直接修改堆中元素，所以通常采用“重复入堆 + 过期记录跳过”。
- `if (d != dist[u]) continue;` 用于跳过旧记录。
- Dijkstra 只适用于非负权边。

## 如何选择堆类型

| 目标 | 选择 |
|------|------|
| 动态取最大 | 大根堆 |
| 动态取最小 | 小根堆 |
| 找第 K 大 | 小根堆维护最大的 K 个 |
| 找第 K 小 | 大根堆维护最小的 K 个 |
| 合并多个有序序列 | 小根堆维护当前最小头部 |
| 数据流中位数 | 大根堆 + 小根堆 |
| 最短路候选点 | 小根堆 |

堆适合维护局部最优候选。如果题目只需要一次性选出第 K 个元素，`nth_element` 可能更快；如果数据持续到来或不能修改原数组，堆更稳妥。

## 常见误区

### 1. 把 priority_queue 当成排序容器

`priority_queue` 只能保证 `top()` 是当前最高优先级元素，不能遍历得到有序序列。

### 2. 小根堆比较器写反

小根堆常用：

```cpp
std::priority_queue<int, std::vector<int>, std::greater<int>> heap;
```

如果自定义比较器，要记住返回 `true` 的元素优先级更低。

### 3. Top K 堆大小没有及时限制

维护最大的 `k` 个数时，堆大小超过 `k` 就要立刻 `pop`，否则堆顶不一定是答案。

### 4. 合并链表忘记推进 next

弹出当前节点后，如果 `node->next` 存在，必须把下一个节点入堆。

### 5. 数据流中位数没有平衡堆大小

两个堆的大小差必须控制在 1 以内，否则中位数位置会错。

### 6. Dijkstra 不处理过期记录

堆里可能存在旧距离。没有跳过旧记录会导致重复计算，严重时还会让理解变乱。

## 复杂度总结

| 场景 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 单次 `push` / `pop` | `O(log n)` | `O(n)` 保存堆 |
| Top K | `O(nlogk)` | `O(k)` |
| 合并 K 个有序链表 | `O(NlogK)` | `O(K)` |
| 数据流中位数插入 | `O(log n)` | `O(n)` |
| 数据流中位数查询 | `O(1)` | `O(n)` |
| 堆优化 Dijkstra | `O((V + E)logV)` | `O(V + E)` |

---

## 关键要点

1. `priority_queue` 默认是大根堆。
2. 小根堆使用 `greater<T>` 或自定义比较器。
3. 堆适合动态维护最大值或最小值，不适合随机访问和遍历。
4. Top K 通常用大小为 `k` 的堆。
5. 合并 K 个有序结构时，堆里只放每个结构的当前候选。
6. 数据流中位数需要两个堆维护左右两半。
7. Dijkstra 用小根堆取当前最短候选，并跳过过期记录。
