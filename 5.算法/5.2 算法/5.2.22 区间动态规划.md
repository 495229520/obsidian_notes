# 5.2.22 区间动态规划

> 区间 DP 用 `dp[i][j]` 表示区间 `[i, j]` 的答案。它适合“从两端收缩”“枚举中间断点”“把一个区间拆成两个小区间”的问题。

---

## 区间 DP 解决什么问题

区间 DP 的典型信号是：题目目标和一段连续区间有关，而且大区间依赖小区间。

| 题目信号 | 常见状态 |
|----------|----------|
| 区间 `[i, j]` 内的最优值 | `dp[i][j]` |
| 从两端选/删/匹配 | 依赖 `dp[i + 1][j]`、`dp[i][j - 1]` |
| 枚举最后一次切分位置 | 枚举 `k`，合并 `dp[i][k]` 和 `dp[k + 1][j]` |
| 回文相关 | 依赖内部区间 `dp[i + 1][j - 1]` |

区间 DP 和 [[5.算法/5.2 算法/5.2.21 子序列动态规划|子序列动态规划]] 有交集：最长回文子序列就是典型区间状态。它和普通线性 DP 最大区别是**填表顺序通常按区间长度从小到大**。

## 基础模板

区间 DP 常用模板：

```cpp
for (int len = 1; len <= n; ++len) {
    for (int left = 0; left + len - 1 < n; ++left) {
        int right = left + len - 1;
        // 根据更短区间计算 dp[left][right]
    }
}
```

如果需要枚举断点：

```cpp
for (int len = 2; len <= n; ++len) {
    for (int left = 0; left + len - 1 < n; ++left) {
        int right = left + len - 1;
        for (int mid = left; mid < right; ++mid) {
            // 合并 [left, mid] 和 [mid + 1, right]
        }
    }
}
```

**为什么按长度遍历**：

- 计算长度为 `len` 的区间时，只会依赖更短区间。
- 更短区间已经在前面的 `len` 中算过。
- 这样能保证状态转移时依赖都可用。

## 回文区间：最长回文子序列

状态定义：

```text
dp[i][j] = s[i..j] 中最长回文子序列长度
```

转移：

```text
s[i] == s[j]: dp[i][j] = dp[i + 1][j - 1] + 2
s[i] != s[j]: dp[i][j] = max(dp[i + 1][j], dp[i][j - 1])
```

```cpp
#include <algorithm>
#include <string>
#include <vector>

int longestPalindromeSubseq(const std::string& s) {
    int n = static_cast<int>(s.size());
    if (n == 0) return 0;

    std::vector<std::vector<int>> dp(n, std::vector<int>(n, 0));

    for (int len = 1; len <= n; ++len) {
        for (int left = 0; left + len - 1 < n; ++left) {
            int right = left + len - 1;
            if (left == right) {
                dp[left][right] = 1;
            } else if (s[left] == s[right]) {
                dp[left][right] = (len == 2 ? 0 : dp[left + 1][right - 1]) + 2;
            } else {
                dp[left][right] = std::max(dp[left + 1][right], dp[left][right - 1]);
            }
        }
    }

    return dp[0][n - 1];
}
```

> [!note]
> 也可以让 `left` 倒序、`right` 正序。两种写法本质一样，都是先算小区间。

## 戳气球模型

戳气球类问题的关键是反着想：不要枚举第一个戳哪个，而是枚举区间内最后一个戳哪个。

状态定义：

```text
dp[left][right] = 开区间 (left, right) 内所有气球被戳完后能获得的最大分数
```

```cpp
#include <algorithm>
#include <vector>

int maxCoins(const std::vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    std::vector<int> points(n + 2, 1);
    for (int i = 0; i < n; ++i) {
        points[i + 1] = nums[i];
    }

    std::vector<std::vector<int>> dp(n + 2, std::vector<int>(n + 2, 0));

    for (int len = 2; len <= n + 1; ++len) {
        for (int left = 0; left + len <= n + 1; ++left) {
            int right = left + len;
            for (int last = left + 1; last < right; ++last) {
                int score = points[left] * points[last] * points[right];
                dp[left][right] = std::max(
                    dp[left][right],
                    dp[left][last] + dp[last][right] + score
                );
            }
        }
    }

    return dp[0][n + 1];
}
```

**为什么使用开区间**：

- `left` 和 `right` 是还没被戳的边界气球。
- 枚举 `last` 表示 `(left, right)` 中最后一个被戳的气球。
- 此时它左右相邻的气球正好是 `left` 和 `right`，得分可确定。

## 合并石子模型

合并石子、矩阵链乘法这类问题需要枚举断点，把一个区间拆成两个子区间。

状态定义：

```text
dp[i][j] = 合并区间 [i, j] 的最小代价
```

```cpp
#include <algorithm>
#include <limits>
#include <vector>

int mergeStonesCost(const std::vector<int>& stones) {
    int n = static_cast<int>(stones.size());
    std::vector<int> prefix(n + 1, 0);
    for (int i = 0; i < n; ++i) {
        prefix[i + 1] = prefix[i] + stones[i];
    }

    std::vector<std::vector<int>> dp(n, std::vector<int>(n, 0));

    for (int len = 2; len <= n; ++len) {
        for (int left = 0; left + len - 1 < n; ++left) {
            int right = left + len - 1;
            dp[left][right] = std::numeric_limits<int>::max();
            int sum = prefix[right + 1] - prefix[left];

            for (int mid = left; mid < right; ++mid) {
                dp[left][right] = std::min(
                    dp[left][right],
                    dp[left][mid] + dp[mid + 1][right] + sum
                );
            }
        }
    }

    return n == 0 ? 0 : dp[0][n - 1];
}
```

这里用 [[5.算法/5.2 算法/5.2.4 前缀和|前缀和]] 快速计算区间和。

## 如何识别题型

| 题目特征 | 优先考虑 |
|----------|----------|
| 区间两端字符是否匹配 | 回文区间 DP |
| 大区间由两个小区间合并 | 枚举断点 |
| 操作顺序正着想很难 | 尝试枚举最后一次操作 |
| 需要区间和参与转移 | 前缀和 + 区间 DP |
| 状态只和前一个位置有关 | 不需要区间 DP，考虑线性 DP |

## 复杂度总结

| 模型 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 两端收缩区间 DP | `O(n²)` | `O(n²)` |
| 枚举断点区间 DP | `O(n³)` | `O(n²)` |
| 戳气球 | `O(n³)` | `O(n²)` |
| 合并石子基础版 | `O(n³)` | `O(n²)` |

## 常见误区

### 1. 没有按区间长度填表

如果先算大区间，小区间还没准备好，转移就会读到默认值。

### 2. 闭区间和开区间混用

最长回文子序列通常用闭区间 `[i, j]`，戳气球常用开区间 `(left, right)`。区间定义一旦确定，转移和答案位置都要一致。

### 3. 枚举第一次操作

很多区间问题第一次操作会改变相邻关系，难以转移；枚举最后一次操作通常更稳定。

### 4. 忘记初始化单点区间

回文类问题中，`dp[i][i] = 1` 是基础状态。

---

## 关键要点

1. 区间 DP 的状态通常是 `dp[i][j]`。
2. 填表顺序优先按区间长度从小到大。
3. 两端匹配类问题依赖内部区间。
4. 合并类问题通常枚举断点。
5. 操作顺序复杂时，优先考虑“最后一次操作”。
