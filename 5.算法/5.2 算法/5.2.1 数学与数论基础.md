# 5.2.1 数学与数论基础

> 数学题不一定每场都考，但一旦出现，通常希望你能快速写出稳定模板：最大公约数、快速幂、取模、素数筛和组合数。

---

## 数学题先看什么

算法里的数学题通常不是考复杂定理，而是考基础模板和边界处理。

做题时可以按这几个点快速判断：

- **看关键词**：题面是否出现最大公约数、幂、取模、素数、组合数等信号。
- **看数据范围**：结果是否可能溢出，是否需要 `long long`、取模或高精度。
- **看查询次数**：单次计算优先写简单模板，多次查询再考虑预处理。
- **看边界条件**：重点检查 `0`、负数、空范围、除法和数组下标。

| 题目关键词 | 优先考虑 | 典型用途 |
|------------|----------|----------|
| 最大公约数、互质、约分 | `gcd` | 化简比例、判断互质、最小公倍数 |
| 幂、指数很大 | 快速幂 | `a^n`、矩阵幂、模逆元 |
| 答案很大、取余 | 模运算 | 防溢出、方案数取模 |
| 多次判断素数 | 素数筛 | 批量预处理素数 |
| 选法、路径数、概率计数 | 组合数 | `C(n, k)`、杨辉三角、预处理阶乘 |

如果数字非常大，超出普通整数范围，再考虑 [[5.算法/5.2 算法/5.2.3 高精度|高精度]]；如果本质是区间求和或计数前缀，则常和 [[5.算法/5.2 算法/5.2.4 前缀和|前缀和]] 搭配。

## 最大公约数 gcd

最大公约数使用欧几里得算法：

```text
gcd(a, b) = gcd(b, a % b)
```

直到 `b == 0`，此时答案是 `a`。

```cpp
#include <cstdlib>

long long gcd(long long a, long long b) {
    a = std::llabs(a);
    b = std::llabs(b);

    while (b != 0) {
        long long r = a % b;
        a = b;
        b = r;
    }

    return a;
}
```

递归法：

```cpp
#include <cstdlib>

long long gcd_impl(long long a, long long b) {
    if (b == 0) {
        return a;
    }

    return gcd_impl(b, a % b);
}

long long gcd(long long a, long long b) {
    return gcd_impl(std::llabs(a), std::llabs(b));
}
```

C++17 也可以直接使用 `<numeric>` 中的 `std::gcd`：

```cpp
#include <numeric>

int g = std::gcd(a, b);
```

### 最小公倍数 lcm

**概念**：

- 两个数的**公倍数**：它们共同的倍数。
- **最小公倍数**（Least Common Multiple）：所有公倍数里最小的那个。

直观理解：

- 两个人跑步，一个人每 `a` 步停一下，另一个人每 `b` 步停一下。
- 他们**第一次同时停下来的位置**就是 `lcm(a, b)`。
- 例如每 4 步停和每 6 步停，第一次同时停在第 12 步，即 `lcm(4, 6) = 12`。

**核心公式**：

LCM 和 GCD 之间有简单的关系：

```text
a × b = gcd(a, b) × lcm(a, b)
```

也就是：

```text
lcm(a, b) = a × b ÷ gcd(a, b)
```

这个等式的含义：

- `a` 和 `b` 的乘积等于“公共部分（gcd）× 各自独有的部分拼在一起（lcm）”。
- 除以 gcd 就是把公共部分去掉，剩下最小公倍数。

**为什么代码写成 `a / gcd * b` 而不是 `a * b / gcd`？**

原因是防止中间溢出：

- 如果先算 `a * b`，两个大数相乘可能超过 `long long` 上限。
- 先除后乘可以把中间结果控制在更小范围。
- 因为 `gcd(a, b)` 一定能整除 `a`，所以 `a / gcd` 一定是整数，不会丢精度。

```cpp
long long lcm(long long a, long long b) {
    if (a == 0 || b == 0) return 0;  // 0 和任何数的最小公倍数都是 0
    return std::llabs(a / gcd(a, b) * b);
}
```

| 要点 | 说明 |
|------|------|
| 先除后乘 | `a / gcd(a, b) * b`，避免中间溢出 |
| 零值处理 | 两个数中有一个是 0，lcm 直接返回 0 |
| 绝对值 | `std::llabs` 保证结果非负 |

**常见用途**：

- 求周期同步：两个周期第一次同时出现的位置，本质是 `lcm`。例如 LeetCode 858（镜面反射）就是求 `lcm(p, q)` 来判断光线路径。
- 容斥计数：求两个条件的重叠周期用 lcm 计算。例如 LeetCode 878（第 N 个神奇数字）用 `lcm(a, b)` 做二分容斥。
- 分数通分：两个分数相加时，分母取 lcm 作为公分母。
- 子数组 lcm：LeetCode 2470 要求子数组的 lcm 等于 k，枚举时维护 lcm。

## 快速幂

直接计算 `a^n` 需要乘 `n` 次。快速幂利用指数的二进制，把复杂度降到 `O(log n)`。

核心思路：

- 把指数拆成二进制位。
- 每一位对应一个不断平方后的 `base`。
- 当前位为 `1` 时，把这个 `base` 乘进答案。

```text
n = 13 = 1101₂
a^13 = a^8 * a^4 * a
```

```cpp
long long fastPow(long long base, long long exp) {
    long long result = 1;

    while (exp > 0) {
        if (exp & 1LL) {
            result *= base;
        }
        base *= base;
        exp >>= 1LL;
    }

    return result;
}
```

如果题目要求取模，要在每次乘法后取模：

```cpp
long long modPow(long long base, long long exp, long long mod) {
    base %= mod;
    long long result = 1 % mod;

    while (exp > 0) {
        if (exp & 1LL) {
            result = result * base % mod;
        }
        base = base * base % mod;
        exp >>= 1LL;
    }

    return result;
}
```

**关键点**：

- `exp & 1` 表示当前二进制位是否需要乘进答案。
- `base = base * base` 表示下一位对应的幂。
- 取模版每一步都 `% mod`，避免数值过大。
- 如果 `mod` 本身接近 `long long` 上限，乘法还可能溢出，需要额外的安全乘法；LeetCode 常见 `1e9+7` 场景用 `long long` 足够。

## N 进制转 M 进制

进制转换的通用思路是**借助十进制中转**。

整体分两步：

- 先把 N 进制的数转成十进制。
- 再把十进制转成 M 进制。
- 这样无论 N、M 是多少，都只需要两套固定模板。

```text
N 进制字符串  --(按位乘权)-->  十进制整数  --(短除取余)-->  M 进制字符串
```

> [!tip]
> 如果 N 或 M 超过 10，需要用字母表示 10 及以上的数位（例如十六进制用 `A~F`）。统一用一张字符表 `0123456789ABCDEFGHIJKLMNOPQRSTUVWXYZ` 做映射，最大支持 36 进制。

### 第一步：N 进制转十进制

从高位到低位处理：

- 每一位的值乘以「进制的幂」再累加。
- 本质就是按权展开。

```text
(1101)₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 13
```

实现时从左到右扫描：

- 用 `result = result * base + digit` 累乘累加。
- 这个写法等价于秦九韶（霍纳）法则。
- 好处是避免显式求幂，更快也更不容易丢精度。

```cpp
#include <string>
#include <cctype>

// 把字符转成数字：'0'~'9' -> 0~9，'A'~'Z' -> 10~35
int charToDigit(char c) {
    if (std::isdigit(static_cast<unsigned char>(c))) {
        return c - '0';
    }
    return std::toupper(static_cast<unsigned char>(c)) - 'A' + 10;
}

// 把 N 进制字符串转成十进制整数
long long toDecimal(const std::string& s, int base) {
    long long result = 0;

    for (char c : s) {
        result = result * base + charToDigit(c);
    }

    return result;
}
```

### 第二步：十进制转 M 进制

转换过程：

- 不断对 M 取余，得到当前最低位。
- 再整除 M，进入下一位。
- 重复直到商为 0。
- 注意取余是**从低位到高位**得到的，所以最后要反转。

```text
13 转二进制：
13 % 2 = 1   13 / 2 = 6
 6 % 2 = 0    6 / 2 = 3
 3 % 2 = 1    3 / 2 = 1
 1 % 2 = 1    1 / 2 = 0
余数从下往上读：1101
```

```cpp
#include <string>
#include <algorithm>

// 把数位转成字符：0~9 -> '0'~'9'，10~35 -> 'A'~'Z'
char digitToChar(int d) {
    if (d < 10) {
        return static_cast<char>('0' + d);
    }
    return static_cast<char>('A' + d - 10);
}

// 把十进制整数转成 M 进制字符串
std::string fromDecimal(long long x, int base) {
    if (x == 0) {
        return "0";  // 边界：0 单独处理，否则返回空串
    }

    std::string s;
    while (x > 0) {
        s += digitToChar(static_cast<int>(x % base));
        x /= base;
    }

    std::reverse(s.begin(), s.end());  // 余数是逆序得到的，最后反转
    return s;
}
```

### 合起来：N 进制直接转 M 进制

```cpp
std::string convertBase(const std::string& s, int fromBase, int toBase) {
    long long decimal = toDecimal(s, fromBase);
    return fromDecimal(decimal, toBase);
}

// 示例：二进制 "1101" 转十六进制
// convertBase("1101", 2, 16) -> "D"
```

**关键点**：

- 中转十进制时用 `result = result * base + digit`，不要显式 `pow`，既快又不丢精度。
- 十进制转 M 进制是**短除取余 + 反转**，余数顺序天然是逆的。
- `0` 一定要单独处理，否则 `while` 循环一次都不执行，返回空字符串。
- 大于 10 的进制要用字母映射，统一字符表最多支持 36 进制。
- 如果输入可能是负数，先记录符号、对绝对值做转换，最后补回 `-`。

> [!warning]
> 中转的十进制可能很大。如果 N 进制字符串很长，十进制值会超出 `long long`，这时不能借助整数中转，需要用 [[5.算法/5.2 算法/5.2.3 高精度|高精度]] 模拟，或直接在两个进制间逐位做带余除法。

## 取模运算

取模题最常见的是让答案对 `1e9 + 7` 取余：

```cpp
const long long MOD = 1000000007LL;
```

基本规则：

- 加法可以拆开取模。
- 乘法可以拆开取模。
- 减法要注意负数规范化。
- 除法不能直接拆，需要看能否使用模逆元。

加法和乘法模板：

```cpp
long long addMod(long long a, long long b, long long mod) {
    return ((a % mod) + (b % mod)) % mod;
}

long long mulMod(long long a, long long b, long long mod) {
    return (a % mod) * (b % mod) % mod;
}
```

### 负数取模

C++ 中负数 `%` 的结果可能是负数，所以要规范化：

```cpp
long long normalizeMod(long long x, long long mod) {
    return (x % mod + mod) % mod;
}
```

### 除法取模

取模下不能直接写：

```cpp
// 错误直觉：不能直接把除法拆到 mod 里
answer = a / b % MOD;
```

可以使用模逆元的常见前提：

- `MOD` 是质数。
- `b` 不是 `MOD` 的倍数。
- 题目语义允许把除法转成乘以逆元。

满足这些条件时，可以用费马小定理求逆元：

```text
b^(MOD - 2) % MOD
```

```cpp
long long modInverse(long long x, long long mod) {
    return modPow(x, mod - 2, mod);
}
```

> [!warning]
> 模逆元不是任何时候都能用。常见力扣和笔试题给 `MOD = 1e9 + 7` 这类质数时才通常这样写。

## 素数筛

判断素数时先看需求：

- 只判断一个数是否为素数：可以试除到 `sqrt(n)`。
- 批量判断 `1..n` 中的素数：埃氏筛更合适。
- 频繁查询某个数是否为素数：保留 `isPrime` 数组。

```cpp
#include <vector>

std::vector<int> sievePrimes(int n) {
    std::vector<bool> isPrime(n + 1, true);
    std::vector<int> primes;

    if (n >= 0) isPrime[0] = false;
    if (n >= 1) isPrime[1] = false;

    for (int i = 2; 1LL * i * i <= n; ++i) {
        if (!isPrime[i]) continue;

        for (long long j = 1LL * i * i; j <= n; j += i) {
            isPrime[static_cast<int>(j)] = false;
        }
    }

    for (int i = 2; i <= n; ++i) {
        if (isPrime[i]) {
            primes.push_back(i);
        }
    }

    return primes;
}
```

**为什么从 `i * i` 开始标记**：

- 小于 `i * i` 的 `i` 的倍数，已经被更小的因子标记过。
- 例如 `2 * 5` 会在处理 `2` 时标记，不需要等到 `5` 再标。

**复杂度**：

- 时间复杂度约为 `O(n log log n)`。
- 空间复杂度 `O(n)`。

如果题目频繁查询“某个数是否素数”，可以保留 `isPrime` 数组，而不是只返回 `primes`。

## 组合数

组合数 `C(n, k)` 表示从 `n` 个元素中选 `k` 个。

常见使用场景：

- 选法数量。
- 路径计数。
- 概率或方案数统计。
- 杨辉三角或阶乘预处理。

常见递推式是：

```text
C(n, k) = C(n - 1, k - 1) + C(n - 1, k)
```

### 杨辉三角预处理

适用条件：

- `n` 不大。
- 不要求特别高的查询速度。
- 需要直观稳定的组合数表。

这时可以用动态规划预处理。

```cpp
#include <vector>

std::vector<std::vector<long long>> buildCombination(int n) {
    std::vector<std::vector<long long>> c(n + 1, std::vector<long long>(n + 1, 0));

    for (int i = 0; i <= n; ++i) {
        c[i][0] = 1;
        c[i][i] = 1;

        for (int j = 1; j < i; ++j) {
            c[i][j] = c[i - 1][j - 1] + c[i - 1][j];
        }
    }

    return c;
}
```

这个写法和 [[5.算法/5.2 算法/5.2.19 动态规划|动态规划]] 很接近：当前状态由上一行两个状态转移而来。

### 组合数取模

如果结果很大，通常对 `MOD` 取模：

```cpp
std::vector<std::vector<long long>> buildCombinationMod(int n, long long mod) {
    std::vector<std::vector<long long>> c(n + 1, std::vector<long long>(n + 1, 0));

    for (int i = 0; i <= n; ++i) {
        c[i][0] = 1;
        c[i][i] = 1;

        for (int j = 1; j < i; ++j) {
            c[i][j] = (c[i - 1][j - 1] + c[i - 1][j]) % mod;
        }
    }

    return c;
}
```

如果 `n` 很大且查询很多，可以预处理阶乘和逆元：

```text
C(n, k) = fact[n] * invFact[k] * invFact[n - k] % MOD
```

这个方案的注意点：

- 依赖模逆元。
- 通常要求 `MOD` 是质数。
- 适合多次查询 `C(n, k)`，用预处理换查询速度。

---

## 如何选择模板

| 需求 | 推荐模板 |
|------|----------|
| 单次求最大公约数 | `std::gcd` 或欧几里得算法 |
| 多次求幂且指数很大 | 快速幂 |
| 幂运算答案取模 | 模快速幂 |
| 批量判断素数 | 埃氏筛 |
| `n` 不大求组合数 | 杨辉三角 DP |
| `n` 大且多次查询组合数 | 阶乘 + 逆元 |
| 数字位数超过整数范围 | 高精度 |

面试里优先写最小可用模板，不要过早上复杂预处理。笔试里如果查询次数很多，再用预处理换时间。

---

## 常见误区

### 1. `lcm` 先乘后除导致溢出

优先写：

```cpp
a / gcd(a, b) * b
```

不要先写 `a * b / gcd(a, b)`。

### 2. 快速幂忘记更新 base

每轮都要执行：

```cpp
base = base * base;
exp >>= 1;
```

否则只是在重复乘同一个底数。

### 3. 取模下误用除法

模运算里不能直接除。需要确认是否能求逆元，或者换成不需要除法的推导。

### 4. 负数取模没有规范化

如果表达式可能变成负数，最终要写：

```cpp
(x % MOD + MOD) % MOD
```

### 5. 素数筛从 `2 * i` 开始标记

这样虽然正确，但会重复标记很多次。从 `i * i` 开始更合适。

### 6. 组合数数组范围开小

如果需要 `C(n, k)`，二维数组至少要支持下标 `[0..n][0..n]`，并处理 `k < 0` 或 `k > n` 的非法查询。

## 面试手写检查清单

| 检查项 | 自查问题 |
|--------|----------|
| 整数范围 | 是否需要 `long long`？乘法是否会溢出？ |
| 取模 | 是否每步都取模？负数是否规范化？ |
| gcd | 是否处理了 `0` 和负数？ |
| 快速幂 | 指数是否可能为 0？ |
| 素数筛 | `0` 和 `1` 是否标记为非素数？ |
| 组合数 | `C(n,0)` 和 `C(n,n)` 是否初始化为 1？ |
| 模逆元 | 是否确认 `MOD` 是质数且分母不为 0？ |

---

## 关键要点

1. `gcd` 用欧几里得算法，`lcm` 先除后乘。
2. 快速幂把指数按二进制拆分，复杂度是 `O(log n)`。
3. 模运算下加法、乘法能拆，除法要用逆元且有前提。
4. 埃氏筛适合批量判断素数，从 `i * i` 开始标记。
5. 组合数小范围用杨辉三角，大范围多查询用阶乘和逆元。
6. 数学模板最重要的是边界和溢出，不是代码长度。
