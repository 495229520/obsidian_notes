# 5.2.28 最短路径算法专题

> 最短路径题的第一步不是写代码，而是先判断：边有没有权重、权重是否可能为负、要求单源还是任意两点、起点是一个还是多个。

---

## 最短路径先看什么

| 题目特征 | 优先算法 | 关键数据结构 |
|----------|----------|--------------|
| 无权图，求最少边数 / 最少步数 | BFS | `queue` + `dist` |
| 多个起点同时扩散 | 多源 BFS | 所有源点一起入队 |
| 带权且边权非负，单源最短路 | Dijkstra | 邻接表 + 小顶堆 |
| 存在负权边，或要判断负环 | Bellman-Ford | 边集数组 |
| 点数较少，求任意两点最短路 | Floyd | 邻接矩阵 |

![[图片/5.算法/5.2 算法/5_2_2_28_1.svg]]

这张图可以简化成一句话：

```text
无权用 BFS，非负权用 Dijkstra，有负权看 Bellman-Ford，任意两点且点少用 Floyd。
```

## BFS 最短路

BFS 只适用于**无权图**，或者所有边权都可以视为 `1` 的图。它按层扩展，第一次到达某个点时，走过的边数一定最少。

```cpp
vector<int> bfsShortestPath(int start, const vector<vector<int>>& g) {
    int n = g.size();
    vector<int> dist(n, -1);
    queue<int> q;

    dist[start] = 0;
    q.push(start);

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : g[u]) {
            if (dist[v] != -1) continue;
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }

    return dist;
}
```

`dist` 同时表示两个含义：

- `dist[v] == -1`：还没有访问过。
- `dist[v] >= 0`：从起点到 `v` 的最少步数。

常见题型：迷宫最短路、单词接龙、网格扩散、树或图上的最少边数。

---

## 多源 BFS

多源 BFS 的本质是：把所有源点同时作为第 `0` 层。这样第一次到达某个点时，得到的是它到**任意一个源点**的最近距离。

```cpp
vector<int> multiSourceBfs(const vector<int>& sources,
                           const vector<vector<int>>& g) {
    int n = g.size();
    vector<int> dist(n, -1);
    queue<int> q;

    for (int s : sources) {
        if (dist[s] != -1) continue;
        dist[s] = 0;
        q.push(s);
    }

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (int v : g[u]) {
            if (dist[v] != -1) continue;
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }

    return dist;
}
```

如果是网格题，源点通常来自所有满足条件的格子，例如腐烂橘子、所有水源、所有出口。写法上只是在普通 BFS 前多做一次“批量入队”。

## Dijkstra

Dijkstra 用于**边权非负**的单源最短路径。核心贪心是：每次从候选集合里取出当前距离最小的点，这个距离就已经确定。

```cpp
vector<long long> dijkstra(int n, int start,
                           const vector<vector<pair<int, int>>>& g) {
    const long long INF = (1LL << 60);
    vector<long long> dist(n, INF);

    using State = pair<long long, int>;  // (距离, 节点)
    priority_queue<State, vector<State>, greater<State>> pq;

    dist[start] = 0;
    pq.emplace(0, start);

    while (!pq.empty()) {
        auto [d, u] = pq.top();
        pq.pop();

        if (d != dist[u]) continue;      // 过期记录

        for (auto [v, w] : g[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                pq.emplace(dist[v], v);
            }
        }
    }

    return dist;
}
```

关键点：

1. `priority_queue` 默认是大顶堆，最短路要写成小顶堆。
2. C++ 的堆不能直接 decrease-key，所以更新距离时直接插入新记录，出堆时用 `d != dist[u]` 跳过旧记录。
3. 只要存在负权边，Dijkstra 的“出堆即确定”就不再可靠。

## Bellman-Ford

Bellman-Ford 可以处理负权边，并能判断从起点可达的负环。它的思路是反复扫描所有边，最多做 `n - 1` 轮松弛。

```cpp
struct Edge {
    int u;
    int v;
    int w;
};

bool bellmanFord(int n, int start, const vector<Edge>& edges,
                 vector<long long>& dist) {
    const long long INF = (1LL << 60);
    dist.assign(n, INF);
    dist[start] = 0;

    for (int i = 1; i <= n - 1; ++i) {
        bool updated = false;

        for (const auto& e : edges) {
            if (dist[e.u] == INF) continue;
            if (dist[e.u] + e.w < dist[e.v]) {
                dist[e.v] = dist[e.u] + e.w;
                updated = true;
            }
        }

        if (!updated) break;
    }

    for (const auto& e : edges) {
        if (dist[e.u] == INF) continue;
        if (dist[e.u] + e.w < dist[e.v]) {
            return false;                // 存在从 start 可达的负环
        }
    }

    return true;
}
```

为什么是 `n - 1` 轮：没有环的最短路径最多经过 `n - 1` 条边。如果第 `n` 轮还能继续变短，说明有负环参与了最短路径。

## Floyd

Floyd 用于求**任意两点之间**的最短路径，适合点数较少的稠密图。核心状态是：

```text
dist[i][j] = i 到 j 的当前最短距离
```

枚举中转点 `k`，尝试用 `i -> k -> j` 更新 `i -> j`。

```cpp
void floyd(vector<vector<long long>>& dist) {
    const long long INF = (1LL << 60);
    int n = dist.size();

    for (int k = 0; k < n; ++k) {
        for (int i = 0; i < n; ++i) {
            for (int j = 0; j < n; ++j) {
                if (dist[i][k] == INF || dist[k][j] == INF) continue;
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);
            }
        }
    }
}
```

初始化时要注意：

- `dist[i][i] = 0`。
- 有边 `u -> v` 时，`dist[u][v] = min(dist[u][v], w)`。
- 无边时保持 `INF`。

## 复杂度对照

| 算法 | 时间复杂度 | 空间复杂度 | 适合场景 |
|------|-----------|-----------|----------|
| BFS | `O(V + E)` | `O(V)` | 无权单源最短步数 |
| 多源 BFS | `O(V + E)` | `O(V)` | 多起点无权扩散 |
| Dijkstra 堆优化 | `O((V + E) log V)` | `O(V + E)` | 非负权单源最短路 |
| Bellman-Ford | `O(VE)` | `O(V)` | 负权边、负环检测 |
| Floyd | `O(V^3)` | `O(V^2)` | 任意两点、点数少 |

---

## 常见误区

1. **带权图误用 BFS**：BFS 求的是最少边数，不是最小权重和。
2. **Dijkstra 用普通队列**：普通队列不能保证每次取出的都是当前最短距离。
3. **负权边仍用 Dijkstra**：只要存在负权边，就应该先考虑 Bellman-Ford。
4. **`INF + w` 溢出**：松弛前先判断 `dist[u] != INF`，并优先使用 `long long`。
5. **多源 BFS 忘记一起入队**：不能一个源点跑完再跑下一个，否则层次含义会错。
6. **Floyd 初始化漏掉 `dist[i][i] = 0`**：会影响自环和中转更新。
