# 5.2.2 位运算

> 位运算经常出现在 C++ 面试的基础题里。它不只是语法技巧，更常用来表达“成对抵消”“集合状态”“快速判断二进制特征”这几类算法思想。

---

## 位运算解决什么问题

位运算适合处理能被压缩成二进制位的问题。

| 场景 | 位的含义 | 常见写法 |
|------|----------|----------|
| 异或消除重复 | 相同数字成对抵消 | `ans ^= x` |
| 判断 2 的幂 | 二进制中只有一个 `1` | `n & (n - 1)` |
| 统计 1 的个数 | 每次删除最低位的 `1` | `x &= x - 1` |
| 枚举子集 | 每一位表示是否选择一个元素 | `mask` |
| 状态压缩 DP | 每一位表示一个状态是否已经完成 | `dp[mask]` |

> [!tip]
> 只要题目里出现“选择/不选择”“访问/未访问”“开/关”“奇偶次出现”，都可以先想一想能不能用一个二进制位表示。

## 常用位操作速查

假设第 `i` 位从右往左、从 `0` 开始编号。

| 操作         | 写法                 | 含义                       | 常见用途 / 注意                     |
| ---------- | ------------------ | ------------------------ | ----------------------------- |
| 按位与        | `a & b`            | 两位都为 `1` 才为 `1`          | 取交集、保留指定二进制位                  |
| 按位或        | `a \| b`           | 至少一位为 `1` 就为 `1`         | 合并状态、打开某些二进制位                 |
| 按位异或       | `a ^ b`            | 两位不同为 `1`，相同为 `0`        | 成对抵消、翻转指定二进制位                 |
| 按位取反       | `~a`               | 每一位都取反                   | 常与 `&` 配合清除指定二进制位             |
| 左移         | `a << k`           | 整体左移 `k` 位               | 常用于乘以 `2^k`，注意不要移出类型范围        |
| 右移         | `a >> k`           | 整体右移 `k` 位               | 常用于除以 `2^k`，负数右移要谨慎           |
| 测试位        | `mask & (1 << i)`  | 判断第 `i` 位是否为 `1`         | 通常写成 `(mask & (1 << i)) != 0` |
| 置位         | `mask \| (1 << i)` | 把第 `i` 位置为 `1`           | 不影响其他位                        |
| 清位         | `mask & ~(1 << i)` | 把第 `i` 位置为 `0`           | 先用 `~` 构造“只有第 `i` 位为 `0`”的掩码  |
| 翻转位        | `mask ^ (1 << i)`  | 把第 `i` 位从 `0/1` 变成 `1/0` | 常用于开关状态切换                     |
| 删除最低位的 `1` | `x & (x - 1)`      | 去掉二进制中最右边的 `1`           | 判断 `2` 的幂、统计 `1` 的个数          |
| 取最低位的 `1`  | `x & -x`           | 只保留二进制中最右边的 `1`          | 树状数组、lowbit 技巧                |

```cpp
int mask = 0;

mask |= (1 << 2);   // 置位：打开第 2 位
mask &= ~(1 << 2);  // 清位：关闭第 2 位
mask ^= (1 << 1);   // 翻转第 1 位

bool hasBit = (mask & (1 << 1)) != 0;
```

> [!warning]
> 左移时要注意类型范围。比如 `1 << 31` 在 32 位有符号 `int` 上容易出问题，必要时使用 `1LL << i`。

## 异或找只出现一次的数

异或有两个核心性质：

- `a ^ a = 0`，相同的数会抵消。
- `a ^ 0 = a`，任何数和 `0` 异或仍然是自己。

如果数组中只有一个数出现一次，其他数都出现两次，就可以把所有数异或起来。

```cpp
#include <vector>

int singleNumber(const std::vector<int>& nums) {
    int ans = 0;

    for (int x : nums) {
        ans ^= x;
    }

    return ans;
}
```

示例：

```text
nums = [4, 1, 2, 1, 2]
4 ^ 1 ^ 2 ^ 1 ^ 2
= 4 ^ (1 ^ 1) ^ (2 ^ 2)
= 4
```

这个技巧本质上是在利用“成对出现的元素会被异或消掉”。

## 位掩码枚举子集

长度为 `n` 的数组有 `2^n` 个子集。可以用一个整数 `mask` 表示当前选了哪些元素：

- 第 `i` 位为 `1`：选择 `nums[i]`。
- 第 `i` 位为 `0`：不选择 `nums[i]`。

```cpp
#include <vector>

std::vector<std::vector<int>> subsetsByMask(const std::vector<int>& nums) {
    int n = static_cast<int>(nums.size());
    std::vector<std::vector<int>> result;

    for (int mask = 0; mask < (1 << n); ++mask) {
        std::vector<int> path;

        for (int i = 0; i < n; ++i) {
            if (mask & (1 << i)) {
                path.push_back(nums[i]);
            }
        }

        result.push_back(path);
    }

    return result;
}
```

以 `nums = [A, B, C]` 为例：

| `mask` | 二进制 | 子集 |
|--------|--------|------|
| `0` | `000` | `{}` |
| `1` | `001` | `{A}` |
| `2` | `010` | `{B}` |
| `3` | `011` | `{A, B}` |
| `4` | `100` | `{C}` |
| `5` | `101` | `{A, C}` |
| `6` | `110` | `{B, C}` |
| `7` | `111` | `{A, B, C}` |

这种写法和 [[5.算法/5.2 算法/5.2.18 回溯算法|5.2.18 回溯算法]] 里的子集回溯做的是同一件事，只是把递归树换成了二进制枚举。主案例见 [[78. 子集|78. 子集]]。

## 判断 2 的幂

一个正整数如果是 `2` 的幂，那么它的二进制里只有一个 `1`。

```text
1  = 0001
2  = 0010
4  = 0100
8  = 1000
```

`n - 1` 会把最低位的 `1` 变成 `0`，并把它右边的所有位变成 `1`。所以：

```text
n     = 1000
n - 1 = 0111
n & (n - 1) = 0000
```

```cpp
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n - 1)) == 0;
}
```

> [!note]
> 必须先判断 `n > 0`。`0` 的二进制里没有 `1`，不是 `2` 的幂。

## Brian Kernighan 计数

`x & (x - 1)` 可以删除 `x` 二进制中最低位的 `1`。

```text
x       = 110100
x - 1   = 110011
x&(x-1) = 110000
```

重复执行这个操作，执行了几次，就说明原来有几个 `1`。

```cpp
int countOnes(unsigned int x) {
    int count = 0;

    while (x != 0) {
        x &= (x - 1);
        ++count;
    }

    return count;
}
```

复杂度是 `O(k)`，其中 `k` 是二进制中 `1` 的个数，而不是整数的总位数。

> [!tip]
> C++20 可以使用 `<bit>` 里的 `std::popcount`。面试手写时仍然要理解 Brian Kernighan 算法。

## 状态压缩 DP 入门

状态压缩 DP 用一个 `mask` 表示当前已经完成或已经选择的元素集合，再用 `dp[mask]` 存这个集合对应的答案。

它通常适合 `n` 比较小的问题。因为状态总数是 `2^n`，当 `n = 20` 时已经有 `1,048,576` 个状态。

![[图片/5.算法/5.2 算法/5_2_2_2_2.svg]]

典型写法：

```cpp
#include <algorithm>
#include <vector>

int minCostByStateCompression(const std::vector<std::vector<int>>& cost) {
    int n = static_cast<int>(cost.size());
    const int INF = 1'000'000'000;

    std::vector<int> dp(1 << n, INF);
    dp[0] = 0;

    for (int mask = 0; mask < (1 << n); ++mask) {
        int step = 0;
        for (int i = 0; i < n; ++i) {
            if (mask & (1 << i)) {
                ++step;
            }
        }

        for (int i = 0; i < n; ++i) {
            if (mask & (1 << i)) {
                continue;
            }

            int next = mask | (1 << i);
            dp[next] = std::min(dp[next], dp[mask] + cost[step][i]);
        }
    }

    return dp[(1 << n) - 1];
}
```

这段代码的核心不是具体业务，而是状态转移形式：

```text
当前集合 mask
选择一个未加入的元素 i
next = mask | (1 << i)
用 dp[mask] 更新 dp[next]
```

它是 [[5.算法/5.2 算法/5.2.19 动态规划|5.2.19 动态规划]] 的一种特殊状态设计：把“集合”压缩成一个整数。

## 常见错误

| 错误 | 后果 | 修正 |
|------|------|------|
| 忘记 `n > 0` | 把 `0` 误判成 `2` 的幂 | 先判断正数 |
| 写成 `1 << n` 但 `n` 太大 | 溢出或状态数爆炸 | 小心范围，必要时用 `1LL` |
| `mask` 和元素下标对应混乱 | 子集或状态转移错误 | 固定第 `i` 位对应第 `i` 个元素 |
| 把位运算优先级想错 | 判断条件出错 | 复杂表达式加括号 |

---

## 面试小结

1. 异或适合处理“成对抵消”。
2. `n & (n - 1)` 能删除最低位的 `1`。
3. 位掩码适合表示小规模集合。
4. 枚举子集是 `O(n * 2^n)`。
5. 状态压缩 DP 的核心是 `dp[mask]` 和 `mask -> next`。
