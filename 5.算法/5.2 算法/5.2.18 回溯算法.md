# 5.2.18 回溯算法

> 回溯是在一棵选择树上做深度优先搜索：做出一个选择，递归深入；发现走完或走不通时，撤销选择，回到上一层继续尝试。

---

## 回溯解决什么问题

回溯适合“枚举所有可能方案”的问题。它通常不是为了求一个最优值，而是为了把所有合法路径都走出来。

| 题型 | 路径表示 | 选择列表 | 答案记录时机 |
|------|----------|----------|--------------|
| 子集 | 已选择的元素 | 从 `startIndex` 往后的元素 | 每个节点都是答案 |
| 组合 | 已选择的元素 | 从 `startIndex` 往后的元素 | `path.size() == k` |
| 排列 | 已排列的元素 | 所有未使用元素 | `path.size() == nums.size()` |
| 切割 | 已切出的片段 | 当前起点后的每个终点 | 切到字符串末尾 |
| 括号生成 | 已生成的括号串 | 左括号或右括号 | 长度达到 `2 * n` |
| N 皇后 | 每一行皇后位置 | 当前行可放的列 | 放完所有行 |
| 单词搜索 | 已匹配路径 | 上下左右相邻格子 | 匹配完整单词 |

> [!tip]
> 回溯题先不要急着写递归。先定义 `path`、选择列表、结束条件，再写做选择和撤销选择。

## 通用模板

回溯模板可以抽象成：

```cpp
void backtrack(状态) {
    if (满足结束条件) {
        记录答案;
        return;
    }

    for (选择 : 当前选择列表) {
        if (选择不合法) continue;

        做选择;
        backtrack(新状态);
        撤销选择;
    }
}
```

每一行都对应一个概念：

| 位置 | 含义 |
|------|------|
| 状态 | 当前递归层知道的信息，例如起点、行号、已使用元素 |
| 结束条件 | 当前路径已经构造出一个完整答案 |
| 选择列表 | 当前层可以尝试的所有选择 |
| 做选择 | 把选择加入 `path`，并同步更新辅助状态 |
| 撤销选择 | 回到进入当前分支之前的状态 |

回溯最容易出错的不是递归，而是状态没有恢复。`push` 和 `pop` 要成对出现，标记访问和恢复访问也要成对出现。

## 子集：每个节点都是答案

子集问题不要求选满固定长度，所以每进入一层都可以记录当前 `path`。

```cpp
#include <vector>

void backtrackSubsets(const std::vector<int>& nums,
                      int startIndex,
                      std::vector<int>& path,
                      std::vector<std::vector<int>>& result) {
    result.push_back(path);

    for (int i = startIndex; i < static_cast<int>(nums.size()); ++i) {
        path.push_back(nums[i]);
        backtrackSubsets(nums, i + 1, path, result);
        path.pop_back();
    }
}
```

关键点：

- `startIndex` 表示下一层只能从后面的元素里选。
- `[1,2]` 和 `[2,1]` 对子集来说是同一个集合，所以不能回头选前面的元素。
- 空集也是子集，所以一进函数就记录 `path`。

主案例见 [[78. 子集|78. 子集]]。

## 组合：固定长度的子集

组合和子集很像，但组合通常要求选出固定数量 `k` 个元素。结束条件变成 `path.size() == k`。

```cpp
#include <vector>

void backtrackCombine(int n,
                      int k,
                      int startIndex,
                      std::vector<int>& path,
                      std::vector<std::vector<int>>& result) {
    if (static_cast<int>(path.size()) == k) {
        result.push_back(path);
        return;
    }

    int need = k - static_cast<int>(path.size());
    for (int i = startIndex; i <= n - need + 1; ++i) {
        path.push_back(i);
        backtrackCombine(n, k, i + 1, path, result);
        path.pop_back();
    }
}
```

这里的剪枝是：

```text
剩余可选数量 < 还需要选择的数量时，不再继续枚举
```

例如从 `1..n` 里选 `k` 个数，当前还需要 `need` 个，那么这一层的 `i` 最多只能到 `n - need + 1`。

## 排列：每个位置都要从未使用元素中选择

排列和组合最大的不同是：顺序有意义。

```text
[1, 2] 和 [2, 1] 是两个不同排列
```

所以排列不能只用 `startIndex`，而要用 `used` 标记每个元素是否已经放进当前路径。

```cpp
#include <vector>

void backtrackPermute(const std::vector<int>& nums,
                      std::vector<int>& path,
                      std::vector<bool>& used,
                      std::vector<std::vector<int>>& result) {
    if (path.size() == nums.size()) {
        result.push_back(path);
        return;
    }

    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        if (used[i]) continue;

        used[i] = true;
        path.push_back(nums[i]);

        backtrackPermute(nums, path, used, result);

        path.pop_back();
        used[i] = false;
    }
}
```

### 有重复元素的排列去重

如果 `nums` 里有重复元素，要先排序，再跳过同一层的重复选择：

```cpp
if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) {
    continue;
}
```

这句话的含义是：同一层里，前一个相同数字还没被使用，说明当前数字会产生重复分支，应该跳过。

> [!warning]
> 子集和组合用 `startIndex` 防止回头选；排列用 `used` 防止同一个位置重复使用。这两个状态不要混用。

## 切割：选择当前片段的结束位置

切割类问题常见于字符串，比如分割回文串。当前层的选择不是“选哪个元素”，而是“当前片段切到哪里”。

```cpp
#include <string>
#include <vector>

bool isPalindrome(const std::string& s, int left, int right) {
    while (left < right) {
        if (s[left] != s[right]) return false;
        ++left;
        --right;
    }
    return true;
}

void backtrackPartition(const std::string& s,
                        int start,
                        std::vector<std::string>& path,
                        std::vector<std::vector<std::string>>& result) {
    if (start == static_cast<int>(s.size())) {
        result.push_back(path);
        return;
    }

    for (int end = start; end < static_cast<int>(s.size()); ++end) {
        if (!isPalindrome(s, start, end)) continue;

        path.push_back(s.substr(start, end - start + 1));
        backtrackPartition(s, end + 1, path, result);
        path.pop_back();
    }
}
```

切割问题的剪枝点通常在合法性判断上：如果当前片段不合法，就不需要递归到下一层。

## 括号生成：保持每个前缀合法

括号生成的核心不是最后再判断是否合法，而是递归过程中就保证任意前缀合法。

```cpp
#include <string>
#include <vector>

void backtrackParentheses(int n,
                          int leftCount,
                          int rightCount,
                          std::string& path,
                          std::vector<std::string>& result) {
    if (static_cast<int>(path.size()) == 2 * n) {
        result.push_back(path);
        return;
    }

    if (leftCount < n) {
        path.push_back('(');
        backtrackParentheses(n, leftCount + 1, rightCount, path, result);
        path.pop_back();
    }

    if (rightCount < leftCount) {
        path.push_back(')');
        backtrackParentheses(n, leftCount, rightCount + 1, path, result);
        path.pop_back();
    }
}
```

剪枝规则：

- 左括号数量不能超过 `n`。
- 右括号数量不能超过左括号数量。
- 这样生成出来的每个前缀都合法，不会出现 `())(` 这种中途已经失败的分支。

## 棋盘类：N 皇后

N 皇后通常按行递归：第 `row` 层只决定第 `row` 行的皇后放在哪一列。

![[图片/SVG/5_2_2_18_2.svg]]

```cpp
#include <string>
#include <vector>

void backtrackQueens(int n,
                     int row,
                     std::vector<std::string>& board,
                     std::vector<bool>& col,
                     std::vector<bool>& diag1,
                     std::vector<bool>& diag2,
                     std::vector<std::vector<std::string>>& result) {
    if (row == n) {
        result.push_back(board);
        return;
    }

    for (int c = 0; c < n; ++c) {
        int d1 = row - c + n - 1;
        int d2 = row + c;

        if (col[c] || diag1[d1] || diag2[d2]) continue;

        board[row][c] = 'Q';
        col[c] = diag1[d1] = diag2[d2] = true;

        backtrackQueens(n, row + 1, board, col, diag1, diag2, result);

        col[c] = diag1[d1] = diag2[d2] = false;
        board[row][c] = '.';
    }
}
```

剪枝状态：

| 状态 | 含义 |
|------|------|
| `col[c]` | 第 `c` 列是否已有皇后 |
| `diag1[row - c + n - 1]` | 主对角线是否已有皇后 |
| `diag2[row + c]` | 副对角线是否已有皇后 |

棋盘类回溯的重点是：不要每次扫描整张棋盘判断冲突，而是用辅助数组把冲突判断降到 `O(1)`。

## 网格搜索：单词搜索

单词搜索属于网格 DFS。路径是已经匹配的字符位置，选择列表是上下左右四个方向。

```cpp
#include <string>
#include <vector>

bool dfsWord(std::vector<std::vector<char>>& board,
             const std::string& word,
             int row,
             int col,
             int index) {
    int rows = static_cast<int>(board.size());
    int cols = static_cast<int>(board[0].size());

    if (row < 0 || row >= rows || col < 0 || col >= cols) return false;
    if (board[row][col] != word[index]) return false;
    if (index == static_cast<int>(word.size()) - 1) return true;

    char saved = board[row][col];
    board[row][col] = '#';

    bool found =
        dfsWord(board, word, row + 1, col, index + 1) ||
        dfsWord(board, word, row - 1, col, index + 1) ||
        dfsWord(board, word, row, col + 1, index + 1) ||
        dfsWord(board, word, row, col - 1, index + 1);

    board[row][col] = saved;
    return found;
}

bool exist(std::vector<std::vector<char>>& board, const std::string& word) {
    if (word.empty()) return true;
    if (board.empty() || board[0].empty()) return false;

    for (int r = 0; r < static_cast<int>(board.size()); ++r) {
        for (int c = 0; c < static_cast<int>(board[0].size()); ++c) {
            if (dfsWord(board, word, r, c, 0)) {
                return true;
            }
        }
    }

    return false;
}
```

网格搜索和 [[200. 岛屿数量|200. 岛屿数量]] 都是 DFS，但目标不同：

- 岛屿数量通常是遍历连通块，访问过后不需要恢复。
- 单词搜索是一条路径匹配，当前起点失败后还要让其他起点使用这些格子，所以必须恢复。

---

## 剪枝与去重

剪枝是提前停止不可能成功的分支，去重是避免不同路径生成相同答案。

| 场景 | 做法 | 例子 |
|------|------|------|
| 剩余数量不足 | 提前缩小循环上界 | 组合 |
| 当前片段不合法 | 不进入下一层 | 回文切割 |
| 前缀已经非法 | 不继续生成 | 括号生成 |
| 位置冲突 | 用辅助状态跳过 | N 皇后 |
| 同层重复选择 | 排序后跳过重复值 | 子集 II、全排列 II |

同层去重的常见写法：

```cpp
if (i > startIndex && nums[i] == nums[i - 1]) {
    continue;
}
```

它表示：同一层里，相同的值只作为第一个分支入口使用一次。

排列去重常见写法：

```cpp
if (i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) {
    continue;
}
```

它表示：同一层不要重复选择相同值；但如果前一个相同值已经在当前路径中使用，当前值仍然可以作为不同位置继续使用。

## 如何识别题型

| 题目特征 | 优先考虑 |
|----------|----------|
| 要求返回所有方案 | 回溯 |
| 每个元素选或不选 | 子集 |
| 从 n 个数中选 k 个 | 组合 |
| 所有元素重新排顺序 | 排列 |
| 字符串要切成若干合法片段 | 切割 |
| 每一步只能加有限几种字符 | 括号生成 |
| 棋盘上逐行或逐格放置 | 棋盘回溯 |
| 从一个格子向四周走 | 网格 DFS |

如果题目只问数量或最优值，先考虑能不能用 [[5.算法/5.2 算法/5.2.19 动态规划|动态规划]] 或贪心优化；如果必须列出所有方案，回溯通常更直接。

## 复杂度总结

| 题型 | 时间复杂度直觉 | 递归深度 |
|------|----------------|----------|
| 子集 | `O(n * 2^n)` | `n` |
| 组合 | 最多枚举 `C(n, k)` 条路径 | `k` |
| 排列 | `O(n * n!)` | `n` |
| 切割 | 最坏 `O(n * 2^n)` | `n` |
| 括号生成 | 与合法括号方案数相关 | `2n` |
| N 皇后 | 指数级，剪枝后远小于暴力 | `n` |
| 单词搜索 | `O(m * n * 3^L)` | `L` |

回溯复杂度通常看两件事：

1. 选择树有多少节点。
2. 每个答案复制或合法性检查要花多少成本。

## 常见误区

### 1. 忘记撤销选择

`path.push_back` 后必须在递归返回后 `path.pop_back`。如果用了 `used`、棋盘标记或访问标记，也必须恢复。

### 2. 结束条件写错位置

子集是每个节点都记录答案；排列和组合通常是到达固定长度才记录答案。

### 3. `startIndex` 和 `used` 混淆

组合、子集不允许回头选，所以用 `startIndex`；排列每一层都可以从头扫描，但不能重复使用同一个元素，所以用 `used`。

### 4. 去重没有区分同层和同枝

去重通常跳过的是同一层的重复分支，不是禁止当前路径里出现相同值。

### 5. 网格搜索没有恢复现场

单词搜索这类路径问题必须恢复格子，否则其他起点会被错误影响。

---

## 最佳实践

- 先写递归函数参数，再写结束条件。
- 只把当前层必须知道的信息放进参数。
- 做选择和撤销选择保持严格对称。
- 排序去重前先确认题目是否允许改变顺序；如果答案不要求原顺序，排序通常更方便。
- 剪枝条件放在递归前，越早剪掉无效分支越好。
- 对棋盘和网格题，优先用辅助状态或原地标记降低判断成本。

---

## 关键要点

1. 回溯本质是 DFS 枚举选择树。
2. `path` 保存当前路径，选择列表决定下一步能走哪里。
3. 子集和组合依赖 `startIndex`，排列依赖 `used`。
4. 剪枝减少不可能成功的分支，去重减少重复答案。
5. 棋盘类通常用列和对角线状态剪枝。
6. 网格搜索要临时标记访问，并在回溯时恢复。
