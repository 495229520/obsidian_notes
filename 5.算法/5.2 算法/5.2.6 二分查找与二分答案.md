# 5.2.6 二分查找与二分答案

> 二分查找不是只会在有序数组里找某个数。它的本质是：**在一个具有单调性的范围里，反复丢弃不可能包含答案的一半**。

---

## 二分解决什么问题

二分常见于两类问题：

| 类型 | 搜索对象 | 前提 | 典型问题 |
|------|----------|------|----------|
| 普通二分 | 数组下标 | 数组有序 | 判断 `target` 是否存在 |
| 边界二分 | 边界位置 | 判断条件具有单调性 | 第一个 `>= target`、第一个 `> target` |
| 旋转数组二分 | 数组下标 | 每轮至少有一侧有序 | 旋转排序数组中找目标值 |
| 二分答案 | 答案值 | `check(mid)` 真假单调 | 最小化最大值、最大化最小值 |

> [!tip] 二分的关键
> 写二分前先回答两个问题：搜索区间表示什么？`check(mid)` 为真时，答案应该留在哪一边？

## 普通二分：查找目标值

普通二分解决的是：在升序数组中判断 `target` 是否存在。

```cpp
#include <vector>

int binarySearch(const std::vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) {
            return mid;
        }
        if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}
```

**为什么这样移动边界**：

- `nums[mid] < target`：`mid` 以及左侧都不可能是答案，移动 `left`。
- `nums[mid] > target`：`mid` 以及右侧都不可能是答案，移动 `right`。
- `left + (right - left) / 2` 可以避免 `left + right` 溢出。

普通二分适合“找任意一个等于目标值的位置”。如果题目要求第一个位置、最后一个位置或插入位置，就不要停在 `nums[mid] == target`，而要改用边界二分。

---

## 边界二分：找第一个满足条件的位置

边界二分把问题转成：

```text
左侧：不满足条件
右侧：满足条件
目标：找到第一个满足条件的位置
```

最常用的写法是左闭右开区间 `[left, right)`：

```cpp
#include <vector>

int lowerBound(const std::vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size());

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] >= target) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    return left;
}
```

这个函数返回第一个 `nums[i] >= target` 的位置。如果所有元素都小于 `target`，返回 `nums.size()`，表示可以插入到末尾。

### lower_bound 和 upper_bound

| 函数 | 手写判断条件 | 返回含义 |
|------|--------------|----------|
| `lower_bound` | `nums[mid] >= target` | 第一个 `>= target` 的位置 |
| `upper_bound` | `nums[mid] > target` | 第一个 `> target` 的位置 |

`upper_bound` 只需要把判断条件换成 `nums[mid] > target`：

```cpp
int upperBound(const std::vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size());

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] > target) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    return left;
}
```

### 典型用途：目标区间

在有重复元素的数组里，`target` 的范围可以写成：

```text
[第一个 >= target 的位置, 第一个 > target 的位置 - 1]
```

这正是 [[5.算法/力扣/34. 在排序数组中查找元素的第一个和最后一个位置|34. 在排序数组中查找元素的第一个和最后一个位置]] 的核心。

> [!warning]
> `lower_bound` 返回的位置不一定真的等于 `target`。访问 `nums[pos]` 前要先判断 `pos < nums.size()`。

## 旋转数组二分

旋转排序数组不再整体有序，但每轮根据 `mid` 仍然能判断出一侧是有序的。

以 `[4,5,6,7,0,1,2]` 为例：

```text
left          mid          right
 4   5   6    7    0   1    2
|-----------|     |----------|
 左半有序           右半有序
```

旋转数组二分的核心不是直接比较 `nums[mid]` 和 `target`，而是先判断哪一侧有序，再判断 `target` 是否落在有序侧。

```cpp
#include <vector>

int searchRotated(const std::vector<int>& nums, int target) {
    int left = 0;
    int right = static_cast<int>(nums.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) {
            return mid;
        }

        if (nums[left] <= nums[mid]) {
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        } else {
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
    }

    return -1;
}
```

**关键不变量**：

- 当前 `[left, right]` 中如果存在答案，答案不会被丢弃。
- 每轮至少有一半区间是有序的。
- 只有当 `target` 落在有序半边时，才保留这半边。

> [!warning]
> 上面的模板默认数组中没有大量重复值。如果允许重复值，例如 `[1,0,1,1,1]`，`nums[left] == nums[mid] == nums[right]` 时可能无法判断哪边有序，通常要先收缩边界，最坏会退化到 `O(n)`。

## 二分答案：在答案空间上二分

二分答案不是在数组里找元素，而是在一段可能的答案值中找最优解。

![[图片/SVG/5_2_2_6_2.svg]]

常见信号：

- 题目问“最小的最大值”
- 题目问“最大的最小值”
- 直接构造答案困难，但给定一个答案 `mid` 后，可以判断它是否可行
- 可行性随着 `mid` 单调变化

### 最小化最大值

这类题通常是：把某个上限 `limit` 尽量压小。

典型表述：

- 把数组分成 `k` 段，使每段和的最大值最小
- 在 `D` 天内运完包裹，求最小运载能力
- 每个工人最多工作 `limit` 时间，求最小的 `limit`

判断函数通常长这样：

```cpp
bool canFinish(const std::vector<int>& nums, int limit, int groups) {
    int used = 1;
    int current = 0;

    for (int x : nums) {
        if (x > limit) return false;

        if (current + x <= limit) {
            current += x;
        } else {
            ++used;
            current = x;
        }
    }

    return used <= groups;
}
```

如果 `limit` 越大越容易可行，那么可行性是：

```text
false false false true true true
                  ^
             找第一个 true
```

模板：

```cpp
#include <algorithm>
#include <vector>

int minimizeMaximum(const std::vector<int>& nums, int groups) {
    int left = 0;
    int right = 0;

    for (int x : nums) {
        left = std::max(left, x);
        right += x;
    }

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (canFinish(nums, mid, groups)) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }

    return left;
}
```

这里 `left` 至少是数组最大值，`right` 是所有元素之和。它们不是数组下标，而是答案可能的上下界。

### 最大化最小值

这类题通常是：让某个下限 `distance` 尽量变大。

典型表述：

- 放置 `m` 个球，使任意两个球之间的最小距离最大
- 安排任务，使最小间隔尽量大
- 选择若干位置，使最差情况尽量好

判断函数通常长这样：

```cpp
#include <vector>

bool canPlace(const std::vector<int>& pos, int distance, int count) {
    int placed = 1;
    int last = pos[0];

    for (int i = 1; i < static_cast<int>(pos.size()); ++i) {
        if (pos[i] - last >= distance) {
            ++placed;
            last = pos[i];
        }
    }

    return placed >= count;
}
```

如果 `distance` 越大越难可行，那么可行性是：

```text
true true true false false false
             ^
        找最后一个 true
```

模板：

```cpp
#include <algorithm>
#include <vector>

int maximizeMinimum(std::vector<int> pos, int count) {
    std::sort(pos.begin(), pos.end());

    int left = 0;
    int right = pos.back() - pos.front();

    while (left < right) {
        int mid = left + (right - left + 1) / 2;

        if (canPlace(pos, mid, count)) {
            left = mid;
        } else {
            right = mid - 1;
        }
    }

    return left;
}
```

这里 `mid` 要向上取整。如果写成 `(left + right) / 2`，当只剩两个候选值时，`left = mid` 可能导致死循环。

## 如何识别题型

| 题目特征 | 优先考虑 |
|----------|----------|
| 有序数组中找某个值 | 普通二分 |
| 找第一个、最后一个、插入位置 | 边界二分 |
| 有序数组被旋转 | 旋转数组二分 |
| 问“最小的最大值” | 二分答案，找第一个可行值 |
| 问“最大的最小值” | 二分答案，找最后一个可行值 |
| 给定答案容易验证，但直接求答案困难 | 二分答案 |

二分答案的题眼不是“数组有序”，而是“答案可行性单调”。如果 `mid` 可行并不能推出更大或更小的答案也可行，就不能直接二分。

---

## 复杂度总结

| 类型 | 时间复杂度 | 空间复杂度 | 说明 |
|------|------------|------------|------|
| 普通二分 | `O(log n)` | `O(1)` | 每次丢弃一半下标 |
| 边界二分 | `O(log n)` | `O(1)` | 常用于重复元素和插入位置 |
| 旋转数组二分 | `O(log n)` | `O(1)` | 无重复值时成立 |
| 二分答案 | `O(log V * check)` | 取决于 `check` | `V` 是答案范围大小 |

二分答案的复杂度常写成：

```text
二分次数 * 每次检查成本
```

例如答案范围是 `[1, 10^9]`，`check` 是一次线性扫描，那么复杂度通常是 `O(n log 10^9)`。

## 常见误区

### 1. 没有定义搜索区间

`[left, right]` 和 `[left, right)` 不能混用。左闭右闭常用于普通查找；左闭右开常用于边界位置。

### 2. 找边界时遇到相等就返回

边界二分遇到 `nums[mid] == target` 不能直接返回，因为左侧或右侧可能还有相同元素。

### 3. 二分答案没有证明单调性

二分答案必须先证明 `check(mid)` 的真假具有连续分布。

### 4. 最大化最小值时 `mid` 没有向上取整

当更新写成 `left = mid` 时，`mid` 必须向上取整：

```cpp
int mid = left + (right - left + 1) / 2;
```

否则可能在 `left + 1 == right` 时死循环。

### 5. 旋转数组误判有序半边

旋转数组每轮先判断 `nums[left] <= nums[mid]` 还是 `nums[mid] <= nums[right]`，再判断 `target` 是否落在有序半边。

---

## 最佳实践

- 先写清楚区间含义，再写循环条件。
- 普通查找可以用 `[left, right]`，边界查找优先用 `[left, right)`。
- 找第一个满足条件的位置时，`check(mid)` 为真通常 `right = mid`。
- 找最后一个满足条件的位置时，`check(mid)` 为真通常 `left = mid`，并让 `mid` 向上取整。
- 二分答案先写 `check`，再写二分外壳。
- 不确定是否能二分时，先画出 `false/true` 或 `true/false` 的单调分布。

---

## 关键要点

1. 普通二分找的是“值”，边界二分找的是“位置”。
2. `lower_bound` 是第一个 `>= target`，`upper_bound` 是第一个 `> target`。
3. LeetCode 34 的本质是两次边界二分。
4. 旋转数组二分每轮先找有序半边，再判断目标值是否落在其中。
5. 二分答案的核心是 `check(mid)` 的单调性。
6. “最小化最大值”通常找第一个可行值。
7. “最大化最小值”通常找最后一个可行值。
