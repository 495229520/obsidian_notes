# 5.2.27 拓扑排序与有向无环图

> 拓扑排序解决的是“依赖必须先完成”的问题。只要任务之间有先后关系，就先想能不能建成一张有向图，再判断它是不是 DAG。

---

## DAG 与拓扑序

DAG 是 Directed Acyclic Graph，也就是**有向无环图**。拓扑排序会把图中的点排成一个线性序列，使每条边 `u -> v` 都满足：

```text
u 出现在 v 前面
```

典型场景：

| 场景 | 点 | 边 |
|------|----|----|
| 课程表 | 课程 | 先修课 `pre -> course` |
| 编译依赖 | 模块 / 文件 | 被依赖项 `lib -> app` |
| 任务调度 | 任务 | 前置任务 `before -> after` |
| DAG DP | 状态 / 节点 | 可转移方向 `u -> v` |

![[图片/5.算法/5.2 算法/5_2_2_27_1.svg]]

拓扑序不唯一。只要所有边的先后约束都满足，就是合法答案。

---

## Kahn 算法

Kahn 算法用入度描述“还有多少前置依赖没完成”。每次取出入度为 `0` 的点，相当于完成一个没有前置条件的任务。

```cpp
vector<int> topoSort(int n, const vector<vector<int>>& g) {
    vector<int> indeg(n, 0);
    for (int u = 0; u < n; ++u) {
        for (int v : g[u]) {
            ++indeg[v];
        }
    }

    queue<int> q;
    for (int i = 0; i < n; ++i) {
        if (indeg[i] == 0) q.push(i);
    }

    vector<int> order;
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        order.push_back(u);

        for (int v : g[u]) {
            if (--indeg[v] == 0) {
                q.push(v);
            }
        }
    }

    if ((int)order.size() != n) return {};  // 有环
    return order;
}
```

判断有环的方法很直接：如果最后处理的点数小于 `n`，说明剩下的点互相依赖，入度永远无法降到 `0`。

## DFS 三色标记

DFS 也能判断有向图是否有环。关键是区分“访问完成”和“仍在递归栈上”。

| 颜色 | 含义 |
|------|------|
| `0` | 未访问 |
| `1` | 正在递归栈上 |
| `2` | 已完成，后续安全 |

```cpp
bool dfs(int u, const vector<vector<int>>& g,
         vector<int>& color, vector<int>& order) {
    color[u] = 1;

    for (int v : g[u]) {
        if (color[v] == 1) return false;         // 回到递归栈，存在环
        if (color[v] == 0 && !dfs(v, g, color, order)) {
            return false;
        }
    }

    color[u] = 2;
    order.push_back(u);                          // 后序加入
    return true;
}

vector<int> topoSortByDfs(int n, const vector<vector<int>>& g) {
    vector<int> color(n, 0);
    vector<int> order;

    for (int i = 0; i < n; ++i) {
        if (color[i] == 0 && !dfs(i, g, color, order)) {
            return {};
        }
    }

    reverse(order.begin(), order.end());
    return order;
}
```

Kahn 算法更适合输出“逐步解锁”的顺序；DFS 三色标记更适合递归判环和理解有向图回边。

## 课程表建模

课程表类题最容易错的是边方向。题目给出：

```text
prerequisites[i] = [a, b]
```

含义是：学 `a` 之前必须先学 `b`。因此应该建边：

```text
b -> a
```

`b` 是前置课程，`a` 是被解锁的课程。

```cpp
vector<vector<int>> g(numCourses);
vector<int> indeg(numCourses, 0);

for (auto& p : prerequisites) {
    int a = p[0];
    int b = p[1];
    g[b].push_back(a);
    ++indeg[a];
}
```

如果只问“能否完成所有课程”，检查拓扑排序是否能处理全部节点即可。如果还要返回一种学习顺序，就返回 `order`。

## 依赖解析

依赖解析和课程表是同一个模型：

```text
先完成 A，才能完成 B  =>  A -> B
```

常见变体：

| 需求 | 做法 |
|------|------|
| 判断是否有循环依赖 | Kahn 处理数是否等于 `n` |
| 输出一种合法执行顺序 | 返回拓扑序 |
| 多个任务都可执行时取编号最小 | 把 `queue` 换成小顶堆 |
| 求每个任务最早完成时间 | 在拓扑序上做 DP |

如果输入不是整数编号，先用 [[5.算法/5.1 STL/5.1.5 map|map]] 或哈希表把名称压缩成 `0..n-1`。

## DAG DP

DAG DP 的核心优势是：拓扑序保证在处理 `u` 时，它的所有前置状态都已经处理完。常见形式是从前往后转移：

```text
dp[v] = max(dp[v], dp[u] + w)
```

下面模板求 DAG 中从所有入度为 `0` 的起点出发，到每个点的最长距离：

```cpp
vector<int> longestPathInDag(int n,
                             const vector<vector<pair<int, int>>>& g) {
    vector<int> indeg(n, 0);
    for (int u = 0; u < n; ++u) {
        for (auto [v, w] : g[u]) {
            ++indeg[v];
        }
    }

    queue<int> q;
    vector<int> dp(n, 0);
    for (int i = 0; i < n; ++i) {
        if (indeg[i] == 0) q.push(i);
    }

    while (!q.empty()) {
        int u = q.front();
        q.pop();

        for (auto [v, w] : g[u]) {
            dp[v] = max(dp[v], dp[u] + w);
            if (--indeg[v] == 0) {
                q.push(v);
            }
        }
    }

    return dp;
}
```

DAG DP 常见题目问法：

- 完成所有任务的最短总时间。
- 从某个起点到终点的路径数量。
- 有向无环图中的最长路径。
- 状态之间有明确先后依赖的计数问题。

## 复杂度对照

| 算法 | 时间复杂度 | 空间复杂度 | 适合场景 |
|------|-----------|-----------|----------|
| Kahn 拓扑排序 | `O(V + E)` | `O(V)` | 依赖解锁、输出顺序、判环 |
| DFS 三色标记 | `O(V + E)` | `O(V)` | 递归判环、后序拓扑序 |
| DAG DP | `O(V + E)` | `O(V)` | 拓扑序上的状态转移 |

---

## 常见误区

1. **把边方向建反**：先修关系应从前置节点指向后继节点。
2. **只把一个入度为 0 的点入队**：DAG 可能有多个起点，必须全部入队。
3. **认为拓扑序唯一**：多个入度为 `0` 的点可以有不同处理顺序。
4. **用普通 visited 做 DFS 判环**：有向图判环需要三色标记，不能只用访问过 / 没访问过。
5. **有环还做 DAG DP**：DAG DP 的前提是无环；先确认拓扑排序能覆盖全部节点。
