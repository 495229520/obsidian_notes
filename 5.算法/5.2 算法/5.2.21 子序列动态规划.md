# 5.2.21 子序列动态规划

> 子序列 DP 处理的是“不要求连续，但要求保持相对顺序”的问题。LIS、LCS、编辑距离、最长回文子序列都属于 LeetCode 高频模型。

---

## 子序列 DP 解决什么问题

子序列和子数组不同：

- 子数组 / 子串：必须连续。
- 子序列：可以跳过元素，但相对顺序不能变。

| 题目信号 | 常见模型 |
|----------|----------|
| 最长递增子序列 | LIS，一维 DP 或贪心 + 二分 |
| 两个字符串最长公共部分 | LCS，二维 DP |
| 最少插入/删除/替换 | 编辑距离类 DP |
| 回文子序列 | 区间式子序列 DP |
| 判断是否为另一个串的子序列 | 双指针或 DP |

和 [[5.算法/5.2 算法/5.2.7 双指针与滑动窗口|双指针与滑动窗口]] 相比，子序列 DP 允许跳过中间元素；和 [[5.算法/5.2 算法/5.2.19 动态规划|动态规划]] 总纲相比，本篇专注“以位置结尾”和“两串前缀”两种状态定义。

## 一维子序列：LIS

最长递增子序列（LIS）的经典状态定义是：

```text
dp[i] = 以 nums[i] 结尾的最长递增子序列长度
```

转移：

```text
如果 j < i 且 nums[j] < nums[i]
dp[i] = max(dp[i], dp[j] + 1)
```

```cpp
#include <algorithm>
#include <vector>

int lengthOfLIS(const std::vector<int>& nums) {
    if (nums.empty()) return 0;

    std::vector<int> dp(nums.size(), 1);
    int best = 1;

    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        for (int j = 0; j < i; ++j) {
            if (nums[j] < nums[i]) {
                dp[i] = std::max(dp[i], dp[j] + 1);
            }
        }
        best = std::max(best, dp[i]);
    }

    return best;
}
```

**为什么答案不是 `dp[n - 1]`**：

- `dp[i]` 表示必须以 `nums[i]` 结尾。
- 最长递增子序列可以在任意位置结尾。
- 因此答案是所有 `dp[i]` 的最大值。

## LIS 的二分优化

LIS 还有一个 `O(nlogn)` 写法，用 `tails[len]` 表示长度为 `len + 1` 的递增子序列的最小结尾值。

```cpp
#include <algorithm>
#include <vector>

int lengthOfLISBinary(const std::vector<int>& nums) {
    std::vector<int> tails;

    for (int x : nums) {
        auto it = std::lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) {
            tails.push_back(x);
        } else {
            *it = x;
        }
    }

    return static_cast<int>(tails.size());
}
```

> [!warning]
> `tails` 本身不一定是一条真实的 LIS，它维护的是“同长度子序列的最优结尾候选”。

如果题目要求非严格递增，把 `lower_bound` 换成 `upper_bound`。

## 两个序列：LCS

最长公共子序列（LCS）通常使用二维 DP：

```text
dp[i][j] = text1 前 i 个字符，与 text2 前 j 个字符的 LCS 长度
```

转移：

```text
text1[i - 1] == text2[j - 1]:
    dp[i][j] = dp[i - 1][j - 1] + 1
否则:
    dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
```

```cpp
#include <algorithm>
#include <string>
#include <vector>

int longestCommonSubsequence(const std::string& a, const std::string& b) {
    int m = static_cast<int>(a.size());
    int n = static_cast<int>(b.size());
    std::vector<std::vector<int>> dp(m + 1, std::vector<int>(n + 1, 0));

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (a[i - 1] == b[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                dp[i][j] = std::max(dp[i - 1][j], dp[i][j - 1]);
            }
        }
    }

    return dp[m][n];
}
```

**为什么数组多开一行一列**：

- `dp[0][j]` 表示空串和 `b` 前 `j` 个字符的 LCS，值为 0。
- `dp[i][0]` 表示 `a` 前 `i` 个字符和空串的 LCS，值为 0。
- 多开的边界能避免大量 `i - 1`、`j - 1` 的越界判断。

## 编辑距离

编辑距离问的是：把 `word1` 变成 `word2`，最少需要插入、删除、替换多少次。

```text
dp[i][j] = word1 前 i 个字符变成 word2 前 j 个字符的最少操作数
```

```cpp
#include <algorithm>
#include <string>
#include <vector>

int minDistance(const std::string& a, const std::string& b) {
    int m = static_cast<int>(a.size());
    int n = static_cast<int>(b.size());
    std::vector<std::vector<int>> dp(m + 1, std::vector<int>(n + 1, 0));

    for (int i = 0; i <= m; ++i) dp[i][0] = i;
    for (int j = 0; j <= n; ++j) dp[0][j] = j;

    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (a[i - 1] == b[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1];
            } else {
                dp[i][j] = 1 + std::min({
                    dp[i - 1][j],
                    dp[i][j - 1],
                    dp[i - 1][j - 1]
                });
            }
        }
    }

    return dp[m][n];
}
```

三个来源分别表示：

| 来源 | 操作含义 |
|------|----------|
| `dp[i - 1][j]` | 删除 `a[i - 1]` |
| `dp[i][j - 1]` | 插入 `b[j - 1]` |
| `dp[i - 1][j - 1]` | 替换 `a[i - 1]` |

## 最长回文子序列

最长回文子序列只有一个字符串，但它的状态是区间：

```text
dp[i][j] = s[i..j] 中最长回文子序列长度
```

```cpp
#include <algorithm>
#include <string>
#include <vector>

int longestPalindromeSubseq(const std::string& s) {
    int n = static_cast<int>(s.size());
    std::vector<std::vector<int>> dp(n, std::vector<int>(n, 0));

    for (int i = n - 1; i >= 0; --i) {
        dp[i][i] = 1;
        for (int j = i + 1; j < n; ++j) {
            if (s[i] == s[j]) {
                dp[i][j] = dp[i + 1][j - 1] + 2;
            } else {
                dp[i][j] = std::max(dp[i + 1][j], dp[i][j - 1]);
            }
        }
    }

    return n == 0 ? 0 : dp[0][n - 1];
}
```

这里 `i` 必须倒序，因为 `dp[i][j]` 依赖 `dp[i + 1][j]`。

---

## 如何识别题型

| 题目特征 | 推荐状态 |
|----------|----------|
| 单数组，要求递增/递减/整除链 | `dp[i] = 以 i 结尾的最优解` |
| 两个字符串/数组，保持相对顺序 | `dp[i][j] = 两个前缀的最优解` |
| 允许插入、删除、替换 | 编辑距离状态 |
| 一个字符串内部找回文子序列 | `dp[i][j] = 区间内最优解` |
| 要求连续子串/子数组 | 不优先用子序列模型 |

---

## 复杂度总结

| 模型 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| LIS 二重循环 | `O(n²)` | `O(n)` |
| LIS 二分优化 | `O(nlogn)` | `O(n)` |
| LCS | `O(mn)` | `O(mn)` |
| 编辑距离 | `O(mn)` | `O(mn)` |
| 回文子序列 | `O(n²)` | `O(n²)` |

## 常见误区

### 1. 混淆子序列和子串

子序列可以跳过元素，子串必须连续。最长回文子串和最长回文子序列不是同一个问题。

### 2. LIS 答案误取最后一个状态

`dp[i]` 是“以 i 结尾”，答案要取全局最大值。

### 3. LCS 下标错位

`dp[i][j]` 表示前 `i`、前 `j` 个字符，所以比较的是 `a[i - 1]` 和 `b[j - 1]`。

### 4. 回文子序列遍历方向错误

`dp[i][j]` 依赖 `i + 1`，所以 `i` 要倒序。

---

## 关键要点

1. 子序列不要求连续，但必须保持相对顺序。
2. LIS 常用“以 i 结尾”的一维状态。
3. LCS 常用“两个前缀”的二维状态。
4. 编辑距离的插入、删除、替换都来自相邻子问题。
5. 最长回文子序列本质上是区间 DP。
