# 5.2.10 栈与单调结构

> 栈和队列不只是 STL 接口，也是一类压缩枚举的算法结构：普通栈处理“最近未匹配”，单调栈处理“最近更大/更小”，单调队列处理“滑动窗口最值”。

---

## 为什么需要算法视角

[[5.算法/5.1 STL/5.1.8 容器适配器|容器适配器]] 主要解释 `stack`、`queue`、`priority_queue` 的接口和底层容器；本篇关注的是：**什么时候用栈或队列维护候选答案，怎样让每个元素只进出一次**。

| 结构 | 维护什么 | 典型问题 |
|------|----------|----------|
| 普通栈 | 最近还没有被匹配、计算或回退的元素 | 括号匹配、表达式求值、DFS 回溯 |
| 辅助栈 | 主栈状态之外的附加信息 | 最小栈、最大栈 |
| 单调栈 | 仍可能成为“下一个更大/更小答案”的下标 | 每日温度、柱状图最大矩形 |
| 单调队列 | 当前窗口中仍可能成为最大/最小值的下标 | 滑动窗口最大值、固定窗口最小值 |

> [!tip]
> 单调结构的关键不是“排序”，而是用弹出操作删除已经不可能成为答案的候选元素。

---

## 栈的基本模型

栈是后进先出结构，算法上最常用来保存“最近的、还没处理完的状态”。

```cpp
#include <stack>

std::stack<int> st;
st.push(10);
st.push(20);

int x = st.top();  // 20
st.pop();
```

适合使用栈的信号：

- 需要匹配最近出现的元素，比如括号、标签、函数调用。
- 遇到新元素时，需要回头处理前面若干个未完成元素。
- 当前元素会让前面的某些候选元素失效。

## 括号匹配

括号匹配是普通栈最典型的用法。左括号入栈，右括号必须和栈顶左括号配对。

```cpp
#include <stack>
#include <string>

bool isValidParentheses(const std::string& s) {
    std::stack<char> st;

    for (char ch : s) {
        if (ch == '(' || ch == '[' || ch == '{') {
            st.push(ch);
            continue;
        }

        if (st.empty()) return false;

        char left = st.top();
        st.pop();

        if ((ch == ')' && left != '(') ||
            (ch == ']' && left != '[') ||
            (ch == '}' && left != '{')) {
            return false;
        }
    }

    return st.empty();
}
```

**关键点**：

- 右括号出现时，必须先判断栈是否为空。
- 只有栈顶元素能和当前右括号匹配，因为它是最近的未匹配左括号。
- 遍历结束后栈必须为空，否则说明还有左括号没有被匹配。

> [!warning]
> 只统计左右括号数量是不够的。`([)]` 中数量正确，但最近匹配关系错误。

## 最小栈

最小栈要求在 `push`、`pop`、`top` 之外，用 `O(1)` 得到当前最小值。做法是额外维护一个最小值栈。

```cpp
#include <stack>

class MinStack {
public:
    void push(int x) {
        data_.push(x);
        if (mins_.empty() || x <= mins_.top()) {
            mins_.push(x);
        }
    }

    void pop() {
        if (data_.top() == mins_.top()) {
            mins_.pop();
        }
        data_.pop();
    }

    int top() const {
        return data_.top();
    }

    int getMin() const {
        return mins_.top();
    }

private:
    std::stack<int> data_;
    std::stack<int> mins_;
};
```

**为什么 `x <= mins_.top()` 要包含等号**：

- 如果最小值重复出现，需要把重复最小值也压入 `mins_`。
- 弹出一个最小值后，另一个相同最小值仍然应该留在辅助栈中。

```text
push: 3, 1, 1
data: 3, 1, 1
mins: 3, 1, 1

pop 一个 1 后：
data: 3, 1
mins: 3, 1     当前最小值仍然是 1
```

## 单调栈总览

单调栈通常保存下标，而不是保存值。它的核心不变量是：

1. 栈中下标对应的值保持单调。
2. 栈中元素都是还没有确定答案的候选元素。
3. 当前元素让栈顶元素确定答案时，就不断弹出栈顶。

![[图片/5.算法/5.2 算法/5_2_2_10_1.svg]]

### 怎么选择单调方向

| 问题 | 栈内值的方向 | 当前元素触发什么 |
|------|--------------|------------------|
| 下一个更大元素 | 从栈底到栈顶单调递减 | 当前值更大时，弹出更小值 |
| 下一个更小元素 | 从栈底到栈顶单调递增 | 当前值更小时，弹出更大值 |
| 每日温度 | 温度单调递减 | 更高温度让低温天数确定答案 |
| 柱状图最大矩形 | 高度单调递增 | 更低高度让高柱子的右边界确定 |

### 下一个更大元素模板

```cpp
#include <vector>

std::vector<int> nextGreaterDistance(const std::vector<int>& nums) {
    std::vector<int> ans(nums.size(), 0);
    std::vector<int> st;

    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!st.empty() && nums[i] > nums[st.back()]) {
            int prev = st.back();
            st.pop_back();
            ans[prev] = i - prev;
        }
        st.push_back(i);
    }

    return ans;
}
```

**这个模板的含义**：

- `st` 中保存还没有找到下一个更大值的下标。
- 当前 `nums[i]` 比栈顶更大时，栈顶下标的答案就是 `i`。
- 每个下标最多入栈一次、出栈一次，所以时间复杂度是 `O(n)`。

## 每日温度

每日温度问的是：对每一天，多少天后会出现更高温度。它就是“下一个更大元素”的距离版本。

```cpp
#include <vector>

std::vector<int> dailyTemperatures(const std::vector<int>& temperatures) {
    std::vector<int> ans(temperatures.size(), 0);
    std::vector<int> st;

    for (int i = 0; i < static_cast<int>(temperatures.size()); ++i) {
        while (!st.empty() && temperatures[i] > temperatures[st.back()]) {
            int day = st.back();
            st.pop_back();
            ans[day] = i - day;
        }
        st.push_back(i);
    }

    return ans;
}
```

示例：

```text
temperatures = [73, 74, 75, 71, 69, 72, 76, 73]
answer       = [ 1,  1,  4,  2,  1,  1,  0,  0]
```

> [!note]
> 栈里不是“已经处理完的天”，而是“还在等更高温度的天”。

## 柱状图最大矩形

柱状图最大矩形的关键是：对每根柱子，找到它左右两侧第一个比它矮的位置。中间连续区间都不矮于它时，就能用它作为矩形高度。

单调递增栈可以在一次扫描中确定右边界：

```cpp
#include <algorithm>
#include <vector>

int largestRectangleArea(std::vector<int> heights) {
    heights.push_back(0);

    std::vector<int> st;
    int best = 0;

    for (int i = 0; i < static_cast<int>(heights.size()); ++i) {
        while (!st.empty() && heights[i] < heights[st.back()]) {
            int height = heights[st.back()];
            st.pop_back();

            int leftLess = st.empty() ? -1 : st.back();
            int width = i - leftLess - 1;
            best = std::max(best, height * width);
        }

        st.push_back(i);
    }

    return best;
}
```

**为什么宽度是 `i - leftLess - 1`**：

- 当前 `i` 是右侧第一个更矮位置，不能包含。
- 弹出后新的栈顶 `leftLess` 是左侧第一个更矮位置，也不能包含。
- 能扩展的范围是 `(leftLess, i)`，长度就是 `i - leftLess - 1`。

> [!tip]
> 末尾追加一个高度为 `0` 的哨兵，可以强制清空栈，避免循环结束后再单独处理剩余柱子。

## 单调队列总览

单调队列常用 `std::deque<int>` 保存下标。做滑动窗口最大值时，队列从队头到队尾对应的值保持单调递减。

![[图片/5.算法/5.2 算法/5_2_2_10_2.svg]]

维护步骤：

1. 队头下标如果已经离开窗口，先弹出。
2. 当前值进入队列前，弹出队尾所有小于等于当前值的下标。
3. 当前下标入队。
4. 窗口形成后，队头就是当前窗口最大值。

> [!note]
> 单调队列和 [[5.算法/5.2 算法/5.2.7 双指针与滑动窗口|滑动窗口]] 经常一起出现：窗口边界负责范围，队列负责范围内的最值。

---

## 滑动窗口最大值

```cpp
#include <deque>
#include <vector>

std::vector<int> maxSlidingWindow(const std::vector<int>& nums, int k) {
    if (k <= 0 || k > static_cast<int>(nums.size())) return {};

    std::deque<int> dq;
    std::vector<int> ans;

    for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
        int left = right - k + 1;

        while (!dq.empty() && dq.front() < left) {
            dq.pop_front();
        }

        while (!dq.empty() && nums[dq.back()] <= nums[right]) {
            dq.pop_back();
        }

        dq.push_back(right);

        if (left >= 0) {
            ans.push_back(nums[dq.front()]);
        }
    }

    return ans;
}
```

**为什么队尾要弹出小于等于当前值的元素**：

- 它们比当前值小，作为最大值没有优势。
- 它们下标更旧，会比当前元素更早离开窗口。
- 因此当前元素进入后，它们不可能再成为未来窗口最大值。

如果要维护窗口最小值，把比较方向反过来即可：

```cpp
while (!dq.empty() && nums[dq.back()] >= nums[right]) {
    dq.pop_back();
}
```

## 如何识别题型

| 题目特征 | 优先考虑 | 典型写法 |
|----------|----------|----------|
| 最近的左括号、标签、状态要被匹配 | 普通栈 | 左侧入栈，右侧匹配栈顶 |
| 栈操作同时要求当前最小值/最大值 | 辅助栈 | 主栈保存数据，辅助栈保存历史最值 |
| 下一个更大、下一个更小、多少天后更高 | 单调栈 | 当前元素让栈顶元素确定答案 |
| 每根柱子向左右扩展到哪里 | 单调栈 | 更矮柱子触发结算面积 |
| 固定长度窗口内的最大/最小值 | 单调队列 | 队头维护当前窗口最优值 |

## 复杂度总结

| 问题 | 时间复杂度 | 空间复杂度 | 原因 |
|------|------------|------------|------|
| 括号匹配 | `O(n)` | `O(n)` | 每个字符最多入栈一次 |
| 最小栈 | 单次操作 `O(1)` | `O(n)` | 辅助栈保存历史最小值 |
| 每日温度 | `O(n)` | `O(n)` | 每个下标最多入栈、出栈一次 |
| 柱状图最大矩形 | `O(n)` | `O(n)` | 每根柱子最多入栈、出栈一次 |
| 滑动窗口最大值 | `O(n)` | `O(k)` | 队列只保存当前窗口候选下标 |

## 常见误区

### 1. 单调栈保存值，不保存下标

大多数题需要计算距离、宽度或答案位置，因此栈里应该保存下标。值可以通过 `nums[index]` 或 `heights[index]` 取到。

### 2. 不清楚答案在什么时候更新

单调栈通常在“弹出元素”时更新被弹元素的答案，因为此时当前元素刚好提供了右侧第一个更大或更小的位置。

### 3. 柱状图宽度少算或多算 1

弹出柱子后，左右两侧更矮柱子都不能包含，所以宽度是 `i - leftLess - 1`。

### 4. 单调队列忘记删除过期下标

窗口移动后，队头可能已经不在窗口内。过期判断应该用下标，而不是用值。

### 5. 把 `stack` / `queue` 当成可遍历容器

`stack` 和 `queue` 是容器适配器，没有迭代器。如果算法需要随机访问或遍历候选集合，通常用 `std::vector<int>` 模拟栈，用 `std::deque<int>` 模拟队列。

---

## 关键要点

1. 普通栈解决最近匹配和状态回退问题。
2. 最小栈用辅助栈保存历史最小值，重复最小值也要记录。
3. 单调栈保存还没确定答案的下标，当前元素可能让一批旧元素结算。
4. 每日温度是下一个更大元素的距离版。
5. 柱状图最大矩形用单调递增栈确定每根柱子的左右矮边界。
6. 单调队列用 `deque` 保存窗口内候选下标，队头永远是当前最值。
7. 单调结构的整体复杂度通常是 `O(n)`，因为每个元素最多进出一次。
