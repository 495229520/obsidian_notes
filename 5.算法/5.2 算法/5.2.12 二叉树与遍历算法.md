# 5.2.12 二叉树与遍历算法

二叉树是一种每个节点最多有两个子节点的树形数据结构。它是算法题中最常见的数据结构之一，很多递归、DFS、BFS、分治和动态规划问题都可以抽象成二叉树上的遍历与状态处理。

---

## 1. 二叉树概览

### 1.1 什么是二叉树

二叉树（Binary Tree）是由节点组成的层级结构，每个节点最多有两个孩子：

- 左孩子：`left`
- 右孩子：`right`

常见 C++ 节点定义如下：

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;

    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
    TreeNode(int x, TreeNode* left, TreeNode* right)
        : val(x), left(left), right(right) {}
};
```

### 1.2 基本术语

| 术语 | 含义 |
|------|------|
| 根节点 | 整棵树最上方的节点 |
| 父节点 | 某个节点的直接上级节点 |
| 子节点 | 某个节点的直接下级节点 |
| 兄弟节点 | 拥有同一个父节点的节点 |
| 叶子节点 | 没有任何子节点的节点 |
| 子树 | 以某个节点为根形成的一棵树 |
| 深度 | 从根节点到当前节点经过的边数或层数 |
| 高度 | 从当前节点到最远叶子节点的距离 |

> [!tip]
> 很多题里“深度”和“高度”的定义可能从 0 或 1 开始，做题时要以题目样例为准。

### 1.3 常见二叉树类型

| 类型 | 特点 | 常见用途 |
|------|------|----------|
| 普通二叉树 | 每个节点最多两个孩子，不要求顺序 | 遍历、递归、路径问题 |
| 满二叉树 | 每个非叶子节点都有两个孩子，所有叶子在同一层 | 理解树结构性质 |
| 完全二叉树 | 除最后一层外都填满，最后一层从左到右填充 | 堆、数组存储二叉树 |
| 二叉搜索树 | 左子树值小于根，右子树值大于根 | 查找、排序、范围查询 |
| 平衡二叉树 | 左右子树高度差受限制 | 保证查找效率 |

### 1.4 二叉树与 STL 的关系

C++ STL 中没有直接提供 `TreeNode` 这种二叉树容器，但很多 STL 结构背后使用树或堆思想：

- [[5.1.4 set]] / [[5.1.5 map]]：常见实现基于红黑树
- [[5.1.8 容器适配器]]：`priority_queue` 底层是堆，堆可以看作完全二叉树
- [[5.2.13 红黑树]]：自平衡二叉搜索树，是关联容器的重要底层结构

## 2. 二叉树的存储方式

### 2.1 链式存储

力扣题中最常见的是链式存储：

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};
```

每个节点通过指针连接左右孩子。

优点：

1. 结构直观，适合递归处理。
2. 方便表示稀疏树。
3. 插入和删除节点时不需要移动大量元素。

缺点：

1. 无法像数组一样通过下标快速定位父子关系。
2. 需要处理空指针边界。

### 2.2 数组存储

完全二叉树常用数组存储，例如堆：

```text
下标 i 的左孩子：2 * i + 1
下标 i 的右孩子：2 * i + 2
下标 i 的父节点：(i - 1) / 2
```

这种方式适合完全二叉树，因为节点按层紧密排列，不会浪费太多空间。

> [!note]
> `priority_queue` 的底层堆通常使用数组实现，所以理解完全二叉树下标关系有助于理解堆操作。

## 3. 遍历方法总览

### 3.1 四种常见遍历

二叉树遍历的目标是：按照某种规则访问树中的每个节点一次。

| 遍历方式 | 访问顺序 | 核心思想 | 常见用途 |
|----------|----------|----------|----------|
| 前序遍历 | 根 -> 左 -> 右 | 先处理当前节点 | 复制树、序列化树、表达式前缀形式 |
| 中序遍历 | 左 -> 根 -> 右 | 根在中间处理 | 二叉搜索树输出升序序列 |
| 后序遍历 | 左 -> 右 -> 根 | 先处理子树，再处理根 | 删除树、统计子树信息、树形 DP |
| 层序遍历 | 从上到下、从左到右 | 按层 BFS | 最短层数、层级输出、宽度问题 |

|----------|------|
| 前序 | `A B D E C F G` |
| 中序 | `D B E A F C G` |
| 后序 | `D E B F G C A` |
| 层序 | `A B C D E F G` |

## 4. 深度优先遍历 DFS

前序、中序、后序都属于深度优先遍历（DFS）。

DFS 的特点是：沿着一条路径尽可能深入，走到底后再回退。

### 4.1 前序遍历

#### 递归写法

```cpp
void preorder(TreeNode* root, vector<int>& result) {
    if (root == nullptr) return;

    result.push_back(root->val);
    preorder(root->left, result);
    preorder(root->right, result);
}
```

访问顺序：

```text
根 -> 左 -> 右
```

适用场景：

1. 需要先处理当前节点，再处理子树。
2. 复制一棵树。
3. 序列化二叉树时记录结构。

#### 迭代写法

```cpp
vector<int> preorderTraversal(TreeNode* root) {
    vector<int> result;
    if (root == nullptr) return result;

    stack<TreeNode*> st;
    st.push(root);

    while (!st.empty()) {
        TreeNode* node = st.top();
        st.pop();

        result.push_back(node->val);

        if (node->right != nullptr) st.push(node->right);
        if (node->left != nullptr) st.push(node->left);
    }

    return result;
}
```

> [!tip]
> 栈是后进先出。前序要先访问左子树，所以迭代时要先压右孩子，再压左孩子。

### 4.2 中序遍历

#### 递归写法

```cpp
void inorder(TreeNode* root, vector<int>& result) {
    if (root == nullptr) return;

    inorder(root->left, result);
    result.push_back(root->val);
    inorder(root->right, result);
}
```

访问顺序：

```text
左 -> 根 -> 右
```

适用场景：

1. 二叉搜索树中序遍历得到升序序列。
2. 判断一棵树是否是合法二叉搜索树。
3. 找二叉搜索树中的第 `k` 小元素。

#### 迭代写法

```cpp
vector<int> inorderTraversal(TreeNode* root) {
    vector<int> result;
    stack<TreeNode*> st;
    TreeNode* curr = root;

    while (curr != nullptr || !st.empty()) {
        while (curr != nullptr) {
            st.push(curr);
            curr = curr->left;
        }

        curr = st.top();
        st.pop();

        result.push_back(curr->val);
        curr = curr->right;
    }

    return result;
}
```

这份写法的含义是：先一路向左走到底，把路径上的节点压栈；当左边走完后，再处理根节点，然后进入右子树。

### 4.3 后序遍历

#### 递归写法

```cpp
void postorder(TreeNode* root, vector<int>& result) {
    if (root == nullptr) return;

    postorder(root->left, result);
    postorder(root->right, result);
    result.push_back(root->val);
}
```

访问顺序：

```text
左 -> 右 -> 根
```

适用场景：

1. 需要先知道左右子树结果，再处理当前节点。
2. 删除一棵树。
3. 计算二叉树高度、直径、最大路径和等树形 DP 问题。

#### 迭代写法

```cpp
vector<int> postorderTraversal(TreeNode* root) {
    vector<int> result;
    if (root == nullptr) return result;

    stack<TreeNode*> st;
    st.push(root);

    while (!st.empty()) {
        TreeNode* node = st.top();
        st.pop();

        result.push_back(node->val);

        if (node->left != nullptr) st.push(node->left);
        if (node->right != nullptr) st.push(node->right);
    }

    reverse(result.begin(), result.end());
    return result;
}
```

这份写法先得到：

```text
根 -> 右 -> 左
```

再整体反转，就得到：

```text
左 -> 右 -> 根
```

## 5. 广度优先遍历 BFS：层序遍历

层序遍历按照层从上到下访问节点，同一层从左到右访问。

它本质上是 BFS，需要使用队列。

### 5.1 基本层序遍历

```cpp
vector<int> levelOrder(TreeNode* root) {
    vector<int> result;
    if (root == nullptr) return result;

    queue<TreeNode*> que;
    que.push(root);

    while (!que.empty()) {
        TreeNode* node = que.front();
        que.pop();

        result.push_back(node->val);

        if (node->left != nullptr) que.push(node->left);
        if (node->right != nullptr) que.push(node->right);
    }

    return result;
}
```

### 5.2 按层分组输出

力扣中更常见的是按层返回二维数组：

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (root == nullptr) return result;

    queue<TreeNode*> que;
    que.push(root);

    while (!que.empty()) {
        int size = que.size();
        vector<int> level;

        for (int i = 0; i < size; ++i) {
            TreeNode* node = que.front();
            que.pop();

            level.push_back(node->val);

            if (node->left != nullptr) que.push(node->left);
            if (node->right != nullptr) que.push(node->right);
        }

        result.push_back(level);
    }

    return result;
}
```

> [!important]
> 按层遍历时，`int size = que.size();` 必须在每一层开始时先固定下来。因为遍历当前层时会继续把下一层节点加入队列。

### 5.3 层序遍历适用场景

| 场景 | 说明 |
|------|------|
| 求最小深度 | BFS 第一次遇到叶子节点就是最小深度 |
| 按层输出 | 每层节点单独放入一个数组 |
| 锯齿形遍历 | 在层序基础上按层反转结果 |
| 找每层最大值 | 遍历每层时维护最大值 |
| 完全二叉树判断 | 层序遍历中检查空节点后的非空节点 |

## 6. 递归遍历的统一模板

### 6.1 递归三要素

写二叉树递归时，可以固定从三个问题入手：

1. 当前函数处理哪棵树？
2. 空节点时返回什么？
3. 当前节点和左右子树的处理顺序是什么？

递归函数通常长这样：

```cpp
void dfs(TreeNode* root) {
    if (root == nullptr) return;

    // 处理当前节点
    dfs(root->left);
    dfs(root->right);
}
```

### 6.2 访问时机决定遍历顺序

同样是三行代码，只要改变“处理当前节点”的位置，就能得到不同遍历：

```cpp
// 前序：根 -> 左 -> 右
visit(root);
dfs(root->left);
dfs(root->right);

// 中序：左 -> 根 -> 右
dfs(root->left);
visit(root);
dfs(root->right);

// 后序：左 -> 右 -> 根
dfs(root->left);
dfs(root->right);
visit(root);
```

### 6.3 返回值递归模板

很多题不是单纯遍历，而是要从子树返回信息：

```cpp
int dfs(TreeNode* root) {
    if (root == nullptr) return 0;

    int left = dfs(root->left);
    int right = dfs(root->right);

    return max(left, right) + 1;
}
```

这类写法常用于：

1. 求最大深度
2. 判断是否平衡
3. 计算路径和
4. 树形动态规划

## 7. 二叉搜索树与中序遍历

二叉搜索树（BST）是二叉树的一种特殊形式。

它满足：

```text
左子树所有节点值 < 根节点值 < 右子树所有节点值
```

因此，中序遍历 BST 会得到升序序列：

```cpp
void inorder(TreeNode* root, vector<int>& result) {
    if (root == nullptr) return;

    inorder(root->left, result);
    result.push_back(root->val);
    inorder(root->right, result);
}
```

常见应用：

| 问题 | 中序遍历的作用 |
|------|----------------|
| 验证二叉搜索树 | 检查中序序列是否严格递增 |
| 二叉搜索树第 k 小 | 中序遍历计数到第 `k` 个 |
| 二叉搜索树范围和 | 按值范围剪枝遍历 |
| 将 BST 转成有序数组 | 中序遍历直接得到升序结果 |

## 8. 复杂度分析

### 8.1 时间复杂度

- 前序 / 中序 / 后序 / 层序遍历：`O(n)`

原因：每个节点都会被访问一次，`n` 是节点数量。

### 8.2 空间复杂度

| 遍历方式 | 空间复杂度 | 原因 |
|----------|------------|------|
| 递归 DFS | `O(h)` | 递归调用栈，`h` 是树高 |
| 迭代 DFS | `O(h)` 到 `O(n)` | 显式栈保存待访问节点 |
| BFS 层序 | `O(w)` | 队列最多保存一层节点，`w` 是最大宽度 |

最坏情况下：

- 链状二叉树高度 `h = n`，递归栈可能是 `O(n)`。
- 完全二叉树最后一层节点很多，BFS 队列可能达到 `O(n)`。

---

## 9. 易错点

1. 空树 `root == nullptr` 必须先处理。
2. 前序、中序、后序的区别只在“访问根节点”的时机。
3. 迭代前序中，因为栈后进先出，要先压右孩子，再压左孩子。
4. 迭代中序要先一路向左入栈，再弹栈访问根节点。
5. 层序遍历按层输出时，要先固定当前层节点数量。
6. BST 中序遍历是升序，但普通二叉树中序遍历没有排序性质。
7. 递归法代码短，但深度过大时可能有栈溢出风险。
