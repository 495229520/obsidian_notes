# 5.2.4 前缀和

## 为什么需要前缀和

设数组长度为 `n`，要回答 `m` 次「区间 `[l, r]` 之和」的询问：

| 做法 | 预处理 | 单次查询 | m 次总复杂度 |
|------|--------|----------|--------------|
| 暴力逐项累加 | 无 | O(n) | **O(n·m)** |
| 前缀和 | O(n) | **O(1)** | O(n + m) |

> [!tip] 核心思想
> 用一次扫描把「从头到每个位置的累加和」预存下来，之后任意区间和都能用**一次减法**得到。
> 适用前提：**数组本身不变，只反复查询区间和**（若频繁单点修改，应改用 [[5.2.10 栈与单调结构|树状数组 / 线段树]]）。

---

## 一维前缀和

### 问题描述

- 输入一个长度为 `n` 的整数序列
- 接下来输入 `m` 个询问，每个询问给一对 `l, r`
- 对每个询问，输出原序列中第 `l` 个数到第 `r` 个数的和

**输入格式**

- 第一行包含两个整数 `n` 和 `m`
- 第二行包含 `n` 个整数，表示整数数列
- 接下来 `m` 行，每行包含两个整数 `l` 和 `r`

**输出格式**：共 `m` 行，每行输出一个询问的结果。

### 原理

定义前缀和 `s[i] = a[1] + a[2] + … + a[i]`，并约定哨兵 `s[0] = 0`。则：

```
s[r]   = a[1] + a[2] + … + a[l-1] + a[l] + a[l+1] + … + a[r]
s[l-1] = a[1] + a[2] + … + a[l-1]
————————————————————————————————————————————————————————————
s[r] - s[l-1] =                     a[l] + a[l+1] + … + a[r]
```

即区间 `[l, r]` 的和 `= s[r] - s[l-1]`，与区间长度无关，恒为 O(1)。

### 图解

以 `a = [3, 1, 4, 1, 5, 9, 2]`（下标 1~7）、查询区间 `[3, 6]` 为例：

![[图片/SVG/5_2_2_4_1.svg]]

`s[6] - s[2] = 23 - 4 = 19`，恰好等于 `a[3] + a[4] + a[5] + a[6] = 4 + 1 + 5 + 9`。

### 代码实现

```cpp
#include <cstdio>
using namespace std;

const int N = 1e6 + 10;

int n, m;
int a[N], s[N];

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++) scanf("%d", &a[i]);

    // 前缀和初始化：s[0] = 0 由全局数组默认值保证
    for (int i = 1; i <= n; i++) s[i] = s[i - 1] + a[i];

    while (m--) {
        int l, r;
        scanf("%d%d", &l, &r);
        // 区间和 = s[r] - s[l-1]
        printf("%d\n", s[r] - s[l - 1]);
    }

    return 0;
}
```

## 二维前缀和

二维的核心是**容斥原理**：任何一块矩形和都能拆成「整块 − 上方 − 左方 + 重叠」。

### 图解

下图用统一的「四块拆分 A·B·C·D」解释**递推构建**与**子矩阵查询**——两者其实是同一句容斥的正反两面：

![[图片/SVG/5_2_2_4_2.svg]]

- **递推构建**：`S(i-1,j)` 与 `S(i,j-1)` 都包含左上角块 `A = S(i-1,j-1)`，相加时 `A` 被算了两次，故要**减回**一次，再补上当前格 `a(i,j)`。
- **子矩阵查询**：减去上方 `S(x1-1,y2)` 与左方 `S(x2,y1-1)` 时，左上角 `A` 被**重复扣**了两次，故要**加回**一次。

### 公式

**前缀和构建**：

```
S(i,j) = S(i-1,j) + S(i,j-1) - S(i-1,j-1) + a(i,j)
```

**区间和查询**（左上角 `(x1, y1)` 到右下角 `(x2, y2)` 的子矩阵）：

```
sum = S(x2,y2) - S(x1-1,y2) - S(x2,y1-1) + S(x1-1,y1-1)
```

### 代码实现

```cpp
#include <cstdio>
using namespace std;

const int N = 1e4 + 10;

int n, m, q;
int a[N][N], s[N][N];

int main() {
    // n 行 m 列，q 表示要查询几次子矩阵和
    scanf("%d%d%d", &n, &m, &q);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            scanf("%d", &a[i][j]);

    // 前缀和初始化（容斥）
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + a[i][j];

    while (q--) {
        int x1, y1, x2, y2;
        scanf("%d%d%d%d", &x1, &y1, &x2, &y2);
        // 子矩阵 [x1..x2][y1..y2] 的和
        printf("%d\n", s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1]);
    }

    return 0;
}
```

## 前缀和的应用场景

| 场景 | 说明 |
|------|------|
| 区间求和 | O(1) 时间查询任意区间和 |
| 子矩阵求和 | 二维前缀和的典型应用 |
| 前缀和 + 哈希 | 统计「和为 K」的子数组个数（同余 / 同前缀差） |
| 前后缀分解 | 除自身以外的乘积、左右两侧聚合 |
| 与差分配合 | [[5.1.11 算法#差分\|差分]]是前缀和的逆运算（区间加 → 前缀和还原） |

---

## 关键要点

1. **一维前缀和**：`s[i] = s[i-1] + a[i]`，区间和 `[l, r] = s[r] - s[l-1]`。
2. **二维前缀和**：构建与查询都是容斥，记住「整块 − 上 − 左 + 重叠」。
3. **下标从 1 开始**：让 `s[0] = 0` 作哨兵，`l = 1` 时无需特判 `s[l-1]`。
4. **时间复杂度**：预处理 O(n)（二维 O(n·m)），单次查询 O(1)。

---

## 易错点

| 易错点 | 说明 |
|--------|------|
| 下标越界 | 一维用到 `s[l-1]`、二维用到 `s[x1-1][*]`，数组下标须从 1 开始且额外预留第 0 行/列。 |
| `l = 1` 漏处理 | 没有哨兵 `s[0] = 0` 时 `s[l-1]` 会越界或读到脏值；约定从 1 开始即可免去特判。 |
| 整型溢出 | 累加和可能远超 `int` 范围，数据较大时 `s[]` 应改用 `long long`。 |
| 二维数组过大 | `int a[1e4][1e4]` 约 400MB 会 MLE；二维题目注意 `N` 取值与内存限制。 |
| 容斥写错符号 | 二维查询是「− 上 − 左 **+** 重叠」，少加回左上角是最常见的错误。 |
