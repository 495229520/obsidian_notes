# 5.2.23 树形动态规划

> 树形 DP 把“父节点的答案”建立在“子树答案”之上。它常见于二叉树打家劫舍、树的最大路径、树上选点、树上独立集等问题。

---

## 树形 DP 解决什么问题

树没有环，天然适合从子节点向父节点汇总信息。树形 DP 常见信号：

| 题目信号 | 状态设计 |
|----------|----------|
| 选了父节点就不能选子节点 | 每个节点维护选/不选两个状态 |
| 子树内部的最大收益 | 后序遍历汇总子树答案 |
| 路径必须经过当前节点 | 分清“向上贡献”和“全局答案” |
| 多叉树上做分组/选择 | 当前节点合并所有子节点状态 |

它和 [[5.算法/5.2 算法/5.2.12 二叉树与遍历算法|二叉树与遍历算法]] 的关系是：遍历提供顺序，DP 定义每个节点返回什么信息。树形 DP 通常使用后序遍历，因为父节点依赖子节点。

## 基础模型：后序返回状态

树形 DP 的通用思路：

1. 明确每个节点需要返回哪些状态。
2. 先递归计算左右子树。
3. 用子树状态合成当前节点状态。
4. 把当前状态返回给父节点。

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
};
```

后序结构：

```cpp
State dfs(TreeNode* node) {
    if (node == nullptr) return baseState;

    State left = dfs(node->left);
    State right = dfs(node->right);

    State cur;
    // 用 left、right 和 node->val 计算 cur
    return cur;
}
```

> [!tip]
> 树形 DP 的状态最好表示“当前子树能给父节点什么信息”，不要只盯着整棵树的最终答案。

## 选或不选：打家劫舍 III

二叉树打家劫舍的限制是：相邻的父子节点不能同时选。

对每个节点维护两个状态：

```text
choose = 选当前节点时，当前子树能得到的最大金额
skip   = 不选当前节点时，当前子树能得到的最大金额
```

转移：

```text
choose = node->val + left.skip + right.skip
skip = max(left.choose, left.skip) + max(right.choose, right.skip)
```

```cpp
#include <algorithm>

struct RobState {
    int choose = 0;
    int skip = 0;
};

RobState dfsRob(TreeNode* node) {
    if (node == nullptr) return {};

    RobState left = dfsRob(node->left);
    RobState right = dfsRob(node->right);

    RobState cur;
    cur.choose = node->val + left.skip + right.skip;
    cur.skip = std::max(left.choose, left.skip) + std::max(right.choose, right.skip);
    return cur;
}

int rob(TreeNode* root) {
    RobState ans = dfsRob(root);
    return std::max(ans.choose, ans.skip);
}
```

**为什么 `skip` 可以取子节点最大值**：

- 当前节点不选时，子节点没有父子相邻限制。
- 子节点可以选，也可以不选，取较大者。

## 向上贡献：二叉树最大路径和

最大路径和题目中，路径可以从任意节点开始、到任意节点结束，但每个节点最多经过一次。

关键是分清两个概念：

| 信息 | 含义 |
|------|------|
| 向上贡献 | 当前节点最多选择一条子路径，返回给父节点 |
| 全局答案 | 路径可以同时经过左子树、当前节点、右子树 |

```cpp
#include <algorithm>
#include <limits>

int dfsGain(TreeNode* node, int& best) {
    if (node == nullptr) return 0;

    int left = std::max(0, dfsGain(node->left, best));
    int right = std::max(0, dfsGain(node->right, best));

    best = std::max(best, node->val + left + right);
    return node->val + std::max(left, right);
}

int maxPathSum(TreeNode* root) {
    int best = std::numeric_limits<int>::min();
    dfsGain(root, best);
    return best;
}
```

**为什么返回时只能选一边**：

- 返回给父节点的路径必须还能继续向上延伸。
- 如果同时带上左右子树，到父节点处就会分叉，不再是一条简单路径。
- 但更新全局答案时，可以用 `left + node + right` 作为一条在当前节点拐弯的路径。

## 监控/覆盖类状态

树上覆盖类问题常需要多个状态。例如二叉树摄像头可以按当前节点状态分类：

```text
0 = 当前节点未被覆盖
1 = 当前节点已覆盖，但没有摄像头
2 = 当前节点有摄像头
```

这类题的关键不是记公式，而是明确每个状态对父节点意味着什么：

- 未覆盖：希望父节点放摄像头。
- 已覆盖无摄像头：不强迫父节点。
- 有摄像头：可以覆盖父节点和子节点。

> [!note]
> 树形 DP 的多状态题，先写清楚每个状态的语义，再写转移。状态语义不清时，代码很容易互相覆盖。

## 多叉树合并

多叉树或普通树上，当前节点可能有很多子节点。常见写法是先初始化当前状态，再依次合并每个子节点。

```cpp
#include <algorithm>
#include <vector>

struct Node {
    int value = 0;
    std::vector<int> children;
};

struct SelectState {
    int choose = 0;
    int skip = 0;
};

SelectState dfsTree(int u, const std::vector<Node>& tree) {
    SelectState cur;
    cur.choose = tree[u].value;

    for (int v : tree[u].children) {
        SelectState child = dfsTree(v, tree);
        cur.choose += child.skip;
        cur.skip += std::max(child.choose, child.skip);
    }

    return cur;
}
```

这和二叉树打家劫舍是同一个模型，只是子节点数量从两个变成多个。

## 如何识别题型

| 题目特征 | 推荐思路 |
|----------|----------|
| 父子不能同时选 | 选/不选两状态 |
| 求整棵树最优，父节点依赖子树 | 后序树形 DP |
| 路径可以在某节点拐弯 | 返回向上贡献，同时维护全局答案 |
| 每个节点有覆盖、安装、未覆盖等状态 | 多状态 DP |
| 图中有环 | 不能直接树形 DP，先确认是否是树 |

## 复杂度总结

| 模型 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 二叉树选/不选 | `O(n)` | `O(h)` 递归栈 |
| 最大路径和 | `O(n)` | `O(h)` 递归栈 |
| 多叉树选/不选 | `O(n)` | `O(h)` 递归栈 |
| 多状态覆盖 | `O(n * 状态数)` | `O(h)` 递归栈 |

`h` 是树高。极端链状树中，递归栈可能达到 `O(n)`。

## 常见误区

### 1. 父节点先于子节点计算

树形 DP 通常依赖子树状态，所以应使用后序遍历。

### 2. 返回了全局答案，而不是向上贡献

最大路径和这类题中，返回给父节点的信息必须能继续接到父节点上，不能返回已经分叉的路径。

### 3. 空节点状态没有定义

空节点应该返回不会影响父节点转移的 base state。例如打家劫舍中，空节点的 `choose` 和 `skip` 都是 0。

### 4. 状态语义重叠

多状态题中，每个状态必须互斥且覆盖完整情况，否则转移会漏解或重复计算。

---

## 关键要点

1. 树形 DP 通常是后序遍历。
2. 每个节点返回的是当前子树的状态。
3. 打家劫舍 III 是典型选/不选模型。
4. 最大路径和要区分向上贡献和全局答案。
5. 多叉树可以按子节点逐个合并状态。
