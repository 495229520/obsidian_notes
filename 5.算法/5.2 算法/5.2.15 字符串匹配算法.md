# 5.2.15 字符串匹配算法

> 字符串匹配解决的是“在文本串中查找模式串”的问题。C++ 后端面试不一定每次手写 KMP，但前缀函数、失配回退和滚动哈希是经典字符串算法基本功。

---

## 字符串匹配解决什么问题

最常见的问题是：给定文本串 `text` 和模式串 `pattern`，找出 `pattern` 在 `text` 中出现的位置。

| 方法 | 核心思想 | 适用场景 |
|------|----------|----------|
| 朴素匹配 | 每个起点重新比较 | 数据小、实现最简单 |
| `string::find` | 使用标准库查找 | 工程代码优先，面试可作为基线 |
| KMP | 失配时利用已匹配前缀跳过重复比较 | 需要线性复杂度、考察字符串算法 |
| Rabin-Karp | 用滚动哈希快速比较窗口 | 多模式扩展、哈希思想题 |

[[5.算法/5.1 STL/5.1.6 string|string]] 提供 `find`、`substr` 等接口；本篇关注算法视角：**怎样避免重复比较，怎样用预处理信息加速匹配**。

> [!tip]
> 面试中如果题目明确要求实现 `strStr()`、讨论 KMP、或强调最坏情况线性复杂度，就不要只回答 `string::find`。

---

## 朴素匹配与 string::find

朴素匹配枚举每个可能起点，再逐字符比较：

```cpp
#include <string>
#include <vector>

std::vector<int> naiveSearch(const std::string& text, const std::string& pattern) {
    std::vector<int> ans;
    int n = static_cast<int>(text.size());
    int m = static_cast<int>(pattern.size());
    if (m == 0) return {0};
    if (m > n) return ans;

    for (int i = 0; i + m <= n; ++i) {
        int j = 0;
        while (j < m && text[i + j] == pattern[j]) {
            ++j;
        }
        if (j == m) {
            ans.push_back(i);
        }
    }

    return ans;
}
```

复杂度最坏是 `O(nm)`。例如文本和模式都由大量重复字符组成，前面匹配很久，最后一个字符才失败，就会反复做重复比较。

标准库版本更适合工程代码：

```cpp
#include <string>

int firstMatchByStdFind(const std::string& text, const std::string& pattern) {
    std::size_t pos = text.find(pattern);
    return pos == std::string::npos ? -1 : static_cast<int>(pos);
}
```

> [!warning]
> `string::find` 返回的是 `size_t`，未找到时是 `std::string::npos`，不要直接拿它和 `-1` 混用。

## 前缀函数

KMP 的核心预处理是前缀函数 `pi`：

```text
pi[i] = pattern[0..i] 的最长相等真前缀与真后缀长度
```

“真前缀 / 真后缀”表示不能等于整个字符串本身。

例如：

```text
pattern = a b a b a c
index   = 0 1 2 3 4 5
pi      = 0 0 1 2 3 0
```

含义示例：`pattern[0..4] = "ababa"`，最长相等真前后缀是 `"aba"`，长度为 3。

![[图片/SVG/5_2_2_15_1.svg]]

构造代码：

```cpp
#include <string>
#include <vector>

std::vector<int> buildPrefix(const std::string& pattern) {
    std::vector<int> pi(pattern.size(), 0);

    for (int i = 1; i < static_cast<int>(pattern.size()); ++i) {
        int j = pi[i - 1];
        while (j > 0 && pattern[i] != pattern[j]) {
            j = pi[j - 1];
        }
        if (pattern[i] == pattern[j]) {
            ++j;
        }
        pi[i] = j;
    }

    return pi;
}
```

**关键点**：

- `j` 表示当前已经匹配的前缀长度。
- 失配时不是回到 0，而是回到 `pi[j - 1]`。
- 回退后继续比较 `pattern[i]` 和 `pattern[j]`。

## KMP

KMP 在匹配阶段也使用同样的回退逻辑。文本指针 `i` 不回退，模式串指针 `j` 根据前缀函数回退。

```cpp
#include <string>
#include <vector>

std::vector<int> kmpSearch(const std::string& text, const std::string& pattern) {
    std::vector<int> ans;
    int n = static_cast<int>(text.size());
    int m = static_cast<int>(pattern.size());
    if (m == 0) return {0};
    if (m > n) return ans;

    std::vector<int> pi = buildPrefix(pattern);
    int j = 0;

    for (int i = 0; i < n; ++i) {
        while (j > 0 && text[i] != pattern[j]) {
            j = pi[j - 1];
        }
        if (text[i] == pattern[j]) {
            ++j;
        }
        if (j == m) {
            ans.push_back(i - m + 1);
            j = pi[j - 1];
        }
    }

    return ans;
}
```

**为什么匹配成功后还要 `j = pi[j - 1]`**：

- 这样可以继续寻找重叠匹配。
- 例如 `text = "aaaaa"`、`pattern = "aaa"`，答案应为 `0, 1, 2`。

KMP 复杂度：

| 阶段 | 时间复杂度 | 空间复杂度 |
|------|------------|------------|
| 构造 `pi` | `O(m)` | `O(m)` |
| 匹配 | `O(n)` | `O(1)` 额外 |
| 总计 | `O(n + m)` | `O(m)` |

## Rabin-Karp

Rabin-Karp 用哈希值比较窗口。每次窗口右移一格，用 `O(1)` 更新哈希值。

![[图片/SVG/5_2_2_15_2.svg]]

教学版使用：

```text
base = 131
mod = 1000000007
hash = (((c0) * base + c1) * base + c2) ...
```

```cpp
#include <string>
#include <vector>

int charValue(char ch) {
    return static_cast<unsigned char>(ch) + 1;
}

std::vector<int> rabinKarpSearch(const std::string& text, const std::string& pattern) {
    const long long base = 131;
    const long long mod = 1000000007;

    std::vector<int> ans;
    int n = static_cast<int>(text.size());
    int m = static_cast<int>(pattern.size());
    if (m == 0) return {0};
    if (m > n) return ans;

    long long patternHash = 0;
    long long windowHash = 0;
    long long highPower = 1;

    for (int i = 0; i < m; ++i) {
        patternHash = (patternHash * base + charValue(pattern[i])) % mod;
        windowHash = (windowHash * base + charValue(text[i])) % mod;
        if (i + 1 < m) {
            highPower = (highPower * base) % mod;
        }
    }

    if (windowHash == patternHash && text.compare(0, m, pattern) == 0) {
        ans.push_back(0);
    }

    for (int right = m; right < n; ++right) {
        int left = right - m;
        windowHash = (windowHash - charValue(text[left]) * highPower % mod + mod) % mod;
        windowHash = (windowHash * base + charValue(text[right])) % mod;

        int start = right - m + 1;
        if (windowHash == patternHash && text.compare(start, m, pattern) == 0) {
            ans.push_back(start);
        }
    }

    return ans;
}
```

**为什么哈希命中后还要比较子串**：

- 不同字符串可能产生相同哈希值，也就是哈希碰撞。
- 二次比较能保证答案正确。
- 如果题目只要求概率正确或使用双哈希，可按题意调整。

## 最小表示法

最小表示法用于循环字符串：在所有旋转结果中，找到字典序最小的那个起点。

题型信号：

- 字符串可以循环旋转。
- 要求所有旋转中的最小字典序。
- 常见于环形序列规范化、判断两个环形串是否等价。

Booth 算法思想：

1. 用两个候选起点 `i`、`j` 比较两段旋转。
2. 用偏移 `k` 向后比较字符。
3. 谁在第一次不同处更大，谁就不可能是最小表示，跳过一整段。

```text
s = b a c a b
候选起点 i 与 j 比较
发现某个候选在第 k 位更大，就整体跳过 [起点, 起点 + k]
```

> [!note]
> 最小表示法和 KMP 都利用“已经比较过的信息”跳过候选，但它不是常规子串匹配题。这里作为扩展概念了解即可。

## 如何识别题型

| 题目特征 | 优先考虑 |
|----------|----------|
| 找一个模式串第一次出现位置 | `string::find` 或 KMP |
| 要求实现 `strStr()` 且强调最坏线性 | KMP |
| 频繁比较等长窗口 | Rabin-Karp / 字符串哈希 |
| 多个模式串共享前缀 | [[5.算法/5.2 算法/5.2.14 Trie 字典树|Trie 字典树]] |
| 循环字符串最小字典序 | 最小表示法 |

## 常见误区

### 1. 前缀函数定义不清

`pi[i]` 是 `pattern[0..i]` 的最长相等真前后缀长度，不是从 `i` 开始的匹配长度。

### 2. KMP 失配后直接 `j = 0`

这样会退化成接近朴素匹配。正确回退是 `j = pi[j - 1]`。

### 3. 匹配成功后忘记继续回退

不回退会漏掉重叠匹配。

### 4. Rabin-Karp 忽略哈希碰撞

单哈希可能碰撞。教学代码命中后做子串比较，工程或竞赛中可以考虑双哈希。

---

## 关键要点

1. KMP 的核心是前缀函数和失配回退。
2. 文本指针不回退，模式指针按 `pi` 回退。
3. Rabin-Karp 用滚动哈希快速比较窗口。
4. 哈希命中不等于字符串一定相等，严谨写法要二次确认。
5. 最小表示法用于循环字符串的最小旋转。
