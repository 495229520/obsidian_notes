# stack 栈容器

## stack 简介

`stack` 是一种**后进先出**（LIFO: Last-In, First-Out）的数据结构。你可以把它想象成一摞叠放的盘子：最后放上去的盘子，总是最先被拿走；要拿最下面的盘子，必须先把上面的全部取走。

### 核心特性

- **后进先出 (LIFO)**：这是 stack 最核心的特性。最后进入栈的元素，将是第一个离开栈的元素
- **容器适配器**：与 [[5.1.8 容器适配器|queue]] 类似，stack 本身也不是独立的容器，而是对其他基础容器（如 `deque`、`vector` 或 `list`）的封装。它提供了一个受限的接口，只允许你在**同一端**（栈顶）进行操作。默认情况下，stack 基于 `deque` 实现
- **受限的操作**：stack 只提供以下几种基本操作，以确保其 LIFO 特性：
  - `push()`：将一个元素压入栈**顶**
  - `pop()`：移除栈**顶**的元素（**不返回**该元素）
  - `top()`：访问栈**顶**的元素，但不移除它
  - `empty()`：检查栈是否为空
  - `size()`：返回栈中元素的数量

### 常用方法

```cpp
stack<int> stk;
stk.push(1);      // 入栈
stk.top();        // 访问栈顶元素
stk.pop();        // 出栈（移除栈顶，无返回值）
stk.empty();      // 判断是否为空
stk.size();       // 返回元素个数
```

### 注意事项

1. stack **不可以访问内部元素**，也不支持迭代器遍历，只能访问栈顶
2. `pop()` 只负责删除栈顶，**不返回**被删除的元素。如果需要使用栈顶值，要先 `top()` 再 `pop()`
3. 对空栈调用 `top()` 或 `pop()` 是**未定义行为**，使用前应先用 `empty()` 判断

```cpp
// 正确的“取出并使用”写法
while (!stk.empty()) {
    int x = stk.top();   // 先取值
    stk.pop();           // 再弹出
    cout << x << " ";
}
```

## 底层实现

stack 默认底层依赖 `deque`，同 [[5.1.2 queue]] 中的分析：

- `vector` 初始内存使用效率较低（0-1-2-4-8 倍增扩容），且需要大片连续内存
- `deque` 采用分段连续内存，扩容代价更小，对内存利用率更好

但 stack 只在一端操作，对“双端”没有要求，因此底层容器可以替换为任意支持 `push_back / pop_back / back` 的序列容器：

```cpp
stack<int> s1;                    // 默认底层 deque
stack<int, vector<int>> s2;       // 底层使用 vector
stack<int, list<int>> s3;         // 底层使用 list
```

### 模板与实现原理

stack 通过封装底层容器的尾部操作来模拟“栈顶”：

```cpp
template<typename T, typename Container = deque<T>>
class Stack
{
public:
    void push(const T& val) { con.push_back(val); }  // 压栈 = 尾部插入
    void pop()              { con.pop_back();     }  // 出栈 = 尾部删除
    T top() const           { return con.back();  }  // 栈顶 = 最后一个元素
    bool empty() const      { return con.empty(); }
    size_t size() const     { return con.size();  }
private:
    Container con;
};
```

> 因为所有操作都集中在容器尾部，`push / pop / top` 均为 **O(1)**。

## 适用场景

stack 的 LIFO 特性天然适合“需要回到上一步”或“最近优先处理”的问题：

| 场景 | 说明 |
|------|------|
| 函数调用栈 | 后调用的函数先返回，是 LIFO 的典型体现 |
| 括号匹配 | 遇左括号入栈，遇右括号与栈顶配对 |
| 表达式求值 | 中缀转后缀、逆波兰表达式计算 |
| 深度优先搜索 | [[5.算法/5.3 力扣/深度优先搜索]] 的迭代写法用栈替代递归 |
| 单调栈 | 求“下一个更大/更小元素”类问题 |

### 经典应用：括号匹配

```cpp
#include <stack>
#include <string>
using namespace std;

bool isValid(const string& s) {
    stack<char> stk;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            stk.push(c);                 // 左括号入栈
        } else {
            if (stk.empty()) return false;  // 没有可匹配的左括号
            char top = stk.top();
            stk.pop();
            // 右括号与栈顶左括号不配对
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) {
                return false;
            }
        }
    }
    return stk.empty();   // 全部匹配完，栈应为空
}
```

## stack 与 queue 对比

| 维度 | stack | queue |
|------|-------|-------|
| 顺序 | LIFO 后进先出 | FIFO 先进先出 |
| 操作端 | 只在栈顶一端 | 队尾入、队头出 |
| 访问元素 | `top()` | `front()` / `back()` |
| 默认底层 | deque | deque |
| 典型场景 | DFS、括号匹配、表达式求值 | BFS、任务队列 |

---

## 关键要点

1. **容器适配器**：stack 不是独立容器，没有迭代器，不能遍历内部元素
2. **只在一端操作**：所有操作都在栈顶，时间复杂度均为 O(1)
3. **`pop()` 无返回值**：取值用 `top()`，删除用 `pop()`，两者分离
4. **底层可配置**：默认 `deque`，也可指定 `vector`、`list`
