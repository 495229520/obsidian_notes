# 算法与数据结构全局学习指南（含 STL 体系）

本指南是本仓库算法模块的全局索引与导航中枢，串联 **STL 标准模板库**、**基础与高级数据结构**、**图论与路径算法**以及**核心算法思想**。

## 推荐学习路径（Roadmap）

按阶段递进学习，前置结构的掌握直接决定后续复杂算法的理解效率：

```text

  STL 容器（vector / string / deque / list） ──> 链表技巧 ──> 迭代器系统 ──> 栈 / 队列 / 哈希表
       │
       ▼
阶段 2: 基础算法思维与序列操作
  双指针 / 滑动窗口 ──> 二分查找与二分答案 ──> 前缀和与差分 ──> 常用排序算法与 STL 算法
       │
       ▼

  二叉树遍历与递归 ──> 红黑树与平衡树 ──> 堆与优先队列 ──> Trie 字典树 ──> 回溯剪枝
       │
       ▼

  图的存储（邻接表/矩阵） ──> 并查集 ──> 图遍历（DFS/BFS） ──> DAG 与拓扑排序 ──> 最短路径专题（Dijkstra / Bellman-Ford / Floyd）

       │
       ▼

  LRU / LFU 缓存设计（哈希表 + 双向链表） ──> 单调结构 ──> CodeTop 高频 300 题复盘
```

## 1. 数据结构体系

### 1.1 序列容器与链表

元素按线性顺序排列，根据内存是否连续决定随机访问与插入性能：

- **动态数组与分块数组**：
  - [[5.1.1 vector]]：连续内存动态数组。支持 $O(1)$ 随机访问，尾部追加摊还 $O(1)$；扩容机制为 1.5 倍或 2 倍重新分配并搬迁，扩容会导致所有旧迭代器与引用失效。
  - [[5.1.6 string]]：特化字符序列容器，底层类似 `vector`，支持短字符串优化（SSO）与常用子串匹配接口。
  - `deque`：双端队列。中控指针数组结合定长缓冲区，支持头尾双向 $O(1)$ 扩容与增删，且头尾扩容不搬迁旧数据，详见 [[5.1.2 queue]] 与 [[5.1.3 list及其与其他结构的区别]]。
- **链表（Linked List）**：
  - [[5.1.3 list及其与其他结构的区别]]：双向循环链表 `std::list`。节点内存离散分配，已知迭代器位置的增删均为 $O(1)$，无扩容开销；不支持下标随机访问；迭代器稳定性高（插入不失效，删除仅当前迭代器失效），但内存碎片多且对 CPU 缓存不友好。
  - `std::forward_list`：单向链表（C++11）。每个节点仅存一个后继指针 `next`，内存开销小于 `std::list`，仅支持单向前向迭代器，增删操作由 `insert_after` / `erase_after` 完成。
  - [[5.2.9 链表常见技巧]]：链表算法核心套路。涵盖裸节点单链表结构、虚拟头节点 `dummy`（统一头节点与中间节点删除边界）、快慢指针（找中点与 Floyd 判圈）、三指针原地反转以及两两有序链表归并。

### 1.2 容器适配器与栈/队列

适配器不独立实现底层存储，而是基于特定序列容器（默认通常为 `deque` 或 `vector`）进行接口封装与功能限制：

- [[5.1.8 容器适配器]]：适配器设计模式，解析为什么适配器不暴露迭代器遍历接口。
- [[5.1.2 queue]]：队列（FIFO 先进先出）。队尾入队、队头出队，用于广度优先搜索与层次遍历。
- [[5.1.12 stack]]：栈（LIFO 后进先出）。栈顶压入弹出，用于递归消除、括号匹配与语法解析。
- [[5.2.10 栈与单调结构]]：单调栈与单调队列进阶。维护单调递增/递减序列，在 $O(n)$ 时间内解决“下一个更大元素”与“滑动窗口极值”问题。
- `priority_queue`：优先队列 / 堆。默认基于 `vector` 维护完全二叉树结构，提供堆顶极值访问与 $O(\log n)$ 插入删除，算法机制详见 [[5.2.11 堆与优先队列]]。

### 1.3 关联容器（红黑树体系）

基于自平衡二叉搜索树组织，元素始终维持严格的偏序关系，增删查均为对数复杂度：

- [[5.1.4 set]]：有序集合。底层为红黑树，键唯一且不可修改，默认升序排序。
- [[5.1.5 map]]：有序键值对映射。底层为红黑树，按 key 排序，支持 `operator[]` 下标访问（键不存在时自动按默认构造插入）。
- `multiset` / `multimap`：允许键重复的红黑树集合与映射。
- [[5.2.13 红黑树]]：关联容器底层结构。五条红黑平衡规则结合旋转变色，确保最坏情况下树高不超过 $2\log(n+1)$。

### 1.4 无序关联容器（哈希表体系）

基于散列表组织，元素无序，通过哈希函数将键映射到桶（bucket），平均查找复杂度为 $O(1)$：

- [[5.2.8 哈希表与计数]]：哈希表专题。包含 `unordered_map` 与 `unordered_set` 核心接口（`find`、`count`、`emplace`、`reserve`）、开链法（桶数组 + 单向链表）解决哈希冲突、负载因子（load factor）与 rehash 翻倍扩容、rehash 导致全体迭代器失效机制，以及两数之和、词频统计与滑动窗口查重套路。
- [[5.1.5 map]] 与 [[5.1.4 set]]：无序容器在标准库中的基础语法及去重实战。
- **选型标准**：
  - 需要按键区间扫描、顺序输出或前驱/后继二分查找（`lower_bound` / `upper_bound`）时，选 `map` / `set`。
  - 仅做单点精确匹配、去重或频次计数，追求低时间开销时，选 `unordered_map` / `unordered_set`。

### 1.5 树形结构与前缀树

- [[5.2.12 二叉树与遍历算法]]：二叉树定义、递归遍历与基于栈的显式迭代遍历、层序遍历 BFS，以及最近公共祖先（LCA）求解。
- [[5.2.14 Trie 字典树]]：多叉前缀树。以空间换时间，高效实现字符串前缀检索、自动补全与异或最大值求解。

### 1.6 动态集合与连通性：并查集

- [[5.2.25 并查集]]：Disjoint Set Union (DSU)。使用父节点数组表示集合森林，支持路径压缩与按秩合并，近乎 $O(1)$ 时间复杂度判定两点连通性或合并集合。
- 典型题目：[[547. 省份数量]]。

### 1.7 复合结构设计（哈希表 + 链表）

- [[5.2.16 面试常考数据结构设计]]：工业级复合结构设计。典型代表为 LRU 缓存（[[146. LRU 缓存]]），以 `unordered_map` 实现 $O(1)$ 查找，配合双向链表 `std::list` 在 $O(1)$ 内更新访问时序与淘汰最久未使用节点。

### 1.8 容器访问机制：迭代器

- [[5.1.7 迭代器]]：容器与算法解耦的桥梁。覆盖五种迭代器层级（输入、输出、前向、双向、随机访问），重点掌握 `insert` 与 `erase` 引发的迭代器失效规则及正确删除写法。

## 2. 容器特性与复杂度速查表

| 容器类别 | 典型容器 | 底层数据结构 | 随机访问 | 查找复杂度 | 增删复杂度 | 迭代器类型 | 迭代器失效规则 |
| :--- | :--- | :--- | :---: | :---: | :---: | :---: | :--- |
| **序列容器** | `vector` | 动态连续数组 | $O(1)$ | $O(n)$ | 尾部摊还 $O(1)$<br>其余位置 $O(n)$ | 随机访问 | 扩容时全部失效；未扩容时，插入/删除点之后的迭代器失效 |
| **序列容器** | `deque` | 中控指针数组 + 定长分块缓冲区 | $O(1)$ | $O(n)$ | 头尾两端 $O(1)$<br>中间插入 $O(n)$ | 随机访问 | 头尾插入可能使迭代器失效；中间增删使所有迭代器失效 |
| **序列容器（链表）** | `list` | 双向循环链表 | 不支持 | $O(n)$ | 任意已知位置 $O(1)$ | 双向 | 仅被删除节点的迭代器失效，其余迭代器保持有效 |
| **序列容器（链表）** | `forward_list` | 单向链表 | 不支持 | $O(n)$ | 任意已知位置 $O(1)$<br>（需用 `insert_after`） | 前向 | 仅被删除节点的迭代器失效，其余迭代器保持有效 |
| **关联容器** | `set` / `map` | 红黑树（自平衡 BST） | 不支持 | $O(\log n)$ | 增删均为 $O(\log n)$ | 双向 | 仅被删除节点的迭代器失效，插入操作不影响已有迭代器 |
| **无序容器（哈希表）** | `unordered_set`<br>`unordered_map` | 哈希表（桶数组 + 开链单链表） | 不支持 | 平均 $O(1)$<br>最坏 $O(n)$ | 平均 $O(1)$<br>最坏 $O(n)$ | 前向 | 未发生 rehash 时仅被删节点失效；触发 rehash 扩容时全部迭代器失效 |
| **容器适配器** | `stack` / `queue`<br>`priority_queue` | 封装底层容器<br>（`deque` / `vector`） | 不支持 | 仅查顶部/队首 | 压入/弹出 $O(1)$<br>（堆为 $O(\log n)$） | 无 | 不暴露迭代器接口 |

## 3. 图论与路径算法专题

图由顶点集合 $V$ 与边集合 $E$ 构成，用于描述对象之间的依赖、连通与权重关系。最短路径是图论中最基础也最高频的问题类型。

### 3.1 图的表示与存储

选择存储方式取决于图的疏密程度与算法要求：

| 存储方式 | 数据结构表示 | 空间复杂度 | 遍历邻居复杂度 | 适合场景 |
| :--- | :--- | :---: | :---: | :--- |
| **邻接表** | `vector<vector<int>>`（无权）<br>`vector<vector<pair<int, int>>>`（带权：目标点, 权重） | $O(V + E)$ | $O(\text{degree}(u))$ | 稀疏图（力扣绝大多数题目首选） |
| **邻接矩阵** | `vector<vector<int>> g(n, vector<int>(n, INF))` | $O(V^2)$ | $O(V)$ | 稠密图、点数较少（$V \le 500$）、需 $O(1)$ 判定两点是否有边、Floyd 算法 |
| **边集数组** | `vector<tuple<int, int, int>> edges` | $O(E)$ | $O(E)$ | Kruskal 最小生成树、Bellman-Ford 算法 |

- 基础笔记：[[5.2.24 图论基础]]、[[5.2.26 图与图算法]]

### 3.2 图遍历与连通分量

- **深度优先搜索（DFS）**：沿着一条路径递归深入，回溯时复原。用于求连通块数量（网格岛屿题）、二分图染色检测、拓扑排序判环。
- **广度优先搜索（BFS）**：借助 `std::queue` 按层向外波浪式扩散。所有边权重相等或均为 1 时，BFS 首次访问到目标点即为最短步数。
- **多源 BFS**：将多个起点在第 0 层同时压入队列，实现多点并发扩散（如腐烂橘子、距离矩阵）。
- **动态连通性**：[[5.2.25 并查集]]，边动态到达时即时维护连通状态。

### 3.3 有向无环图（DAG）与拓扑排序

解决任务调度、先修课程等存在先后依赖关系的问题：

- **核心概念**：有向无环图（DAG）中，排出一个线性序列，使对任意边 $u \to v$，$u$ 都在 $v$ 前面。如果图中存在有向环，则无法生成拓扑序。
- **Kahn 算法（入度表 + BFS 队列）**：
  1. 统计每个节点的入度；
  2. 将所有入度为 0 的节点加入队列；
  3. 队头出队，将该节点加入拓扑序，并将其所有后继节点的入度减 1；
  4. 若后继节点入度降为 0，则加入队列；
  5. 循环结束后，若拓扑序列长度小于节点总数 $V$，说明图中存在有向环。
- 专题笔记：[[5.2.27 拓扑排序与有向无环图]]
- 典型题目：[[207. 课程表]]

### 3.4 最短路径算法核心体系

最短路径问题的关键在于边权性质（是否有权、是否非负）与求解目标（单源还是全源）：

![[图片/5.算法/5.2 算法/5_2_2_28_1.svg]]

#### 核心算法横向对比

| 算法名称 | 边权约束 | 源点类型 | 核心数据结构 | 时间复杂度 | 适用场景与关键机制 |
| :--- | :--- | :--- | :--- | :---: | :--- |
| **BFS 最短路** | 无权图 / 边权均为 1 | 单源 | 队列 `queue` + `dist` 数组 | $O(V + E)$ | 按层扩展，首次到达即最短；空间 $O(V)$ |
| **Dijkstra 算法** | **边权必须非负** | 单源 | 邻接表 + 小顶堆 `priority_queue` | $O((V + E) \log V)$ | 贪心选择当前未收录的最短点松弛出边；遇负权边贪心策略失效 |
| **Bellman-Ford** | 支持负权边，能检测负环 | 单源 | 边集数组 + `dist` 数组 | $O(V \cdot E)$ | 对所有边进行 $V-1$ 轮松弛；第 $V$ 轮若还能松弛说明有负权环 |
| **SPFA（队列优化）** | 支持负权边（最坏退化） | 单源 | 邻接表 + 队列 + `inQueue` 标记 | 平均 $O(kE)$<br>最坏 $O(VE)$ | 仅对松弛成功的点再次入队；网格图等特殊图易被卡到最坏时间 |
| **Floyd-Warshall** | 允许负权边，不能有负环 | **全源** | 邻接矩阵（二维或三维 DP 表） | $O(V^3)$ | 三重循环动态规划，以中间点 $k$ 转移；代码最精炼，适用于 $V \le 400$ |

#### 最短路径选型口诀

```text
无权用 BFS；
非负权选 Dijkstra；
有负权走 Bellman-Ford 或 SPFA；
全源任意两点且点数小（V ≤ 400）选 Floyd。
```

- 专题笔记：[[5.2.28 最短路径算法专题]]
- 典型题目：[[743. 网络延迟时间]]（Dijkstra 经典网络延迟时间单源最短路）

## 4. 核心算法思想与解题范式

算法部分关注常见算法思想在 C++ 中的落地实现，与 STL 容器及标准算法接口紧密结合：

- [[5.2.1 数学与数论基础]]：最大公约数 GCD、快速幂、质数筛法（埃氏筛/欧拉筛）、模逆元与组合数。
- [[5.2.2 位运算]]：位运算技巧、掩码状态压缩、Lowbit 与异或消消乐。
- [[5.2.3 高精度]]：大整数加减乘除及字符串模拟。

### 4.2 序列处理与双指针

- [[5.2.4 前缀和]]：一维前缀和快速求区间和、二维前缀和容斥原理、差分数组做区间批量增减。
- [[5.2.6 二分查找与二分答案]]：闭区间与左闭右开二分模板、`std::lower_bound` / `std::upper_bound` 边界定义、单调性答案二分判定。
- [[5.2.7 双指针与滑动窗口]]：对撞双指针（有序数组两数和）、快慢双指针（链表判圈/数组去重）、不定长与定长滑动窗口（子串最值与计数）。
- [[5.2.15 字符串匹配算法]]：KMP 算法（`next` 数组构造与失配跳转）、前缀哈希。

### 4.3 排序与 STL 泛型算法

- [[5.2.5 常见排序算法与STL排序]]：快速排序 Partition 划分、归并排序递归与自底向上、堆排序、计数排序，以及 `std::sort` 混合内省排序（Introsort）。
- [[5.1.9 函数对象]]：仿函数与比较规则封装（`less`、`greater` 与自定义 lambda）。
- [[5.1.10 泛型算法与绑定器]]：算法、迭代器与绑定器配合。
- [[5.1.11 算法]]：STL 常用算法实战（查找、区间极值、计数、旋转与变换）。

### 4.4 搜索与回溯

- [[5.2.18 回溯算法]]：穷举解空间树。子集、全排列、组合、分割与棋盘放置问题，掌握递归回溯状态恢复与重枝剪枝。

### 4.5 贪心算法

- [[5.2.17 贪心算法]]：每一步选择局部最优以达到全局最优。区间调度、跳跃游戏、买卖股票最佳时机与贪心正确性反证法。

### 4.6 动态规划（DP 全景）

动态规划的核心是明确状态定义、转移方程与无后效性：

- [[5.2.19 动态规划]]：DP 基础、爬楼梯、打家劫舍与一维/二维空间压缩技巧。
- [[5.2.20 背包问题]]：01 背包（倒序遍历容量）、完全背包（正序遍历容量）、多重背包与分组背包模型。
- [[5.2.21 子序列动态规划]]：最长递增子序列（LIS，含 $O(n\log n)$ 贪心二分法）、最长公共子序列（LCS）、最长回文子序列。
- [[5.2.22 区间动态规划]]：大区间依赖小区间合并（石子合并、戳气球），按区间长度阶段递推。
- [[5.2.23 树形动态规划]]：树结构上的后序遍历 DP，自底向上由子树状态汇总根节点状态（打家劫舍 III、树的直径）。
