> [!abstract] vector 速记卡片
> **一句话**：动态数组，元素连续存储（`vector<bool>` 是特殊实现）；随机访问快，尾部增删快，中间增删需要搬移元素。
>
> | 要做什么 | 常用写法 / 要点 |
> | --- | --- |
> | 头文件 | `#include <vector>`；类型写作 `std::vector<int>` |
> | 初始化 | `vector<int> v(n, x)`：n 个 x；`vector<int> v{1, 2, 3}`：三个指定值（下列示例省略 `std::`） |
> | 访问 | `v[i]`：不检查越界；`v.at(i)`：越界抛异常；均为 O(1) |
> | 首尾元素 | `v.front()` / `v.back()`；必须非空 |
> | 尾部增删 | `v.push_back(x)` / `v.emplace_back(args...)`：均摊 O(1)，扩容时 O(n)；`v.pop_back()`：O(1)，必须非空、不返回元素 |
> | 中间增删 | `v.insert(it, x)`：插在 it 前；`v.erase(it)`：删除 it 指向元素，返回下一个元素的迭代器；O(n) |
> | 个数与容量 | `v.size()`：现有元素数；`v.capacity()`：可容纳的元素数；`v.empty()`：判空 |
> | 预留与改大小 | `v.reserve(n)`：容量不足才扩容，size 不变；`v.resize(n)`：改变 size，增大时补元素 |
> | 清空与缩容 | `v.clear()`：清空元素，保留容量；`v.shrink_to_fit()`：请求缩容，不保证执行 |
> | 遍历 | `for (const auto& x : v)` 只读；`for (auto& x : v)` 修改（普通 vector） |
> | 排序与最值 | `<algorithm>`：`sort(v.begin(), v.end())` 升序，O(n log n)；`max_element` / `min_element` 返回迭代器，O(n)，取值前判空 |
> | 翻转 | `<algorithm>`：`reverse(v.begin(), v.end())` 原地翻转，O(n) |
>
> **iterator 迭代器速记**
> - **是什么**：指向容器某个位置的“游标”，用法类似指针；`*it` 访问元素，`++it` 前进。vector 的迭代器支持随机访问，如 `it + n`、`it - n`。
> - **声明**：`vector<int>::iterator it = v.begin();`，通常简写为 `auto it = v.begin();`。
> - **范围**：`[v.begin(), v.end())` 左闭右开；`end()` 是尾后位置，不能解引用。空容器的 `begin() == end()`。
> - **只读**：`auto it = v.cbegin();` 得到 `const_iterator`，可以移动 it，但不能通过 `*it` 修改元素；`const auto it = v.begin();` 则是固定迭代器本身，两者不同。
> - **反向**：`rbegin()` 指向最后一个元素，`rend()` 是反向遍历的终止位置，不能解引用；反向迭代器的 `++it` 朝容器开头移动，显式类型为 `vector<int>::reverse_iterator`。
> - **下标转换**：`v.begin() + i` 对应下标 i；正向迭代器 `it - v.begin()` 得到下标。运算须在同一容器的有效范围内，尾后位置可以作为边界，不能当元素访问。
>
> ```cpp
> // 正向遍历并修改元素
> for (auto it = v.begin(); it != v.end(); ++it) {
>     *it += 1;
> }
>
> // 反向只读遍历（cout 需要 <iostream>，这里省略 std::）
> for (auto it = v.crbegin(); it != v.crend(); ++it) {
>     cout << *it << ' ';
> }
>
> // 边遍历边删除偶数：erase 返回下一个位置
> for (auto it = v.begin(); it != v.end(); ) {
>     if (*it % 2 == 0) it = v.erase(it);
>     else ++it;
> }
> ```
>
> 关联：[[5.1.7 迭代器]] · [[12.3 迭代器的失效问题]]
>
> **三个必记易错点**
> - **有容量 ≠ 有元素**：`reserve(100)` 后若 size 仍为 0，就不能写 `v[0]`；先 `resize`，或用 `push_back` 添加。合法下标始终是 `[0, size())`。 **`reserve(n)` 不会缩容；`resize(n)` 缩小 size 时删除后面的元素，但保留容量。** 例如容量为 30、size 为 20 时，依次执行 `reserve(10)` 和 `resize(10)`，最终 size 为 10、capacity 仍为 30，合法下标只有 `0～9`；`v[11]` 越界，即使该位置仍在预留空间内也不合法，`v.at(11)` 则抛出 `std::out_of_range`。
> - **迭代器失效**：重新分配内存 → 全部迭代器、指针、引用失效；插入未重新分配 → 插入位置及之后失效；删除 → 删除位置及之后失效。尾部添加即使未扩容，旧 `end()` 也失效。
> - **扩容倍数不固定**：由实现决定；扩容会移动或拷贝旧元素。提前知道数量可 `reserve(n)`，循环删除用 `it = v.erase(it)`，不要再无条件 `++it`。
>
> **口诀**：下标看 size，预留用 reserve；尾增均摊常数，中间增删线性；搬家全部失效，原地改动看位置。


# vector 容器

> 本笔记是对 [[4.2 vector数组]] 的深入补充，主要讲解 vector 的底层实现原理和高级用法。

## 简介

`vector` 是**向量容器**，底层数据结构是**动态数组**（Dynamic Array）。它允许你在程序执行过程中动态地改变数组的大小，与静态数组不同，不需要在编译时确定大小。

```cpp
#include <vector>
using namespace std;
```

### vector 的特点

- 动态开辟的数组，每次以**原来空间大小的 2 倍**进行扩容（MSVC 实现为 1.5 倍）
- 扩容时会分配新的连续内存空间，将原有数据复制过去，释放旧内存
- 支持随机访问，底层内存连续

## 初始化方式

```cpp
vector<int> vec;                    // 空 vector
vector<int> vec(10);                // 10 个元素，默认初始化为 0
vector<int> vec(10, 5);             // 10 个元素，全部初始化为 5
vector<int> vec{1, 2, 3, 4, 5};     // 列表初始化
vector<int> vec = {1, 2, 3, 4, 5};  // 等价写法

// 拷贝构造
vector<int> vec2(vec);
vector<int> vec3 = vec;

// 从迭代器范围构造
vector<int> vec4(vec.begin(), vec.end());
```

## 常用操作

### 增加元素

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| `push_back(20)` | 末尾添加元素 | 均摊 O(1) |
| `insert(it, 20)` | 在迭代器指向的位置添加一个元素 | O(n) |
| `vec.insert(vec.begin(), 20)` | 导致容器扩容，需要更新迭代器 | O(n) |

### 删除元素

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| `pop_back()` | 末尾删除元素 | O(1) |
| `erase(it)` | 删除迭代器指向的元素 | O(n) |

### 查询

| 操作 | 说明 | 时间复杂度 |
|------|------|-----------|
| `operator[]` | 下标随机访问 `vec[5]` | O(1) |
| `iterator` | 迭代器遍历 | - |
| `find_for_each` | 范围遍历 | O(n) |
| `foreach` | 底层也是通过 iterator 实现 | O(n) |

### 使用迭代器

```cpp
// 正向迭代
for (vector<int>::iterator it = vec.begin(); it != vec.end(); ++it) {
    cout << *it << " ";
}

// 反向迭代
for (vector<int>::reverse_iterator it = vec.rbegin(); it != vec.rend(); ++it) {
    cout << *it << " ";
}

// 使用 auto 简化（C++11）
for (auto it = vec.begin(); it != vec.end(); ++it) {
    cout << *it << " ";
}
```

- `begin()` 返回指向 vector 第一个元素的迭代器
- `end()` 返回指向 vector 最后一个元素之后位置的迭代器
- **注意**：对容器进行连续插入或删除操作（insert/erase），需要更新迭代器，因为首次 insert 或 erase 完成后迭代器就失效了

### 常用方法

| 方法 | 说明 |
|------|------|
| `size()` | 获取 vector 的长度（元素个数） |
| `empty()` | 判断 vector 是否为空 |
| `reserve(20)` | 为 vector 预留空间（只改变 capacity，不改变 size） |
| `resize(20)` | 重新分配的内存空间，用于容器扩充（改变 size） |
| `swap` | 两个容器进行元素交换 |

### 快速查找最大值、最小值、排序与翻转

这些算法定义在 `<algorithm>` 中，接收的是左闭右开的迭代器区间：

| 需求 | 写法 | 时间复杂度 |
|------|------|-----------|
| 查找最大值 | `max_element(vec.begin(), vec.end())` | O(n) |
| 查找最小值 | `min_element(vec.begin(), vec.end())` | O(n) |
| 同时查找最小值和最大值 | `minmax_element(vec.begin(), vec.end())` | O(n) |
| 升序排序 | `sort(vec.begin(), vec.end())` | O(n log n) |
| 降序排序 | `sort(vec.begin(), vec.end(), greater<int>())` | O(n log n) |
| 翻转容器 | `reverse(vec.begin(), vec.end())` | O(n) |

```cpp
#include <algorithm>
#include <functional>
#include <iostream>
#include <iterator>
#include <vector>
using namespace std;

int main()
{
    vector<int> vec{8, 3, 12, 5, 1};

    // max_element 和 min_element 返回迭代器，解引用后得到元素值。
    if (!vec.empty())
    {
        auto maxIt = max_element(vec.begin(), vec.end());
        auto minIt = min_element(vec.begin(), vec.end());

        cout << "最大值：" << *maxIt << endl;
        cout << "最小值：" << *minIt << endl;
        cout << "最大值下标：" << distance(vec.begin(), maxIt) << endl;
        cout << "最小值下标：" << distance(vec.begin(), minIt) << endl;
    }

    sort(vec.begin(), vec.end());
    // vec: 1 3 5 8 12

    sort(vec.begin(), vec.end(), greater<int>());
    // vec: 12 8 5 3 1

    reverse(vec.begin(), vec.end());
    // vec: 1 3 5 8 12

    return 0;
}
```

> [!warning]
> 空 vector 调用 `max_element` 或 `min_element` 时会返回 `vec.end()`，不能直接解引用，因此取值前应先用 `empty()` 判断。

> [!note]
> `std::sort` 是 STL 的高效排序接口。标准只规定排序结果和复杂度，不保证内部固定使用纯快速排序；常见实现采用内省排序（Introsort）。

## 代码示例

```cpp
int main()
{
    // 只让容器底层开辟指定大小的内存空间，并不会添加新的元素
    // 此时容器是空的
    vec.reserve(20);    // 为 vector 预留空间
    // 重新分配 20 的内存空间，用于容器扩充
    vec.resize(20);

    cout << vec.empty() << endl;     // 1（reserve 后为空）
    cout << vec.size() << endl;      // 0

    for (int i = 0; i < 20; ++i)
    {
        vec.push_back(rand() % 100 + 1);
    }

    cout << vec.empty() << endl;     // 0
    cout << vec.size() << endl;      // 20

    // vector 的 operator[] 运算符重载函数
    int size = vec.size();
    for (int i = 0; i < size; ++i)
    {
        cout << vec[i] << " ";
    }

    // 把 vec 容器中所有的偶数全部删除
    auto it2 = vec.begin();
    while (it2 != vec.end())
    {
        if (*it2 % 2 == 0)
        {
            it2 = vec.erase(it2);  // 更新迭代器
        }
        else
        {
            ++it2;
        }
    }

    // 通过迭代器遍历 vector 容器
    auto it1 = vec.begin();
    for (; it1 != vec.end(); ++it1)
    {
        cout << *it1 << " ";
    }
    cout << endl;

    // 给 vector 容器中所有的奇数前面都添加一个小于奇数 1 的偶数
    for (it1 = vec.begin(); it1 != vec.end(); ++it1)
    {
        if (*it1 % 2 != 0)
        {
            it1 = vec.insert(it1, *it1 - 1);
            ++it1;  // 跳过刚插入的元素
        }
    }

    return 0;
}
```

## vector 底层机制

### 三个核心指针

vector 内部维护三个指针：

```cpp
template<class T>
class vector {
    T* _first;   // 指向数组起始位置
    T* _last;    // 指向有效元素的后继位置
    T* _end;     // 指向数组空间的后继位置
};
```

```
内存布局：
┌───┬───┬───┬───┬───┬───┬───┬───┐
│ 1 │ 2 │ 3 │ 4 │ 5 │   │   │   │
└───┴───┴───┴───┴───┴───┴───┴───┘
↑                   ↑           ↑
_first            _last       _end
```

- `size()` = `_last - _first`（有效元素个数）
- `capacity()` = `_end - _first`（容量大小）

### 扩容机制详解

当 `push_back` 导致 `size > capacity` 时：

1. 分配新内存（通常为原容量的 2 倍，MSVC 为 1.5 倍）
2. 将原有元素拷贝到新内存
3. 释放原内存
4. 更新 `_first`、`_last`、`_end` 指针

```cpp
vector<int> vec;
// vec: 0-1-2-4-8... 扩容序列
```

### size 与 capacity 的区别

| 属性 | 说明 |
|------|------|
| `size` | 当前有效元素的个数 |
| `capacity` | 当前分配的内存能容纳的元素个数 |

```cpp
vector<int> v;
v.reserve(100);  // capacity = 100, size = 0
v.resize(50);    // capacity = 100, size = 50
```

## 迭代器失效问题

> 详见 [[12.3 迭代器的失效问题]]

### 什么时候迭代器会失效？

1. **插入元素**：当容器需要扩容时，所有迭代器失效
2. **删除元素**：被删除元素及其之后的迭代器失效

### 解决方法

对迭代器进行更新操作：

```cpp
// 删除时更新迭代器
it = vec.erase(it);

// 插入时更新迭代器
it = vec.insert(it, value);
```

## 性能优化建议

### 1. 使用 reserve 预分配内存

```cpp
vector<int> vec;
vec.reserve(1000);  // 预分配空间，避免多次扩容
for (int i = 0; i < 1000; ++i) {
    vec.push_back(i);
}
```

### 2. 使用 emplace_back 代替 push_back

`emplace_back` 直接在容器内原地构造对象，避免临时对象的创建和拷贝：

```cpp
struct Point {
    int x, y;
    Point(int x, int y) : x(x), y(y) {}
};

vector<Point> points;
points.push_back(Point(1, 2));   // 构造临时对象 + 移动/拷贝
points.emplace_back(1, 2);       // 直接原地构造
```

### 3. 释放多余内存

```cpp
// 方法1：shrink_to_fit (C++11)
vec.shrink_to_fit();

// 方法2：swap with temporary (C++11之前)
vector<int>(vec).swap(vec);

// 方法3：swap with copy
vector<int> v2(vec);
v2.swap(vec);
```

## 一个简略的例子

```cpp
// 直接类型 size=sizeof(int) 即 4c
vector<int> v;
// v:_first   _last   _end
// 初始状态：v._first = nullptr, v._last = nullptr, v._end = nullptr

for (int i = 0; i < 20; ++i) {
    v.push_back(rand() % 100);
}
// 扩容过程：1 -> 2 -> 4 -> 8 -> 16 -> 32
```

观察发现，为什么 6~7 能过 vector 类初始化成员变量的扩容，但改成使用下标初始化就不行：

```cpp
// 错误示例
vector<int> v;
for (int i = 0; i < 100; i++) {
    v[i] = i;  // 未分配内存，行为未定义！
}

// 正确做法
vector<int> v(100);  // 或 v.resize(100);
for (int i = 0; i < 100; i++) {
    v[i] = i;
}
```

## 关键要点

1. **摊还时间复杂度**（Amortized Time Complexity）为 O(1)
   - 虽然单次扩容操作是 O(n)，但由于扩容次数随元素增加而指数级减少
   - 从长远来看，每次 `push_back` 的平均时间仍是 O(1)

2. **内存连续**：vector 的内存是连续的，支持 O(1) 随机访问

3. **迭代器失效**：插入和删除操作可能导致迭代器失效，需要更新

4. **扩容开销**：频繁扩容会影响性能，建议使用 `reserve` 预分配



## 综合示例：vector 常见考点实验

下面是一份可独立编译运行的 **C++17** 示例，来自 `vector_test.cpp`。每个实验独立使用自己的容器，便于观察操作前后的变化。

| 实验函数 | 重点 |
| --- | --- |
| `initializationAndCapacity` | 初始化、size/capacity、reserve/resize、at 越界检查 |
| `growthAndTraversal` | 扩容观察、正反向遍历、只读迭代器、data、首尾操作 |
| `eraseAndInsert` | 边遍历边增删、接收返回迭代器、控制前进次数 |
| `iteratorValidity` | 不扩容与扩容时的迭代器失效边界 |
| `clearCopyAndAlgorithms` | 拷贝移动、排序去重、查找、清空与缩容 |
| `emplacementAndMove` | 原地构造、扩容搬移、noexcept、vector<bool> |

> [!tip] 观察方式
> 先预测 size、capacity 和元素顺序，再运行对照。容量增长倍数、缩容结果和异常提示文本可能随标准库实现不同；示例不依赖固定容量数值。断言用于核对关键结果，调试时不要定义 `NDEBUG`。

```cpp
#include <algorithm>
#include <cassert>
#include <iostream>
#include <stdexcept>
#include <string>
#include <utility>
#include <vector>

// C++17 vector 学习实验。每个函数独立，避免前一个实验改变后一个实验的数据。
// 普通 vector<T> 连续存储；常见实现用三个指针表示开始、元素尾后、容量尾后。
// 这不是标准强制的内部布局，capacity 的单位是元素个数，不是字节。
void print(const std::string& label, const std::vector<int>& values) {
    std::cout << label << " [size=" << values.size()
              << ", capacity=" << values.capacity() << "]: ";
    for (const auto& value : values) {
        std::cout << value << ' ';
    }
    std::cout << '\n';
}

void initializationAndCapacity() {
    std::cout << "\n--- 1. 初始化、大小与容量 ---\n";
    std::vector<int> zeros(10);       // 10 个值为 0 的 int。
    std::vector<int> ones(10, 1);     // 10 个 1。
    std::vector<int> values{1, 2, 3, 4, 5};
    std::vector<int> braces{10, 1};   // 注意：两个元素 10、1，不是十个 1。
    std::vector<int> range(values.begin() + 1, values.end()); // [first, last)：2～5。
    print("zeros", zeros);
    print("ones", ones);
    print("braces", braces);
    print("range", range);

    zeros.resize(20);                // 增加元素；新 int 为 0，容量不足时也会扩容。
    print("resize(20)", zeros);
    zeros.reserve(30);               // capacity 至少为 30，size 不变，不创建额外元素。
    print("reserve(30)", zeros);
    const auto reservedCapacity = zeros.capacity();
    zeros.reserve(10);               // 请求小于现有容量，不会缩容，所以 zeros.capacity() == reservedCapacity)。
    zeros.resize(10);                // 删除后面的元素，但不缩小 capacity。
    print("reserve(10), resize(10)", zeros);
    assert(zeros.size() == 10 && zeros.capacity() == reservedCapacity);

    // 下标必须 < size；容量内尚无元素的位置也不能通过 [] 访问。
    // zeros[11] = 100;              // 未定义行为；不保证抛异常，不能靠 try/catch 修复。
    try {
        zeros.at(11) = 100;          // at 检查 size，越界抛 std::out_of_range。
    } catch (const std::out_of_range& error) {
        std::cout << "捕获越界异常：" << error.what() << '\n';
    }
    zeros.push_back(100);            // 追加到下标 10；size 变 11，不是写入下标 11。
    print("push_back(100)", zeros);
    zeros.resize(13, 7);             // 只把新增加的两个元素设为 7，旧元素不变。
    print("resize(13, 7)", zeros);
}

void growthAndTraversal() {
    std::cout << "\n--- 2. 扩容与遍历 ---\n";
    std::vector<int> values;
    for (int value = 0; value < 20; ++value) {
        const auto oldCapacity = values.capacity(); // size_type，避免用 int 截断。
        values.push_back(value);
        if (values.capacity() != oldCapacity) {
            std::cout << "扩容：" << oldCapacity << " -> " << values.capacity()
                      << ", size=" << values.size() << '\n';
        }
    }
    // 倍数由实现决定，不保证为 2；push_back 随时可调用，容量不足才重新分配。
    // 尾插均摊 O(1)，重新分配时 O(n)，需要搬移旧元素。
    print("正向", values);
    std::cout << "反向：";
    for (auto it = values.rbegin(); it != values.rend(); ++it) {
        std::cout << *it << ' ';     // reverse_iterator 的 ++ 朝前面的元素走。
    }
    std::cout << '\n';

    // cbegin/cend 是只读迭代器；const auto it 则只是迭代器自身不能改变。
    std::cout << "只读迭代器的首元素：" << *values.cbegin() << '\n';
    for (auto& value : values) {     // 引用修改真实元素；auto value 是副本。
        value += 10;
    }
    assert(values.data()[2] == values[2]); // 非空普通 vector 的 data 指向连续元素。
    // data 返回借用指针；vector 析构或重新分配后不能继续使用旧指针。
    if (!values.empty()) {          // front/back/pop_back 均要求容器非空。
        std::cout << "首元素=" << values.front() << ", 尾元素=" << values.back() << '\n';
        values.pop_back();          // 删除末元素，size 减一，容量不缩小，不返回被删除值。
    }
    // begin/end 配套；end 是尾后位置，不可解引用，也不可继续 ++。
}

void eraseAndInsert() {
    std::cout << "\n--- 3. 边遍历边删除与插入 ---\n";
    std::vector<int> values{1, 2, 3, 4, 5, 6, 7};
    for (auto it = values.begin(); it != values.end(); ) {
        if (*it % 2 == 0) {
            it = values.erase(it);  // 返回下一个元素的有效迭代器，原 it 已失效。
            // 这里不能再 ++：会跳过待检查元素；删除最后一个时返回 end。
        } else {
            ++it;
        }
    }
    assert((values == std::vector<int>{1, 3, 5, 7}));
    print("删除偶数后", values);

    for (auto it = values.begin(); it != values.end(); ) {
        if (*it % 2 != 0) {
            const int doubled = *it * 2;
            it = values.insert(it, doubled); // 在原元素前插入，返回新元素的迭代器。
            ++it;                   // 新元素 2 -> 已处理的原元素 1。
            ++it;                   // 原元素 1 -> 下一个待处理的原元素 3。
            // 循环头不能再 ++it，否则跳过 3；reserve 也不能避免插入位置失效。
        } else {
            ++it;
        }
    }
    assert((values == std::vector<int>{2, 1, 6, 3, 10, 5, 14, 7}));
    print("奇数前插入两倍值", values);

    // 区间删除同样采用左闭右开范围，返回删除后紧接的元素。
    auto next = values.erase(values.begin(), values.begin() + 2);
    assert(next == values.begin() && *next == 6);
    print("删除前两个元素", values);
    // 中间插入/删除需要搬移后面的元素，通常 O(n)。
}

void iteratorValidity() {
    std::cout << "\n--- 4. 迭代器失效边界（不访问失效迭代器）---\n";
    std::vector<int> values{1, 2, 3};
    values.reserve(10);
    auto first = values.begin();
    values.push_back(4);             // 没有重新分配：原元素的迭代器仍有效，旧 end 失效。
    assert(*first == 1);
    auto inserted = values.insert(values.begin() + 1, 9);
    assert(*first == 1 && *inserted == 9); // 插入位置之前的迭代器仍有效。
    // 即使不扩容，插入位置及之后的迭代器、引用、指针也失效。
    // erase 使删除位置及之后的迭代器和引用失效，之前的仍有效。
    // 重新分配使全部旧迭代器、引用、指针失效，包括旧 end。
    values.reserve(values.capacity() + 1); // 强制重新分配；不要再访问 first/inserted。
    first = values.begin();         // 必须重新获取。
    assert(*first == 1);
    print("重新获取迭代器后", values);
}

void clearCopyAndAlgorithms() {
    std::cout << "\n--- 5. 清空、缩容、拷贝移动与算法 ---\n";
    std::vector<int> original{3, 1, 3, 2};
    auto copied = original;          // 拷贝独立元素，修改 copied 不影响 original。
    copied[0] = 99;
    assert(original[0] == 3);
    auto moved = std::move(copied);  // 默认分配器下，普通移动构造转移存储资源。
    // moved 获得原 copied 的元素；不要依赖 moved-from 容器一定为空。
    copied.clear();                  // 被移动后的容器仍可执行没有元素前提要求的操作。
    copied.push_back(8);
    print("拷贝后再移动", moved);

    std::sort(original.begin(), original.end()); // O(n log n)。
    // unique 只把不重复值整理到前面，不改变 size，必须配合 erase。
    original.erase(std::unique(original.begin(), original.end()), original.end());
    print("排序去重", original);
    auto found = std::find(original.begin(), original.end(), 2); // O(n)。
    if (found != original.end()) {   // 未找到返回 end，不可直接解引用。
        std::cout << "2 的下标=" << (found - original.begin()) << '\n';
    }
    std::reverse(original.begin(), original.end());
    print("翻转", original);

    original.reserve(30);
    const auto oldCapacity = original.capacity();
    original.clear();               // 销毁所有元素，size=0，保留容量；旧元素引用失效。
    assert(original.empty() && original.capacity() == oldCapacity);
    print("clear 后", original);
    original.shrink_to_fit();        // 请求缩容，不保证执行；若重新分配则旧迭代器失效。
    print("shrink_to_fit 后（观察实现）", original);
}

struct Trace {
    int value;
    explicit Trace(int number) : value(number) { std::cout << "构造 " << value << '\n'; }
    Trace(const Trace& other) : value(other.value) { std::cout << "拷贝 " << value << '\n'; }
    Trace(Trace&& other) noexcept : value(other.value) { std::cout << "移动 " << value << '\n'; }
};

void emplacementAndMove() {
    std::cout << "\n--- 6. 原地构造与扩容搬移 ---\n";
    std::vector<Trace> values;
    values.reserve(2);               // 先隔离扩容影响，比较两种添加方式。
    values.push_back(Trace{1});      // 临时对象构造，再移动到 vector 中。
    values.emplace_back(2);         // 用构造参数直接创建元素，省去该临时对象。
    // emplace_back 不保证所有场景都更快；扩容时仍须搬移已有元素。
    std::cout << "强制扩容，观察旧元素的搬移：\n";
    values.reserve(values.capacity() + 1);
    // 常见实现对 noexcept 移动使用移动构造；移动可能抛异常且可拷贝时，
    // 通常选择拷贝来维护异常保证。移动构造不可拷贝类型时还需考虑异常边界。

    // 进阶：vector<bool> 是特殊化，元素访问通常返回代理，不是普通 bool&。
    // 不应套用普通 vector<T> 的连续 T 对象、T* data 和 auto& 遍历模型。
    std::vector<bool> flags{false, true};
    flags[0] = true;
    assert(flags[0] && flags[1]);
}

int main() {
    initializationAndCapacity();
    growthAndTraversal();
    eraseAndInsert();
    iteratorValidity();
    clearCopyAndAlgorithms();
    emplacementAndMove();
}
```

> [!warning] 插入与删除循环的区别
> `erase` 返回删除后的下一个元素；`insert` 返回新插入的元素。示例在奇数前插入两倍值后，第一次 `++it` 回到原奇数，第二次到下一待处理元素，循环头不能再递增。结果为 `2 1 6 3 10 5 14 7`。
