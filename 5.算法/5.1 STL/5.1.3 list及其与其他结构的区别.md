> [!abstract] list 速记卡片
> **一句话**：`std::list` 是双向循环链表，任意已知位置的增删均为 O(1)，不支持随机访问；相比 [[5.算法/5.2 算法/5.2.9 链表常见技巧|5.2.9 链表常见技巧]] 中的裸单链表，STL 内部以环形哨兵节点消除了头尾边界判断，并提供 `splice` 实现 O(1) 的指针零拷贝嫁接。以下示例省略 `std::`，以 C++17 为准。
>
> | 要做什么 | 常用写法 / 要点 |
> | --- | --- |
> | 头文件与类型 | `#include <list>`；类型写作 `list<int>` |
> | 初始化 | `list<int> l{1, 2, 3};` 列表初始化；`list<int> l(n, val);` 填入 n 个指定值 |
> | 首尾访问 | `l.front()` / `l.back()`；调用前容器必须非空，不支持 `l[i]` 或 `l.at(i)` |
> | 两端增删 | `push_front(x)` / `push_back(x)`；`pop_front()` / `pop_back()`；均为 O(1) |
> | 指定位置增删 | `l.insert(it, x)` 插在 it 前；`l.erase(it)` 删当前节点，返回后继节点迭代器；均为 O(1) |
> | 零拷贝拼接 | `l1.splice(it, l2)` 把 l2 整条剪切并入 it 前；`l1.splice(it, l2, it2)` 转移单个节点；仅改指针，O(1) |
> | 条件删除与去重 | `l.remove(val)` 删所有匹配值；`l.remove_if(pred)` 按谓词删；`l.unique()` 消除相邻重复项（需先排好序） |
> | 排序与反转 | 成员函数 `l.sort()`（默认升序，降序 `l.sort(std::greater<int>())`），底层归并 O(n log n)；`l.reverse()` 原地反转；不能用 `std::sort` |
> | 有序归并 | `l1.merge(l2)` 将有序链表 l2 合入 l1，调用后 l2 被清空；O(n) |
> | 大小与清空 | `l.empty()` 判空；`l.size()` 获取节点数，O(1)；`l.clear()` 释放所有节点 |
>
> **splice 与 merge 核心对比**
>
> | 维度 | `l1.splice(it, l2)` | `l1.merge(l2)` |
> | --- | --- | --- |
> | 操作目的 | 机械拼接：把 `l2` 整体插到指定位置 `it` 前 | 有序归并：按大小穿插合并（类似归并排序） |
> | 位置决定权 | **由程序员指定**（参数 `it` 决定插入点） | **由元素值决定**（比较大小自动找位置） |
> | 前置条件 | **无要求**，两链表任意乱序均可 | **必须已有序**（两链表必须先按相同规则排序） |
> | 时间复杂度 | $O(1)$（只改动 4~6 个头尾指针） | $O(n_1 + n_2)$（线性双指针逐个比对） |
> | 局部剪切能力 | 支持重载：可只剪切单节点或某个子区间 | 不支持：必须整条链表参与归并 |
> | 调用后 `l2` 状态 | `l2` 被掏空变为空链表（`l2.empty() == true`） | `l2` 被掏空变为空链表（`l2.empty() == true`） |
>
> **iterator 迭代器与指针操作**
> - **双向迭代器**：支持 `++it` 与 `--it`，不支持 `it + n` 或 `it1 - it2`。跨步移动需用 `std::advance(it, k)`，耗费 O(k) 时间。
> - **区间定义**：`[l.begin(), l.end())` 左闭右开。`end()` 对应底层的哨兵节点，不可解引用；反向迭代器用 `rbegin()` / `rend()`。
> - **迭代器稳定性**：插入（`insert` / `push_back`）和节点嫁接（`splice`）完全不会导致其他迭代器、指针或引用失效；删除（`erase`）仅使被删节点的迭代器失效。循环中删除必须接住返回值：`it = l.erase(it);`。
> **三个必记易错点**
> - **不能用全局 `std::sort`**：`std::sort` 要求随机访问迭代器（RandomAccessIterator），传入 `list::iterator` 无法通过编译；必须使用成员函数 `l.sort()`。
> - **插入是 O(1)，寻位是 O(n)**：拿到迭代器后插入确实是常数时间，但若要定位到“第 k 个元素”，必须从头逐个移动迭代器；频繁按索引查找请换用 `vector` 或 `deque`。
> - **缓存缺失与内存开销**：每个节点除数据外还要保存前驱、后继两个指针（64 位系统下额外占用 16 字节），且节点在堆区分散分配。数据量大、遍历频繁时，Cache Miss 带来的开销通常会让链表比连续数组更慢。
>
> **口诀**：已知位置增删快，随机查找逐个跨；外部排序编译报错，自带归并把序排；哨兵成环省分支，节点搬移 splice 灵。
>

# list 链表容器

## 简介

- **全称**：链表容器
- **底层数据结构**：双向循环列表

```
双向循环链表结构：

     ┌──────────────────────────────────────────┐
     │                                          │
     ↓                                          │
  ┌─────┐    ┌─────┐    ┌─────┐    ┌─────┐     │
  │     │←──→│     │←──→│     │←──→│     │─────┘
  └─────┘    └─────┘    └─────┘    └─────┘
     ↑                                │
     └────────────────────────────────┘
```

## 常见方法

```cpp
list<int> mylist;

// 增加
mylist.push_back(20);       // 从末尾添加元素 O(1)
mylist.push_front(20);      // 从首部添加元素 O(1)
mylist.insert(it, 20);      // 从 it 迭代器指向的位置添加元素 O(n)

// 删除
mylist.pop_back();          // 从末尾删除元素 O(1)
mylist.pop_front();         // 从首部删除元素 O(1)
mylist.erase(it);           // 从 it 指向的位置删除元素 O(n)

// 查询搜索
// iterator（连续的 insert 和 erase 一定要考虑迭代器失效的问题）
```

## 区别

### deque 和 list 比 vector 容器多出来的增加删除函数接口

- `push_front` 和 `pop_front`

### vector、deque、list 三方对比

| 容器 | 特点 |
|------|------|
| **vector** | 动态数组，内存是连续的，并且以二倍的方式进行扩容<br>`vector<int> vec; 0-1-2-4-8...` |
| **deque** | 动态开辟的二维数组空间，第二维是固定长度的数组空间，扩容的时候，第一维的数组进行二倍扩容<br>**面经问题**：deque 底层内存是否是连续的？<br>不是，deque 每一个二维数组都是独立 new 出来的，单独的二维数组是连续的，但是各个二维数组的内存空间不连续 |
| **list** | 底层数据结构的区别：一个是一维的，一个是二维的<br>前中后插入删除元素的时间复杂度：<br>- **前面插入**：`vector` O(n)，`deque` O(n)，**末尾插入** `vector` O(1)，`deque` O(1)<br>- 对于内存的使用效率：`vector` 需要的内存空间必须是连续的，`deque` 可以分块进行数据存储，不需要内存空间必须是连续的<br>- 在中间进行 insert 或者 erase 和 deque 的效率区别？虽然二者的时间复杂度都是 O(n)，但是由于 deque 的第二维内存空间不是连续的，所以在 deque 中间进行元素的 insert 或者 erase 的时候，元素移动的效率比 vector 要慢 |

### vector 和 deque 的区别

1. **底层数据结构的区别**：一个是一维的，一个是二维的
2. **前中后插入删除元素的时间复杂度**：

| 操作 | 前面插入 | 中间插入 | 末尾插入 |
|------|----------|----------|----------|
| vector | O(n) | O(n) | O(1) |
| deque | O(1) | O(1) | O(1) |

3. **对于内存的使用效率**：
   - `vector` 需要的内存空间必须是连续的
   - `deque` 可以分块进行数据存储，不需要内存空间必须是连续的

4. **在中间进行 insert 或者 erase 和 deque 的效率区别**：
   - 虽然二者的时间复杂度都是 O(n)
   - 但是由于 deque 的第二维内存空间不是连续的
   - 所以在 deque 中间进行元素的 insert 或者 erase 的时候，元素移动的效率比 vector 要慢

```
deque 中间删除示意图：

          ┌─────────────────┐
          │   预留空行       │
          ├─────────────────┤ first
          │   ○ ○ ○ ○ ○     │ ←── 需要移动
          ├─────────────────┤
          │   ○ ○ X ○ ○     │ ←── 删除中间元素
          │       ↑         │
          │   需要跨块移动   │
          ├─────────────────┤ last
          │   预留空行       │
          └─────────────────┘
```

### vector 和 list 的区别

| 对比项 | vector | list |
|--------|--------|------|
| **底层结构** | 一个动态开辟的数组 | 一个双向循环链表 |
| **增加删除时间复杂度** | 数组增加删除 O(n)，查询 O(n)，随机访问 O(1) | 链表增加删除 O(1)，查询 O(n)，链表没有随机访问 |

---

## 关键要点

1. **list 适合频繁插入删除**：由于是链表结构，在任意位置插入删除都是 O(1)（找到位置后）
2. **list 不支持随机访问**：不能使用 `[]` 下标访问，只能通过迭代器遍历
3. **list 内存不连续**：每个节点独立分配，可能导致缓存不友好
4. **迭代器稳定性**：list 的迭代器在插入删除后不会失效（除了被删除的元素）
