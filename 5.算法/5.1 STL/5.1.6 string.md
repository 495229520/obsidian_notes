> [!abstract] string 速记卡片
> **一句话**：`std::string` 是自动管理内存的可变字符序列，支持下标访问、拼接、查找和截取；结合 [[8.1 string]] 的基础用法整理。以下示例省略 `std::`，以 C++17 为基准。
>
> | 要做什么 | 常用写法 / 要点 |
> | --- | --- |
> | 头文件与初始化 | `<string>`；`string s;` 空串；`string s = "hello";`；`string s(3, 'a');` 得到 `"aaa"` |
> | 长度与判空 | `s.size() == s.length()`，O(1)，不计末尾终止符；`s.empty()` 判空 |
> | 访问与修改 | `s[i]` 不检查边界；`s.at(i)` 越界抛异常；`s[i] = 'x'` 修改一个字符，O(1) |
> | 首尾字符 | `s.front()` / `s.back()`；必须非空 |
> | 拼接 | `s += "abc"` / `s.append("abc")` 修改 s；`s + "abc"` 生成新字符串；`s.push_back('x')` 追加单个字符 |
> | 删除 | `pos` 就是 `string` 的下标。`s.pop_back()` 删除末尾字符，必须非空；`s.erase(pos, len)` 删除 len 个字符；`s.erase(pos)` 删除至末尾 |
> | 插入与替换 | `s.insert(pos, "abc")` 插在 pos 前；`s.replace(pos, len, "abc")` 替换从 pos 开始的 len 个字符 |
> | 截取子串 | `s.substr(pos, len)` 返回新串，不改变 s；`s.substr(pos)` 截至末尾；len 是数量，不是结束下标 |
> | 查找 | `s.find("ab", start)` 从 start 向后找；`s.rfind("ab")` 找最后一次出现；返回下标，失败为 `string::npos` |
> | 查找字符集合 | `s.find_first_of("aeiou")` 找第一个元音；与查找整个子串的 `find` 不同 |
> | 比较 | `s == t` 比较内容；`s < t` 按字典序；`s.compare(t)` 返回负数 / 0 / 正数，不保证恰好是 -1 / 1 |
> | 大小与容量 | `reserve(n)` 预留空间，size 不变；`resize(n, 'x')` 改变长度，增长时补 x；`resize(n)` 增长时补 `'\0'`；`clear()` 清空内容 |
> | 数值转换 | `stoi(s)` / `stoll(s)` / `stod(s)` 转数值；`to_string(42)` 得到 `"42"`；`stoi("1A", nullptr, 16)` 得到 26 |
> | C 风格接口 | `s.c_str()` 返回以 `'\0'` 结尾的 `const char*`，不拥有独立副本，不可通过它修改内容 |
> | 输入 | `<iostream>`：`cin >> s` 读一个词；`getline(cin, s)` 读整行，保留空格、消费但不保存换行符 |
> | 排序与反转 | `<algorithm>`：`sort(s.begin(), s.end())`，O(n log n)；`reverse(s.begin(), s.end())`，O(n) |
>
> **iterator 迭代器速记**
> - **声明**：`string::iterator it = s.begin();`，常写为 `auto it = s.begin();`；`*it` 访问字符，`++it` 前进，支持 `it + n` 随机访问。
> - **边界**：遍历区间是 `[begin(), end())`，`end()` 不能解引用；空串的 `begin() == end()`。
> - **只读与反向**：`cbegin()` / `cend()` 只读；`rbegin()` / `rend()` 反向；`crbegin()` / `crend()` 反向只读。反向迭代器 `++it` 朝开头移动。
> - **失效提醒**：`append`、`insert`、`erase` 等修改操作可能使旧迭代器、引用和 `c_str()` 指针失效；修改后重新获取，不直接套用 vector 的失效规则。迭代器版 `erase(it)` 返回下一个位置。
>
> ```cpp
> // 原地修改字符；只读遍历可用 for (char ch : s)
> for (auto it = s.begin(); it != s.end(); ++it) {
>     if (*it == 'a') *it = 'A';
> }
>
> // 找到后再使用下标，不能写 if (s.find("ab"))
> auto pos = s.find("ab");
> if (pos != string::npos) s.replace(pos, 2, "XY");
>
> // 删除所有 '.'：remove 只整理元素，erase 才真正缩短字符串
> // 需要 <algorithm>
> s.erase(remove(s.begin(), s.end(), '.'), s.end());
> ```
>
> **输入与分割模板**
> ```cpp
> // 成功用 cin >> num 读取数值后，丢弃该行余下内容再读下一行
> // 需要 <limits>、<iostream>、<string>
> cin.ignore(numeric_limits<streamsize>::max(), '\n');
> getline(cin, s);
>
> // 按逗号分割，需要 <sstream>
> stringstream ss("apple,banana,orange");
> string token;
> while (getline(ss, token, ',')) {
>     // 使用 token
> }
> ```
>
> **五个必记易错点**
> - **下标与终止符**：正文字符下标为 `[0, size())`；C++17 中 `s[s.size()]` 可读取终止符 `'\0'`，不能改成其他字符，也不能继续越界。`reserve` 不会创建可写的新字符。
> - **位置与数量**：`substr` / `erase` / `replace` 的第二个整数参数是数量；超出剩余长度时处理到末尾。起点 `pos > size()` 会抛异常，`substr(size())` 返回空串。
> - **查找与转换**：用 `auto` 接收查找结果，并与 `string::npos` 比较，不用 `-1` 或真假值判断。`stoi` 等可能抛异常，也可能只解析前缀（如 `"12abc"` 得到 12）；严格校验需检查已解析长度。
> - **字符不等于文字**：`'a'` 是 char，`"a"` 是字符串字面量；UTF-8 下 `size()` 统计字节数，不是汉字数，按 char 截取或反转可能破坏中文编码。
> - **所有权与生命周期**：`string_view`（C++17，`<string_view>`）只借用字符，不负责保活，也不保证以 `'\0'` 结尾；原字符串销毁或重分配后，旧视图可能悬空。
>
> **复杂度速记**：访问、长度、判空 O(1)；复制长度为 k 的子串 O(k)；中间插入、删除通常需要移动后缀，开销随字符串长度增长。短字符串可能采用 SSO（小字符串优化），不一定单独分配堆内存。
>
> **口诀**：长度 size，整行 getline；查找判 npos，截取数个数；迭代尾后不取值，remove 之后接 erase。
>
> 关联：[[8.1 string]] · [[5.1.7 迭代器]] · [[5.1.1 vector]]


# string 字符串容器

> 本笔记是对 [[8.1 string]] 的补充，主要讲解 string 在 STL 中的高级用法。

## C 风格字符串

```cpp
// char 数组
char charVARS;
char arr[10];
int i = 0;
// i == 'hello'
```

## C++ 风格字符串

```cpp
string str("hello");
string str = "hello";
```

## 两者区别

| 特性 | C 风格 | C++ 风格 |
|------|--------|----------|
| 初始化 | `char* s = "hello"` | `string s("hello")` 或 `string s = "hello"` |
| 获取长度 | `strlen(s)` | `s.length()` 或 `s.size()` |
| 字符串拼接 | `strcat(s1, s2)` | `s1 + s2` 或 `s1.append(s2)` |
| 字符串比较 | `strcmp(s1, s2)` | `s1 == s2` 或 `s1.compare(s2)` |
| 安全性 | 需要手动管理内存 | 自动管理，无溢出风险 |

## 常用方法

| 类型 | 函数 | 用法 | 功能 |
|------|------|------|------|
| **初始化与赋值** | `string s = "hello world"` | 用 `"hello world"` 初始化 s | 初始化字符串 |
| | `assign(str)` | `s1.assign(s2)` | 将 s2 的内容赋给 s1 |
| | `push_back(ch)` | `s.push_back('a')` | 在尾部追加一个字符 |
| | `pop_back()` | `s.pop_back()` | 移除最后一个字符 |
| **append 系列** | `append(str)` | `s1.append(s2)` | 追加字符串 s2 到 s1 后面；等价于 `s1 += s2` |
| | `append(n, ch)` | `s.append(3, 'x')` | 追加 n 个字符 ch |
| | `append(str, pos, len)` | `s1.append(s2, 0, 3)` | 追加 s2 的子串 |
| **获取长度** | `length()` | `s.length()` | 返回字符串长度（与 `size()` 等价） |
| | `size()` | `s.size()` | 返回字符串长度 |
| | `capacity()` | `s.capacity()` | 返回当前分配的容量 |
| | `empty()` | `s.empty()` | 判断是否为空 |
| **操作** | `clear()` | `s.clear()` | 清空字符串 |
| | `resize(n)` | `s.resize(10)` | 调整大小为 n |
| | `reserve(n)` | `s.reserve(100)` | 预留至少 n 个字符的空间 |
| **元素访问** | `operator[]` | `s[0]` | 访问指定位置字符（无边界检查） |
| | `at(pos)` | `s.at(0)` | 访问指定位置字符（有边界检查） |
| | `front()` | `s.front()` | 返回首字符 |
| | `back()` | `s.back()` | 返回尾字符 |
| **子串与查找** | `substr(pos, len)` | `s.substr(0, 5)` | 返回从 pos 开始长度为 len 的子串 |
| | `find(str)` | `s.find("hello")` | 查找子串，返回位置或 `npos` |
| | `rfind(str)` | `s.rfind("lo")` | 从后向前查找 |
| | `find_first_of(chars)` | `s.find_first_of("aeiou")` | 查找第一个属于 chars 的字符 |
| | `find_last_of(chars)` | `s.find_last_of("aeiou")` | 查找最后一个属于 chars 的字符 |
| **插入与删除** | `insert(pos, str)` | `s.insert(0, "Hello")` | 在 pos 位置插入字符串 |
| | `erase(pos, len)` | `s.erase(0, 5)` | 删除从 pos 开始的 len 个字符 |
| **比较与替换** | `compare(str)` | `s1.compare(s2)` | 比较字符串，返回 0（相等）、负数（小于）、正数（大于） |
| | `replace(pos, len, str)` | `s.replace(0, 5, "Hi")` | 替换从 pos 开始的 len 个字符为 str |
| **迭代器** | `begin()` | `s.begin()` | 返回指向首字符的迭代器 |
| | `end()` | `s.end()` | 返回指向尾后的迭代器 |
| | `rbegin()` | `s.rbegin()` | 返回反向迭代器（指向最后一个字符） |
| | `rend()` | `s.rend()` | 返回反向迭代器（指向第一个字符之前） |

## 字符串与数值转换

### std::stoi/stol/stoll/stof/stod 系列

将 `std::string` 转换为对应的数值类型：
- `stoi`：转 `int`
- `stol`：转 `long`
- `stoll`：转 `long long`
- `stof`：转 `float`
- `stod`：转 `double`

```cpp
std::string numStr = "12345";
int num = std::stoi(numStr);  // num = 12345

std::string floatStr = "3.14159";
double pi = std::stod(floatStr);  // pi = 3.14159
```

### std::to_string

将数值类型转为 `std::string`：

```cpp
int value = 42;
std::string str = std::to_string(value);  // str = "42"
```

## 字符串分割

### std::stringstream 配合 getline

```cpp
// 将 "apple,banana,orange,pear" 分割成一个 vector
#include <sstream>
#include <vector>
#include <string>

std::string input = "apple,banana,orange,pear";
std::stringstream ss(input);
std::string token;
std::vector<std::string> tokens;

while (std::getline(ss, token, ',')) {
    tokens.push_back(token);
}
// tokens = {"apple", "banana", "orange", "pear"}
```

### C++20 std::ranges 和 std::views::split

```cpp
#include <ranges>
#include <string_view>

std::string str = "Split these words into a vector";
auto words = str | std::views::split(' ');
for (auto word : words) {
    // 处理每个单词
}
```

## 字符串拼接

### 使用 std::ostringstream 高效拼接

```cpp
#include <sstream>

std::ostringstream oss;
oss << "Hello" << ", " << "World" << "!";
std::string result = oss.str();  // result = "Hello, World!"
```

### C++17 std::string::reserve 预分配

```cpp
std::string result;
result.reserve(1000);  // 预分配空间，减少重分配

for (int i = 0; i < 100; ++i) {
    result += std::to_string(i) + " ";
}
```

## str.erase() 删除指定字符

```cpp
int main() {
    std::string s = "Hello World! This is C++..."; // 去掉感叹号和省略号以外的标点

    // 找到 '!' 的位置并删除
    size_t pos = s.find('!');
    if (pos != std::string::npos) {
        s.erase(pos, 1);  // 删除 1 个字符
    }

    // 使用 erase-remove idiom 删除所有指定字符
    s.erase(std::remove(s.begin(), s.end(), '.'), s.end());
}
```

## str.remove_if 删除满足条件的字符

配合 `erase` 使用 `remove_if` 删除满足特定条件的字符：

```cpp
#include <algorithm>
#include <cctype>

std::string str = "Hello123World456";

// 删除所有数字
str.erase(
    std::remove_if(str.begin(), str.end(), ::isdigit),
    str.end()
);
// str = "HelloWorld"
```

**重要说明**：`std::remove_if` 不是真正删除元素，它只是将不符合条件的元素移到前面，并返回一个指向"逻辑结尾"的迭代器。需要配合 `erase` 才能真正删除元素。

## 关键要点

1. **string 是动态数组**：底层是动态分配的字符数组，自动管理内存
2. **与 C 风格兼容**：使用 `c_str()` 或 `data()` 获取 C 风格字符串
3. **预分配优化**：使用 `reserve()` 预分配空间可提高拼接性能
4. **边界检查**：`at()` 有边界检查，`[]` 没有
5. **迭代器支持**：支持所有标准迭代器操作
