## 题目

一批成绩可能包含无效值和重复值。使用 `std::vector<int>` 完成录入、清理、插入和排序去重。

原始数据：

```text
88, -1, 60, 105, 88, 59, 100, 60, 0
```

有效成绩范围为 `[0, 100]`，两端都包含。允许查接口名称，先自己写实现。无需键盘输入、菜单、类或文件读写。

## 实现要求

1. 在 `main` 中，对空的 `scores` 调用 `reserve(20)`，然后遍历 `raw`，用 `push_back` 逐个录入。
2. 实现 `std::size_t eraseInvalid(std::vector<int>& scores)`：删除所有小于 0 或大于 100 的值，返回删除数量。**这一步必须用迭代器循环和单元素 `erase`**；不使用 `remove_if` 或辅助容器。
3. 实现 `bool insertBeforeFirst(std::vector<int>& scores, int target, int value)`：只在第一个 `target` 前插入一个 `value`，成功返回 `true`；找不到返回 `false`，容器不变。可用 `std::find`。调用方保证 `value` 合法，函数不负责校验成绩范围。即使 `value == target`，也只能插入一次。
4. 实现 `void sortUniqueDesc(std::vector<int>& scores)`：使用 `std::sort`、`std::unique` 和区间 `erase` 完成降序去重，直接修改传入的容器，不创建另一份结果容器。
5. 在主流程去重后，依次执行 `resize(8, -1)`、`resize(3)` 和 `clear()`。这里的 `-1` 只用于观察补值，不再参与成绩清理。记录每步的 `size` 和 `capacity`。

不要修改测试中的期望值，也不要把主样例的结果直接写进实现。三个函数都必须能接收空容器。

## 已提供的边界测试

- 空容器：删除返回 `0`，插入返回 `false`，排序去重后仍为空。
- 全部无效：`{-1, 101, -8, 150}` 删除后为空，返回 `4`。
- 连续无效：`{-1, -2, 60, 101, 102, 100}` 删除后为 `{60, 100}`，返回 `4`。
- 有效边界：`{0, 100}` 不被删除。
- 全部重复：`{88, 88, 88}` 去重后只有一个 `88`。
- 插入位置：覆盖首元素、尾元素、目标不存在，以及 `value == target`。
- 插入扩容：测试会先填满已有容量，再执行插入，检查原元素和新元素的顺序。
