迭代器失效与安全删除 · 为什么要 it = erase(it)

目标：删除 {1, 2, 2, 3} 里所有的 2 —— 先看错误写法怎么漏删，再看正确姿势　·　← → 单步，空格 播放

vector 内存（红色 = 待删除的 2）
▲it
✗ 错误写法
for (auto it = v.begin(); it != v.end(); ++it)
  if (*it == 2) v.erase(it);  // 删完还 ++
✓ 正确写法
for (auto it = v.begin(); it != v.end(); /* 空 */)
  if (*it == 2) it = v.erase(it);  // 接住返回值
  else ++it;
