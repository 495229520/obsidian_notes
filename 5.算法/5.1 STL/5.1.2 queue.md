> [!abstract] queue & deque 速记卡片
> **一句话**：`queue`（先进先出）与 `priority_queue`（按堆序出队）是受限的容器适配器，无迭代器；`deque` 是双端队列，底层分段连续，支持两端 O(1) 增删与下标随机访问。以下示例省略 `std::`。
>
> | 操作 / 特性 | queue (普通队列) | priority_queue (优先队列) | deque (双端队列) |
> | --- | --- | --- | --- |
> | 头文件 | `<queue>` | `<queue>` | `<deque>` |
> | 声明方式 | `queue<int> q;` | `priority_queue<int> pq;`（默认大根堆）<br>`priority_queue<int, vector<int>, greater<int>> min_pq;`（小根堆） | `deque<int> dq;` |
> | 默认底层 | `deque` | `vector` | 独立容器（中控 map + 固定 buffer） |
> | 入队 / 添加 | `q.push(x)` / `emplace()` 均摊 O(1) | `pq.push(x)` / `emplace()` O(log n) | `dq.push_front()` / `dq.push_back()` O(1) |
> | 出队 / 移除 | `q.pop()` 移除队头，无返回值，O(1) | `pq.pop()` 移除堆顶，无返回值，O(log n) | `dq.pop_front()` / `dq.pop_back()` O(1) |
> | 查看极值 / 端点 | `q.front()` 队头，`q.back()` 队尾 | `pq.top()` 堆顶（优先级最高），无 front/back | `dq.front()` 队头，`dq.back()` 队尾，`dq[i]` 随机访问 |
> | 判空与大小 | `q.empty()`，`q.size()` | `pq.empty()`，`pq.size()` | `dq.empty()`，`dq.size()` |
> | 迭代器遍历 | 无迭代器，不支持遍历 | 无迭代器，不支持遍历 | 支持随机访问迭代器 `begin()/end()` |
> | 预留与底层配置 | 不支持 reserve | 不支持 reserve | 无 reserve（扩容零数据搬迁；块大小如 512B 由实现固定不可调） |
> | 清空容器 | `q = {};` 或循环 `pop` | `pq = {};` 或循环 `pop` | `dq.clear();` |
>
> **常用操作模板**
> ```cpp
> // 1. BFS 队列标准遍历：先判空，再取值，后弹出
> while (!q.empty()) {
>     int cur = q.front();
>     q.pop();
>     // 处理 cur...
> }
>
> // 2. 小根堆（找前 K 个大数或 Dijkstra 最短路）
> priority_queue<int, vector<int>, greater<int>> min_heap;
>
> // 3. priority_queue 自定义排序（结构体仿函数）
> struct Node { int id, dist; };
> struct Cmp {
>     bool operator()(const Node& a, const Node& b) const {
>         return a.dist > b.dist; // dist 小的优先级高（小顶堆）
>     }
> };
> priority_queue<Node, vector<Node>, Cmp> pq;
> ```
>
> **五个必记易错点**
> - **空容器访问未定义**：对空容器调用 `front()`、`back()`、`top()`、`pop()` 属于未定义行为（通常引发段错误崩溃），取值或弹出前必须先调用 `empty()` 判空。
> - **pop() 不返回元素**：为保证异常安全强保证，C++ 标准中 `pop()` 返回类型为 `void`；必须先通过 `front()` / `top()` 读出数据，再调用 `pop()`。
> - **比较器与堆顶相反**：`priority_queue` 规则中，`less<T>` 产生大根堆（堆顶为最大值）；`greater<T>` 产生小根堆（堆顶为最小值）。比较器返回 `true` 表示前者优先级低于后者，排在堆底。
> - **适配器接口被封装**：`queue` 和 `priority_queue` 没有 `clear()` 方法，不支持 `[]` 随机访问，也不能用范围 for 遍历；若要清空容器，直接赋值空对象 `q = {};` 最简洁高效。
> - **deque 无 reserve 且底层块不可调**：底层 Buffer 块大小（如 GCC 默认约 512 字节）由编译器实现写死，程序员无法指定；因扩容只追加独立小块、原有数据零搬迁，故无 `reserve()` 接口。`dq[i]` 得到的是元素引用，不能对单块调用 `push_back()`。
>
> **口诀**：先判空再取值，pop 不带回；大顶堆用 less，小顶堆用 greater；适配器无迭代，两端自由选 deque。
>
> 关联：[[5.1.8 容器适配器]] · [[5.1.1 vector]] · [[5.1.12 stack]] · [[5.1.7 迭代器]]


# queue 队列容器

## queue 简介

`queue` 是一种**先进先出**（FIFO: First-In, First-Out）的数据结构。你可以把它想象成银行的排队队伍：最先排队的人，总是最先得到服务并离开队伍。

### 核心特性

- **先进先出 (FIFO)**：这是 queue 最核心的特性。第一个进入队列的元素，将是第一个离开队列的元素
- **容器适配器**：与 [[5.1.8 容器适配器|stack]] 类似，queue 本身也不是独立的容器，而是对其他基础容器（如 deque 或 list）的封装。它提供了一个受限的接口，只允许你进行 FIFO 操作。默认情况下，queue 基于 `deque` 实现
- **受限的操作**：queue 只提供以下几种基本操作，以确保其 FIFO 特性：
  - `push()`：将一个元素添加到队列的**尾部**
  - `pop()`：移除队列**头部**的元素
  - `front()`：访问队列**头部**的元素，但不移除它
  - `back()`：访问队列**尾部**的元素，但不移除它
  - `empty()`：检查队列是否为空
  - `size()`：返回队列中元素的数量

### 常用方法

```cpp
queue<int> que;
que.push(1);      // 入队
que.front();      // 访问队头元素
que.back();       // 访问队尾元素
que.pop();        // 出队（移除队头）
que.empty();      // 判断是否为空
que.size();       // 返回元素个数
```

### 注意事项

1. queue **不可以访问内部元素**，只能访问队头和队尾
2. 有些时候可以把 queue 当做 stack 使用（只使用一端操作）

### 适用场景

持续维护元素的有序性：每次向队列插入大小不定的元素，或者每次从队列里取出大小最小/最大的元素，元素数量、插入操作数量 k：
- 使用普通队列维护，每次插入后进行快速排序：k·n·logn
- 使用优先队列维护：k·logn

## deque 双端队列

### 简介

![[图片/SVG/5_1_1_2_2.svg|1378]]

- **全称**：双端队列容器（Double-Ended Queue）
- **为什么常被称为「动态二维数组」**：
  - **第一维（行索引）**：中控器 `map` 是一个指针数组（`T**`），集中记录各个缓冲区的物理基址。
  - **第二维（列索引）**：每个指针指向一块固定长度的独立连续缓冲区（`T* buffer`，大小通常为 512 字节 / sizeof(T)）。
  - **二维寻址语法**：定位任意逻辑下标 $i$ 时，内部通过除法和取模直接拆解为行号与列号：
    $$\text{row} = \frac{\text{index}}{\text{BUF\_SIZE}}, \quad \text{col} = \text{index} \pmod{\text{BUF\_SIZE}}$$
    寻址底层即执行 `map[row][col]`，在语法与表现上呈现典型的二维数组形态。
- **与传统物理二维数组的区别**：
  - 传统二维数组（如 `T[M][N]`）在物理内存上必须是一整块不可分割的连续大平层，各行首尾紧贴，无法在首部挂载新内存，扩容必须全量搬迁。
  - deque 是**分段连续（Segmented Array）**，各行 Buffer 分散在堆的不同区域，行与行之间物理并不相邻。这使得它既能在首尾直接挂接新 Buffer 实现两端 $O(1)$ 增删，又能凭两次解引用保持 $O(1)$ 的随机访问。

### 常见方法

```cpp
deque<int> deq;

// 增加
deq.push_back(20);       // 从末尾添加元素 O(1)
deq.push_front(20);      // 从首部添加元素 O(1)
deq.insert(it, 20);      // 从 it 迭代器指向的位置添加元素 O(n)

// 删除
deq.pop_back();          // 从末尾删除元素 O(1)
deq.pop_front();         // 从首部删除元素 O(1)
deq.erase(it);           // 从 it 指向的位置删除元素 O(n)

// 查询搜索
// iterator（连续的 insert 和 erase 一定要考虑迭代器失效的问题）
```

### 扩容过程

![[图片/SVG/5_1_1_2_1.svg|1497]]

deque 底层由固定大小的连续内存块（Buffer）与一个管理各 Buffer 地址的指针数组（中控器 Map）组成。其扩容机制包含两个层级：

1. **缓冲区（Buffer）级扩展**：
   - 当向队头 `push_front` 或队尾 `push_back` 且当前活跃 Buffer 空间耗尽时，直接申请一个独立的定长 Buffer，并将其指针挂接在 Map 的相邻空槽中。
   - 该过程只需分配一个定长小块，不改变已有内存，操作为 $O(1)$。

2. **中控器（Map）级倍增扩容**：
   - **触发条件**：Map 数组前端或后端的指针槽位已全部耗尽，无法再挂接新的 Buffer。
   - **倍增与居中**：分配容量倍增的新 Map 指针数组（如 2 倍或更大），并将旧 Map 中的节点指针**拷贝到新 Map 的正中间**：
     $$\text{new\_start} = \text{new\_map} + \frac{\text{new\_size} - \text{old\_size}}{2}$$
   - **对称缓冲**：旧指针居中放置后，新 Map 的首尾两端留出等量的空闲槽位，使后续朝两端继续追加元素时均拥有对称的缓冲余量，避免频繁重构 Map。

3. **与 vector 扩容对比**：
   - vector 扩容必须申请整片更大的连续空间，并将全部已有元素逐一搬迁（拷贝或移动），单次重分配开销与数据总量 $O(n)$ 线性相关。
   - deque 的 Map 扩容**只拷贝指针数组本身**（仅数个至数十个指针的大小），底层的各个 Buffer 物理内存地址完全保持不变，**无任何数据元素搬移与构造析构开销**。

### deque 内部参数

```cpp

#define QUE_SIZE 4096/sizeof(T)  // 每个队列块的大小
```

## priority_queue 优先级队列

`priority_queue` 是一种特殊的队列，它不是按照先进先出（FIFO）的原则排列元素，而是按照元素的**优先级**排序。

### 核心特性

- 最大（或最小）优先级的元素总是在队列的最前面，可以最先被访问和移除
- 通常用堆（Heap）数据结构来实现，这使得插入和移除操作都能在 O(log n) 的时间复杂度内完成
- **重要操作**：
  - `push()`：添加一个元素，优先队列会自动将其放置到正确的位置，以保持堆的性质
  - `pop()`：移除优先级最高的元素（默认是最大的元素）
  - `top()`：访问优先级最高的元素，但不移除它
  - `empty()`：检查队列是否为空
  - `size()`：返回队列中元素的数量

### 底层实现

`priority_queue` 底层依赖 vector，底层默认是大根堆。

底层默认把数据组成一个大根堆结构，通常在一个内存的连续数组上构建一个大根堆或者小根堆。因为堆中每一个节点跟它左右孩子之间的关系是通过下标实现的：
- 左孩子：`2 * i + 1`
- 右孩子：`2 * i + 2`
- 父节点：`(i - 1) / 2`

### 基本操作

| 容器 | 操作 |
|------|------|
| stack | `push`: 入栈 `pop`: 出栈 `top`: 查看栈顶元素 `empty`: 判断栈空 `size`: 返回元素个数 |
| queue | `push`: 入队 `pop`: 出队 `front`: 查看队头元素 `empty`: 判断队空 `size`: 返回元素个数<br>stack 底层依赖 deque，原理同上 |
| priority_queue | `push`: 入队 `pop`: 出队 `top`: 查看队头元素 `empty`: 判断队空 `size`: 返回元素个数<br>priority_queue 底层依赖 vector，底层默认是大根堆 |

### 大根堆（Max-Heap）

大根堆（Max-Heap）中，父节点的值总是大于或等于其子节点的值。因此，堆的根节点（即 `top()` 返回的元素）总是堆中最大的元素。

```cpp
#include <iostream>
#include <queue>
using namespace std;

int main() {
    // A. 实现自定义比较器
    // // 1.1 按照默认的规则大堆（Max-Heap）
    // struct cmp {
    //     // 规则：当 A.priority < B.priority 时，返回 true (A 优先级低)
    //     bool operator()(const Task& A, const Task& B) const {
    //         return A.priority < B.priority;  // 告诉优先队列
    //     }
    // };

    // // 1.2 实现比较器自定义小堆（Min-Heap）
    // // 规则：当 A.priority > B.priority 时，返回 true
    // struct cmp {
    //     bool operator()(const Task& A, const Task& B) const {
    //         return A.priority > B.priority;  // 优先级高的反而排后面
    //     }
    // };

    // 默认大顶堆
    priority_queue<int> max_heap;
    max_heap.push(rand() % 100 + 1);

    // 使用 greater 创建小顶堆
    priority_queue<int, vector<int>, greater<int>> min_heap;

    // 1.2 定义空容器，最高优先级 priority 最大的 Item
    priority_queue<int> max_heap_top1;
    max_heap_top1.push(10);  // 优先队列大顶堆
    // or max_heap_top.priority <= 1 or <= std::endl;

    // 测试 Task E（Priority: 90)
    // 输出: Task E（Priority: 90)
    // 输出: Task E（Priority: 90)

    // 使用 less 创建大顶堆
    priority_queue<string, vector<string>, less<string>> max_heap2;
    max_heap2.push("Task A");
    max_heap2.push("Task X");
    max_heap2.push("Task C");
    cout << max_heap2.top() << endl;  // Task X (字典序最大)

    return 0;
}
```

### 使用 Lambda 表达式自定义比较器

```cpp
#include <iostream>
#include <queue>
#include <functional>  // 需要包含 <functional>

struct Task {
    string name;
    int priority;
};

int main()
{
    // 2. 使用 Lambda 表达式
    // Min Heap 用于找最小的元素
    auto min_heap_lambda = [](const Task& A, const Task& B) {
        return A.priority > B.priority;  // 注意这里是 >
    };

    // Lambda min_heap_lambda 的底层 decltype 取类型生成 Lambda 匿名函数种类，Lambda 实际上 '>' 号值函数
    // 中的的尖括号描述种类，'>' 号括号的每个尖括号传个参数 Lambda 函数地址/引用传函数指针
    priority_queue<Task, vector<Task>, decltype(min_heap_lambda)>
        lambda_min_heap_top(min_heap_lambda);  // 需要 decltype 获取 Lambda 匿名类型

    lambda_min_heap_top.push({"Task A", 10});
    lambda_min_heap_top.push({"Task B", 5});
    cout << "Top: " << lambda_min_heap_top.top().name << endl;
    // 输出: Top: Task B (Priority: 5)
}
```

### 使用注意

1. 对于自定义类型，需要提供比较器
2. `greater<T>` 创建小顶堆，`less<T>` 创建大顶堆（默认）
3. 底层使用堆结构，插入和删除都是 O(log n)

## 关键要点

| 容器 | 特点 | 底层结构 | 适用场景 |
|------|------|----------|----------|
| queue | FIFO 先进先出 | deque | 任务队列、BFS |
| deque | 双端操作 O(1) | 分段连续数组 | 需要两端操作的场景 |
| priority_queue | 按优先级排序 | 堆（基于 vector） | 任务调度、Dijkstra 算法 |
