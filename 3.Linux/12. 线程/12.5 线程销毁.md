# 线程销毁

线程的生命周期管理是多线程编程中的重要环节。与 [[12.2 线程的创建与运行|线程的创建]] 相对应，线程销毁有多种方式，每种方式都有其适用场景和注意事项。

---

## 自然退出

这是最推荐、最安全的方式。当线程的入口函数（你用 `pthread_create` 传入的函数）执行完毕并返回时，线程就会自然终止。

### 实现方式

- **使用 return 语句**：在线程函数内部，你可以使用 `return` 语句或 `pthread_exit()` 函数来结束线程
- **pthread_exit()**：这个函数允许你指定一个返回值，其他线程可以通过 `pthread_join()` 来获取这个值

### 代码案例：return 与 pthread_exit 的区别

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <unistd.h>

// 方式一：使用 return 退出
void *task_return(void *arg) {
    printf("[return线程] 开始执行任务...\n");
    sleep(1);
    
    // 在堆上分配返回值（不能返回局部变量的地址！）
    int *result = malloc(sizeof(int));
    *result = 42;
    
    printf("[return线程] 任务完成，返回结果 %d\n", *result);
    return (void *)result;  // return 会自然退出线程
}

// 方式二：使用 pthread_exit 退出
void *task_exit(void *arg) {
    printf("[exit线程] 开始执行任务...\n");
    sleep(1);
    
    int *result = malloc(sizeof(int));
    *result = 100;
    
    printf("[exit线程] 任务完成，返回结果 %d\n", *result);
    pthread_exit((void *)result);  // 显式退出，效果与 return 相同
    
    // 这行代码永远不会执行
    printf("这行不会被打印\n");
}

int main() {
    pthread_t t1, t2;
    void *ret1, *ret2;
    
    pthread_create(&t1, NULL, task_return, NULL);
    pthread_create(&t2, NULL, task_exit, NULL);
    
    // pthread_join 会阻塞，直到目标线程退出，并获取其返回值
    pthread_join(t1, &ret1);
    pthread_join(t2, &ret2);
    
    printf("[主线程] return线程返回: %d\n", *(int *)ret1);
    printf("[主线程] exit线程返回: %d\n", *(int *)ret2);
    
    free(ret1);
    free(ret2);
    return 0;
}
```

**编译运行**：
```bash
gcc -o natural_exit natural_exit.c -lpthread
./natural_exit
```

**输出**：
```
[return线程] 开始执行任务...
[exit线程] 开始执行任务...
[return线程] 任务完成，返回结果 42
[exit线程] 任务完成，返回结果 100
[主线程] return线程返回: 42
[主线程] exit线程返回: 100
```

> [!tip] return vs pthread_exit
> 两者在线程函数中效果几乎一样，但有一个关键区别：如果在线程函数调用的**子函数**中使用 `pthread_exit()`，它会直接终止整个线程；而 `return` 只会从当前函数返回到调用者。

### 优点

这种方式能确保所有线程内部的资源（如局部变量、[[1.2 函数栈帧建立与销毁原理|栈空间]]）都得到正确释放，避免了[[6.3 动态内存分配的风险|内存泄漏]]。

---

## 强制终止

这是一种不推荐的方式，因为它非常危险，可能会导致不可预测的后果。你可以在一个线程中，强制终止另一个线程的执行。

### 函数

```c
#include <pthread.h>

int pthread_cancel(pthread_t thread);
```

### pthread_cancel()

这个函数会向指定线程发送一个终止信号。然而，被终止的线程并非立即停止，它需要在代码中设置**取消点（cancellation point）**。这些取消点通常是阻塞的系统调用，如 `read()`、`write()`、`sleep()` 等。当线程执行到取消点时，它才会检查是否有挂起的终止信号并退出。

### 代码案例：pthread_cancel 与取消点

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <unistd.h>

void *worker(void *arg) {
    int i = 0;
    printf("[工作线程] 开始运行...\n");
    
    while (1) {
        printf("[工作线程] 正在工作... 第 %d 次循环\n", ++i);
        
        // sleep() 是一个取消点
        // 当主线程调用 pthread_cancel 后，线程会在此处检查并响应取消请求
        sleep(1);
    }
    
    // 这行永远不会执行（线程会在取消点处被终止）
    printf("[工作线程] 正常退出\n");
    return NULL;
}

int main() {
    pthread_t tid;
    pthread_create(&tid, NULL, worker, NULL);
    
    // 让工作线程运行 3 秒
    sleep(3);
    
    printf("[主线程] 发送取消请求...\n");
    int ret = pthread_cancel(tid);  // 发送取消信号
    if (ret != 0) {
        perror("pthread_cancel");
        return 1;
    }
    
    void *retval;
    pthread_join(tid, &retval);
    
    // 被 cancel 的线程，其返回值为 PTHREAD_CANCELED（即 (void *)-1）
    if (retval == PTHREAD_CANCELED) {
        printf("[主线程] 工作线程已被成功取消\n");
    }
    
    return 0;
}
```

**输出**：
```
[工作线程] 开始运行...
[工作线程] 正在工作... 第 1 次循环
[工作线程] 正在工作... 第 2 次循环
[工作线程] 正在工作... 第 3 次循环
[主线程] 发送取消请求...
[主线程] 工作线程已被成功取消
```

### 代码案例：使用清理函数防止资源泄漏

`pthread_cleanup_push` / `pthread_cleanup_pop` 允许你注册清理函数，在线程被取消或调用 `pthread_exit()` 时自动执行，类似于 C++ 中的 RAII 机制。

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <unistd.h>

// 清理函数：释放动态分配的内存
void cleanup_memory(void *arg) {
    printf("[清理函数] 释放内存: %p\n", arg);
    free(arg);
}

// 清理函数：关闭文件
void cleanup_file(void *arg) {
    FILE *fp = (FILE *)arg;
    printf("[清理函数] 关闭文件\n");
    fclose(fp);
}

void *risky_worker(void *arg) {
    // 分配资源
    char *buffer = malloc(1024);
    printf("[工作线程] 分配了 buffer: %p\n", buffer);
    
    // 注册清理函数（后注册的先执行，类似栈的 LIFO 顺序）
    pthread_cleanup_push(cleanup_memory, buffer);
    
    FILE *fp = fopen("/tmp/test_thread.txt", "w");
    if (fp) {
        printf("[工作线程] 打开了文件\n");
        pthread_cleanup_push(cleanup_file, fp);
        
        // 模拟工作（sleep 是取消点，线程可能在此处被 cancel）
        for (int i = 0; i < 10; i++) {
            fprintf(fp, "第 %d 行数据\n", i);
            printf("[工作线程] 写入第 %d 行...\n", i);
            sleep(1);  // 取消点
        }
        
        // 参数非零表示执行清理函数，0 表示仅弹出不执行
        pthread_cleanup_pop(1);  // 弹出并执行 cleanup_file
    }
    
    pthread_cleanup_pop(1);  // 弹出并执行 cleanup_memory
    return NULL;
}

int main() {
    pthread_t tid;
    pthread_create(&tid, NULL, risky_worker, NULL);
    
    sleep(3);  // 等 3 秒后取消
    
    printf("[主线程] 取消工作线程...\n");
    pthread_cancel(tid);
    pthread_join(tid, NULL);
    
    printf("[主线程] 线程已取消，资源已通过清理函数回收\n");
    return 0;
}
```

**输出**：
```
[工作线程] 分配了 buffer: 0x55a3e7c002a0
[工作线程] 打开了文件
[工作线程] 写入第 0 行...
[工作线程] 写入第 1 行...
[工作线程] 写入第 2 行...
[主线程] 取消工作线程...
[清理函数] 关闭文件
[清理函数] 释放内存: 0x55a3e7c002a0
[主线程] 线程已取消，资源已通过清理函数回收
```

> [!warning] pthread_cleanup_push/pop 必须成对出现
> 它们在某些实现中是用宏展开的（push 包含 `{`，pop 包含 `}`），所以必须在同一个作用域内成对使用，否则编译会报错。

### 危险性

1. **资源泄漏**：如果线程在持有锁、分配了内存或打开了文件的情况下被强制终止，这些资源可能永远不会被释放，导致**死锁**或[[6.3 动态内存分配的风险|内存泄漏]]
2. **数据不一致**：线程可能在修改共享数据的过程中被终止，使得数据处于一个不完整或不一致的状态，引发严重的数据错误

因此，除非你非常清楚你在做什么，并且已经为强制终止设计了完善的清理机制（如上述 `pthread_cleanup_push/pop`），否则应该避免使用此方法。

## 分离（Detach）

这是另一种管理线程生命周期的方式，它主要用于**自动回收资源**，而不是手动终止线程。

### 线程的两种状态

一个线程在被创建后，有两种状态：

- **可汇合（Joinable）**：这是默认状态。当线程结束时，它的资源不会被立即释放，而是等待其他线程调用 `pthread_join()` 来回收。如果忘记调用 `pthread_join()`，就会造成**僵尸线程**，占用系统资源
- **分离（Detached）**：在这种状态下，线程在结束时，其资源会自动被系统回收，不需要任何线程来调用 `pthread_join()`

### 函数

```c
#include <pthread.h>

int pthread_detach(pthread_t thread);
```

### pthread_detach()

可以在线程创建后立即调用此函数来将其设置为分离状态，或者在创建时通过属性（`pthread_attr_t`）来设置。

### 代码案例：两种分离方式

**方式一：创建后调用 pthread_detach**

```c
#include <stdio.h>
#include <pthread.h>
#include <unistd.h>

void *background_task(void *arg) {
    int id = *(int *)arg;
    printf("[后台线程 %d] 开始执行...\n", id);
    sleep(2);
    printf("[后台线程 %d] 执行完毕，资源将自动回收\n", id);
    return NULL;
}

int main() {
    pthread_t tid;
    int id = 1;
    
    pthread_create(&tid, NULL, background_task, &id);
    pthread_detach(tid);  // 创建后分离
    
    printf("[主线程] 后台线程已分离，主线程继续工作...\n");
    
    // 注意：分离后不能再 join，否则会返回错误
    // int ret = pthread_join(tid, NULL);  // 错误！返回 EINVAL
    
    // 主线程需要等足够久，否则 main 返回后整个进程退出，
    // 分离线程也会被强制终止
    sleep(3);
    printf("[主线程] 退出\n");
    return 0;
}
```

**方式二：创建时通过属性设置为分离状态**

```c
#include <stdio.h>
#include <pthread.h>
#include <unistd.h>

void *background_task(void *arg) {
    printf("[后台线程] 执行中...\n");
    sleep(1);
    printf("[后台线程] 完成\n");
    return NULL;
}

int main() {
    pthread_t tid;
    pthread_attr_t attr;
    
    // 初始化属性对象
    pthread_attr_init(&attr);
    
    // 设置为分离状态（线程一创建就是 detached）
    pthread_attr_setdetachstate(&attr, PTHREAD_CREATE_DETACHED);
    
    // 使用属性创建线程
    pthread_create(&tid, &attr, background_task, NULL);
    
    // 销毁属性对象（线程已创建，属性不再需要）
    pthread_attr_destroy(&attr);
    
    printf("[主线程] 线程已创建为分离状态\n");
    
    sleep(2);
    return 0;
}
```

### 代码案例：线程内部自我分离

线程也可以在自己的函数内部调用 `pthread_detach(pthread_self())` 将自身分离：

```c
#include <stdio.h>
#include <pthread.h>
#include <unistd.h>

void *self_detach_task(void *arg) {
    // 线程自己将自己分离
    pthread_detach(pthread_self());
    
    printf("[线程] 我已经自我分离了\n");
    sleep(1);
    printf("[线程] 任务完成，资源会自动回收\n");
    return NULL;
}

int main() {
    pthread_t tid;
    pthread_create(&tid, NULL, self_detach_task, NULL);
    
    // 主线程无需（也不能）join 这个线程
    sleep(2);
    return 0;
}
```

> **注意**：分离后的线程无法再被 `pthread_join()`，也无法获取其返回值。

> [!caution] 主线程退出 = 进程退出
> 无论子线程是否分离，一旦 `main()` 函数返回（或调用了 `exit()`），整个进程都会终止，所有线程被强制杀掉。如果需要主线程退出但子线程继续运行，可以在 `main` 末尾调用 `pthread_exit(NULL)` 而非 `return 0`。

---

## 三种方式对比

| 方法 | 核心函数 | 优点 | 缺点 | 适用场景 |
|:---|:---|:---|:---|:---|
| **自然退出** | `return` / `pthread_exit()` | 安全、资源清理完善 | 无法从外部强制停止 | 大多数常规任务 |
| **强制终止** | `pthread_cancel()` | 可以从外部立即停止线程 | 极易导致资源泄漏和死锁 | 紧急情况，如用户强制关闭程序 |
| **分离** | `pthread_detach()` | 自动回收资源，无须 `pthread_join()` | 无法获取线程返回值 | 后台运行的、不依赖主线程的独立任务 |

## 与 C++ std::thread 的对比

在 C++11 中，`std::thread` 提供了类似的线程生命周期管理机制，详见 [[15.2 thread|std::thread]]：

| POSIX pthread | C++ std::thread | 说明 |
|:---|:---|:---|
| `pthread_join()` | `thread.join()` | 等待线程结束并回收资源 |
| `pthread_detach()` | `thread.detach()` | 分离线程，自动回收资源 |
| `pthread_exit()` | 函数返回 | 线程自然退出 |
| `pthread_cancel()` | 无直接对应 | C++ 标准库不提供强制终止 |

---

## 关键要点

1. **首选自然退出**：让线程函数正常返回是最安全的方式

2. **谨慎使用 pthread_cancel()**：
   - 只在紧急情况下使用
   - 必须考虑资源清理问题
   - 需要正确设置取消点

3. **分离适用于独立任务**：
   - 后台任务
   - 不需要返回值的任务
   - 生命周期独立于主线程的任务

4. **避免僵尸线程**：对于 Joinable 状态的线程，必须调用 `pthread_join()` 回收资源

## 综合案例：三种销毁方式对比演示

```c
#include <stdio.h>
#include <stdlib.h>
#include <pthread.h>
#include <unistd.h>

// ===== 线程1：自然退出 =====
void *natural_thread(void *arg) {
    printf("[线程1-自然退出] 开始工作\n");
    sleep(1);
    
    int *result = malloc(sizeof(int));
    *result = 200;
    printf("[线程1-自然退出] 完成，返回 %d\n", *result);
    return (void *)result;
}

// ===== 线程2：被强制取消 =====
void cleanup_handler(void *arg) {
    printf("[线程2-清理函数] 释放资源: %s\n", (char *)arg);
    free(arg);
}

void *cancel_thread(void *arg) {
    char *buf = malloc(64);
    snprintf(buf, 64, "线程2的缓冲区");
    
    pthread_cleanup_push(cleanup_handler, buf);
    
    printf("[线程2-强制取消] 开始无限循环工作...\n");
    while (1) {
        sleep(1);  // 取消点
    }
    
    pthread_cleanup_pop(0);
    return NULL;
}

// ===== 线程3：分离线程 =====
void *detach_thread(void *arg) {
    pthread_detach(pthread_self());
    printf("[线程3-分离] 我是分离线程，自生自灭\n");
    sleep(1);
    printf("[线程3-分离] 工作完成，资源自动回收\n");
    return NULL;
}

int main() {
    pthread_t t1, t2, t3;
    
    // 创建三个线程
    pthread_create(&t1, NULL, natural_thread, NULL);
    pthread_create(&t2, NULL, cancel_thread, NULL);
    pthread_create(&t3, NULL, detach_thread, NULL);
    
    // 等待线程1自然退出，获取返回值
    void *ret1;
    pthread_join(t1, &ret1);
    printf("[主线程] 线程1返回值: %d\n", *(int *)ret1);
    free(ret1);
    
    // 等 2 秒后取消线程2
    sleep(2);
    printf("[主线程] 取消线程2...\n");
    pthread_cancel(t2);
    
    void *ret2;
    pthread_join(t2, &ret2);
    if (ret2 == PTHREAD_CANCELED)
        printf("[主线程] 线程2已被取消\n");
    
    // 线程3是分离的，不需要 join
    // 给线程3足够时间完成
    sleep(1);
    
    printf("[主线程] 所有线程处理完毕\n");
    return 0;
}
```

**编译运行**：
```bash
gcc -o thread_destroy thread_destroy.c -lpthread
./thread_destroy
```

**输出**：
```
[线程1-自然退出] 开始工作
[线程2-强制取消] 开始无限循环工作...
[线程3-分离] 我是分离线程，自生自灭
[线程1-自然退出] 完成，返回 200
[主线程] 线程1返回值: 200
[线程3-分离] 工作完成，资源自动回收
[主线程] 取消线程2...
[线程2-清理函数] 释放资源: 线程2的缓冲区
[主线程] 线程2已被取消
[主线程] 所有线程处理完毕
```
