# 7.0 网络编程基础学习路线

本章先建立网络编程需要的共同语言，再进入 TCP/UDP、Socket 和应用层协议。链路层与网络层的报文细节放在“协议深挖”分组；非阻塞 I/O、Reactor 和性能调优放在基础编程之后。

## 1. 基础主线

1. [[7. 网络编程/01. 网络基础/1.1 网络分层模型|网络分层模型]]：理解各层负责什么，以及数据如何封装和逐跳转发。
2. [[7. 网络编程/01. 网络基础/1.2 IP地址与CIDR|IP 地址与 CIDR]]：掌握地址、子网、广播和特殊地址。
3. [[7. 网络编程/01. 网络基础/1.3 端口与五元组|端口、端点与五元组]]：理解端点标识、连接唯一性和端口占用。
4. [[7. 网络编程/01. 网络基础/1.5 传输层协议：TCP与UDP|TCP 与 UDP 总览]]：先比较两种传输层协议，再学习各自的能力边界。
5. [[7. 网络编程/02. TCP 协议/2.1 TCP协议基础|TCP 协议基础]] → [[7. 网络编程/02. TCP 协议/2.2 TCP原理|TCP 原理]]：掌握报文、握手、状态机、序号、确认和窗口。
6. [[7. 网络编程/03. Socket API/3.1 套接字|套接字]] → [[7. 网络编程/03. Socket API/3.3 listen和accept函数|listen 和 accept]]：把协议概念对应到 Linux Socket API。
7. [[7. 网络编程/01. 网络基础/1.4 应用层协议|应用层协议]]：观察 HTTP、SSH、DNS 等协议如何在字节流上建立消息边界。
