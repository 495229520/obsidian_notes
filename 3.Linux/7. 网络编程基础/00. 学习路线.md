# 7.0 网络编程基础学习路线

本章先建立网络编程需要的共同语言，再进入 TCP/UDP、Socket 和应用层协议。链路层与网络层的报文细节放在“协议深挖”分组；RPC、事件驱动和高性能 I/O 放在 [[18.1 RPC 协议模板]] 之后单独学习。

## 1. 基础主线

1. [[7.1 网络分层模型]]：理解各层负责什么，以及数据如何封装和逐跳转发。
2. [[7.2 IP地址与CIDR]]：掌握地址、子网、广播和特殊地址。
3. [[7.3 端口与五元组]]：理解端点标识、连接唯一性和端口占用。
4. [[7.5 传输层协议：TCP与UDP]]：先比较 TCP 与 UDP，再学习各自的能力边界。
5. [[7.6 TCP协议基础]]：掌握握手、挥手、状态机、序号、确认和窗口。
6. [[7.7 套接字]] → [[7.8 listen和accept函数]]：把协议概念对应到 Linux Socket API。
7. [[7.4 应用层协议]]：观察 HTTP、SSH、DNS 等协议如何在字节流上建立消息边界。

[[18.1 RPC 协议模板]] → [[18.2 gRPC]] → [[18.3 非阻塞 RPC：epoll + 状态机]] → [[18.4 C++ Coroutine 非阻塞 RPC]] → [[18.5 gRPC Completion Queue：异步 Add RPC]] → [[18.6 io_uring 非阻塞 RPC]] → [[18.7 RDMA Verbs 与 CQ 非阻塞 RPC]]
