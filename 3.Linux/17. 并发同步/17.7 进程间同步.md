# 17.7 进程间同步

> 前面的锁/条件变量多用于**线程间**。跨进程时，同步原语必须放在进程都能访问的地方（内核对象或共享内存）。
> 关联 [[11.2 进程间通信IPC]]、[[11.4 共享内存]]、[[11.5 信号量]]、[[11.6 消息队列]]。

---

## 1. 为什么进程间同步更难

- 不共享地址空间，普通 `pthread_mutex` 默认不可跨进程
- 需要内核对象或共享内存承载同步状态

## 2. System V vs POSIX

| | System V | POSIX |
|--|----------|-------|
| 信号量 | `semget/semop` | `sem_open/sem_wait` |
| 共享内存 | `shmget/shmat` | `shm_open/mmap` |
| 消息队列 | `msgget/msgsnd` | `mq_open/mq_send` |

> 详见 [[11.5 信号量]]、[[11.4 共享内存]]、[[11.6 消息队列]]

## 3. 进程共享的 pthread 原语

- `PTHREAD_PROCESS_SHARED` 属性
- 放在共享内存中的 `pthread_mutex_t` / `pthread_cond_t`
