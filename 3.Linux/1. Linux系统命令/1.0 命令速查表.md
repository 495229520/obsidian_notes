# 1.0 Linux 命令速查表

按用途分组的命令速查。详细用法看对应笔记：[[1.1 ls、echo、cd、head、tail、ps]]、[[1.2 cp、rm、chmod、vim、gcc]]、[[1.3 cat、mv、mkdir、grep、find、kill、tar]]。

---

## 1. 目录与文件浏览

| 命令 | 作用 | 最常用形式 |
|------|------|-----------|
| `ls` | 列出目录内容 | `ls -alh`（全部文件 + 详情 + 人类可读大小） |
| `cd` | 切换目录 | `cd ..` 上级、`cd ~` 主目录、`cd -` 上次目录 |
| `pwd` | 显示当前所在路径 | `pwd` |
| `cat` | 打印整个文件 | `cat -n file`（带行号） |
| `less` | 分页查看长文件 | `less file`，空格翻页，`/` 搜索，`q` 退出 |
| `head` | 看文件开头 | `head -n 20 file`（前 20 行） |
| `tail` | 看文件末尾 | `tail -f log`（实时跟踪日志） |

---

## 2. 文件与目录操作

| 命令 | 作用 | 最常用形式 |
|------|------|-----------|
| `cp` | 复制 | `cp -r 源目录 目标/`（递归复制目录） |
| `mv` | 移动 / 重命名 | `mv old new`；批量移动加 `-i` 防覆盖 |
| `rm` | 删除 | `rm -r 目录`；`-f` 强制，**慎用** |
| `mkdir` | 创建目录 | `mkdir -p a/b/c`（递归创建，已存在不报错） |
| `touch` | 创建空文件 / 更新时间戳 | `touch file.c` |
| `ln` | 创建链接 | `ln -s 目标 链接名`（软链接） |
| `chmod` | 修改权限 | `chmod 755 脚本`、`chmod +x 脚本` |

---

## 3. 搜索

| 命令 | 作用 | 最常用形式 |
|------|------|-----------|
| `grep` | 搜**文件内容** | `grep -rn "关键词" 目录/`（递归 + 行号） |
| `find` | 搜**文件本身** | `find . -name "*.c"`（按名字找） |

区分：找"哪个文件里写了 connect_server"用 `grep -rn`；找"main.c 在哪个目录"用 `find -name`。

---

## 4. 进程管理

| 命令 | 作用 | 最常用形式 |
|------|------|-----------|
| `ps` | 进程快照 | `ps aux \| grep 进程名` |
| `top` | 实时监控 CPU/内存 | `top`，`M` 按内存排序，`q` 退出 |
| `kill` | 向进程发信号 | `kill PID` 请求退出；`kill -9 PID` 强制 |
| `killall` | 按名字杀进程 | `killall 进程名` |

停进程顺序：先 `kill`（SIGTERM，给进程清理机会），几秒后没退再 `kill -9`。

## 5. 打包与压缩

| 命令 | 作用 | 记忆 |
|------|------|------|
| `tar -czvf x.tar.gz 目录/` | 打包并压缩 | **c**reate + g**z**ip + **f**ile |
| `tar -xzvf x.tar.gz` | 解压 | e**x**tract + g**z**ip + **f**ile |
| `tar -tzvf x.tar.gz` | 只看内容不解压 | lis**t** |

---

## 6. 磁盘与内存

| 命令 | 作用 | 最常用形式 |
|------|------|-----------|
| `df` | 磁盘分区剩余空间 | `df -h`，看 `Use%` 列 |
| `du` | 目录占用大小 | `du -sh *`（当前目录各子项汇总） |
| `free` | 内存用量 | `free -h`，看 `available` 列 |

磁盘满排查流程：`df -h` 定位哪个分区满 → `du -sh /该分区/*` 逐层找占用大户。

---

## 7. 输出与变量

| 命令 | 作用 | 最常用形式 |
|------|------|-----------|
| `echo` | 打印文本 / 变量 | `echo $HOME`；`echo "文本" >> file` 追加写入 |
| `>` / `>>` | 重定向：覆盖 / 追加 | `命令 > file` 覆盖，`命令 >> file` 追加 |
| `\|` | 管道：前一命令输出作为后一命令输入 | `ps aux \| grep nginx \| grep -v grep` |

## 8. 开发工具

| 命令 | 作用 | 最常用形式 |
|------|------|-----------|
| `vim` | 文本编辑器 | `i` 进插入模式，`Esc` 回命令模式，`:wq` 保存退出，`:q!` 不保存退出 |
| `gcc` | C/C++ 编译 | `gcc main.c -o app -Wall`；`-c` 只编译不链接 |

## 9. 常见选项字母对照

同一个字母在不同命令里含义不同，容易混。按字母整理：

### 9.1 -n

| 命令 | 含义 |
|------|------|
| `head -n 20` / `tail -n 20` | 指定显示的**行数** |
| `grep -n` | 显示匹配行的**行号** |
| `cat -n` | 输出时给每行**编号** |
| `mv -n` / `cp -n` | **不覆盖**已存在的目标文件（no-clobber） |
| `echo -n` | 输出后**不换行** |

### 9.2 -f

| 命令 | 含义 |
|------|------|
| `tail -f` | **实时跟踪**文件新增内容（follow） |
| `rm -f` / `cp -f` / `mv -f` | **强制**执行，不提示（force） |
| `tar -f` | 指定**归档文件名**，必须紧跟文件名 |
| `ps -ef` | 完整格式（full）显示所有进程 |

同一个字母两种性格：`tail -f` 是无害的"盯着看"，`rm -f` 是危险的"不问就删"。

### 9.3 -r

| 命令 | 含义 |
|------|------|
| `cp -r` / `rm -r` | **递归**处理目录及其全部内容（recursive） |
| `grep -r` | **递归**搜索目录下所有文件 |
| `sort -r` | **逆序**排序（reverse） |

`ls -R` 的递归是大写 R；`cp`/`rm` 大小写都行，习惯用小写。

### 9.4 -s

| 命令 | 含义 |
|------|------|
| `ln -s` | 创建**软链接**（symbolic） |
| `du -s` | 只显示**汇总**大小，不递归列出子目录（summarize） |
| `gcc -S` | 只编译到**汇编代码**（大写 S，生成 `.s` 文件） |

### 9.5 -i

| 命令 | 含义 |
|------|------|
| `rm -i` / `cp -i` / `mv -i` | 覆盖/删除前**交互式确认**（interactive） |
| `grep -i` | **忽略大小写**（ignore case） |
| `ls -i` | 显示文件的 **inode 号** |

### 9.6 -h / -l / -c

| 选项 | 命令 | 含义 |
|------|------|------|
| `-h` | `ls -lh` / `df -h` / `du -h` / `free -h` | **人类可读**的大小单位（K/M/G） |
| `-l` | `ls -l` | **长格式**详情 |
| `-l` | `grep -l` | 只输出**含匹配的文件名** |
| `-c` | `head -c` / `tail -c` | 按**字节数**显示 |
| `-c` | `grep -c` | 只输出**匹配行数** |
| `-c` | `gcc -c` | 只编译汇编，**不链接**（生成 `.o`） |
| `-c` | `tar -c` | **创建**归档（create） |

## 10. 场景反查

想做某件事时查这张表：

| 我想… | 用这个 |
|--------|--------|
| 看日志最新内容并持续跟踪 | `tail -f 日志文件` |
| 在整个项目里找一个函数定义 | `grep -rn "函数名" src/` |
| 找出磁盘被什么占满了 | `df -h` → `du -sh 目录/* \| sort -rh \| head` |
| 机器卡了，看谁在吃资源 | `top`（`M` 按内存排） |
| 停掉一个卡死的程序 | `ps aux \| grep 名字` → `kill PID`，没用再 `kill -9 PID` |
| 把目录发给别人 | `tar -czvf 名字.tar.gz 目录/` |
| 给脚本加执行权限 | `chmod +x 脚本.sh` |
| 批量删除编译产物 | `find . -name "*.o" -exec rm {} \;` |
| 对比两次配置改了什么 | `grep -v "^#" 配置文件`（过滤注释后再看） |
| 强制 make 重新编译某文件 | `touch 该源文件` |
