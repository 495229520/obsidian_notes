# 5.3 FIRST 与可空性

FIRST(α) 收集符号串 α 能推导出的开头终结符。本章约定：若 α 能推出空串，还将 ε 放入 FIRST(α)。可空性 nullable(α) 就是 $\alpha\Rightarrow^*\varepsilon$。

## 1. 基础规则

对终结符 a，FIRST(a) 只有 a；FIRST(ε) 只有 ε。对非终结符 A，将所有候选右部的 FIRST 合并到 FIRST(A)。

FIRST 的参数可以是一个符号，也可以是一整串符号。构造预测表时需要的是某条产生式右部的 FIRST，不能用左部的总集合代替。

ε 不是输入 Token。普通文法符号串的 FIRST 也不包含外加的输入结束标记 `$`。

## 2. 符号串的 FIRST

计算 $FIRST(Y_1\cdots Y_k)$ 时，从左向右扫描：

1. 加入 FIRST(Yi) 中除 ε 外的元素。
2. 若 Yi 不可空，停止；否则继续看下一个符号。
3. 只有所有 Yi 都可空时，才将 ε 加入整个串的 FIRST。

例如：

```text
S → A B c
A → a | ε
B → b | ε
```

| 扫描位置 | 加入的元素 | 是否继续 |
|---|---|---|
| A | a | A 可空，继续 |
| B | b | B 可空，继续 |
| c | c | 终结符不可空，停止 |

因此 FIRST(ABc) 为 {a, b, c}，不含 ε；FIRST(AB) 则为 {a, b, ε}。不能因为串中某个符号可空，就认定整个串可空。

## 3. 迭代到不动点

遇到相互依赖时，不必猜计算顺序。初始化所有非终结符的 FIRST 为空，反复扫描产生式，按上面的符号串规则增加元素，直到完整一轮没有变化。

```text
repeat:
    changed ← false
    for each production A → α:
        将 FIRST(α) 的新元素加入 FIRST(A)
        若有新增，changed ← true
until changed is false
```

集合只增加，可能的终结符和 ε 有限，因此会终止。也可以先独立计算 nullable：空产生式令左部可空，右部所有符号都可空时令左部可空，重复到稳定。

## 4. 课件算术文法的结果

采用 [[5.2 左递归消除与左因子提取]] 中的 E、X、T、Y 文法：

| 符号 | FIRST | 可空 |
|---|---|---|
| E | {int, `(`} | 否 |
| T | {int, `(`} | 否 |
| X | {+, ε} | 是 |
| Y | {*, ε} | 是 |

T 的两个候选分别以 int 和左括号开头；E 的右部 TX 中，T 不可空，因此 FIRST(E) 只取 FIRST(T)，不再加入 FIRST(X)。

若按 E、X、T、Y 的顺序原地更新，第一轮 E 尚无元素，X、T、Y 已得到各自结果；第二轮把 FIRST(T) 传给 E；第三轮无变化，结束。换顺序可能减少轮数，但最终集合相同。

## 5. 常见误算

- 将 FIRST(A) 与 FOLLOW(A) 混淆：前者看 A 能生成什么开头，后者看 A 后面能出现什么。
- 只看右部第一个符号：遇到可空前缀会漏掉后面的终结符。
- 把 ε 随其他元素一路传播：只有整个右部可空时，左部才可空。
- 扫描一轮就结束：递归依赖通常需要多轮传播。
