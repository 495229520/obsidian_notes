# 5.5 LL(1) 分析表与预测分析器

LL(1) 的第一个 L 表示从左向右读取输入，第二个 L 表示构造最左推导，1 表示用一个前瞻 Token 选择产生式。预测分析可以手写成函数，也可以用显式栈和表实现。

## 1. 填表规则

表 M 的行是非终结符，列是终结符及结束标记。对每条 $A\to\alpha$：

1. 对 $a\in FIRST(\alpha)-\{\varepsilon\}$，把该产生式加入 M[A, a]。
2. 若 α 可空，对 $b\in FOLLOW(A)$，也把该产生式加入 M[A, b]。

使用的是右部 FIRST(α)，不是左部 FIRST(A)。同一格加入不同规则时记录冲突，不能覆盖旧值。没有规则的格子表示错误。

如果 α 是可空的符号串，表项仍然保存原产生式；不能把它擅自替换为 `A → ε`。运行时还要展开其中的符号。

## 2. 完整分析表

文法见 [[5.2 左递归消除与左因子提取]]；FIRST、FOLLOW 的计算分别见 [[5.3 FIRST 与可空性]]、[[5.4 FOLLOW 的含义与计算]]。下表只写右部，— 表示错误。

| 非终结符 | int | ( | * | + | ) | $ |
|---|---|---|---|---|---|---|
| E | T X | T X | — | — | — | — |
| X | — | — | — | + E | ε | ε |
| T | int Y | ( E ) | — | — | — | — |
| Y | — | — | * T | ε | ε | ε |

例如，Y 在 `*` 列选乘法后缀，在 `+` 列选空分支，让外层 X 处理加号；这个 `+` 并没有在展开 Y 时被消费。

## 3. 栈如何运行

初始栈为开始符号和 `$`。本文展示时栈顶在左。

| 栈顶情况 | 动作 |
|---|---|
| 终结符，且等于前瞻 | 弹栈，消费一个 Token |
| 终结符，但与前瞻不同 | 报错 |
| 非终结符 A | 查 M[A, 前瞻]，用右部替换 A |
| 选中空产生式 | 只弹出 A，不消费输入 |
| 栈与输入都到 `$` | 接受 |

实现若使用尾端为栈顶的数组，应将产生式右部逆序压入，使最左符号最先处理。分析栈保存尚待匹配的结构，不是已经读入的 Token 历史。

## 4. 输入 int * int 的完整跟踪

每行记录动作执行前的状态。

| 栈（顶在左） | 未读输入 | 动作 |
|---|---|---|
| E $ | int * int $ | E → T X |
| T X $ | int * int $ | T → int Y |
| int Y X $ | int * int $ | 匹配 int |
| Y X $ | * int $ | Y → * T |
| * T X $ | * int $ | 匹配 * |
| T X $ | int $ | T → int Y |
| int Y X $ | int $ | 匹配 int |
| Y X $ | $ | Y → ε |
| X $ | $ | X → ε |
| $ | $ | 接受 |

## 5. 错误输入在哪停止

`int * + int` 在读完 `int *` 后，需要展开 T，却查到 M[T, +] 为空，因此报错。

`int )` 则先让 Y、X 依次选空分支，最后栈顶 `$` 与输入 `)` 不匹配。FOLLOW 汇总了括号内的上下文，所以错误可能在几次不消费输入的展开之后才报告。

这份表不含恢复动作；报错后是否跳过 Token，需要另行设计，见 [[4.6 语法错误与错误恢复]]。
