# 2.3 类、方法与输入输出

## 1. 从入口程序开始

```cool
class Main inherits IO {
    main() : Object {
        out_string("Hello, COOL!\n")
    };
};
```

运行时创建 `Main` 对象并调用无参数的 `main()`。`Main` 继承 `IO` 后，可以直接调用输入输出方法；省略接收者的调用使用当前对象 `self`。

方法写作 `方法名(参数名 : 类型, ...) : 返回类型 { 主体表达式 };`。主体的静态类型必须符合声明的返回类型，不要求两者完全相同。例如，返回子类对象可以符合父类返回类型。

类型名以大写字母开头，变量名和方法名以小写字母开头。常用注释为：

```cool
-- 单行注释
(* 多行注释，允许嵌套 *)
```

关键字通常不区分大小写；布尔常量 `true`、`false` 的首字母必须小写。这条规则在实现词法分析器时需要准确处理。

## 2. 对象、继承与动态分派

`new C` 创建对象；`self` 表示当前对象；用 `对象.方法(...)` 调用方法，不使用 C++ 的 `->`。

```cool
class Animal {
    sound() : String { "animal" };
};

class Cat inherits Animal {
    sound() : String { "meow" };
};

class Main inherits IO {
    main() : Object {
        let a : Animal <- new Cat in {
            out_string(a.sound());
            out_string("\n");
        }
    };
};
```

预期输出为 `meow`。a 的静态类型是 `Animal`，实际引用 `Cat` 对象；普通调用根据实际对象类型选择方法实现，这称为动态分派，不需要写 `virtual`。

COOL 对象变量应按“引用对象”理解。不要类比为 C++ 的按值基类变量，否则会误以为存在对象切片。

显式写 `a@Animal.sound()` 则从指定的 `Animal` 类型查找实现，本例返回 `"animal"`。这是静态分派，与普通的 `a.sound()` 不同。

## 3. 类和初始化的规则

- 只支持单继承。除 `Object` 本身外，未写 `inherits` 的类默认继承 `Object`。
- 不能继承 `Int`、`Bool`、`String`，可以继承 `IO`。
- 属性由本类及子类的方法访问，外部不能用 `a.field` 直接访问属性；需要提供方法。
- 属性的初始化表达式在创建对象时求值。需要带参数初始化时，可以自定义普通的 `init(...)` 方法。
- `init` 不会因为名字叫 init 就被自动调用，常见用法是 `(new C).init(...)`。
- 没有 C++ 式的用户构造函数、析构函数和 `delete`；对象内存由运行时管理。
- 对空引用调用方法会产生运行时错误，必要时先用 `isvoid` 检查。

`SELF_TYPE` 保留与当前对象类型的关联，常用于返回 `self` 的方法。它不等同于固定写下某个父类类型；正式的类型检查规则留到语义分析章节。

## 4. IO 与 String 的常用方法

| 方法 | 功能 | 返回值 |
|---|---|---|
| `out_string(s)` | 输出字符串，不自动换行 | 接收者自身，返回类型为 `SELF_TYPE` |
| `out_int(n)` | 输出整数，不自动换行 | 接收者自身，返回类型为 `SELF_TYPE` |
| `in_string()` | 读取一行，去掉末尾换行 | `String` |
| `in_int()` | 从一行输入读取整数，丢弃该行剩余内容 | `Int` |
| `s.length()` | 字符串长度 | `Int` |
| `s.concat(t)` | 拼接两个字符串 | `String` |
| `s.substr(start, len)` | 从零起算的下标开始，取指定长度 | `String` |

输出方法返回接收者，因此可以连写：

```cool
out_string("sum = ").out_int(10).out_string("\n")
```

`"hello".substr(1, 3)` 得到 `"ell"`，第二个参数是长度，不是结束下标；越界会产生运行时错误。

没有继承 `IO` 时，也可以显式创建 IO 对象调用方法：

```cool
(new IO).out_string("Hello\n")
```

这里的 IO 对象是调用接收者，字符串是参数。把另一个 IO 对象当作 `out_string` 的参数会产生类型错误；对象不会自动变成字符串。若要输出类型名，可以使用 `(new IO).type_name()`，它返回 `"IO"`。

## 5. A2I：字符串和整数转换

`A2I` 提供 `a2i(String) : Int` 和 `i2a(Int) : String`。它不是内置类，需要把课程的 `atoi.cl` 一同编译，命令见 [[2.1 COOL 编译运行与环境排错]]。

下面的完整程序读取字符串形式的整数，加 1 后输出：

```cool
class Main inherits A2I {
    main() : Object {
        (new IO).out_string(
            i2a(
                a2i((new IO).in_string()) + 1
            ).concat("\n")
        )
    };
};
```

输入 `123`，先得到字符串 `"123"`，转换成整数后计算 124，再转回字符串并输出一行 `124`。

`Main` 已继承 `A2I`，不能再同时继承 `IO`，所以这里显式创建 IO 对象。仅需读写整数时，可以直接使用 `in_int()` 和 `out_int()`；本例绕经字符串是为了练习类型转换。
