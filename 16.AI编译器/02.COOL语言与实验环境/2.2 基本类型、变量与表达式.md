# 2.2 基本类型、变量与表达式

COOL 中，方法体、块、`let`、`if` 和 `while` 都是表达式。读程序时，要同时追踪“执行了什么”和“整个表达式得到什么值、具有什么静态类型”。

## 1. 声明、赋值与默认值

| 用途 | COOL 写法 | 含义 |
|---|---|---|
| 类属性 | `count : Int <- 3;` | 声明类型并给出初始化表达式 |
| 局部变量 | `let x : Int <- 3 in x + 1` | 声明局部变量后计算主体 |
| 给已有变量赋值 | `x <- 5` | 修改变量，表达式的值为赋进去的值 |
| 比较相等 | x \= 5 | 返回 `Bool`；不要沿用 C++ 的双等号写法 |

未提供初始化表达式时：

| 声明类型 | 默认值 |
|---|---|
| `Int` | `0` |
| `Bool` | `false` |
| `String` | 空字符串 |
| 其他对象类型 | `void`，即没有引用任何对象 |

COOL 的 `void` 是空引用值，不是 C++ 中的无返回值类型，也没有可以直接写出的 `void` 字面量。可用 `isvoid x` 检查空引用。

类属性写在类体中；方法内的局部变量用 `let` 声明，不能直接在块内写属性声明。

## 2. let 的主体与作用域

```cool
let x : Int <- 3, y : Int <- x + 1 in
    x + y
```

结果为 `7`。多个声明按顺序嵌套：后面的初始化表达式可以访问前面已声明的变量。

新变量在自己的初始化表达式中还不可见。如果外层也有同名变量，初始化式中的同名引用仍指向外层；进入后续声明和主体后，新变量才遮蔽旧变量。

`in` 后只需要一个表达式，主体尽可能向右延伸。需要多个操作时，使用块：

```cool
let x : Int <- 3 in {
    x <- x + 1;
    x * x;
}
```

块先把 x 改为 4，再得到 16；整个 `let` 的结果也是 16。离开 `let` 后不能再访问这个局部变量。

## 3. 块、方法体与分号

块按顺序求值，以最后一个表达式的值作为结果，静态类型也取最后一个表达式的类型。

```cool
square(n : Int) : Int {
    n * n
};

print_square(n : Int) : Int {
    {
        out_int(n * n);
        out_string("\n");
        n * n;
    }
};
```

这两个方法片段可放入继承 `IO` 的类。COOL 没有 `return`；主体表达式的结果就是方法返回值。

第二个方法有两层大括号：外层属于方法定义，内层是块表达式。

| 结构 | 分号位置 |
|---|---|
| 块 `{ e1; e2; }` | 每个表达式后都有分号，最后一个也不例外 |
| 方法 `f() : T { expression };` | 主体后关闭方法大括号，再结束定义 |
| 类 `class C { ... };` | 结束类定义后有分号 |

因此，单表达式方法的 `n * n` 后没有分号；作为块中最后一个表达式时则需要分号。

## 4. if 和 while 的值与类型

```cool
if x < 0 then "negative" else "non-negative" fi
```

`if` 必须有 `else`，条件必须是 `Bool`。运行时只计算选中的分支；静态类型则由两个分支类型的最近公共祖先确定。

例如，两边都是 `String` 时结果类型为 `String`；一边是 `Int`、另一边是 `String` 时，结果类型为 `Object`，不能直接当作 `String` 使用。

```cool
while x < 3 loop
    x <- x + 1
pool
```

`while` 的条件也必须是 `Bool`。循环结束后，整个表达式的值为 `void`，静态类型为 `Object`，与最后一轮循环体产生什么值无关。

## 5. 运算符容易混淆的地方

| 操作 | COOL 写法／规则 |
|---|---|
| 整数四则运算 | `+ - * /`；除零会产生运行时错误 |
| 小于、小于等于 | `<`、`<=` |
| 大于、大于等于 | 交换操作数，使用 `<`、`<=` |
| 相等、不相等 | x \= y；not (x \= y) |
| 布尔取反 | `not flag` |
| 整数取负 | `~x`；负五写成 `~5`，不能写一元 `-5` |
| 自增 | `x <- x + 1` |
| 字符串拼接 | `s.concat(t)`，不能用 `+` |

COOL 没有 C++ 的 `&&` 和 `||`，可以用嵌套 `if` 表达条件逻辑。`not` 的优先级低于比较运算，显式加括号更容易阅读。

相等比较中，`Int`、`Bool`、`String` 比较值；如果一侧是这些基本类型，另一侧必须是相同类型。其他对象比较引用是否指向同一对象，而不是逐个比较属性。

## 6. 完整例子：循环计算平方

保存为 `square_test.cl`：

```cool
class Main inherits IO {
    square(n : Int) : Int {
        n * n
    };

    main() : Object {
        let x : Int <- 0 in {
            while x < 3 loop {
                out_int(square(x));
                out_string("\n");
                x <- x + 1;
            } pool;
        }
    };
};
```

```bash
coolc square_test.cl
spim -file square_test.s
```

预期程序输出：

```text
0
1
4
```

最后一个表达式是 `while`，所以块、`let`、`main` 最终都得到空引用值；静态类型 `Object` 与方法声明相容。这里的 `Object` 是返回类型，不表示要执行 `new Object`。
