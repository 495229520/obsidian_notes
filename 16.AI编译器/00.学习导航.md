# AI编译器学习导航：先走完这一条路线

当前目标：做一个基于 MLIR 的小型张量编译器，让 `MatMul → Add → ReLU` 在 CPU 上算对，再完成一次有测试、有测量的优化。

**现在从第 1 阶段继续，近期里程碑是亲手写出第一个 C++ Pass。** 依据已有 Day 1 记录，已接触 AST 和伪 IR，但尚未完成独立复述与 MLIR 工程验收。下一次学习先画出返回 `(a + 0) + b` 的函数 AST、伪 IR，并解释整数加零消除的条件。

## 每一步具体怎么学

按顺序打开对应阶段，里面只列本阶段要读的章节、要做的练习、产物和过关标准：

1. [[16.AI编译器/03.MLIR学习与项目实践指南#第一阶段：读懂程序表示，算清张量结果|读懂 IR 与张量]]：注释 IR，完成数值参考。
2. [[16.AI编译器/03.MLIR学习与项目实践指南#第二阶段：搭好工程，写出第一个 Pass|写第一个 Pass]]：在固定环境中独立实现受限整数加零消除。
3. [[16.AI编译器/03.MLIR学习与项目实践指南#第三阶段：定义自己的 MiniNN 算子|定义 MiniNN 算子]]：操作定义、Verifier、合法与非法输入测试。
4. [[16.AI编译器/03.MLIR学习与项目实践指南#第四阶段：让 MiniNN 在 CPU 上算对|跑通 CPU 执行]]：自己的转换代码与上游机制接起来，形成项目第一版。
5. [[16.AI编译器/03.MLIR学习与项目实践指南#第五阶段：完成一项优化，解释它的收益与代价|完成一项优化]]：先做 MatMul 分块，说明正确性、收益与代价，完成主线。

五个阶段始终扩展同一个项目。到第四阶段即可整理第一版成果；片上内存、量化、工业 NPU 修改放到主线之后，详见 [[16.AI编译器/03.MLIR学习与项目实践指南#4. 主线完成后，再走向 NPU 编译优化|后续深化顺序]]。
