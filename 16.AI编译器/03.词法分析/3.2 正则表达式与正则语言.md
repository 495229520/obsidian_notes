# 3.2 正则表达式与正则语言

正则表达式描述一组字符串。对词法分析而言，这组字符串就是某条规则允许匹配的词素集合。

## 1. 字母表、字符串与语言

| 记号 | 含义 | 例子 |
|---|---|---|
| $\Sigma$ | 字母表，即允许使用的符号集合 | $\{0,1\}$ |
| $w$ | 有限长字符串 | `010` |
| $\varepsilon$ | 长度为 0 的字符串 | 空字符串 |
| $\Sigma^*$ | 字母表上全部有限字符串的集合 | 包括空字符串 |
| $L\subseteq\Sigma^*$ | 一种语言，即字符串集合 | 所有以 1 结尾的二进制串 |
| $\emptyset$ | 不含任何字符串的语言 | 连空字符串也不包含 |

$\varepsilon$ 是字符串，$\{\varepsilon\}$ 是只含这个字符串的集合，$\emptyset$ 是空集合。三者不能混用。

## 2. 表达式与语义函数 L

表达式是表示法，语言是它表示的集合。用 $L(R)$ 表示正则表达式 R 对应的语言。

| 表达式 | 语义 |
|---|---|
| $\emptyset$ | $L(\emptyset)=\emptyset$ |
| $\varepsilon$ | $L(\varepsilon)=\{\varepsilon\}$ |
| 字符 $a$ | $L(a)=\{a\}$ |
| $A\mid B$（并） | $L(A)\cup L(B)$ |
| $AB$（连接） | $\{xy\mid x\in L(A),y\in L(B)\}$ |
| $A^*$（Kleene 星闭包） | $\bigcup_{k\geq0}L(A)^k$ |

课程主线使用空串、字符、并、连接、星闭包五种构造；这里补列空语言作为基本情形。对于任意语言 K，定义 $K^0=\{\varepsilon\}$，所以星闭包总包含空字符串。

连接空字符串不改变字符串；语言与空语言连接得到空语言。例如：

$$
K\{\varepsilon\}=K,\qquad K\emptyset=\emptyset,
\qquad \emptyset^*=\{\varepsilon\}.
$$

不同表达式可以描述相同语言，例如 $a\mid b$ 和 $b\mid a$。这里的“语义”是字符串集合，并不是语义分析章节里的变量类型检查。

## 3. 逐步读懂一个表达式

`a(b|c)*` 的构造顺序是：先对 b、c 取并，再重复零次或多次，最后在前面连接 a。

它匹配 `a`、`ab`、`ac`、`abbc`，不匹配空串、`b` 或 `aa`。括号改变分组；通常星闭包优先于连接，连接优先于并。

| 表达式 | 语言的特征 |
|---|---|
| $1^*$ | 只有 1，可以为空 |
| $(1\mid0)1$ | 仅包含 `11`、`01` |
| $0^*\mid1^*$ | 全是 0 或全是 1，可以为空 |
| $(0\mid1)^*$ | 任意二进制串，可以为空 |
| $(0\mid1)^*1$ | 非空且以 1 结尾 |

## 4. 正则定义与语法糖

正则定义为已有模式命名，便于复用；这里的定义是有限展开的缩写，不引入上下文无关文法式的递归。

```text
digit  = [0-9]
letter = [a-zA-Z]
ID     = letter (letter | digit)*
INT    = digit+
```

| 简写 | 基本含义 |
|---|---|
| `A+` | 一次或多次，即 `AA*` |
| `A?` | 零次或一次，即 A 与空串的并 |
| `[a-z]` | 单个字符，取小写字母之一 |
| `[^a-z]` | 单个字符，取约定字母表中不在该范围内的字符 |

原课件常用中缀 `A + B` 表示并，工具通常用竖线。不要把中缀的并与后缀 `A+` 的“一次或多次”混淆。本文公式统一用 $\mid$ 表示并。

空格、换行、制表符、回车可以分别写成 `' '`、`'\n'`、`'\t'`、`'\r'`。字符类与转义的具体语法需要遵循所用工具，伪规则不一定能直接粘贴到生成器中。

这里讨论的是形式语言理论中的正则表达式。实际正则库的反向引用等扩展，不在本章的自动机等价关系范围内。
