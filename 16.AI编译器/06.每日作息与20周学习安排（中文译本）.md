# 每日作息与20周学习安排（中文译本）

> [!info] 文档用途
> 本文是 [[16.AI编译器/韩文/06.매일 학습 계획과 하루 일과.ko|韩文作息文档]] 的中文译本，保留韩国课程、实验室与节假日场景。日常任务另见 [[07.每日计划|07]]；本次整理不合并两套日历，也不改变下方时间表。

本文将[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko|韩文五个月学习路线]]的 20 周路线图（2026 年 10 月 26 日至 2027 年 3 月 14 日）拆成每日任务，并安排兼顾课程和实验室工作的作息。以[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko|韩文五个月学习路线]] §3.2 的**每周 15 小时**为基准。数据结构、算法、操作系统、计算机体系结构的面试准备每周另计 2–3 小时，不包含在这 15 小时内。

> [!info] 使用方法
> - 每日任务是**当天应完成的最小单元**。提前完成时，不提前做次日任务，改为整理当天结果或补充测试。
> - 进度和实测记录与[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko|韩文五个月学习路线]]一样，放在 Trellis 中；本文不标记完成状态。
> - 如果 W6 末（12/6）检查后决定缩小范围，就重写 W7 及以后的每日计划。在该次检查之前，W7 以后的安排均为草案。

## 1. 每日作息

### 1.1 工作日（周一至周五）：课程、实验室与晚间 2 小时

| 时间 | 任务 | 备注 |
|---|---|---|
| 07:00 | 起床 | 保持至少 7 小时睡眠，23:30 就寝 |
| 07:40–08:30 | 去学校 | 路上只重读前一天的 3 行 Trellis 记录，不看新资料 |
| 08:30–08:50 | 启动实验室 PC，用一行写下当天目标 | 需要构建时，此时在后台启动 `ninja` |
| 09:00–12:00 | 课程、实验室工作 | |
| 12:00–13:00 | 午餐与**面试准备 15 分钟**（§1.4） | |
| 13:00–18:00 | 课程、实验室工作 | 课间空档用于休息或完成作业，不安排学习时段 |
| 18:00–19:00 | 晚餐、散步 | |
| **19:00–21:00** | **学习 2 小时**（§1.3） | 在实验室 PC 上完成，占每周 15 小时中的 10 小时 |
| 21:00–21:10 | 记录与 `git push` | 使用公用设备，每天都 push，见[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko\|韩文五个月学习路线]] §7.1 |
| 21:10–22:00 | 回家 | |
| 22:00–23:30 | 自由时间 | 不学习 |

- 课程结束较晚、超过 18:00 时，将学习时段缩短为 20:00–21:30（1.5 小时），少掉的 30 分钟放到周六学习时段之后。一周发生两次以上时，不强求补满 15 小时，按 §4 的延期规则处理。
- 如果实验室允许外部 SSH 访问（[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko|韩文五个月学习路线]] §7.1），也可以回家后在 21:30–23:00 学习，但仍保持 23:30 就寝。

### 1.3 工作日晚间 2 小时的安排

| 时间 | 任务 |
|---|---|
| 19:00–19:10 | 确认当天任务（§3），阅读前一天留下的“下次要做什么” |
| 19:10–20:00 | 第一段专注：阅读或实现 |
| 20:00–20:10 | 休息，离开屏幕 |
| 20:10–20:50 | 第二段专注：运行、测试 |
| 20:50–21:00 | 写 3 行 Trellis 记录：做了什么、卡在哪里、下次做什么 |

- **不安排只阅读的一天。** 即便当天以阅读为主，也要执行一条命令或为一段 IR 加注释，见[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko|韩文五个月学习路线]] §5“仅阅读不算完成”。
- 卡住超过 30 分钟时，将问题缩小为最小复现并记录，再转向下一个任务，周六集中处理。

### 1.4 面试准备（每周另计 2–3 小时）

| 星期 | 午餐时的 15 分钟主题 |
|---|---|
| 周一 | 数据结构：哈希、树、堆、图的表示 |
| 周二 | 算法：排序、DFS/BFS、拓扑排序、动态规划基础 |
| 周三 | 操作系统：进程与线程、虚拟内存、缓存 |
| 周四 | 计算机体系结构：流水线、缓存层次、SIMD、内存带宽 |
| 周五 | C++：值类别、移动语义、智能指针、模板基础 |
| 周六 14:30–15:30 | 两道编程测试题，或本周主题中较薄弱的一项 |

午餐时的 15 分钟只选一个问题，尝试口头作答，再用一行写下答案。

### 1.5 根据校历调整

| 时段 | 调整 |
|---|---|
| 期末考试周（2026 年 12 月中旬，具体日期查看校历） | 工作日学习缩至 1 小时，每周约 10 小时。减少的任务移到预留周 W21–W22 |
| 寒假（12 月底至 2 月） | 工作日可增加至**每天 3 小时**，每周约 20 小时。增加的时间用于补进度、补测试和文档，不扩大范围 |
| 公共假日（12/25、1/1、韩国春节假期、3/1） | 休息；下方每日计划已计入 |

## 4. 延期处理规则

- **工作日未完成的任务，不在当天深夜补做。** 放到周六学习时段的前半部分处理。
- 周六仍未完成时，将该周成果中最不重要的一项移到预留周，不提前占用下周计划。
- 连续两周完成量不足计划的 70% 时，在周日复盘中从基础、环境、范围、投入时间四项中判断原因，并采用[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko|韩文五个月学习路线]] §5 的缩减标准，例如去掉 Add、缩减 P4。
- 构建等待、实验室设备故障损失的时间，不计入学习时间，见[[16.AI编译器/韩文/04.AI 컴파일러 5개월 학습 로드맵.ko|韩文五个月学习路线]] §3.2。
