# 6.4 LR(0) 项集与 DFA 构造

将活前缀 NFA 的状态集合视为一个 DFA 状态，就得到 LR(0) 项集自动机。CLOSURE 对应 ε 闭包，GOTO 对应读一个符号后再求闭包。

## 1. CLOSURE 与 GOTO

CLOSURE(I) 先包含 I 的所有项。只要其中出现 `A → α · B β` 且 B 是非终结符，就加入 B 的全部起始项 `B → · γ`。重复直到没有新项。

闭包只补充项，不移动圆点；如果 B 可空，会加入完成项 `B → ·`，而不是直接跳过父项中的 B。

$$GOTO(I,X)=CLOSURE(\{A\to\alpha X\cdot\beta\mid A\to\alpha\cdot X\beta\in I\}).$$

先同时推进所有圆点后为 X 的项，再求闭包。非空的新项集成为新状态；已有相同集合就复用状态，不按生成路径重复建状态。

## 2. 初始状态与两个转移

使用 [[6.1 移进归约与句柄]] 的文法：

```text
I0:
    S' → · E
    E  → · T + E
    E  → · T
    T  → · int * T
    T  → · int
    T  → · ( E )
```

在 int 上推进两项，得到 `T → int · * T`、`T → int ·`，无需再补项。在左括号上推进得到 `T → ( · E )`，随后闭包补入 E 的两个起始项，再补入 T 的三个起始项。

## 3. 全部 11 个项集

为压缩表格，记：

- KE 是 E 的两个起始项与 T 的三个起始项，共 5 项。
- KT 是 T 的三个起始项，共 3 项。

它们只是集合的简写，不是新的非终结符。状态编号在本章 6.4—6.7 中保持一致。

| I2 | {E → T · + E, E → T ·} |
| I3 | {T → int · * T, T → int ·} |

## 4. 状态如何对应有效项

从 I0 读取活前缀 α 到达的状态，包含对 α 有效的全部 LR(0) 项。状态集合因此描述当前可能的产生式进度，不需要运行时重新枚举最右推导。

例如读取 `( int *`，依次经过 I4、I3、I6。I6 包含等待右侧 T 的项以及 T 的起始项，与 NFA 的集合模拟相同。

I4 在 `(` 上回到自身，所以多个嵌套左括号可以到达同一状态。栈深仍然不同，不能仅凭 I4 还原有多少个未闭合括号。

## 5. 自动机不等于完整分析表

这里的 GOTO(I, X) 接受所有文法符号。通常的运行时 GOTO 表只保留非终结符列；终结符转移进入 ACTION 的移进项。

DFA 确定，只说明“给定栈符号时下一状态唯一”。一个状态内仍可能同时存在移进项和完成项，不能因此断言文法是 LR(0)。决策冲突见 [[6.5 LR(0) 决策与冲突]]。
