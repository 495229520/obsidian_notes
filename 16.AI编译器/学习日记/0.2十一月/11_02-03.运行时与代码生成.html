你的 AddCheck 遇到另一层 Add，会拿到什么？

把 1 + (2 + 3) 交给你写过的 check。外层 Add 要求两个孩子都是 Int。右孩子也是 Add，所以先让它检查自己的两个孩子，再回来读它的类型。

检查结束，根节点的类型是 Int。接下来 cgen 读这棵树，为两个 Add 各生成一组指令。运行时算出的 5 和 6，要等处理器执行到相应的加法才会出现。

11.02 → 11.03　从抽象机器到 MIPS

算右边时，左边的值放在哪里？

纯栈机算 7 + 5 时先把 7、5 依次压栈，ADD 取出两数，再压回 12。讲义把最新结果留在累加器 $a0。如果右子树还要用这个寄存器，就先把左值存到栈里。

cgen(e) 在编译期生成指令。这些指令运行完毕时，结果在 $a0，栈指针回到入口位置，原先仍在使用的栈槽内容保持原值。于是外层加法可以直接拼接内层表达式的代码。

如果所有左值都用 $t1 保存，会算出什么？

外层先把 1 存入 $t1，内层随后把 2 写进同一个寄存器。内层算出 5 后，外层读到的左值成了 2，得到 7。上面的两个栈槽分别保住了 1 和 2。

11.02　运行时组织

一份函数代码，三份调用状态

sumto(x) =
    if x == 0 then 0
    else x + sumto(x - 1)

调用 sumto(2) 时，外层要等内层返回才能做加法。每次进入函数都建立一份激活记录（AR），保存本次参数和返回信息。各次调用执行同一段代码，当前帧指针决定指令读到哪一份 x。

普通同步调用按进入的逆序返回。作用域决定源码中哪些位置可以引用名字，生命周期描述运行时对象从何时存在到何时结束。三次调用的 x 来自同一个声明，各自有自己的生命周期。

偏移为什么有时会跳一格？

假设 char 占 1 字节，int 占 4 字节且要求 4 字节对齐。在结构体中先放 char，再放 int，编译器会在两者之间留出 3 字节。

11.03　教学用 MIPS 调用约定

同一条 lw，取出本次调用的参数

进入

调用者压入旧 $fp，再依次压入 y、x。jal f_entry 把返回地址写入 $ra。被调用者令 $fp = $sp，保存 $ra，并下移 $sp 一格。这样，嵌套调用可以安全改写 $ra。

返回

函数体把结果留在 $a0。被调用者恢复 $ra，将 $sp 上移 4n + 8 字节（n 个实参、旧 $fp 和 RA），从恢复后的栈指针所指位置读回旧 $fp，再执行 jr $ra。

把调用序列代回 sumto(2)
lw   $a0, 4($fp)     # 当前帧的 x = 2
# 按加法模板把左值 2 压栈
# 保存旧 fp，计算 x - 1，将结果 1 作为实参压栈
jal  sumto_entry     # 内层返回时，$a0 = 1
lw   $t1, 4($sp)     # 调用已清理，外层左值重新位于栈顶
add  $a0, $t1, $a0   # 2 + 1 = 3
addiu $sp, $sp, 4

条件比较由 beq 选择分支。x 为 0 时直接返回 0，递归分支保留 x，等子调用返回后执行加法。以上为讲义指令片段，省略分支标签及调用准备指令。

11.03　固定临时槽位

编译时就能数出要留几格

按从左到右的顺序计算加法。算左子树时所有槽位可用；算右子树时已有一格保存左值。因此 NT(L + R) = max(NT(L), 1 + NT(R))。常量和变量都直接写入 $a0，需求为 0。

编译器先遍历函数体，为每个调用帧预留 NT 个槽位。以笔记的 fib 为例，T0 在 −8($fp)，T1 在 −4($fp)。表达式用固定偏移读写临时值，省去临时压栈和弹栈时的指针调整。准备下一次函数调用时仍要移动 $sp。

函数调用的 NT 为什么取各实参需求的最大值？

每算完一个实参，就把结果放入传参区，其临时槽随即可以复用。这里的 NT 只统计表达式临时槽，传参区单独计算。

11.03　对象布局与动态分派

偏移固定，调用目标可以变化

沿用“基址 + 偏移”的寻址思路。单继承教学模型中，B 继承 A 的字段布局，新字段接在后面。因此 A 的方法拿到 B 对象的 self，也能按原偏移读出 a。

编译器根据 e 的静态类型 A 确定 f 的槽号。运行时从 e 取表指针，再按槽号加载函数地址，把 e 作为 self 传入并间接调用。子类重写方法时，只要在自己的表中换掉该槽的地址即可。
