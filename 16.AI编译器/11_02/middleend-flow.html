중간 코드 · 단계별 시연

식 하나를 3-주소 코드로: igen(x + y * 2, t)

연산자 노드를 만나면 새 임시 이름을 둘 만들고, 두 자식을 먼저 번역한 뒤 한 줄을 낸다. 재귀 호출이 쌓이고 풀리는 순서를 따라간다.

노트 11/2 최적화 노트 §1.3

번역 규칙

  1. 규칙 1: e가 정수나 변수면 t := e를 낸다
  2. 규칙 2: e = e₁ op e₂면 새 임시 t₁, t₂를 만든다
  3. 규칙 3: igen(e₁, t₁), igen(e₂, t₂)를 차례로 부른다
  4. 규칙 4: 둘이 끝나면 t := t₁ op t₂를 낸다

AST (배지 = 결과를 담을 이름)

리더를 찾아 블록을 자르고 CFG를 잇는다

줄마다 "블록의 첫 명령이 될 수밖에 없는가"를 묻는다. 리더에서 다음 리더 직전까지가 한 블록이다. 각 줄의 판정은 직접 골라 본다.

노트 11/2 최적화 노트 §2.2–§2.3

  1. 손으로 할 때
  2. 위에서 아래로 한 줄씩 본다.
  3. 리더 규칙 세 개 중 하나라도 맞으면 리더다: ① 첫 명령, ② 점프의 대상(레이블이 붙은 줄), ③ 점프 바로 다음 줄.
  4. 리더에서 다음 리더 직전까지 묶는다.
  5. 블록의 마지막 줄을 보고 화살표를 긋는다: 점프면 대상 블록으로, 조건 점프나 보통 문장이면 바로 아래 블록으로도.

블록과 CFG

지역 최적화 · 단계별 시연

한 블록을 아홉 번 다듬기 (슬라이드 60–77)

바뀔 줄이 주황으로 표시된다. 그 변화가 어떤 최적화인지 고르면 적용된다. 한 최적화가 다음 최적화의 기회를 만드는 모습을 본다.

노트 11/2 최적화 노트 §4

  1. 손으로 할 때
  2. 주황 줄과 오른쪽의 "바뀔 모습"을 비교한다.
  3. 연산이 싼 것으로 바뀌었나(대수), 이름이 다른 이름이나 상수로 바뀌었나(전파), 상수끼리 계산했나(접기), 같은 식을 재사용했나(CSE), 줄이 사라졌나(DCE)를 본다.
  4. 고르면 적용되고, 블록이 끝에서 g만 쓴다는 사실은 그대로다.

피홀 · 단계별 시연

피홀: 두 줄짜리 창을 밀며 규칙 맞추기

창 안의 명령 한두 개가 규칙의 왼쪽과 맞으면 오른쪽으로 바꾼다. 바뀐 자리는 다시 본다. 한 바퀴 동안 아무것도 안 바뀌면 끝이다.

노트 11/2 최적화 노트 §3.3

명령 (주황 = 창)

규칙

  1. R1: move $a $b; move $b $a → move $a $b
  2. R2: addiu $a $a i; addiu $a $a j → addiu $a $a i+j
  3. R3: addiu $a $b 0 → move $a $b
  4. R4: move $a $a → (지움)
  5. 조건: 지울 둘째 명령에 레이블이 없어야 한다(점프 대상이 아님)

피홀 · 두 방법 비교

점프 대상 조건을 빼면 무엇이 깨지나

같은 루프에 같은 규칙 R1을 쓴다. 왼쪽은 레이블을 확인하고, 오른쪽은 확인하지 않는다. 그다음 두 프로그램을 나란히 실행한다.

노트 11/2 최적화 노트 §3.3 보충

왼쪽: 레이블 확인함

오른쪽: 레이블 확인 안 함

상수 전파의 반복 절차

규칙과 맞지 않는 칸을 하나 찾아 고치고, 처음부터 다시 비교한다. 맞지 않는 칸이 없으면 끝이다.

노트 11/2 최적화 노트 §5.3–§5.4

전역: 상수 전파 · 단계별 시연

루프가 있는 CFG에서 상수 전파 (슬라이드 50)

되돌아가는 화살표 때문에 A := 2 * X의 in을 정하려면 아직 계산하지 않은 칸이 필요하다. ⊥로 시작하면 이 순환을 끊고 시작할 수 있다.

노트 11/2 최적화 노트 §5.2–§5.4

전역: 상수 전파 · 두 방법 비교

⊥로 시작할 때와 ⊤로 시작할 때

같은 루프를 같은 순서로 돈다. 왼쪽은 나머지 칸을 ⊥로, 오른쪽은 ⊤로 시작한다. 둘 다 규칙과 맞는 상태에서 멈추지만 답이 다르다.

노트 11/2 최적화 노트 §5.4

왼쪽: 나머지 칸 = ⊥

오른쪽: 나머지 칸 = ⊤

전역: 생존성 · 절차

생존성의 반복 절차

상수 전파와 같은 틀이다. 다른 점은 정보가 뒤에서 앞으로(out → in) 흐르고, 값이 true/false 둘뿐이라는 것이다.

노트 11/2 최적화 노트 §6.2–§6.4

순서도

CFG와 칸 값 (X 하나)

전역: 생존성 · 단계별 시연

변수 여러 개의 생존 집합 (레지스터 할당 슬라이드 12)

변수마다 true/false를 따로 두는 대신, 지점마다 "살아 있는 변수의 집합"을 적는다. 아래에서 위로 훑는 것을 바뀌는 것이 없을 때까지 되풀이한다.

노트 11/2 최적화 노트 §6.4, 레지스터 할당 노트 §2.1

  1. 손으로 할 때
  2. out(s) = 후속 문장들의 in을 합친 것 (끝 문장은 b만).
  3. in(s) = (out(s)에서 s가 쓰는 변수를 뺀 것) ∪ s가 읽는 변수.
  4. 맨 아래 문장부터 위로 올라가며 계산한다. 한 바퀴 동안 바뀐 칸이 없으면 끝.
