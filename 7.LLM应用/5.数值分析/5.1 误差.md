# 5.1 误差

> [!important] 🔑 核心公式速记（必背）
> **① 绝对/相对误差**（$x$ 真值，$x^*$ 近似值）：
> $$e^* = x^* - x,\qquad e_r^* = \frac{e^*}{x^*},\qquad |e^*|\le\varepsilon^*,\quad |e_r^*|\le\varepsilon_r^*$$
> **② 有效数字 ⟺ 绝对误差限**（$x^*=\pm10^m(a_1+a_2\cdot10^{-1}+\cdots)$，$a_1\ne0$，$n$ 位有效数字）：
> $$|e^*|\le\frac12\times10^{m-(n-1)},\qquad a_1\times10^m\le|x^*|<(a_1+1)\times10^m$$
> **③ 定理 1（有效数字 ↔ 相对误差限）**：
> $$n\text{ 位有效数字}\Rightarrow\varepsilon_r^*=\frac{1}{2a_1}\times10^{-(n-1)};\qquad \varepsilon_r^*=\frac{1}{2(a_1+1)}\times10^{-(n-1)}\Rightarrow\text{至少 }n\text{ 位}$$
> （正向 $|x^*|$ 在分母取**下界 $a_1$**，反向在乘数取**上界 $a_1+1$**；推导见定理 1 折叠块。）
> **④ 数值运算四原则**：避免**相近数相减**（有效数字大量损失，如一元二次求根）、避免**大数除小数**、防止**大数吃小数**、保证**数值稳定性**（选误差不被放大的算法/递推方向）。

> [!note] 考情速览
> - 误差·有效数字·数值稳定性（绪论这章）历年真题 **0/5，未单独命题**，判定 🔶 **眼熟即可**。
> - 卷面里出现的"误差"字样，实际多是 **条件数**（4/5）或 **插值/求积余项**（4/5）。复习时间应优先给那些。
> - 但本章的**思想**（相近数相减、稳定性、有效数字）会**渗透**进其它大题，理解即可，不必死磕例题。

## 误差来源与分类

- **模型误差**：用数学模型近似实际问题时引入的误差
- **观测误差**：测量原始数据时引入的误差
- **截断误差**：用有限项近似无穷过程时引入的误差
- **舍入误差**：机器只能保留有限位数字，对中间结果取舍引入的误差

**舍入误差举例**：

$$R = \pi - 3.14159 = 0.0000026\cdots$$

**截断误差举例**：求 $\mathrm{e}^x$。其泰勒展开为无穷级数，而计算机只能进行有限次计算：

$$\mathrm{e}^x = 1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!} + \cdots$$

$$S_n(x) = 1 + x + \frac{x^2}{2!} + \cdots + \frac{x^n}{n!}$$

只取前 $n+1$ 项，余下部分就是截断误差：

$$\mathrm{e}^x - S_n(x) = \frac{x^{n+1}}{(n+1)!}\,\mathrm{e}^{\theta x},\quad 0 < \theta < 1$$

## 绝对误差与绝对误差限

**绝对误差**：

$$e^* = x^* - x$$

其中 $x^*$ 为准确值 $x$ 的近似值。

**绝对误差限** $\varepsilon^*$ 是 $|e^*|$ 的一个上界。例如毫米尺测量长度 $x$，最小刻度 1 mm，则

$$|765 - x| \le 0.5$$

## 相对误差与相对误差限

**相对误差**：

$$e_r^* = \frac{e^*}{x},\quad \text{或}\quad e_r^* = \frac{e^*}{x^*}$$

其中 $x^*$ 为准确值 $x$ 的近似值。

**相对误差限** $\varepsilon_r^*$ 是 $|e_r^*|$ 的一个上界。相对误差限表达"能差出多少"的直观感觉，有效数字也将与其相关。

例如 $x = 10 \pm 1$，$y = 1000 \pm 5$：

$$\frac{\varepsilon_x^*}{|x|} = 10\%,\qquad \frac{\varepsilon_y^*}{|y|} = 0.5\%$$

绝对误差 $y$ 更大，但相对误差 $y$ 更小。

## 定理 1：有效数字与相对误差限

设近似数 $x^*$ 表示为

$$x^* = \pm 10^m \times \left(a_1 + a_2 \times 10^{-1} + \cdots + a_l \times 10^{-(l-1)}\right) \tag{2.1}'$$

其中 $a_1 \ne 0$。

- 若 $x^*$ 具有 $n$ 位有效数字，则其相对误差限为

$$\varepsilon_r^* = \frac{1}{2a_1} \times 10^{-(n-1)}$$

> 已知一个测量结果，计算其相对误差限。回答：测出来的东西，最多能差多少？

- 反之，若 $x^*$ 的相对误差限为

$$\varepsilon_r^* = \frac{1}{2(a_1+1)} \times 10^{-(n-1)}$$

则 $x^*$ 至少具有 $n$ 位有效数字。

> 已知可容忍的相对误差限，获得一个测量结果的技术要求。回答：要精确到多少，得测多准？

> [!abstract]- 为什么一个用 $a_1$、一个用 $a_1+1$？（点开看推导）
> **根子**：$|x^*|$ 不是定值，而是被首位数字夹在一个区间里——
> $$a_1\times 10^m \;\le\; |x^*| \;<\; (a_1+1)\times 10^m$$
> 即 $a_1$ 是**下界**、$a_1+1$ 是**上界**。再加一条：$n$ 位有效数字 $\Leftrightarrow$ 绝对误差限 $|e^*|\le\frac12\times10^{m-n+1}$（只跟 $n$ 有关）。两个公式都取"最坏情况"，但 $|x^*|$ 一次当分母、一次当乘数，所以一次取小、一次取大：
>
> **① 正向（有效数字 ⇒ 相对误差限）**：$\varepsilon_r^*=\dfrac{|e^*|}{|x^*|}$，$|x^*|$ 在**分母**。要让误差限**尽量大**，分母取**最小 $=a_1\times10^m$**：
> $$\varepsilon_r^*\le\frac{\frac12\times10^{m-n+1}}{a_1\times10^m}=\frac{1}{2a_1}\times10^{-(n-1)}$$
>
> **② 反向（相对误差限 ⇒ 保证 $n$ 位有效数字）**：$|e^*|=\varepsilon_r^*\times|x^*|$，$|x^*|$ 在**乘数**位。要在**最坏情况（$|x^*|$ 最大 $=(a_1+1)\times10^m$）下仍达标**：
> $$|e^*|<\frac{1}{2(a_1+1)}\times10^{-(n-1)}\cdot(a_1+1)\times10^m=\frac12\times10^{m-n+1}\ ✓$$
> 若这里偷用 $a_1$，则 $|e^*|$ 最大到 $\frac{a_1+1}{2a_1}\times10^{m-n+1}>\frac12\times10^{m-n+1}$，**超标，保证不了 $n$ 位**。
>
> **一句话**：$|x^*|$ 在分母 → 取下界 $a_1$；在乘数 → 取上界 $a_1+1$。
>
> > [!warning] 别和例题搞混
> > 下面**例 2**（已知容差求几位有效数字）用的是 $\frac{1}{2a_1}$ 而非 $\frac{1}{2(a_1+1)}$，并不矛盾：
> > - **$n$ 由你自己挑**（"我取 3 位，误差最多多少？" 及其反用）→ 用 $\dfrac{1}{2a_1}$（例 1、例 2，正向公式够紧）。
> > - **$\varepsilon_r^*$ 被别人给定、要倒推保证几位**→ 才用 $\dfrac{1}{2(a_1+1)}$（兜 $|x^*|$ 最大的最坏情况）。
> >
> > 实战："求几位有效数字"的题绝大多数用 $\frac{1}{2a_1}$ 解不等式即可；$a_1+1$ 那式是定理里更严的**充分条件**，懂含义即可，很少直接套。

### 例 1：求相对误差限（已知 $a_1$ 和 $n$ 求 $\varepsilon$）

测量 1 块板长 954 cm，相对误差是多少？

**解法一（按定义）**：测量结果是 954 cm，没有读到毫米，最小刻度是 1 cm。绝对误差限不超过半个单位，所以绝对误差限为 0.5 cm。

$$\varepsilon_r^* = \frac{0.5}{954} < 0.0525\%$$

可取为 0.053%。

**解法二（用定理 1）**：954 为 3 位有效数字，故 $n = 3$，$a_1$ 是第一位数字 9。

$$\varepsilon_r^* = \frac{1}{2 \times 9} \times 10^{-(3-1)} = 0.056\%$$

### 例 2：求需要的有效数字位数（定理 1 反过来用，已知 $a_1$ 和 $\varepsilon$ 求 $n$）

取 $\sqrt{70}$，要相对误差限小于 0.1%，要取几位有效数字？

**解**：先定出 $a_1$。$\sqrt{70}$ 在 8 和 9 之间，取 $a_1 = 8$（最坏情况，分母最小、误差限最大）：

$$\varepsilon_r^* = \frac{1}{16} \times 10^{-(n-1)} < 0.001$$

求解 $n$，$n = 3$ 时即可满足不等式。所以取 3 位有效数字，$\sqrt{70} \approx 8.37$。

## 误差的核心问题

数值算法使用的时候，真实值 $x$ 是不知道的：

$$e^* = x^* - x$$

所有的数值算法都要解决"无法得知真值的情况下怎么估计误差"。能够解决这个问题，才算得上合格的数值算法。

## 数值稳定性

**稳定性**：用一个算法进行计算，初始误差会在计算中传播。如果传播会造成误差增长，则算法不稳定；反之则稳定。

稳定性在"迭代"算法中尤其重要，也是数值分析作为"数学"属性的体现。

### 不稳定的迭代

计算积分

$$I_n = \int_0^1 \frac{x^n}{x+5}\,\mathrm{d}x,\quad n = 0, 1, \cdots, 8$$

构造递推关系：

$$I_n + 5I_{n-1} = \int_0^1 \frac{x^n + 5x^{n-1}}{x+5}\,\mathrm{d}x = \int_0^1 x^{n-1}\,\mathrm{d}x = \frac{1}{n}$$

得正向递推式：

$$I_n = \frac{1}{n} - 5I_{n-1},\quad n = 1, \cdots, 8$$

取 4 位有效数字，$I_0 = 0.1823$，逐项递推：

| $n$ | $I_n$（正向递推，4 位有效数字） | $I_n$（精确值） |
|----|------------------|--------------|
| 0  | 0.1823           | 0.182322     |
| 1  | 0.0885           | 0.0883922    |
| 2  | 0.0575           | 0.0580389    |
| 3  | 0.045833         | 0.0431387    |
| 4  | 0.020833         | 0.0343063    |
| 5  | 0.095833         | 0.0284684    |
| 6  | -0.3125          | 0.0243249    |
| 7  | 1.705357         | 0.0212326    |
| 8  | -8.40179         | 0.0188369    |

每步把误差放大 5 倍，误差越来越大，结果完全失真。

### 稳定的迭代

把同一个递推关系反过来解：

$$I_{n-1} = \frac{1}{5}\left(\frac{1}{n} - I_n\right),\quad n = 8, 7, \cdots, 1$$

取 4 位有效数字，$I_8 = 0.01884$，反向递推：

| $n$ | $I_n$（反向递推） | $I_n$（精确值） |
|----|--------------|--------------|
| 0  | 0.182321557  | 0.182322     |
| 1  | 0.088392216  | 0.0883922    |
| 2  | 0.05803892   | 0.0580389    |
| 3  | 0.043138733  | 0.0431387    |
| 4  | 0.034306334  | 0.0343063    |
| 5  | 0.028468328  | 0.0284684    |
| 6  | 0.024325029  | 0.0243249    |
| 7  | 0.021232     | 0.0212326    |
| 8  | 0.01884      | 0.0188369    |

每步把误差缩小为 $1/5$，误差没有增大。同一个数学关系，递推方向不同，稳定性相反。

## 典型问题：一元二次方程

$$ax^2 + bx + c = 0,\quad a \ne 0,\ b^2 - 4ac > 0$$

求根公式：

$$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

当 $b^2 \gg 4ac$ 时，$\sqrt{b^2-4ac} \approx |b|$，分子出现**相近数相减**，损失大量有效数字，必有一个根误差很大。算法不稳定。

以

$$x^2 + 62.10x + 1.000 = 0$$

为例：

| | $x_1$ | $x_2$ |
|--|------|------|
| 精确解 | $-62.083892$ | $-0.016107237$ |
| 4 位有效数字直接代公式 | $-62.08$ | $-0.02000$ |

$x_1$ 用 $-b - \sqrt{\cdots}$（两个负向量相加）算得很准；$x_2$ 用 $-b + \sqrt{\cdots}$（相近数相减），有效数字只剩一位。

### 算法改良

避开相近数相减：分子统一取同号相加，另一个根用韦达定理 $x_1 x_2 = c/a$ 反求。

$$x_1 = \frac{-b - \operatorname{sign}(b)\sqrt{b^2 - 4ac}}{2a},\qquad x_2 = \frac{c}{a x_1}$$

这样 $x_1$ 永远是两同号数相加，$x_2$ 由乘除得到，是一定稳定的算法。

## 数值运算的几条原则

- **避免"大数"除以"小数"**：商会被放大，输入的小误差被放大成大误差。
- **避免相近数相减**：相近数字相减会造成大量有效数字损失。一元二次方程求根就是这个例子。
- **防止大数吃小数**：计算机处理浮点数会对阶，小数被舍掉。求和顺序不同，结果不同：

$$123 + \underbrace{0.01 + 0.01 + \cdots + 0.01}_{100\ \text{项}} \ne \underbrace{0.01 + 0.01 + \cdots + 0.01}_{100\ \text{项}} + 123$$

- **减少运算次数**：每步运算都可能引入舍入误差，运算次数越少，误差累积越少。
- **保证数值稳定性**：选择误差不被放大的算法与递推方向。
