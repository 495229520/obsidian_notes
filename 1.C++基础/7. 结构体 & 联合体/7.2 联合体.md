# 7.2 联合体

联合体（union）是一种特殊的数据类型，它允许在相同的内存位置存储不同的数据类型。联合体是 C++ 最古老的特性之一，旨在一种节省内存的方式。

---

## union 概述

### 核心概念

- 联合体（union）的**非静态数据成员共享同一块存储**
- 联合体的大小**至少能容纳最大成员**，实际大小还要考虑对齐和尾部填充
- 同一时刻**至多有一个活动成员**，也可能没有活动成员；活动与否由成员对象的生命周期决定

### 内存对比

下面假设 `short/int/double` 的大小和自然对齐分别为 2/4/8 字节，`char` 为 1 字节，且没有额外对齐或打包设置。

```text
struct MyStruct          union MyUnion
┌─────────────┐          ┌─────────────┐
│   short s   │          │             │
├─────────────┤          │  共享内存   │
│   int i     │          │  (8 bytes)  │
├─────────────┤          │             │
│  double d   │          └─────────────┘
└─────────────┘
  (16 bytes)               (8 bytes)
```

### union 大小与对齐

常见说法是"union 的大小等于最大成员大小"，但更准确的说法是：
union 的大小至少能容纳最大的非静态数据成员，并且要满足整体对齐；常见自然布局会向上补齐到整体对齐的整数倍。

```text
sizeof(U) >= 最大非静态数据成员的 sizeof
```

没有额外对齐或打包设置时，union 的整体对齐通常取各成员中最严格的那个。`alignas` 可以提高整体对齐，不能把下面的常见计算方式当成无条件的标准公式：

```text
常见自然布局：alignof(U) = max(各非静态数据成员类型的 alignof)
```

以下示例及三张图沿用 `int` 大小、对齐均为 4，`char` 大小、对齐均为 1 的自然布局假设：

```cpp
union U {
    int i;        // sizeof = 4, alignof = 4
    char buf[5];  // sizeof = 5, alignof = 1
};
```

`char buf[5]` 的大小确实是 5，也已经能覆盖 `int` 的 4 字节空间。但问题不在"能不能装下 `int`"，而在**下一个 `union` 对象的起始地址是否还能满足 `int` 的 4 字节对齐**。

单个 `U` 的内部可以这样理解：

![[图片/1.C++基础/7. 结构体 & 联合体/1_7_2_1.svg]]

后面的 `pad` 不是为了让 `int` 塞进 `buf[5]`，而是为了让数组中的下一个 `U` 仍然从满足对齐的位置开始。

如果错误地假设 `sizeof(U) == 5`：

![[图片/1.C++基础/7. 结构体 & 联合体/1_7_2_2.svg]]

所以编译器会把 `sizeof(U)` 从 5 向上补齐到 4 的倍数，也就是 8：

![[图片/1.C++基础/7. 结构体 & 联合体/1_7_2_3.svg]]

因此：

```text
sizeof(U) == 8
alignof(U) == 4
```

> [!note]
> `union` 也可能有 padding，只是它通常不是成员之间的 padding，而是**尾部 padding**。尾部 padding 的作用是保证 `union` 数组中的每个元素都满足整体对齐要求。

## 基本用法

```cpp
#include <iostream>

union Value {
    int intValue;
    double doubleValue;
    char charValue;
};

int main() {
    Value myValue;

    // 存储一个整数
    myValue.intValue = 42;
    std::cout << "Integer value: " << myValue.intValue << std::endl;

    // 存储一个浮点数（覆盖整数）
    myValue.doubleValue = 3.14159;
    std::cout << "Double value: " << myValue.doubleValue << std::endl;

    // 存储一个字符（覆盖浮点数）
    myValue.charValue = 'A';
    std::cout << "Character value: " << myValue.charValue << std::endl;

    return 0;
}
```

> 在这个例子中，给另一个标量成员赋值会切换活动成员；再读取之前的成员是未定义行为。“用于类型双关”不能让这种读取在标准 C++ 中变合法。

## 主要用途

### 1. 节省内存

当你确定在任何给定时间只需要存储一种类型的数据时，`union` 可以节省内存：

```cpp
union Data {
    int i;        // 4 bytes
    float f;      // 4 bytes
    char str[20]; // 20 bytes
};
// 假设 int/float 大小与对齐均为 4，采用自然布局：sizeof(Data) 通常为 20
```

### 2. 类型转换（类型双关）

写入 `union` 的 `float` 成员再读取 `int` 成员，是常见的类型双关写法，但不是标准 C++ 的可移植做法。即使两个类型大小相同，也不能任意读取非活动成员；GCC 将部分 union 类型双关作为扩展支持，不能把该扩展当成标准保证。

数值转换用 `static_cast<int>(value)`。若要观察对象的表示字节，可以复制到 `unsigned char` 数组：

```cpp
#include <cstring>
#include <iostream>

int main() {
    float value = 3.14f;
    unsigned char bytes[sizeof value];
    std::memcpy(bytes, &value, sizeof value);

    for (unsigned char byte : bytes) {
        std::cout << std::hex << static_cast<unsigned int>(byte) << ' ';
    }
    std::cout << '\n';
}
```

输出取决于浮点表示和字节序，例如采用 IEEE 754 binary32 的常见小端环境会输出 `c3 f5 48 40`。这个例子观察字节，不把它们解释为另一类型的值。

C++20 的 `std::bit_cast<To>(from)` 可用于复制表示并得到另一类型的值，要求源、目标同大小且都可平凡复制；目标位模式还必须对应合法值。`memcpy` 同样不能把任意字节变成任意类型的有效值。[C++20 草案：bit_cast](https://timsong-cpp.github.io/cppwp/n4861/bit.cast)、[GCC：union 类型双关扩展](https://gcc.gnu.org/onlinedocs/gcc/Optimize-Options.html#index-fstrict-aliasing)。

## 注意事项

### 1. 活动成员

- 活动成员是生命周期已经开始且尚未结束的非静态数据成员；同一时刻至多有一个。
- 简单标量成员常可通过赋值开始生命周期并切换活动成员；未初始化的普通 union 可能没有活动成员。
- 一般不能读取非活动成员。有限例外是：标准布局 union 包含的标准布局结构体具有共同初始序列时，可按规则读取该序列中的成员；这不允许任意 `int/float` 重解释。

C++11 起可在 union 中声明 `std::string` 等非平凡类型，但相关默认特殊成员函数可能被删除，切换时需要正确构造和析构。不能把尚未构造的 string 当作普通对象直接赋值。规则见 [C++17 草案：活动成员与生命周期](https://timsong-cpp.github.io/cppwp/n4659/class.union)、[共同初始序列例外](https://timsong-cpp.github.io/cppwp/n4659/class.mem#23)。

### 2. 初始化规则

- 聚合初始化不能同时初始化多个 union 成员。
- 下面没有成员默认初始化器的简单 union，`{10}` 初始化首成员；C++20 可用指定初始化器选择其他成员。有构造函数的 union 还可以由构造函数选择要初始化的成员。

```cpp
union MyUnion {
    int i;
    float f;
};

MyUnion u1 = {10};       // 初始化 i
MyUnion u2 = {.f = 3.14f}; // C++20: 初始化 f
```

### 3. 访问规则

- 切换活动成员会结束原活动成员的生命周期。原成员不能再当作仍然存活的对象读取，不能仅理解为“值变得不可预测”。
- union 本身不记录当前类型。程序需要维护活动成员与标签的一致性，或使用 `std::variant` 管理。

## 内存访问注意事项

读取 `union { int i; char c; }` 的 `c` 并不能自动绕过活动成员规则。若想观察整数的字节序，应读取复制出来的表示字节：

```cpp
#include <climits>
#include <cstdint>
#include <cstring>

static_assert(CHAR_BIT == 8);
std::uint32_t value = 0x12345678;
unsigned char bytes[sizeof value];
std::memcpy(bytes, &value, sizeof value);

// 纯小端：bytes 为 78 56 34 12
// 纯大端：bytes 为 12 34 56 78
```

复制后的字节数组（上述 8 位字节、小端环境）：

```text
地址:  低 ───────────────────> 高
内存:  [78] [56] [34] [12]
        ↑
        bytes[0]
```

## 匿名联合体

匿名联合体（anonymous union）是一种特殊的联合体，它**没有名字**，且其成员可以直接在包含它的作用域中访问：

```cpp
struct Variant {
    enum Type { INT, FLOAT, STRING } type;

    union {  // 匿名联合体
        int intValue;
        float floatValue;
        char stringValue[20];
    };
};

int main() {
    Variant v;
    v.type = Variant::INT;
    v.intValue = 42;  // 直接访问，无需 union 名称

    return 0;
}
```

**匿名联合体的规则**：
- 其成员被注入到外围作用域
- 只能包含非静态数据成员
- 不能有成员函数
- 不能有 `private` 或 `protected` 成员

---

## std::variant（C++17 推荐）

在 C++17 中，推荐使用 `std::variant` 替代 `union`：

```cpp
#include <variant>
#include <iostream>

int main() {
    // 定义一个可以存储 int、float 或 double 的 variant
    std::variant<int, float, double> myVariant;

    // 存储一个 int
    myVariant = 10;
    std::cout << "int: " << std::get<int>(myVariant) << std::endl;

    // 存储一个 float
    myVariant = 3.14f;
    std::cout << "float: " << std::get<float>(myVariant) << std::endl;

    // 存储一个 double
    myVariant = 2.71828;
    std::cout << "double: " << std::get<double>(myVariant) << std::endl;

    return 0;
}
```

### std::variant 的优势

- **类型安全**：访问错误类型会抛出 `std::bad_variant_access` 异常
- **可以使用 `std::visit`** 进行模式匹配
- **存储当前活动类型**：知道当前存储的是哪种类型
- 可以使用 `std::holds_alternative<T>(v)` 检查当前类型
- 可以使用 `std::get_if<T>(&v)` 安全地获取值

```cpp
// 检查当前类型
if (std::holds_alternative<int>(myVariant)) {
    std::cout << "存储的是 int" << std::endl;
}

// 安全访问
if (auto* val = std::get_if<float>(&myVariant)) {
    std::cout << "Float value: " << *val << std::endl;
}
```

## union vs struct vs variant

| 特性 | union | struct | std::variant |
|------|-------|--------|--------------|
| 内存共享 | ✓ | ✗ | ✓ |
| 类型安全 | ✗ | ✓ | ✓ |
| 知道活动成员 | ✗ | N/A | ✓ |
| C++ 版本要求 | C++98 | C++98 | C++17 |

---

## 关键要点

1. **内存共享**：联合体的非静态数据成员共享同一块存储
2. **大小**：联合体大小至少能容纳最大成员，实际大小还要考虑对齐，可能包含尾部 padding
3. **活动成员**：同一时刻至多有一个；读取时要遵守生命周期规则
4. **类型双关**：任意读取非活动成员不是标准 C++ 的通用许可；观察表示可复制到字节数组
5. **推荐使用 std::variant**：C++17 提供了类型安全的替代方案
