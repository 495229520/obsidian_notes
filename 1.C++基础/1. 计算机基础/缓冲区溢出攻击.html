缓冲区溢出 · char buf[8]; strcpy(buf, src)

strcpy 不做长度检查——看它如何一路写坏 saved ebp 和返回地址，最终让 ret 跳飞　·　← → 切换，空格 播放

sum 的栈帧（上 = 高地址，下 = 低地址；每格 4 字节）
数据从 buf（低地址）开始写，越界后向高地址方向蔓延 → 先毁 saved ebp，再毁返回地址。
源字符串 src（15 个 'A' + 结尾 '\0'，共 16 字节，远超 buf 的 8 字节）：
// 正确写法：有界拷贝，杜绝 strcpy
// ✗ char buf[8]; strcpy(buf, src);
std::string s = src; // 自动扩容，不会溢出
snprintf(buf, sizeof buf, "%s", src); // 有界，超出即截断
