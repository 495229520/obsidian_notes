符号解析与重定位 · 链接器如何把 U 连到 D

多个 .o 各自留着「未定义」符号，链接器负责把它们对上定义、再修正地址　·　← → 切换，空格 播放

file1.o 目标文件
// file1.c int gdata = 999;
nm file1.o
Dgdata.data 已定义
file2.o 目标文件
// file2.c extern int gdata; int a = gdata; int main(){ printf(...); }
nm file2.o
Tmain.text 已定义
Da.data 已定义
Ugdata未定义 → 待解析
Uprintf未定义 → 待解析
libc.so 动态库
// C 标准库 … 大量函数定义 …
nm -D libc.so
Tprintf.text 已定义
// file2.o 里引用 gdata 的指令（重定位前后）
mov eax, [0x00000000] ; gdata 地址未知（占位 0）
mov eax, [0x00601020] ; ✓ 修正为 gdata 的最终地址
// call printf 同理
call 0x00000000 ; printf 地址未知
call 0x004010a0 ; ✓ 指向 libc 的 printf
