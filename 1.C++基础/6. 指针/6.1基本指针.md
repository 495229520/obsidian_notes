# 6.1 基本指针

## 一、指针基础

### 1. 内存地址与指针
计算机内存中每个字节都有唯一的地址编号。C/C++ 通过指针直接操作内存，让程序运算更加高效，但这种操作有危险性，现已逐渐被安全指针或引用等手段替代。

### 2. 指针的本质
指针是一种**存储内存地址的变量**，通过它可以间接访问该地址上的数据。

- `p`：指针变量中存储的地址
- `*p`：解引用，获取该地址中存放的值
- `&p`：指针变量自身在内存中的地址

### 3. 指针的声明
```cpp
// 推荐：类型与 * 放在一起
int* a;
int* b;

// 不推荐（容易误解）
int *a;
int *b;
```

### 4. 指针的大小
- **32 位系统**：指针占用 4 字节
- **64 位系统**：指针占用 8 字节

同一系统下，`char*`、`int*`、`double*` 等所有指针类型的大小均相同，因为它们存储的都是内存地址，只需足够表示系统最大内存的位数即可。

```cpp
int* ptr;
std::cout << sizeof(ptr) << std::endl;  // 32位：4，64位：8
```

## 二、指针的基本操作

### 1. 取地址与解引用
```cpp
int a = 1000;
int* ptr = &a;      // & 取地址

std::cout << *ptr;  // * 解引用，输出 1000
*ptr = 2000;        // 通过指针修改值
std::cout << a;     // 输出 2000
```

### 2. 数组名与指针
数组名在多数表达式中会退化为指向首元素的指针。

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int* ptr = arr;      // arr 退化为 &arr[0]
int* ptr2 = &arr[0]; // 等价于上一行

// 下标访问的本质：arr[i] 等价于 *(arr + i)
std::cout << *arr;         // arr[0] 的值，即 1
std::cout << *(arr + 1);   // arr[1] 的值，即 2

// 数组名与指针的关键区别
std::cout << sizeof(arr);  // 整个数组大小：5 * sizeof(int)
std::cout << sizeof(ptr);  // 指针大小：4 或 8
```

### 3. 数组的遍历
```cpp
for (int i = 0; i < 5; i++) {
    std::cout << arr[i] << std::endl;
}
```

## 三、动态内存分配

### 1. 使用 `new` 和 `delete`
```cpp
// 动态分配单个对象
int* p = new int(5);  // 分配并初始化为 5
delete p;             // 使用后必须释放

// 动态分配数组
int* pArr = new int[5];
delete[] pArr;         // 正确：数组必须用 delete[]
// delete pArr;        // 错误！数组必须用 delete[]
```

> **注意**：`new int[5]` 分配的内存必须用 `delete[]` 释放，而不是 `delete`。

### 2. `new` 的原理
- `new` 本质调用 `operator new`，底层调用 `malloc`
- `delete` 本质调用 `operator delete`，底层调用 `free`

### 3. 内存泄漏与悬空指针

**内存泄漏**：动态分配的内存地址被覆盖，导致原内存永远无法释放。

```cpp
int* p = new int[5];
p = new int[7];  // 内存泄漏！原来 5 个 int 的空间未释放就被覆盖
```

**悬空指针**：指针仍保存某块内存的地址，但该内存已被释放。

```cpp
int* p = new int(10);
delete p;
// p 仍保存旧地址，但对应内存已释放，此时 p 是悬空指针
```

### 4. Modern C++ 替代方案
手动 `new[]` / `delete[]` 容易出错。Modern C++ 应优先使用标准容器或智能指针：

```cpp
std::array<int, 100> scores{};                  // 编译期固定大小
std::vector<int> scores2(100);                  // 运行期动态大小
auto scores3 = std::make_unique<int[]>(100);    // 确需独占动态数组时
```

使用上述方案后无需手动 `delete[]`，资源会自动释放。

## 四、常量指针与指针常量

### 1. 区分方法
**记忆技巧**：`const` 修饰其右边紧邻的内容。

### 2. 常量指针（Pointer to const）
指向常量的指针：**不能通过指针修改值**，但指针本身可以改变指向。

```cpp
const int* ptr;
// 或
int const* ptr;

int a = 1000, b = 2000;
const int* p = &a;
// *p = 2000;   // 错误！不能通过 p 修改值
p = &b;          // 正确，可以改变指向
```

### 3. 指针常量（Const pointer）
指针本身是常量：**不能改变指向**，但可以通过指针修改值。

```cpp
int a = 1000;
int* const p = &a;
*p = 2000;       // 正确，可以修改值
// p = &b;       // 错误！不能改变指向
```

### 4. 常量指针常量
既不能改变指向，也不能通过指针修改值。

```cpp
const int a = 1000;
const int* const p = &a;
// *p = 2000;   // 错误
// p = &b;      // 错误
```

### 5. 总结表格

| 声明方式 | 能否修改指向 | 能否通过指针修改值 |
|----------|:---------:|:-------------:|
| `int* ptr` | ✓ | ✓ |
| `const int* ptr` | ✓ | ✗ |
| `int* const ptr` | ✗ | ✓ |
| `const int* const ptr` | ✗ | ✗ |

## 五、指针数组与数组指针

> [!warning] 易错点
> `[]` 的优先级高于 `*`，没有括号时先和数组结合。先判断"本质是数组"还是"本质是指针"。

### 1. 指针数组：数组中存放指针
```cpp
int a = 10, b = 20;
int* arr[2] = { &a, &b };    // arr 是数组，每个元素是 int*

arr[0];      // 类型 int*，值 &a
*arr[0];     // 类型 int，值 10
```

`int* arr[5]` 的本质是数组，表示 `arr` 有 5 个元素，每个元素都是 `int*`。

### 2. 数组指针：指向数组的指针
```cpp
int a[5] = {1, 2, 3, 4, 5};
int (*p)[5] = &a;             // p 是指针，指向包含 5 个 int 的数组

(*p)[0];  // 访问 a[0]
(*p)[1];  // 访问 a[1]
```

`int (*p)[5]` 的本质是指针：括号让 `*p` 先结合，表示 `p` 是指针；`[5]` 说明指向的是包含 5 个 `int` 的数组。

### 3. 对比总结

| 声明 | 本质 | 含义 |
|------|:---:|------|
| `int* arr[5]` | 数组 | 指针数组 |
| `int (*p)[5]` | 指针 | 数组指针 |

> [!tip] 记忆方法
> `int* arr[5]` → 先读 `arr[5]`，`arr` 是数组。
> `int (*p)[5]` → 先读 `*p`，`p` 是指针。

### 4. 数组名、指针与解引用
```cpp
int a[3] = {10, 20, 30};
int* p = a;  // a 退化为 &a[0]

p;          // 地址，等价于 &a[0]
*p;         // 值，等价于 a[0]，结果是 10
p + 1;      // 地址，等价于 &a[1]
*(p + 1);   // 值，等价于 a[1]，结果是 20
```

解引用 `*p` 得到的是地址中存放的值，不是地址本身。

```cpp
std::cout << &a[0] << std::endl;  // a[0] 的地址
std::cout << *a << std::endl;     // a[0] 的值，即 10
std::cout << p[1] << std::endl;   // a[1] 的值，即 20
std::cout << sizeof(a) << std::endl; // 整个数组大小：3 * sizeof(int)
std::cout << sizeof(p) << std::endl; // 指针大小：4 或 8
```

## 六、多维数组

### 1. 内存布局
数组的本质是连续的内存区域。多维数组在底层仍然是连续的空间。

```cpp
int test[2][5] = {
    {1001, 1002, 1003, 1004, 1005},
    {2001, 2002, 2003, 2004, 2005}
};
```

**一维数组 `int a[10]`：**

| a[0] | a[1] | a[2] | a[3] | a[4] | a[5] | a[6] | a[7] | a[8] | a[9] |

**二维数组 `int a[2][5]`（行优先）：**

| a[0][0] | a[0][1] | a[0][2] | a[0][3] | a[0][4] | a[1][0] | a[1][1] | a[1][2] | a[1][3] | a[1][4] |

### 2. 多维数组与指针
```cpp
int (*ptest)[5] = test;

std::cout << test[1][4];   // 2005
std::cout << ptest[1][4];  // 2005
```

> [!warning] 二维数组不是 `int**`
> `int test[2][5]` 的类型是"包含 2 个 `int[5]` 的数组"。`test` 退化为指向第一行的指针，类型是 `int (*)[5]`，**不是** `int**`。
> ```cpp
> int (*p)[5] = test;  // 正确
> // int** pp = test;  // 错误！
> ```

虽然 `test`、`&test[0]`、`&test[0][0]` 的地址值可能相同，但类型不同，指针运算的步长也不同：

```cpp
test + 1;         // 跳过一整行，即 5 个 int
&test[0][0] + 1;  // 只跳过 1 个 int
```

## 七、进阶：指针与汇编

### 1. 指针访问的汇编实现
```asm
; ptrA = &a[0]
mov     dword ptr [ebp-28h], edx    ; ptrA 存放 a[0] 的地址

; *ptrA = 5
mov     eax, dword ptr [ebp-28h]    ; 取出 ptrA 中存放的目标地址
mov     dword ptr [eax], 5          ; 将 5 写入该地址
```

**总结**：`[ebp-28h]` 是 `ptrA` 自身的内存位置，里面存放着目标地址；通过 `[eax]` 间接寻址完成赋值。

### 2. 数组下标的汇编分析
```asm
; a[0] = 5
mov     dword ptr [ebp+ecx-1Ch], 5

; a[1] = 5
mov     eax, 4
shl     eax, 0                      ; eax = 4（偏移 1 个 int）
mov     dword ptr [ebp+eax-1Ch], 5

; a[3] = 5
mov     eax, 4
imul    ecx, eax, 3                 ; ecx = 12
mov     dword ptr [ecx], 5
```

**结论**：数组下标访问的本质是通过基地址加偏移量来计算目标内存地址。

## 关键要点

1. **指针本质**：存储内存地址的变量；`p` 是地址，`*p` 是值，`&p` 是指针自身的地址
2. **动态内存**：`new`/`delete` 配对，`new[]`/`delete[]` 配对；覆盖动态地址前必须先释放或交由 RAII 管理
3. **常量指针 vs 指针常量**：`const` 修饰谁，谁就不能变
4. **数组与指针**：数组名多数情况下退化为首元素指针；`arr[i]` 等价于 `*(arr + i)`
5. **指针数组 vs 数组指针**：`int* arr[5]` 是数组，元素是指针；`int (*p)[5]` 是指针，指向数组
6. **多维数组**：内存中连续存储；退化后指向一行，类型是 `int (*)[N]`，不是 `int**`
7. **Modern C++ 优先级**：固定大小用 `std::array`，动态大小用 `std::vector`，确需独占动态数组用 `std::unique_ptr<T[]>`
