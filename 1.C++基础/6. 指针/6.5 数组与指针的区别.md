# 6.5 数组与指针的区别

> 本节深入探讨数组与 [[6.1基本指针|指针]] 的关系与区别，补充 [[6.1基本指针]] 中关于数组指针的内容。

---

## 1 数组 vs 指针

| 特性 | 数组 | 指针 |
|------|------|------|
| **定义** | 一段**连续的内存空间**，用于存储相同类型的数据 | 一个**变量**，存储的是内存地址，可以指向任何类型的数据包括数组 |
| **内存分配** | 声明时**静态分配**内存空间 | 可以**动态分配**内存空间，如 `int* p = new int` |
| **赋值** | 数组名**不能被重新赋值**，始终代表数组的起始地址 | 指针**可以被重新赋值**，指向不同的内存空间 |
| **sizeof** | 返回整个数组的大小 | 返回指针本身的大小（4或8字节） |

---

## 2 联系

数组和指针有着密切的关系：

1. **数组名本质上是指针**：数组名可以看作是一个指向数组第一个元素的**常量指针**

2. **指针可以访问数组元素**：可以通过指针的算术运算来访问数组中的元素
   - 例如，`p` 是一个指向数组 `a` 的指针，`p + i` 指向 `a[i]`

3. **数组作为函数参数会退化为指针**：当数组作为函数参数传递时，会退化为指向数组第一个元素的指针

---

## 3 示例代码

### 3.1 sizeof 的区别

```cpp
#include <iostream>

int main() {
    int arr[5] = {1, 2, 3, 4, 5};
    int* ptr = arr;

    std::cout << "sizeof(arr) = " << sizeof(arr) << std::endl;  // 20 (5 * 4)
    std::cout << "sizeof(ptr) = " << sizeof(ptr) << std::endl;  // 4 或 8

    return 0;
}
```

### 3.2 数组名不能重新赋值

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int brr[5] = {6, 7, 8, 9, 10};

// arr = brr;  // 错误！数组名是常量，不能重新赋值

int* ptr = arr;
ptr = brr;     // 正确，指针可以重新赋值
```

### 3.3 指针访问数组元素

```cpp
int arr[5] = {1, 2, 3, 4, 5};
int* ptr = arr;

// 以下两种方式等价
std::cout << arr[2] << std::endl;   // 3
std::cout << *(ptr + 2) << std::endl; // 3
std::cout << ptr[2] << std::endl;   // 3
```

---

## 4 函数参数中的退化

```cpp
// 以下三种声明等价
void func(int arr[]);
void func(int arr[10]);
void func(int* arr);

// 数组传入函数后退化为指针，无法获取原数组大小
void printSize(int arr[]) {
    // sizeof(arr) 返回指针大小，不是数组大小
    std::cout << sizeof(arr) << std::endl;  // 4 或 8
}
```

## 5 arr vs &arr：同名不同义

这是数组与指针最容易被误解的地方：数组名 `arr` 和 `&arr` 打印出来的地址值**通常一样**，但它们的**类型完全不同**，因此指针运算的行为也完全不同。

### 5.1 类型差别

```cpp
int arr[3]{1, 2, 3};
```

- `arr` 在大多数表达式中会**衰减（decay）**为指向首元素的指针，类型是 `int*`，表示"第一个 `int` 的地址"
- `&arr` 是整个数组的地址，类型是 `int (*)[3]`，表示"一个包含 3 个 `int` 的数组对象的地址"

二者在数值上相等（都等于数组起始内存地址），但类型不同：

| 表达式 | 含义 | 类型 |
|--------|------|------|
| `arr` | 首元素地址 | `int*` |
| `&arr` | 整个数组的地址 | `int (*)[3]` |

### 5.2 指针步长的差异

类型不同，最直接的后果就是 `+1` 时跳过的距离不同。假设 `arr` 起始地址为 `0x1000`，`int` 占 4 字节：

```cpp
int arr[3]{1, 2, 3};

arr + 1    // 跳过一个 int，地址 → 0x1004
&arr + 1   // 跳过整个 int[3] 数组，地址 → 0x100C (跳过 3 × 4 = 12 字节)
```

| 表达式 | 跳过的单位 | 跳过的字节数 | 结果指向 |
|--------|-----------|-------------|---------|
| `arr + 1` | 一个 `int` | `sizeof(int)` = 4 | `arr[1]` |
| `&arr + 1` | 一个 `int[3]` 数组 | `sizeof(int[3])` = 12 | 数组末尾之后 |

这就说明：`arr` 和 `&arr` 虽然入口位置一样，但编译器被告知的"移动单位"完全不同。`arr` 的单位是 `int`，`&arr` 的单位是 `int[3]`。

### 5.3 数组指针 vs 指针数组

**数组指针**（pointer to array）是一个指针，它指向**整个数组对象**，而不是指向某个元素。注意它与**指针数组**（array of pointers）是完全不同的概念：

```cpp
int (*p)[3]  = &arr;   // 数组指针：p 是指向 int[3] 的指针
int*  p2[3];           // 指针数组：p2 是一个包含 3 个 int* 的数组
```

| 声明 | 含义 | 类型 |
|------|------|------|
| `int (*p)[N]` | 数组指针：指向 `int[N]` 的指针 | `int (*)[N]` |
| `int* p[N]` | 指针数组：包含 N 个 `int*` 的数组 | `int* [N]` |

括号在这里至关重要——`*` 先与 `p` 结合就是指针，先与 `int[N]` 结合就是数组。

### 5.4 用数组指针访问元素

数组指针必须用 `&arr` 初始化，不能用衰减后的 `arr`：

```cpp
int arr[3]{10, 20, 30};

int* q = arr;            // ✅ 普通指针，指向 arr[0]
int (*p)[3] = &arr;      // ✅ 数组指针，指向整个 arr
// int (*p)[3] = arr;    // ❌ 类型不匹配：int* 不能赋给 int (*)[3]
```

通过数组指针访问元素时，需要先解引用得到数组，再取下标：

```cpp
(*p)[0]   // 等价于 arr[0]，值为 10
(*p)[1]   // 等价于 arr[1]，值为 20
(*p)[2]   // 等价于 arr[2]，值为 30
```

`*p` 得到的是 `int[3]` 数组的引用，`(*p)[i]` 等价于 `arr[i]`。括号不能省略——`[]` 优先级高于 `*`，`*p[0]` 会被解析为 `*(p[0])`，语义完全不同。

### 5.5 直观理解

可以把 `arr` 和 `&arr` 想象成两个不同的"入口描述"：

- `arr` 是**第一个元素的入口**：你告诉编译器"从这里开始，按 `int` 为单位移动"
- `&arr` 是**整个数组这个整体的入口**：你告诉编译器"从这里开始，按 `int[3]` 为单位移动"

入口位置相同，但你声明的移动单位不同，后续所有指针运算的结果也就不同了。

### 5.6 判断标准

判断一个与数组相关的指针到底是什么，关键不是看"地址数字是多少"，而是看两个问题：

1. **它的类型是什么？**——`int*` 还是 `int (*)[N]`？
2. **对它 `+1`，跳多远？**——跳一个元素，还是跳整个数组？

这两条规则比死记"数组名等于首元素地址"更准确、更实用。

## 6 关键要点

1. **数组是静态的**：大小在编译时确定，不能改变
2. **指针是动态的**：可以指向不同的内存地址
3. **数组名是常量指针**：指向首元素，不能修改
4. **函数参数退化**：数组作为参数传递时会退化为指针
5. **sizeof 行为不同**：数组返回总大小，指针返回指针大小
6. **`arr` vs `&arr`**：数值相同但类型不同——`arr` 是 `int*`（首元素地址），`&arr` 是 `int (*)[N]`（整个数组的地址）
7. **步长差异**：`arr + 1` 跳一个元素，`&arr + 1` 跳整个数组
8. **数组指针**：`int (*p)[N] = &arr`，注意与指针数组 `int* p[N]` 区分
9. **判断标准**：不看地址数字，看类型（`int*` vs `int (*)[N]`）和 `+1` 跳多远
