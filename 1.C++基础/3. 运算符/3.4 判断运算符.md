# 判断运算符

## 判断语句概览

判断语句用于根据条件决定程序接下来执行哪一段代码。C++ 中常见的判断控制结构有：

| 语句 | 作用 | 适合场景 |
|------|------|----------|
| `if` / `else` | 根据布尔条件选择分支 | 范围判断、复杂条件判断 |
| `switch` / `case` | 根据整数、枚举等离散值选择分支 | 多个固定选项分支 |
| `goto` | 无条件跳转到标签位置 | 了解即可，现代 C++ 中应尽量避免 |

这些语句的底层本质都是：先比较条件，再根据结果跳转到不同的代码位置执行。

---

## if 语句

### 基本语法

```cpp
if (条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}
```

`else` 不是必须的，只有需要处理“条件不成立”的情况时才写。

```cpp
if (a > b) {
    std::cout << "a 更大";
}
```

### if-else 示例

```cpp
int a = 10;
int b = 20;

if (a > b) {
    std::cout << "a 更大";
} else {
    std::cout << "b 更大或二者相等";
}
```

### C++17 新语法：条件中声明变量

C++17 允许在 `if` 条件前加一个初始化语句，初始化出来的变量只在 `if-else` 语句内部有效。

```cpp
if (初始化语句; 条件) {
    // 条件成立时执行
} else {
    // 条件不成立时执行
}
```

示例：

```cpp
if (int a{}, b{}, c{}; true) {
    std::cout << a << b << c;
} else {
    std::cout << a + 1 << b + 1 << c + 1;
}
```

> [!note]
> `a`、`b`、`c` 的作用域只在这个 `if-else` 结构中，离开后就不能继续访问。

## switch 语句

### 基本语法

```cpp
switch (值) {
    case 选项1:
        // ...
        break;
    case 选项2:
        // ...
        break;
    default:
        // 没有任何 case 匹配时执行
        break;
}
```

- `case`：匹配某个固定值。
- `break`：结束当前 `switch`，避免继续执行后面的 `case`。
- `default`：兜底分支，没有任何 `case` 匹配时执行。
- case 穿透：如果某个 `case` 后面没有 `break`，程序会继续执行下一个 `case`。

### 示范用法：学生抽奖

```cpp
int main()
{
    unsigned int sId{}, sPr{};
    std::cin >> sId;

    switch (sId)
    {
        case 15692:
            sPr = 500;
            break;
        case 65421:
            sPr = 450;
            break;
        case 98741:
            sPr = 250;
            break;
        case 2531:
            sPr = 150;
            break;
        case 666:
            [[fallthrough]];  // C++17：显式声明 fallthrough
        case 321:
            sPr = sId * 2;
            break;
        default:
            sPr = 0;
            std::cout << "对不起，同学，您本次活动没有中奖，下次继续！\n";
            break;
    }

    std::cout << "同学你的奖金总额为" << sPr << std::endl;
}
```

> [!note]
> `[[fallthrough]]` 是 C++17 引入的属性，用于显式说明这里故意让 `case` 穿透，避免编译器警告。

### C++17 新语法：switch 中声明变量

和 `if` 类似，C++17 也允许在 `switch` 中加入初始化语句。

```cpp
switch (初始化语句; 值) {
    case 选项1:
        break;
    default:
        break;
}
```

示例：

```cpp
switch (int a{}; 3) {
    case 1:
        a++;
        break;
    case 2:
        a++;
        break;
    case 3:
        a++;
        break;
    default:
        break;
}
```

## goto 语句

`goto` 会无条件跳转到指定标签位置，通常只用于理解早期 C/C++ 控制流，现代 C++ 中应优先使用 `while`、`for`、函数拆分或异常处理。

### 示例代码

```cpp
int main()
{
    char a;

linput:
    printf("请您输入一个大写字母，我们会将其转换为小写字母\n");
    std::cin >> a;

    if (a > 64 && a < 91) {  // ASCII: 65='A', 90='Z'
        a += 32;             // 大写转小写
        std::cout << a;
    } else {
        printf("您输入的不是字符\n");
        goto linput;
    }
}
```

> [!warning]
> `goto` 容易让程序控制流变得混乱。需要重复执行时，通常用循环更清晰。

## 底层实现：比较与跳转

高级语言里的判断，本质上通常可以拆成两步：

1. `cmp`：比较两个值。
2. 条件跳转指令：根据比较结果跳到不同的代码位置。

### if-else 的汇编层级逻辑

C++ 代码：

```cpp
if (a > b) {
    std::cout << "a 大";
} else {
    std::cout << "b 大或相等";
}
```

底层可以理解为：

```asm
mov eax, [a]      ; 把变量 a 的值放入 eax 寄存器
cmp eax, [b]      ; 比较 eax 和 b，也就是比较 a 和 b
jg  if_block      ; 如果 a > b，就跳转到 if_block

else_block:
    ; 执行 else 中的代码
    jmp end_if

if_block:
    ; 执行 if 中的代码

end_if:
    ; if-else 结束后继续执行后面的代码
```

### if 没有 else 时的汇编逻辑

C++ 代码：

```cpp
if (a > b) {
    a = 100;
}
```

底层思路是：如果条件不成立，就直接跳过 `if` 代码块。

```asm
mov eax, [a]
cmp eax, [b]
jle end_if       ; 如果 a <= b，说明 a > b 不成立，跳过 if 代码块

mov [a], 100     ; 条件成立时执行

end_if:
    ; 继续执行后续代码
```

这里用的是 `jle`，因为它跳的是“条件不成立”的情况。C++ 里判断的是 `a > b`，跳过 `if` 时判断它的反面 `a <= b`。

### 常见条件跳转指令

| 汇编指令 | 英文含义 | 中文理解 | 常见 C++ 判断 |
|---|---|---|---|
| `je` | jump if equal | 相等就跳转 | `a == b` |
| `jne` | jump if not equal | 不相等就跳转 | `a != b` |
| `jg` | jump if greater | 大于就跳转 | `a > b` |
| `jge` | jump if greater or equal | 大于等于就跳转 | `a >= b` |
| `jl` | jump if less | 小于就跳转 | `a < b` |
| `jle` | jump if less or equal | 小于等于就跳转 | `a <= b` |
| `jz` | jump if zero | 结果为 0 就跳转 | 常用于判断是否相等或是否为 0 |
| `jnz` | jump if not zero | 结果不为 0 就跳转 | 常用于判断是否不为 0 |

记忆方法：

```cpp
e = equal      // 相等
g = greater    // 更大
l = less       // 更小
n = not        // 取反
z = zero       // 零
```

例如：

```asm
cmp eax, ebx
je  same
jg  greater
jl  less
```

可以理解为：

```cpp
if (eax == ebx) goto same;
if (eax > ebx)  goto greater;
if (eax < ebx)  goto less;
```

### switch 的底层实现方式一：跳转表

当 `case` 的值比较连续、范围紧凑时，编译器可能生成跳转表。

```cpp
switch (x) {
    case 1:
        f1();
        break;
    case 2:
        f2();
        break;
    case 3:
        f3();
        break;
    case 4:
        f4();
        break;
    default:
        f_default();
        break;
}
```

跳转表可以理解为一张地址表：

```text
x = 1  -> case_1 的地址
x = 2  -> case_2 的地址
x = 3  -> case_3 的地址
x = 4  -> case_4 的地址
其他值 -> default 的地址
```

汇编层级大致类似：

```asm
mov eax, [x]              ; 把 x 放入 eax
cmp eax, 1                ; 判断 x 是否小于最小 case 值 1
jl  default_case          ; 如果 x < 1，跳转到 default
cmp eax, 4                ; 判断 x 是否大于最大 case 值 4
jg  default_case          ; 如果 x > 4，跳转到 default

sub eax, 1                ; 把 case 值转换成数组下标：1->0, 2->1, 3->2, 4->3
jmp [jump_table + eax*4]  ; 根据下标查表，跳到对应 case 的地址

jump_table:
    dd case_1             ; 下标 0，对应 case 1
    dd case_2             ; 下标 1，对应 case 2
    dd case_3             ; 下标 2，对应 case 3
    dd case_4             ; 下标 3，对应 case 4

case_1:
    ; f1();
    jmp end_switch

case_2:
    ; f2();
    jmp end_switch

case_3:
    ; f3();
    jmp end_switch

case_4:
    ; f4();
    jmp end_switch

default_case:
    ; f_default();

end_switch:
    ; switch 结束
```

`jmp [jump_table + eax*4]` 的意思是：根据 `eax` 的值去跳转表里查一个地址，然后直接跳过去执行。32 位地址通常占 4 字节，所以示例中使用 `eax*4`；64 位环境中实际寻址方式可能不同，重点是理解“用下标查表跳转”。

### switch 的底层实现方式二：链式比较

当 `case` 的值很分散时，如果使用跳转表会浪费大量空间，编译器更可能使用链式比较。

```cpp
switch (x) {
    case 1:
        f1();
        break;
    case 100:
        f100();
        break;
    case 9999:
        f9999();
        break;
    default:
        f_default();
        break;
}
```

汇编层级大致类似：

```asm
mov eax, [x]

cmp eax, 1
je  case_1        ; 如果 x == 1，跳转到 case_1

cmp eax, 100
je  case_100      ; 如果 x == 100，跳转到 case_100

cmp eax, 9999
je  case_9999     ; 如果 x == 9999，跳转到 case_9999

jmp default_case  ; 都不匹配，进入 default

case_1:
    ; f1();
    jmp end_switch

case_100:
    ; f100();
    jmp end_switch

case_9999:
    ; f9999();
    jmp end_switch

default_case:
    ; f_default();

end_switch:
    ; switch 结束
```

这种方式类似多个 `if-else if`：

```cpp
if (x == 1) {
    f1();
} else if (x == 100) {
    f100();
} else if (x == 9999) {
    f9999();
} else {
    f_default();
}
```

### ja 与 jg 的区别

`ja` 和 `jg` 都可以理解为“大于就跳转”，但比较方式不同：

| 汇编指令 | 英文含义 | 中文理解 | 比较方式 | 常见场景 |
|---|---|---|---|---|
| `jg` | jump if greater | 有符号意义下大于就跳转 | signed，有符号比较 | 比较 `int` 这类有正负含义的数 |
| `ja` | jump if above | 无符号意义下大于就跳转 | unsigned，无符号比较 | `switch` 跳转表的范围检查、数组下标越界检查 |

例如：

```asm
cmp eax, 5
jg  greater_signed
ja  greater_unsigned
```

如果 `eax = 10`，`jg` 和 `ja` 都会跳转，因为无论按有符号还是无符号理解，`10 > 5` 都成立。

如果 `eax = -1`，情况就不同：

```cpp
-1 的 32 位二进制表示通常是 0xFFFFFFFF
```

按有符号数理解：

```cpp
0xFFFFFFFF == -1
```

所以：

```asm
cmp eax, 5
jg greater_signed
```

不会跳转，因为 `-1 > 5` 不成立。

按无符号数理解：

```cpp
0xFFFFFFFF == 4294967295
```

所以：

```asm
cmp eax, 5
ja greater_unsigned
```

会跳转，因为无符号意义下 `4294967295 > 5` 成立。

因此，在 `switch-case` 的跳转表范围检查中，经常会看到：

```asm
cmp eax, 5
ja  default_case
```

它可以同时排除 `x > 5` 和 `x < 0`，因为负数在无符号视角下会变成非常大的数，也会被 `ja` 判断为越界。

快速记忆：

```cpp
jg = signed greater     // 有符号大于
ja = unsigned above     // 无符号大于
```

## 关键要点

1. `if` 适合处理范围判断和复杂条件，`switch` 适合处理多个固定选项。
2. `switch` 中的 `break` 用来结束当前分支，缺少 `break` 会发生 case 穿透。
3. C++17 支持在 `if` 和 `switch` 中写初始化语句，用来限制临时变量作用域。
4. `goto` 可以无条件跳转，但现代 C++ 中应尽量使用循环、函数拆分或异常处理替代。
5. 判断语句的底层核心是 `cmp + 条件跳转`。
6. `switch` 可能被编译为跳转表，也可能被编译为链式比较，取决于 `case` 值是否紧凑。
7. `jg` 是有符号大于跳转，`ja` 是无符号大于跳转，常见于范围检查。
