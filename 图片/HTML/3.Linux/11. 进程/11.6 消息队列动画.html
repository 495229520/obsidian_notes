按类型接收

概览
▸ 观察队列中的类型与物理顺序

System V 消息队列在内核中保存完整消息节点；接收时可用 msgtyp 指定选择规则。

ssize_t n = msgrcv(msqid, &msg, sizeof msg.text,
msgtyp, flags);
// msgtyp == 0 : 队首消息
// msgtyp > 0 : 第一条同类型消息
// msgtyp < 0 : 最小类型且 type <= |msgtyp|
struct msg_buffer { long type; char text[32]; };
msg.type = 1; strcpy(msg.text, "HEAD");
msgsnd(msqid, &msg, sizeof msg.text, 0);
msg.type = 2; strcpy(msg.text, "BODY");
msgrcv(msqid, &out, sizeof out.text, 0, 0);
// 默认：队列满则等待可用空间
msgsnd(msqid, &msg, sizeof msg.text, 0);
msgrcv(msqid, &out, sizeof out.text, 0, 0);
// 非阻塞：满队列立即失败
int rc = msgsnd(msqid, &msg, sizeof msg.text, IPC_NOWAIT);
// rc == -1 && errno == EAGAIN
enum { REQUEST = 1, REPLY = 2 };
// client
msgsnd(msqid, &req, sizeof req.text, 0);
// server: msgrcv(..., REQUEST, 0)
// server: msgsnd(..., REPLY, 0)
// client: msgrcv(..., REPLY, 0)
要点速查
消息类型long，必须大于 0。
消息边界缓冲区足够时，一次接收移除一个完整节点。
满队列默认发送阻塞；IPC_NOWAIT 返回 EAGAIN。
空接收IPC_NOWAIT 且无匹配消息时返回 ENOMSG。
