# 一周 Linux 复习与力扣训练

## Goal

在 2026-08-21 至 2026-08-27 完成 `3.Linux/` 的 111 篇 Markdown、30 个配套动画复习，并每天完成三道力扣。

## Execution Rules

- 每天约 5–6 小时：Linux 3.5–4 小时，力扣 1.5–2 小时。
- Linux 采用“通读 → 闭卷复述 → 小实验/对比表”流程，不逐字重抄笔记。
- 动画跟随对应笔记观看，每个最多 5 分钟；已经理解则快进。
- 力扣绿勾题先做 60 秒回忆测试：能说清算法、不变量与复杂度则换替补题，否则关掉旧代码盲写复刷。
- 中等题卡住 25 分钟后允许看一个提示，但必须关闭题解重新实现。

- 10:45–12:15：Linux 第二学习块
- 14:30–15:30：闭卷复述与实验
