# 一周 Linux 复习与力扣训练

## Goal

在 2026-08-24 至 2026-08-30 完成 `3.Linux/` 的 111 篇 Markdown、30 个配套动画复习，并每天完成三道力扣。

## Execution Rules

- 每天约 5–6 小时：Linux 3.5–4 小时，力扣 1.5–2 小时。
- Linux 采用“通读 → 闭卷复述 → 小实验/对比表”流程，不逐字重抄笔记。
- 动画跟随对应笔记观看，每个最多 5 分钟；已经理解则快进。
- 力扣题目只能来自 [[CodeTop 高频题 Top300]]；再以 [[00. 力扣刷题记录]] 过滤：未解决与待修复题优先，仅通过 1 次的题可以盲写复刷，通过 2 次及以上的题不再占用本周名额。
- 中等题卡住 25 分钟后允许看一个提示，但必须关闭题解重新实现。

## Daily Rhythm

- 09:00–10:30：Linux 第一学习块
- 10:45–12:15：Linux 第二学习块
- 14:30–15:30：闭卷复述与实验
