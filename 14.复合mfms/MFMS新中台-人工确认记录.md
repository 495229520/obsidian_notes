# MFMS 新中台 · 人工确认记录

> [!important] 只有人在这里拍板
> Agent 可以整理证据、提出候选和发现冲突，但不能替代业务、下位机、Adapter、Scheduler、DBA 或 MFMS 负责人确认外部事实。每次确认必须记录责任人、日期、版本、结论、证据和写回位置。

## 1. 确认状态

| 状态 | 含义 |
| --- | --- |
| 待确认 | 证据或责任人尚未齐全 |
| 评审中 | 已有候选报告，正在联合评审 |
| 已接受 | 指定版本和范围已经签字，可由集成者写回 |
| 有条件接受 | 允许进入下一步，但保留明确限制和到期复审 |
| 已否决 | 候选不可进入合同，保留原因与替代方向 |
