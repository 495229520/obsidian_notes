# 存储方向阶段计划索引

> [!goal] 本目录的作用
> 这是 [[AI Infra 存储与 GPU 数据路径系统工程师培养方案]] 的每周执行层。每篇周计划都是"三线合一"的：存储主线 + 推理保温（直接挂接推理版 [[AI Agent Native AI Infra GPU Performance Engineer 培养方案]] 的周任务）+ 面试保底（算法 + 八股 + 项目问答）。

> [!important] 配比与排期以本索引和总纲为准（2026-07-12 重排）
> **12 月投递前：存储 70% / 推理保温 10% / 面试保底 20%；投递后恢复 60 / 25 / 15。**
> 各周计划正文中写的旧配比（60/25/15）不再逐篇修改——保温任务照做但按 10% 减速，harness 达标节点放宽到 S4 启动前。排期冲突时，一律以本索引的阶段划分为准。

> [!note] 存储方向三目录导航
> - 阶段计划（本目录）：每周做什么 + 验收标准。
> - 专题清单：[[00.存储方向专题清单索引]] —— 某个知识点一次讲透的横向专题。
> - 参考资料：[[00.存储方向参考资料索引]] —— 按阶段收敛的教材 / 开源项目 / 官方文档。

## 使用方式

- 每周只看当周一篇笔记，不需要回总纲翻任务。
- 周计划给的是任务和验收标准，前置知识优先看笔记内链接，不够再查官方文档。
- 每周日复盘时勾掉验收清单，把新增 Q&A 写进 `interview_qa.md`。
- 进度弹性分段：阶段 0 / 1 和 S3 段允许一篇周计划摊到两个自然周；**S-Week 12-17（S2 冲刺段）与自然周一一对应，不许摊**——这段是 12 月投递节点的关键路径。推理保温按实际进度推进，不与存储周强制对齐。
