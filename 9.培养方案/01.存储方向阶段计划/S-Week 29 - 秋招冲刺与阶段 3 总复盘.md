# S-Week 29 - 秋招冲刺与阶段 3 总复盘

> [!goal] 本周目标
> 培养方案的最后一篇周计划：三轮全真模拟面试 + 笔试限时模拟 + 2027 秋招提前批/正式批集中投递，然后对照总纲做全程复盘——从 2026-07 的 S-Week 1 到现在，验收清单逐条打勾，未竟事项转成"入职后学习清单"。本周之后，执行层交给投递与面试的实战节奏。

## 学习目标

1. **全真模拟怎么设计才有效？** 完整流程（自我介绍 → 项目深挖 → 八股 → 手撕 → 系统设计 → 反问），限时、录音、他评或录音自评——不打断、不查资料，暴露的卡点才是真卡点。
2. **三轮模拟各聚焦什么？** 第一轮找卡点（全流程走完，记录所有卡壳）；第二轮补强验证（卡点回炉后重打）；第三轮节奏与表达（内容已熟，练控场与时间分配）。
3. **投递节奏怎么排？** 提前批（7-8 月）大厂 AI Infra / 存储岗全覆盖 + 对标外企（总纲第二节的公司列表）；每周 ≥15 投，投递表记录状态与复盘。
4. **总复盘验收什么？** S1-S4 四项目 + 作品集 + 开源贡献三选一 + CodeTop/八股 + 五板块题库——总纲全部硬指标。
5. **未竟事项怎么处理？** 转成两张清单：面试可聊的"我知道缺什么"（圈边界加分项）+ 入职后学习清单（Ceph 源码级、真实生产调优、Mooncake 实测……）。

## 1. 三轮全真模拟（Day 1-3，隔天一轮）

- 题源：自我介绍用 S-Week 27 的四段故事线；项目深挖从 [[存储面试问题清单 - AI 数据路径]] Q9 往下钻；八股从五板块题库随机 10 题；手撕从近六周的手撕清单抽一道；系统设计用"多级 KV cache 存储层"或"高吞吐日志存储服务"。
- 每轮后 2 小时复盘：卡壳点分类（不会 / 会但讲不清 / 讲清但太慢），分别回炉（补知识 / 改口述稿 / 练节奏）。
- 笔试限时模拟一场穿插（90 分钟 3 题，[[AI Infra 岗算法笔试保底清单]] 组卷）。

## 2. 集中投递（Day 4，此后常态化）

- 目标池：总纲第二节的岗位映射表（NVIDIA/Pure/VAST/WEKA/Dell 系 + 国内大厂 AI Infra、存储、端侧 RDMA 岗）。
- 材料终检：简历数字溯源、作品集链接可访问、开源贡献状态真实。
- 投递表：公司 / 岗位 / 渠道 / 日期 / 状态 / 复盘一行——每周复盘时更新，面试反馈回填题库。

## 3. 总纲全程复盘（Day 5）

- 逐条验收：S1 完整版（毛刺定位案例）✓ / S2 v1（崩溃注入 1000 次）✓ / S3（延迟分解 + RDMA + SPDK）✓ / S4（GDS + KV offload 对账）✓ / 作品集 ✓ / 开源三选一 ✓ 或在途 / CodeTop 与八股 ✓ / 五板块题库 ✓。
- 配比总复盘：三年计划里 60/25/15 的实际执行曲线，写给未来的自己。
- 两张清单落盘：`面试边界清单.md`（我知道缺什么 + 为什么可以缺）与`入职后学习清单.md`（Ceph 源码、生产级调优、真实 RDMA 网络、Mooncake/3FS 实测……）。
- 本索引与总纲的 status 更新：阶段 3 执行层收口。

## 4. 推理线合流（约 25%）

- 口算总复习：[[LLM 推理面试公式速算清单]] + [[GPU 存储层次与算子融合口述]] 全表过一遍——推理侧口算是交叉岗面试的隐藏考区。

## 5. 面试保底（约 15%）

> 阶段 3 秋招冲刺编排第 7 讲（收口）：面试保底与主线在本周合一——整周都是面试保底。

- 手撕清单终检：LRU / LFU / 有界队列 / shared_ptr / 线程安全单例 / 时间轮——每道 20 分钟内一次过。
- 八股弱章终扫：五板块 + C++/Linux 章节清单，红黄绿标记，红项本周清零。
