# 存储方向参考资料索引

> [!goal] 本目录的作用
> 这是 [[AI Infra 存储与 GPU 数据路径系统工程师培养方案]] 的**参考资料层**：按阶段收敛"这一阶段真正要读/要跑的东西"，避免开局就陷进 Ceph 源码那类陷阱。清单来源是培养方案第十节（项目真实性核验）与各阶段"配套学习"，只列真实开源项目、免费教材与官方文档。
>
> 对照推理版 `03.参考资料` 按 `1.阶段一 / 2.阶段二` 分子目录；存储版按阶段 0-3 组织，先给一份总索引，后续可按需拆子目录。

> [!warning] 只读架构、不过早深挖
> Ceph、RocksDB、SPDK 工业价值高但体量大。阶段标注 = 该阶段只需读到的深度；不要在阶段 0/1 就通读大项目源码，深入留到入职后或秋招后。

## 开源贡献优先级（秋招前）

> 沿用推理版 Reproduce → Minimize → Analyze → Contribute 四步法，目标至少一个 merged PR + 三个高质量 issue reproduction + 两篇被社区认可的 benchmark report。

```text
LMCache（新项目、贴 AI 存储叙事、贡献门槛低）
> JuiceFS / fio（社区友好）
> RocksDB / SPDK（认可度高但门槛高）
> Ceph（只读架构，不贡献核心）
```
