1 安装包拷贝与文件检查
  • 插入 U 盘，将 MFMS一键安装-中国大陆一键版 文件夹整体完整复制到 Ubuntu 本地桌面。
  • 进入桌面该文件夹，确认核心文件齐全：run-installer.sh、install.sh、payload、database。
2 定位目录并打开终端（防闪退规范）
  • 推荐操作（GUI）：进入桌面上的 MFMS一键安装-中国大陆一键版 文件夹，在窗口空白处右键点击 $\rightarrow$ 选择 “在终端中打开 (Open in Terminal)”。
  • 备用操作（CLI）：按快捷键 Ctrl + Alt + T 打开终端，执行命令直接跳转进入目录：
    cd ~/Desktop/MFMS* 2>/dev/null || cd ~/桌面/MFMS*
3 执行安装指令（带排错追踪与日志落盘）

在打开的终端中，整段复制并粘贴运行以下命令：

bash -x ./run-installer.sh 2>&1 | tee "$HOME/mfms-install.log" rc=${PIPESTATUS[0]} echo echo "安装器退出码：$rc" echo "日志位置：$HOME/mfms-install.log" read -r -p "请拍下最后几行，然后按回车关闭..."
  • 终端提权：执行过程中若出现密码提示，输入工控机登录密码并回车（系统提权）。
  • 自动处理：安装器将依次配置 ROS/Qt/MySQL 依赖并部署程序至 /opt/mfms。若原工控机已有 MFMS_BASE 数据库，脚本将自动保留原数据仅增量兼容字段，无需人工干预。
  • 执行结果判定：命令运行完毕后将输出 安装器退出码：$rc：
    • rc 为 0：部署成功，敲击回车关闭终端即可。
    • rc 非 0：部署异常，请立即拍照终端最后屏幕内容，并将日志文件 ~/mfms-install.log 导出提供给研发人员。
4 客户端启动与验收
  • 安装成功后桌面将生成 MFMS客户端.desktop（若未即时刷新可按 F5）。
  • 双击打开客户端（如提示选择“允许启动”），输入默认账号 admin / 密码 123456 登录，确认设备列表加载正常。
可选步骤：配置开机自动启动脚本
💡
适用场景：仅在现场要求工控机通过桌面统一的 mfms-setup-startup.bash 自启上位机时配置（只需修改一次）。若仅通过桌面快捷方式手动启动，可跳过此步骤。
  1. 桌面右键 mfms-setup-startup.bash $\rightarrow$ “打开方式” $\rightarrow$ “文本编辑器”（切勿选“作为程序运行”）。
  2. 搜索定位到注释行：#上位机。
  3. 在该行正下方写入或修改为以下两行配置：
#上位机
UPPER_WORKDIR="/opt/mfms/current"
UPPER_CMD="/usr/bin/mfms-launch"
4. 按 Ctrl + S 保存并退出文本编辑器。
现场常见问题与排障速查 (FAQ)
异常现象 可能原因 现场处置方案
右键“作为程序运行”闪退 桌面管理器无法保持终端上下文 切勿通过图形右键运行。严格按规范在文件夹空白处右键“在终端中打开”，执行指定 shell 命令。
提示软件包锁被占用 (apt lock) 系统后台自动更新正在占用 dpkg 切勿强行关机。等待 2~3 分钟后台更新释放锁后，重新在终端执行安装命令。
提示 MFMS_BASE 已存在 工控机此前已安装过历史数据库 正常现象。安装器会自动增量适配字段并保留原有数据，静待其完成即可。
退出码 rc 非 0 环境依赖缺失或权限被中断 按提示先拍照终端最后几行，然后拷贝个人主目录下的日志文件 ~/mfms-install.log 发送给研发。
安装后桌面无客户端图标 桌面管理器缓存延迟 在桌面按 F5 刷新桌面，或重新注销/登录系统。
